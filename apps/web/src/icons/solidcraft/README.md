# SolidCraft command artwork

The 125 SVG masters in this directory are **unaltered** original SolidCraft artwork, used under MIT:

- Repository: https://github.com/tangency-labs/solidcraft
- Source commit: `bbc3aa4301380f4d6180ccbb12c35162d1fd98a1`
- Authors: Copyright (c) 2026 SolidCraft contributors
- Full license distributed with the application: `apps/web/public/licenses/solidcraft-icons-MIT.txt`
- Upstream asset attribution: `ATTRIBUTION.md`, individual `assets/icons/ui/design/svg/model/` and `flat/` entries.

`manifest.json` records every original path and SHA-256, all 205 existing command IDs, and upstream semantic palette values. Original masters are retained for comparison. No SolidCraft brand or application logo is used.

`../actionIcons.ts` adapts the palette to green sketch/orange surface/blue solid roles and normalizes `currentColor` in isolated SVG images. 3D-Builder adds a subtraction badge for four cut operations, a partial-selection badge for partial unfold, dashed cosmetic-thread strokes and a knurl surface cue; vertical/aligned dimensions rotate the dimension drawing. Angle/radius/diameter/chamfer/baseline/ordinate dimensions and drafting symbols use additional 3D-Builder vector diagrams. These are derived presentations, not claims of upstream-approved new artwork. Labels always remain visible, and tooltips continue to use the existing translated help.
