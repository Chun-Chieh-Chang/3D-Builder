# ADR 0085：邊線凸緣（Phase 7-2，C11.2，零件 Schema 37）

- 狀態：已實作並驗證（2026-10-04）。限制見最後一節。
- 相關：[phase7-plan](../phase7-plan.md)、[ADR 0083](0083-sheet-metal-validation.md)、[ADR 0084](0084-base-flange.md)（鈑金參數與折彎資料）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **特徵 `edgeFlange`**（零件 Schema 37）：`edge`（邊線參考）、`length`、`angle`（沒有就是 90°，要大於 0、小於 180°）、`lengthFrom`（`outer` 外側虛擬交點，預設；`inner`；`tangent` 折彎之後）、`position`（`materialInside` 材料在內，預設；`bendOutside` 折彎在外）、`radius`（沒有就用基材凸緣的）、`flip`（往另一面折）。指令 `setEdgeFlange`（整組設定，包括邊線；邊線一定要是邊）；沒有基材凸緣就報錯 | 計畫的假設；SW 的預設 |
| 2 | **邊線是板的端面與板的一個面之間的直邊**。程式用「板的面後面隔一個板厚有一個平行的面」來認哪個是板的面、哪個是端面（不用面積：端面可能已經和相鄰凸緣的側面併成一個大面）；兩個都是或都不是就說「要選板的端面上的一條直邊」。**凸緣往你點的那條邊所在的面那一側折**（`flip` 換邊）：那個面是折彎的內側 | 一個點選決定邊與方向；不靠面積 |
| 3 | **折彎是板的端面斷面繞折彎中心旋轉**（`revolve`），中心在斷面起點往折彎方向 `內側面 + 半徑` 處；旋轉的方向由 `(e × −m)·o` 的正負決定（先往外走），不假設。**凸緣是同一個斷面轉到折彎終點後沿切線拉伸**（`extrude`）；兩者與板以填料合併 | ADR 0083 驗證過的做法 |
| 4 | **長度的定義**：`outer` 從外側虛擬交點量，平直段 = 長度 −（r + T）·tan(θ/2)；`inner` 從內側虛擬交點，平直段 = 長度 − r·tan(θ/2)；`tangent` 平直段 = 長度。平直段不是正的就報錯、說至少要多長 | 工程圖的外側尺寸；各家定義不同，三種都給 |
| 5 | **位置**：`materialInside`：外側虛擬交點放在邊上，板在這條邊附近**切掉** (r + T)·tan(θ/2) 長（整條邊的寬度），折彎從切口開始，所以 90° 時凸緣的外側與原來的邊切齊、總高是 `length`；`bendOutside`：板不動，折彎從邊開始（板的外包變大） | SW 的「材料在內」是預設，尺寸對得上工程圖；「折彎在外」最簡單。SW 的第三種（材料在外）不做 |
| 6 | **每一步用體積檢查**：板切掉的體積要等於 trim·寬·T（不然「這條邊附近的板放不下折彎」：板太短或旁邊已經有折彎）；加上去的體積要等於折彎 θ·T·w·(r + T/2) 加平直段 T·w·長（不然「凸緣撞到板的其他部分」）。**錯的凸緣不會安靜地做出來** | 同 6-4 不等殼厚的做法 |
| 7 | **登記**：每個凸緣在 `sheet.bends` 加一筆（名字 `bend`、裕度 θ(r + K·T)）、在 `sheet.flanges`（新）加一筆（邊的名字、寬、角度、半徑、切掉的 `trim`、平直段、裕度）；平板型式（7-5）從這些算 | 計畫的特徵原生 |
| 8 | **命名**：`<特徵>:side:flange.bend.in`、`.bend.out`、`.bend.s0`、`.bend.s1`（折彎的內、外面與兩個側面）、`.flange.in`、`.flange.out`、`.flange.s0`、`.flange.s1`、`.flange.end`（凸緣的內、外面、兩側與末端）。**凸緣的側面與板的側面共面併成一個面時，併起來的面叫凸緣的名字**（見限制） | 持久命名 |
| 9 | **介面**：功能區「鈑金」頁的「邊線凸緣」；開啟後在圖面點一條邊（編輯時顯示凸緣之前的模型，像圓角：點的是那個模型上的邊）；PropertyManager：邊線、凸緣長度、長度從哪裡量（下拉）、折彎角度、折彎半徑、凸緣的位置（下拉）、往另一面折。**編輯時看不到凸緣的結果與錯誤**（像圓角，✔ 後設計樹顯示） | 邊線一定要在凸緣之前的模型上點 |

## 驗證（證據）

- **特徵**（`tests/phase7/edge-flange.test.ts`，13 項；板 100 × 50 × 1.5、半徑 2、K 0.5）：
  - 材料在內、90°、30 從外側虛擬交點量：**板切掉 3.5、折彎 θ·T·w·(r + T/2) = 323.98、平直段 26.5 → 9548.98 mm³**、一個有效的實體；外包盒 x 最大 100（外側切齊）、z 最大 30；凸緣內面在 x = 98.5、面積 50·26.5；名字全有且不重複。登記：一個折彎（90°、半徑 2、寬 50、裕度 (π/2)(2 + 0.75)）與一個凸緣（trim 3.5、平直段 26.5）。
  - 折彎在外：7500 + 323.98 + 1987.5，凸緣外側 x = 103.5，仍然高 30；從內側虛擬交點量 28（頂 z = 31.5）、從折彎之後量 30（頂 z = 33.5）；往另一面折：體積相同、往下到 z = −28.5；**45°：切口 (r + T)·tan 22.5° = 1.4497、平直段 28.5503，外側角在虛擬交點 + 30 沿凸緣（x 最大 121.2132、z 最大 22.2739）**；折彎半徑 4。
  - **凸緣上的凸緣**（回折的唇，長 10 從外側虛擬交點量）：體積 = 第一個 − 262.5 + 323.98 + 487.5、一個實體、兩個折彎兩個凸緣、唇的外面在 z = 30。
  - 兩條相鄰的邊都做凸緣：第二個做在剩下的 96.5 長的邊上，兩者在角落相貼（一條線），一個有效的實體、體積為手算的總和（真實的角落需要的離隙是 7-4）。
  - 跟著模型：長度 40、基材凸緣改成板厚 2 半徑 3，名字集合不變、體積對手算、外側仍切齊在 x = 100、頂在 z = 40。
  - 拒絕：太短（說「要 3.500」）、沒點邊、點了端面的短邊、沒有基材凸緣；**第一個凸緣只有 5 長（平直 1.5）時，上面的唇放不下 3.5 的折彎被擋下來**；長度 0、角度 0 與 180° 在輸入時被拒；`setEdgeFlange` 拒絕面。
- **瀏覽器**（`tests/e2e/phase7-eflange-ui.js`，全部通過）：開啟一片板、「鈑金」→「邊線凸緣」；PropertyManager 要求選邊；點面沒有作用、點邊進了選取框；✔ 後體積 7500 − 262.5 + 323.98 + 1.5·50·16.5、設計樹有邊線凸緣、特徵的訊息說平直段 16.500；重新開啟改長度 30（9548.98）、位置改折彎在外（9811.48）、改回材料在內加 45° 加從折彎之後量、長度 1 被說太短。
- `npm run check`：1439 項通過、21 項略過。

## 限制與未做

- **邊線只能是直邊、凸緣是整條邊的寬度**；沒有「凸緣比邊短」（偏移起訖）、沒有斜接凸緣、沒有曲線邊的凸緣；SW 的「材料在外」不做；折彎角度要小於 180°（180° 是摺邊，7-3）。
- **（已在 [ADR 0092](0092-naming-merge.md) 修好：併起來的面現在保留本體的名字；下面是修之前的描述。）併面改名的問題（持久命名的缺口）**：凸緣的側面與板的側面共面時，融合後併成一個面，**併起來的面用凸緣的名字**（`flange.s1`），於是板的那條邊後來的名字就變了（例如第二個凸緣要點的邊，在第一個凸緣之後名字和之前不同；邊的指紋也因為長度變了對不上）。**在介面上不受影響**（編輯時顯示的是凸緣之前的模型、點的是那裡的名字），但**重新排序特徵、或在第一個凸緣之前插入東西**會讓後面凸緣的邊找不到，要重新選（會說「遺失參考」）。要根治需要融合時讓舊面保留原來的名字（命名的改動，不在這一段）。
- **板切掉的檢查是體積**：折彎旁邊已經有別的特徵（孔、另一個折彎）時，體積不符就報錯，但**說不出是哪個**。兩個凸緣在角落只是相貼，沒有離隙（7-4）。
- **凸緣之間的碰撞只檢查體積**（加上去的體積不對）；兩個彎過來的凸緣在空中互相穿過、但沒有重疊到板的材料時（體積正確）不會發現。
- **編輯時看不到結果與錯誤**（✔ 後才看到），因為邊線要在凸緣之前的模型上點。
- 展開（平板型式）與輸出是 7-5、7-6。
