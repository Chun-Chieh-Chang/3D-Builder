# ADR 0046：3b-0 技術驗證——鏡射零組件與干涉檢查效能（部分）

- 狀態：② ③ 已量測（2026-10-01，雲端工作階段）；① Tauri、④ STEP 組合件輸入的結構對應**還沒做**。
- 腳本：`spikes/occt-gaps/phase3b-interference.test.ts`（`npx vitest run --config spikes/occt-gaps/vitest.config.ts phase3b`）。

## ② 鏡射零組件

`kernel.transformed` 用行列式 −1 的矩陣可以直接鏡射：30×20×10 帶孔的板，鏡射後體積不變（5717.2567）、有效、質心 x 由 15.35 變成 −15.35；輸出 STEP 再輸入，體積差 < 1e-6、質心相同、有效。
**決定**：照 phase3-plan §6 決定 4，鏡射時產生「鏡射零件」檔（衍生資料，原件改了就更新）；STEP 的位置變換不放行列式 −1 的矩陣，鏡射的幾何本身在零件檔裡。上述往返證明這條路可行。

## ③ 干涉檢查效能

20 個零組件（5×4 排列，相鄰兩個在 x 重疊 2 mm）共 190 對：

| 做法 | 時間 | 布林運算次數 |
|---|---|---|
| 先用包圍盒排除，再做 `common` | 259 ms | 16（16 對都找到有重疊） |
| 每一對都做 `common` | 776 ms | 190 |

**決定**：3b-5 先用包圍盒過濾，再對重疊的配對做 `common`；20 個零組件的預算先訂 1 s。零組件更複雜（面數多）時要重量，這裡只用簡單的板。

## 還沒做

- ① Tauri 2：這個雲端環境有 `cargo`／`rustc`，但沒有 Windows 的 WebView2，無法驗證 File System Access API，要在使用者的機器上做。
- ④ STEP 組合件輸入的結構對應：需要保留結構的真實組合件 STEP（handoff §8）。
