# ADR 0012：結合求解器（2B）

- 狀態：已採用（Phase 2B，2026-09-29）。
- 依據：藍圖 §2.5 Solver3D、附錄 C 的 A3.1、A3.2、A3.4、A5.2、C15.8；handoff §10 的 2B。

結合（mate）是組合件的設計意圖：「這兩個元素之間有這種關係」。零組件實際在哪裡，是從擺放位置和結合解出來的衍生資料。2B 做的是求解器本身，以及它和文件、零件幾何之間的連接；結合的 PropertyManager 與設計樹在 2C。

## 決策

| # | 決策 | 理由 |
|---|---|---|
| 1 | **新套件 `@3db/assembly`，純 TS，只依賴 `@3db/model`**：幾何、結合方程式、求解、自由度。`@3db/regen` 負責把文件接上它：以持久名稱找到零件上的元素、取出幾何、呼叫求解器 | 求解器可以脫離 UI 與 OCCT，用測試完全釘住；主執行緒日後拖曳（2D）也能直接呼叫 |
| 2 | **組合件 Schema 升到 2**：`mates` 資料夾，每個結合存類型、兩個元素（零組件 + 零件內的持久名稱，或組合件本身的基準面、原點）、對齊方式、數值（運算式）、反轉、鎖住時的相對位置、抑制。求解結果（位置、狀態）不存。版本 1 的檔案（2A）遷移時補上空的結合資料夾；v1 樣本由 2A 的程式寫出 | 只存設計意圖（ADR 0001）。刪除零組件時一併刪除它的結合，同 SW |
| 3 | **未知數**：每個浮動零組件 6 個，繞零件中心的平移與轉動；轉動乘上零件大小（約半徑），讓「轉一點」和「移一點」依點實際移動的距離來比較 | 繞零件原點轉動，遠離原點的零件會被甩開；不按大小加權，最小移動會偏好轉動而不是平移 |
| 4 | **Levenberg–Marquardt，阻尼用 λI**：每一步都落在 Jacobian 的列空間，結合沒有拘束的自由度完全不動 | 擺放位置就是「結合沒拘束的自由度」的意圖（藍圖 §2.3）：銷沿孔滑動的位置、繞軸的角度都保留使用者放的樣子；已經成立的結合再解一次不會移動任何東西 |
| 5 | **每次都從擺放位置解起**，不從上次的解 | 同一份文件永遠得到同一個位置（B3.1），與操作順序無關 |
| 6 | **依連通分量分組**：只有「兩個浮動零組件之間」的結合把它們連成一組；固定零組件與組合件本身不算未知數 | 夾治具常見的「每個銷、螺絲各自結合在固定的底板上」拆成許多小組，求解極快 |
| 7 | **衝突依設計樹順序判定**：全部一起解不成立時，二分搜尋「在它之前的結合都成立、加上它就不成立」的第一個結合，把它標為衝突，其餘照常成立，再往後找。最後的位置從擺放位置重解一次（不含衝突的結合） | 同 SW 的行為：通常是剛加的那個結合出問題；被指名的結合是確定的，與搜尋路徑無關 |
| 8 | **失敗時從稍微轉過的位置再試一次** | 剛好朝向相反（或剛好垂直）的起點，所有小轉動看起來都一樣差，梯度為零、動不了。沒有旋轉插入的零件很常剛好在這種位置 |
| 9 | **自由度 = 零組件自己能動的方向數**：結合 Jacobian 的零空間中，這個零組件 6 個未知數所佔的維度（樞軸 Cholesky 求零空間，再求每個零組件那一塊的秩） | 「能不能動」是 SW 的定義：跟著另一個未定義零組件一起動也算能動，所以是「(-)」。兩個同軸的轉動在同一個零組件上只算一個方向 |
| 10 | **狀態**：固定 (f)；有自由度 (-)；0 個自由度（無記號）；有衝突的結合 (+) | 同 SW 的設計樹記號（2C 顯示） |
| 11 | **對齊**：有方向的結合（面對面、軸對軸）存「同向／反向」；沒存時取起點較接近的那個 | SW 的做法；2C 建立結合時會存下目前的方向，「反轉」切換它 |
| 12 | **A5.2 零件幾何**：拓撲的每個面、邊附上解析幾何：平面、圓柱（軸、半徑）、圓錐（頂點、軸、半角）、球、環面；直線、圓（圓心、法向、半徑）；以及「材料在內還是在外」（軸、孔） | 結合需要軸、半徑與材料在哪一側（相切：軸在面的哪一側；圓柱相切在外或在內） |
| 13 | **面的外法向由曲面本身的偏導數決定**（∂u × ∂v，面反向時相反），不採用 `Plane()`、`Cylinder()` 回報的座標系方向 | 旋轉特徵掃出的平面，OCCT 回報的平面方向不一定與參數化一致：削邊銷的底面、凸緣下緣原本被算成朝內（見「修正」） |

## 支援的結合與元素

元素：平面（面、基準面）、直線（直線邊線）、點（頂點、原點）、圓（圓形邊線）、圓柱面、圓錐面、球面。

| 結合 | 支援的組合 |
|---|---|
| 重合 | 平面–平面（共面，同向/反向）、平面–直線、平面–點、平面–圓（圓在平面上）、直線–直線（共線）、直線–點、直線–圓柱面（直線在曲面上）、圓柱面–點、球面–點、點–點 |
| 同軸心 | 軸對軸（至少一個是圓、圓柱或圓錐；直線可當軸）、軸與中心（點或球心在軸上）、球–球、球–點 |
| 平行 | 平面–平面、平面–直線/軸、直線/軸–直線/軸 |
| 垂直 | 同上 |
| 相切 | 平面–圓柱面、平面–球面、直線–圓柱面、圓柱–圓柱（外切，或一個是孔時內切）、圓柱–球、球–球 |
| 距離 | 平面–平面、平面–直線/軸、平面–點/球心/圓心、軸–軸、軸–中心、中心–中心 |
| 角度 | 平面–平面、平面–直線/軸、軸–軸 |
| 鎖住 | 任兩個零組件 |

**尚未支援**（回報原因，不會移動任何東西）：圓錐面的相切；兩個半徑相同、一個在另一個之內的相切（應該用同軸心）。

## 修正：旋轉特徵的平面法向

- **發現**：取出結合幾何時，削邊銷底面（y = 0）與凸緣下緣（y = 15）的法向是 +y，實際應朝外（−y）；V 型槽、定位板這類伸長件不受影響。
- **影響**：在旋轉件的這類平面上畫草圖時，草圖法向朝內，伸長會長進零件。修正後，這類草圖的方向改成朝外（同 SW）。
- **相容性**：修正前存檔、而且草圖放在旋轉件平面上的零件，重新開啟後伸長方向可能相反，需要檢查。三個金樣零件與舊版樣本都不受影響。

## 驗證

- **每種結合的解析解**（`packages/assembly/test/solver.test.ts`）：重合（含從完全相反的方向開始）、同軸心（銷入孔 2 個自由度，加上凸緣貼面剩 1 個）、平行、垂直、相切（軸在面上、兩軸外切、軸在孔內）、距離（兩側）、角度、鎖住。
- **自由度**：方塊貼三面 = 0；滑塊上的銷 = 3（跟滑塊在面上移動、繞 z 轉，自己的轉動也是繞 z）；重複但一致的結合不算衝突；兩個基準面上的方塊只能沿交線滑動。
- **衝突**：被指名的是依序第一個不能成立的結合，其餘照常成立；固定零組件之間的結合也會檢查。
- **擺放意圖**：結合沒拘束的自由度完全不動；已成立時再解不移動。
- **效能**（最快的一次；全部測試同時跑時會變慢，所以取三次中最快）：19 個互相結合的銷連成一組 約 12–18 ms；19 個銷各自結合在底板上 約 2 ms；一組 19 個加上一個衝突 約 65 ms（找衝突沒有預算要求）。
- **真實零件**（`tests/phase2/mates.test.ts`）：削邊銷的 R5 柄與定位板 R4 孔同軸心、凸緣下緣貼板面 → 剩繞軸 1 個自由度；再加上削平面與板側面平行 → 完全定義；多加一個矛盾的距離 → 被指名，銷仍在原位；參考的面不存在 → 報告遺失參考，不綁到別的面；柄長 15 → 13，結合照樣成立，銷升高 2 mm；柄長 20 時削平面的切除改變了凸緣下緣 → 報告遺失；存檔再開，解出的位置相同。
- **旋轉件法向**：回歸測試確認環形件的上下面朝外、內孔是孔；在底面上畫圓並伸長，長在零件外面。改回舊的算法時這個測試會失敗。
