# ADR 0222: 草圖獨立 Split 工具探針 (G08, D1)

- 日期：2026-11-02
- 狀態：探針報告（未進入正式實作）
- 相關：G08（plan.md）、C05（acceptance.md）、ADR 0194（延伸既定語意）、trim/extend 實作（`packages/sketch/src/ops.ts`）

## 1. 探針目的

G08 要求「獨立 Split 與參照繼承」：分割工具須定義 ID、尺寸與外部參照繼承，不能只畫新線。本探針先證實精確幾何／參照／求解可行，再核定範圍（plan.md P5：每項探針 2–4 日）。

## 2. 現有基礎

- **沒有**獨立 `split` 函式。分割能力已存在於 `trim()`：當修剪點落在曲線中段，曲線被切成兩段——原曲線保留第一段，`Parts` 建立第二段（新 ID），切點為新點 `pin` 並加上 `pointOnCurve` 拘束。
- `extend()` 與 `transformInPlace()` 已示範「共用端點分割」：`usedElsewhere` 判斷端點是否被其他圖元共用；共用時不搬動原端點，另建新點並把新曲線接到新點，原曲線保留舊端點。這正是 Split 所需的 ID 繼承範本。
- `stale()` 定義「整條曲線不再完整」時必須丟棄的拘束：整體長度尺寸（`distance` 且 `b === undefined`）、整體相等（`equal`）、中點（`midpoint`）。

## 3. 幾何可行性

- 直線／圓弧：trim 已證實可切出兩段並在切點建立 `pointOnCurve` 拘束，求解穩定。
- 圓：trim 將圓切成弧，並 retarget 所有引用該圓的拘束（`a/b/circle/curve` 欄位）到新弧。可行。
- 樣條（spline）：trim 明確拒絕（`e.type === 'spline'`）。PlaneGCS 對樣條的表示為點列，切分需拆點列並共用切點，尚無先例；**本探針結論：樣條 Split 延後**，待獨立探針。
- Bézier：同上，延後。

## 4. 參照繼承策略（探針結論）

| 參照類型 | 現行 trim 行為 | Split 應採策略 |
|---|---|---|
| 整體長度尺寸（`distance`, `b` undefined） | 丟棄（stale） | **丟棄**：哪一段的長度不明；不可自動分給某一段 |
| 整體相等（`equal` 兩曲線） | 第二段複製 parallel/perp/collinear；equal 丟棄 | **第一段保留** equal；第二段不自動 equal（避免無聲長度變更）；提示使用者 |
| 中點（`midpoint`） | 丟棄 | **丟棄**（切點 ≠ 中點） |
| 平行／垂直／共線 | 第二段複製 | **兩段皆保留**（方向不變） |
| 半徑相等（弧） | 第二段 `equal` 第一段 | **保留**（兩段同圓） |
| 點在曲線上的拘束（`pointOnCurve`） | 切點新建 `pointOnCurve` 到切割曲線 | **依切點落在哪一段，retarget 到該段**；若切點恰為端點，保留原端點 |
| 外部／模型參照（`ref`、`pierce`） | trim 未檢查 followsModel | **阻擋**：分割會產生無 ref 的新曲線／新點，無聲失去模型連結；必須顯式拒絕並說明原因（與 transform 的 `sketch.xformFollowsModel` 一致） |
| 固定（`fix` on point） | trim 不檢查 | **允許**：切點為新點，未 fixed；原端點 fixed 狀態不變；但若整條曲線被 `block` 拘束，分割後第二段不受 block → 必須提示或拒絕 |
| 尺寸標註位置（`labelPosition`） | 不處理 | **第一段保留**，第二段無標註（避免重疊） |

## 5. ID 繼承方案

- **原曲線保留 ID**（第一段），新曲線取新 ID（`ids.take('l'/'a')`），切點取新 ID（`ids.take('p')`）。
- 這與 trim/extend 一致，避免破壞引用原曲線的外部參照與 DAG。
- 拘束 retarget 規則：引用原曲線 id 的拘束**預設留在第一段**；只有明確落在第二段幾何上的拘束才 retarget。不做自動猜測，避免無聲變更（plan.md 硬性：不可用刪舊建新而隱藏失效）。
- 若使用者需要把某拘束移到第二段，由 UI 明示「移動拘束到新段」操作完成，並在提交前試解。

## 6. 輸入與操作模型（建議）

- 工具 `split`：第一點選目標曲線（line/arc/circle），第二點選切分位置——可為曲線上一點、與其他曲線的交點、或游標吸附到曲線的點（建立新點）。
- 若切分位置不在曲線上（或在端點），拒絕並提示。
- 預覽：顯示切點與兩段結果；取消零變更。
- 明示目標（G08 P2-5 延伸語意）：可越過近線選遠線，不偷偷改目標。

## 7. 風險與開放問題

1. **樣條／Bézier**：未證實；需獨立探針（G17 相關）。
2. **多段鏈**：選中一條曲線只切該條；鏈式分割（一次切多條）屬 G07 掃掠，不在本工具範圍。
3. **外部參照 retarget**：阻擋策略保守但安全；若未來需要「分割後兩段都跟隨模型」，需 OCCT 層級的參照映射，不在本輪範圍。
4. **Undo／Redo**：沿用 OpResult edit 模型，一次提交一次 Undo，與 trim 一致。
5. **Schema**：不需升版——Split 是操作，不新增持久特徵（與 trim/extend 一致）。

## 8. 探針結論

- **可行**：直線／圓弧／圓的 Split，復用 trim 的 Parts/ids 與 pointOnCurve 拘束，幾何與求解穩定。
- **不可行／延後**：樣條與 Bézier Split；外部參照自動繼承（阻擋而非自動）。
- **建議**：進入正式實作時，先做直線／圓弧／圓，附上本 ADR 的參照繼承策略與 i18n 訊息；樣條另立探針。估計 3–5 工作日。
