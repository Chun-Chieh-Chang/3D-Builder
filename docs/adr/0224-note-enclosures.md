# ADR 0224：註解的自適應圓形及圓角外框

工程圖註解可選「無」、「圓形」或「圓角框」。選取註解後在屬性更改，預設無外框。外框依展開屬性後每行文字的最大估計寬度和總高度，以紙面毫米計算並保留邊距。圓形以外接半徑建立；圓角框在文字範圍加邊距後，以固定比例字高產生圓角。引線從外框邊緣出發，箭頭仍指向原目標。縮放視圖不改字高或外框紙面尺寸，改文字、字高或屬性時自動重算。

工程圖 schema 35 曾增加圓形和橢圓設定；依使用者要求改為圓形和圓角框，schema 36 將舊檔橢圓設定轉為圓角框。沒有外框的舊檔不變，非法值拒絕，不修改零件模型。圓角以小線段近似；SVG、DXF、PDF 共用同一場景。

使用者曾回報單字母偏右：原文字估寬與 SVG 實際字寬不一致。帶外框的註解用共用字寬計算，並使每行以外框中心為錨點；無外框的註解維持原有位置。以瀏覽器實際文字和圓框包圍盒核對中心，檢視單字母及多行截圖。

驗證：格式儲存／重開、v35 遷移、非法值、文字矩形角點、引線起點、SVG/DXF/PDF 解析、100 組文字尺寸、瀏覽器切換及存檔重開；圓角框畫面截圖檢視通過。
