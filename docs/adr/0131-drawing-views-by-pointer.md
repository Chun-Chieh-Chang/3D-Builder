# ADR 0131：比照 SolidWorks，在圖紙上拖曳與點選產生視圖和剖面（D-V）

- 狀態：**已完成（2026-10-13）**。
- 需求追溯：使用者在 2026-10-13 提出：「視圖的選擇不夠直觀，應該要跟 SW 一樣，直接在工程圖上拖曳生成」、「剖面圖的生成也要比照 SW 的方式」。這兩項原本規劃在 D-I1b 與 D-I5，現在提前成為 D-V，排在 D-I3 之前（[ADR 0129](0129-drawing-interaction-roadmap.md)）。

## 背景

原本加視圖要先在下拉選單選方向再按按鈕，投影視圖要先選「哪一側」，畫面上沒有任何預覽。剖面工具雖然是先畫線再點一下放置，但放置時看不到預覽，剖面視圖會放在游標位置（不對齊母視圖），箭頭方向也要另外到面板勾選「翻轉」。

## 決定

1. **視圖調色盤**：放在面板頂部，顯示工程圖零件從 7 個方向看的樣子（前、上、右、後、下、左、等角）。縮圖是 worker 真正算出的線條，和視圖共用同一個快取，所以放上圖紙後立刻畫得出來。
   - 操作：把方塊拖到圖紙上放開；或點一下方塊，再到圖紙上點一下。
   - 拖曳時預覽跟著游標。
   - 刪光所有視圖後，調色盤仍保留原本的零件。
2. **投影工具（比照 SW）**：從調色盤放好一個視圖後，自動進入投影模式；選一個視圖後按「投影視圖」也可以進入。
   - 游標在視圖的上下左右：預覽該側的投影視圖，與母視圖對齊、跟著游標滑動。
   - 游標在斜角：預覽等角視圖。
   - 點一下放置，可以連續放置；Esc 結束。
   - 判斷側別用 `sideAt`：游標剛越過帶狀範圍、仍明顯靠近某一側時，算那一側，不算斜角。
3. **剖面工具（比照 SW 的剖面視圖輔助）**：
   - 圖紙上有浮動按鈕切換垂直／水平切割線。
   - 按下之前，切割線預覽就跟著游標，並自動貼齊孔中心、側看成線的平面、視圖中心（`snapCut`）。貼齊時線變成橘色。
   - 點一下固定切割線之後，剖面視圖的預覽在母視圖的那一側對齊顯示，標「A–A」。
   - **游標在哪一側，就決定箭頭方向**（第一角法：箭頭朝向剖面視圖那一側；第三角法：背向），不必再去面板勾翻轉。
   - 按住 Ctrl 可以放在任意位置，不對齊母視圖（SW 的慣例）。
4. **放置的位置是「沿對齊線的 slide」**：投影或剖面視圖仍以衍生視圖的方式和母視圖對齊，再用 `slide` 移到游標位置。最近只能離母視圖 `MIN_PLACE_GAP` = 5 mm，不會壓在母視圖上。
5. **不移動既有的視圖**：原本的排版在加入視圖後會整組重新置中，結果新視圖不在點的位置，其他視圖也會跳動。`previewDerived` 算出一個補償用的 `sheet.shift`，和插入視圖包成同一個 batch 指令：一個復原步驟，其他視圖完全不動。
6. **預覽線條是轉出來的**：投影或剖面的預覽，取調色盤中「看的方向相同」的那個視圖，再依需要的「上方」在圖面內轉向（`turnLines`）。例如從上視圖切出的剖面，看的方向和右視圖相同，但「上方」是上視圖的。這是精確計算，不需要另外投影。
7. 「以數值建立」（原本的下拉選單和數值輸入）收進可展開區，保留給需要精確數值的情況，既有的 e2e 腳本也還在用。

## 限制

- 剖面預覽用的是**沒切開的**零件從同方向看的線條。剖面的外框可能比較小；外框真的變小時，排版會在剖面線條算出來之後重新置中，其他視圖可能小幅移動。這次在定位板上量到的是 0 mm（外框相同）；外框不同的零件**還沒量測**。
- 切割線目前只有垂直和水平。任意角度、對正、階梯剖面在 D-I5。
- 貼齊對象還沒有頂點，要等 D-I2 讓視圖的線有名字之後才有。
- 調色盤只顯示第一個模型視圖的零件；不含鈑金展開圖（展開圖仍從「以數值建立」加入）。
- 細部放大圖的流程沒有改（原本就是 SW 的「畫圓 → 點一下放置」）。

## 驗證

- `tests/phase5/drawing-place-views.test.ts`（7 項）：
  - `turnLines` 與 3D 核心從轉向後的視角直接投影的結果比對：外框相同到 1e-6；可見線與隱藏線的每一點都落在核心算出的線上（誤差 1e-3）。看的方向不同時回傳 null。
  - 200 組隨機游標，涵蓋 4 側、2 種投影法、3 個母視圖：用 batch 指令實際插入後重新排版，其他視圖都沒有移動；新視圖就在預覽的位置；與母視圖的間距至少 5 mm；「跟著游標」與「被擋在最小間距」兩種情況都有出現。
  - `sideAt`、`snapCut` 的邊界情況；輸入 NaN 時明確拒絕。
- 瀏覽器（定位板，真實 pointer 事件）：
  - 刪光視圖後，調色盤仍在。
  - 把前視圖從調色盤拖到 (150, 180) 放開：放在該點，並進入投影模式。
  - 右側的投影視圖放在 x = 280（就是點的位置），y 和母視圖對齊；下方的放在點的位置、x 對齊；斜角放等角視圖；Esc 結束。
  - 在上視圖上做剖面：游標離孔中心 0.8 mm 就貼齊到 x = −50。放在右側時箭頭朝右；放在左側時自動翻轉；Ctrl 放在任意位置。
  - 剖面預覽 15 × 80，與實際剖面視圖相同。
  - 放置前後，其他視圖的位置完全相同；復原一次，就把視圖和補償一起拿掉。
- `verify:ui` 的工程圖腳本：14 支有 11 支通過，3 支是 10-12 記載的既有失敗。`manual-drawing-linked` 第 2 步的數字和上一次差 1 mm，還沒查明是不是每次執行的時間差造成的。
