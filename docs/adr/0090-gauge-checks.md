# ADR 0090：量規表與可製造性檢查（Phase 7-7，C11.1、C11，零件 Schema 40）

- 狀態：已實作並驗證（2026-10-04）。限制見最後一節。
- 相關：[phase7-plan](../phase7-plan.md)、[ADR 0084](0084-base-flange.md)（鈑金參數）、[ADR 0088](0088-flat-pattern.md)（平板型式，孔的位置從這裡來）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **量規表是零件的一張表**（零件 Schema 40）：`PartDoc.sheetGauges?: { name, thickness, radius, kFactor }[]`（毫米與數字，不是運算式），沒有預設的列，指令 `setSheetGauges`（整張表；空的拿掉；名字不能空、不能重複，板厚與半徑大於 0，K 在 0 到 1） | 數字是工廠的；沒有我編的資料。數字不是運算式，變數改名不會漏掉表 |
| 2 | **套用一列 = 把它的數字複製進基材凸緣**（不連動）：特徵不記是哪一列，改表不會改特徵。基材凸緣的 PropertyManager 有「套用量規…」的下拉、每列可改、可刪，「把目前的參數加為一列」 | 單一來源仍是特徵上的數字；SW 的連動做法（特徵記表名）需要表也是版本化的來源——以後要再做 |
| 3 | **可製造性檢查**（`sheetChecks`，`@3db/regen`）：從折彎資料與平板型式算，四個規則，**每個做過的檢查都回報（過或不過）**：`bendRadius`（每個折彎的內側半徑 ≥ 板厚 × 比例，預設 1）、`flangeLength`（每個凸緣折彎之後的平直段 ≥ 板厚 × 比例，預設 4）、`holeToBend`（每個孔的邊到**最近**的折彎區的距離 ≥ 板厚 × 比例，預設 2；距離 = 孔心到折彎線段的距離 − 裕度/2 − 孔半徑，在折彎區裡是負的）、`reliefMissing`（凸緣縮短了但沒有離隙） | 計畫列的三項加上 7-4 之後自然多的一項 |
| 4 | **比例是使用者的**：三個比例在平板型式視窗裡改（顯示輸入的字串，數字有效就重算），**預設值是我的起點，不是標準**，視窗上這樣寫。孔只認平板型式輪廓裡的圓（外輪廓是整個圓時不算孔）；折彎之後才切的孔（除料特徵）不在平板型式裡 | 老實說規則是經驗法則 |
| 5 | **檢查不阻擋、不改特徵**：只是一張清單；結果不存進文件（和分析、平板型式一樣）。Worker 的 `sheetChecks(limits)` 用最後一次重算的結果；平板型式做不出來時（折過的基材上有凸緣）折彎半徑、平直段、離隙還是檢查，孔不查 | 與其他檢查的視窗一致 |

## 驗證（證據）

- **量規表與檢查**（`tests/phase7/manufacturing.test.ts`，10 項；板 100 × 50 × 1.5、半徑 2、K 0.5、90° 凸緣長 30 從外側量 → 平直段 26.5、折彎裕度 4.32）：
  - 量規表：存進零件檔再讀回相同、版本 ≥ 40、空表拿掉；套用一列（2 mm、半徑 3、K 0.4）後板是 2 厚（體積 10000）、`sheet` 是 2／3／0.4；沒有名字、重名、板厚或半徑 0、K 1.5 都被拒。
  - **內側半徑**：2 對 1 倍板厚（1.5）過；基材半徑 1 不過（值 1、限 1.5）；比例 1.5 倍（限 2.25）時 2 也不過。
  - **平直段**：26.5 對 4 倍板厚（6）過；凸緣長 8（平直段 4.5）不過。
  - **孔到折彎**（折彎線在 x = 96.5 + BA/2，區半寬 BA/2）：Ø5 的孔在 x = 90：距離 **4.0**（限 3）過；x = 93：**1.0** 不過；x = 92：**2.0** 不過；兩個孔各查最近的折彎，遠的孔過（距離 = 手算）；整個圓的外輪廓（圓盤）不是孔。
  - **離隙**：凸緣縮短沒有離隙不過、有離隙過；整條邊的凸緣沒有這項檢查。
  - **折過的 U 形槽**：半徑 2 兩個折彎都過、半徑 1 都不過。
- **瀏覽器**：`tests/e2e/phase7-flat-ui.js`（加了檢查）：視窗說「2 項檢查：2 通過、0 不通過」，平直段的限改成 30 倍板厚：「1 通過、1 不通過」、不過的是平直段，改回 4：2 通過；`tests/e2e/phase7-gauge-ui.js`：基材凸緣的 PropertyManager 一開始沒有列也沒有可套用的、「把目前的參數加為一列」得到 1.5／2 的一列、加一列 2.0 mm、從下拉套用，基材凸緣拿到 2／3／0.4、板體積 10000；存檔後表在零件裡。
- `npm run check`：1484 項通過、21 項略過。

## 限制與未做

- **規則是經驗法則，預設比例是我的起點**：最小半徑、平直段、孔到折彎沒有隨材料變（鋁、不鏽鋼的最小半徑不同）；量規表的列沒有放材料與比例。使用者的工廠規定要手填。
- **孔只認圓**：長孔、矩形孔（輪廓的直線）不當孔；沒有折彎到邊的距離、折彎到折彎的距離、凸緣對孔等其他 DFM 檢查；折彎之後才切的除料特徵不在平板型式裡（平板型式的限制，ADR 0088），也不被檢查。
- **量規表不連動**（上）；表是整個零件一張，不是每種材料一張，也沒有從檔案（SW 的量規表檔）匯入。
- 結果不存、不標在特徵上（沒有設計樹上的警告記號）。
