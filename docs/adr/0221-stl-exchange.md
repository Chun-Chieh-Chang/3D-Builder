# ADR 0221：STL 輸出與輸入（F4.1 補完、F2.3）

日期：2026-11-01。狀態：已實作；eDrawings 對照檔待使用者判定（見「未完成」）。

## 問題

F4.1「STL 輸出」已有最小版（3a-8c，ADR 0039）：只輸出零件、只有二進位、全部本體合成一個檔、細緻度跟著文件設定，沒有對話框。F2.3「網格輸入作參考」（P2）沒有做。

使用者決定（2026-11-01）：
- STL 輸入成為**網格參考本體**：只顯示、量測，不能做布林或圓角。不把每個三角形轉成 B-rep 面（上萬個面會拖垮縫合、布林與命名，且 B-spline 以外的布林亦會佔 Heap，AGENTS.md §3.5）。
- 輸出補：對話框（二進位／ASCII、mm／inch、細緻度、座標系統）、組合件輸出 STL、多本體各存一檔。
- 輸入讀二進位與 ASCII，從內容判斷。

## 決策

1. **網格不是本體，也不進 OCCT。** 新特徵 `importedMesh`（Schema 87）：`blob`（`BlobRef.kind` 增加 `stl`，存成 `blobs/<sha256>.stl`）與 `unit?: 'mm' | 'inch'`（缺省 mm）。重建以純 TypeScript 讀檔，結果放在 `RebuildResult.meshes`（比照裝飾螺紋線 ADR 0156 的輕量資料），**不在 `BodyState` 清單裡**。
   - 這是刻意的：AGENTS.md 10-19 第 2 條「新的本體種類不得借用既有旗標」。若把網格做成一個只有三角化、沒有曲面的 OCCT 面放進本體清單，所有讀本體的消費端（拓樸、質量、布林、命名、點選、工程圖、干涉、STEP）都要逐一防禦；放在清單外，這些消費端**按構造就看不到它**，不必逐一判定。
   - 因此：實體與曲面特徵、質量、零件表、STEP／IGES／STL 輸出、工程圖都不含網格；只有網格的零件 `result.body` 為 null。
   - 不經 kernel，所以不佔 Emscripten Heap（量測見下）。
2. **讀取器 `parseStl`（`@3db/model/stl.ts`）**。放在 model 而非 io：regen 依分層規則不能依賴 io（`check-deps.mjs`），讀取是對位元組的純運算（比照 `picture.ts` 讀圖片標頭）。寫出器留在 `@3db/io`。
   - 判斷格式：檔案大小等於 `84 + 50 × 檔頭三角形數` 即為二進位——**即使檔頭以 `solid` 開頭**（許多程式這樣寫）；否則以 `solid` 開頭且是合法 UTF-8 文字者為 ASCII；其餘依大小回報「二進位不完整（應為 84 + 50 × N 位元組，實際 M）」或「不是 STL」。
   - ASCII 嚴格逐字解析，錯誤帶行號（「第 9 行：應為 endsolid，卻是檔案結尾」）。法向量不讀（由角點算；有些程式寫 `nan`），但必須有三個字。多個 `solid` 合成一個網格。數字必須是有限的，超出 float32 範圍（如 `1e39`）也拒絕。
   - 角點完全相同者合為一個頂點，以計算邊的共用：只屬於一個三角形的邊（破洞）、屬於三個以上的邊（非流形）、兩側方向相同的邊（法向量矛盾）各自計數；三者皆為 0 才算封閉，封閉才報體積。封閉但體積為負（全部朝內）另行警告。**沒有面積的三角形略過並計數**，不默默吃掉。
   - 不修補、不翻轉法向量、不猜單位：非法單位拋錯（AGENTS.md §2.1）。
   - 上限 `STL_MAX_TRIANGLES = 2,000,000`：網格每次重建都要送到頁面（約 18 bytes／三角形）。二進位在讀角點前就以檔頭數字拒絕。
3. **單位**：STL 不記錄單位。輸入時對話框列出「當成 mm」與「當成 inch」各自的範圍，由使用者選；之後可在網格面板改（指令 `setMeshUnit`）。
4. **輸出 `writeStl`**：二進位或 ASCII（每個數字 9 位有效數字，能精確還原 float32）、mm 或 inch（除以 25.4）。不認得的格式或單位拋錯。
   - 修正：二進位檔頭原以 `slice(0, 80)` 截**字元**再編碼，中文名稱編碼後超過 80 位元組；三角形數為 0 時 `out.set` 越界拋 `RangeError`。改為以位元組截斷且不切斷字元。
   - ASCII 名稱只留可列印 ASCII，其餘字元寫成 `_`（比照 IGES）。
5. **多本體、組合件**：零件可勾「每個本體各存一檔」，組合件可勾「每個零組件各存一檔」，多檔時打包成 ZIP（`writeZip`），檔名重複者加「 (2)」。合成一檔的零件維持原行為（全部本體合在一起網格化，弦高相對於整體大小）；各存一檔時每個本體依自己的大小網格化。組合件沿用 STEP 組合件的 `stepRequest()`：每個零件網格化一次，再依各零組件（含子組合件內）的位置以四元數放置；壓縮的零組件不輸出；鏡像零件比照 STEP。參考本體不輸出。
6. **畫面**：`viewer.setReferenceMeshes`：每個三角形平面著色，顏色 `--view-reference-mesh`（比本體暖），隨剖面裁切、隨顯示模式（線架構時畫三角形邊、透明時半透明），納入「全部顯示」的範圍；不參與點選。設計樹可隱藏（`isHideable`）。
7. **介面**：「輸入 STEP／IGES」改名「輸入 STEP／IGES／STL」；「開啟舊檔」也開 `.stl`，開成以檔名命名的新零件。說明 `help.importStep`、`help.exportStl` 更新（每一句用途都有測試或程式路徑對應）。
8. **順帶修正的既有缺陷**：`deleteFeatures` 只保留 `importedBody` 用的資料，刪除**任何**特徵時草圖圖片的影像資料（png／jpg）會一起被丟掉。改為保留 `importedBody`、`importedMesh` 與 `pictureBlobs()` 用到的資料；紅隊回退後測試以實際結果失敗。

## 驗證

- `packages/io/test/stl.test.ts`（16 項）：二進位方塊（12 三角形、8 頂點、封閉、體積、面積、範圍）；ASCII 與二進位讀得完全相同的 float32；inch 寫出除以 25.4、讀回乘回；非法單位；`solid` 開頭的二進位以大小判定；截斷檔回報應有位元組；ASCII 錯誤帶行號、非數字、超出 float32、`nan` 座標；`nan` 法向量、多個 solid、CRLF 與大小寫；二進位 NaN／Infinity 指出第幾個三角形；空檔、全部無面積、部分無面積計數；破洞、非流形、單一翻面、全部朝內；三角形上限（以參數觸發，二進位與 ASCII 都斷言）；中文長名稱檔頭；ASCII 名稱；**200 個固定種子的壞檔**（截斷、改位元組、刪除、重複片段）：27 讀入、173 以 `StlError` 拒絕，0 個其他錯誤，讀入者座標皆有限、索引皆在範圍內。
- `tests/phase8/stl-exchange.test.ts`（17 項）：
  - 三個金樣零件 × 兩種格式，以 **OCCT 自己的讀取器 `RWStl`**（不是本程式的）讀回：三角形數相同、體積與實體差 < 2e-3（弦高）、本程式讀取器與 OCCT 讀取器的體積差 < 1e-6、封閉。
  - **OCCT 的 `StlAPI_Writer` 寫的 ASCII STL**（第三方寫出器）由本程式讀入：三角形數相同、封閉、體積與 OCCT 讀取一致。
  - inch：OCCT 讀到的數字小 25.4 倍；說明中的例子（40 × 30 × 20 方塊 12 個三角形、24000 mm³、inch 為 1/25.4）。
  - 零件中：只有網格時 `body` 為 null、`bodies` 為空；與 V 型塊並存時本體數與體積（`massProps`）完全不變；單位重選；壞檔是該特徵的錯誤，後面的特徵照常建立；未封閉網格的警告；指令只接受 stl 資料當網格、網格只接受 stl；存檔版本等於 `SCHEMA_VERSION` 且 ≥ 87、資料存為 stl、讀回重建同體積；刪除特徵移除資料、保留草圖圖片資料。
  - 組合件：子組合件內零件的路徑與位置（含 90° 旋轉）、ZIP 檔名。
- `tests/phase8/stl-memory.test.ts`：各情境全新 Heap，以 `wasmMemory.buffer.byteLength` 量測並先斷言基準 > 0，`liveShapes` 回到基準。1000 次重建（每次新的 Regenerator、交替單位、1088 個三角形的圓柱網格）：**+0.00 MiB**（斷言為 0——讀取完全不經 kernel）；1000 次輸出（二進位、ASCII 交替）：+0.00 MiB（印出，不斷言）；對照組 1000 次布林除料：**+190.63 MiB**（斷言 > 0，證明量得到成長）。

## 未完成

- **eDrawings／切片軟體判定**：本程式寫出的 STL 只以 OCCT 讀取器驗證。需產生對照檔（二進位、ASCII、inch、ZIP 內多檔）由使用者在 eDrawings 開啟確認。
- **別的程式寫的 STL**：只驗證過 OCCT 的 ASCII 寫出器；沒有其他 CAD 或掃描器的樣本。
- **範圍外**：網格上點選頂點量測（量測工具只認 B-rep 元素）、網格移動／複製、網格轉實體、組合件中零件內的網格參考（組合件只顯示零件的本體）、輸出時含網格。
