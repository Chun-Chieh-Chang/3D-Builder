# ADR 0194：共用草圖端點的接續延伸

2026-10-24。使用者明確選擇：「保留矩形，接續新增共線延伸段」。零件 Schema 維持 81。

## 問題與行為

原本 `extend` 對端點被其他圖元使用的線／弧直接回報不可延伸，封閉矩形每個角點都被兩條邊共用，因此任何一邊都會遭拒。這個限制源自 ADR 0023 的原始決策，現在改為下列行為：

- 未共用端點：沿用原本延長原圖元的方式，舊端點及其關係、整條曲線的線長／相等／中點關係會隨操作移除。
- 共用端點：保留原圖元、共用點、相鄰圖元及原有尺寸／關係；從共用點新增一條接續線或同圓弧，到所選方向上第一個有效交點。**延伸段是獨立圖元，原矩形線長仍量原矩形的邊，不自動改成包含延伸段的總長。**
- 線段用「共用端點＋平行」保持共線，避免再加完整共線約束造成冗餘。圓弧沿用原圓心與共用弧端點，原生弧幾何規則使半徑一致，不另加多餘相等關係。
- 新端點加在目標曲線上。保留建構幾何屬性；起端、末端都可接續。
- 既有共線線段或同圓弧／圓覆蓋延伸路徑時顯式拒絕，避免重複圖元。若已新增延伸段，需點最外側延伸段靠端點處才能繼續延伸。
- 一次操作是一個 `editSketch`，試解成功才提交，一次復原／重做。成功訊息說明共用端點的接續方式；之後成功延伸會替換先前的重疊提示。

點選方式不變：啟動「草圖 → 延伸」，點要延伸那一端附近的線或弧；點角點本身會有多個候選，應點曲線本身。支援範圍仍為直線與圓弧，未新增樣條／橢圓延伸，也不宣稱含接續分支的草圖必定能直接作封閉特徵輪廓。

## 前置檢查與模型鏈路

沿用實際求解幾何尋找交點，只接受目標圖元實際畫出的區間；共用原角點的交點不算向外延伸。新檢查拒絕非有限點擊座標，以及延伸區間與既有共線段或同圓區間的正長度重疊。端點接觸本身不當成重疊。

使用既有模型的點、線、弧、平行與點在曲線關係，沒有新增儲存欄位。所有參照經既有 `editSketch` 驗證、真實 PlaneGCS 試解與正式命令提交；不直接移動網格或假造求解結果。此操作保留原圖元，原先外部參照及草圖依賴不被換名或刪除。
