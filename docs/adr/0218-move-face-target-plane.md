# ADR 0218：移動面至目標平面

## 決定
移動面可選較早建立的基準面或模型平面作為目標（Schema 85，舊檔仍使用距離）。端面與目標必須平行；位移由兩平面的有向距離計算。目標加入 DAG 與參照替換，變更位置後連動。

操作：開啟「移動面」，點選平面端面；直接點選設計樹的基準面，或按「目標平面」在圖形區點選平行的模型平面，也可使用下拉清單；按 ✔。不需要手算距離或錐體半徑。「給定距離」回到原模式。

## 核心修正
OCCT 對錐面的無界半空間裁切可能回空形狀；改用原生錐面頂點、軸與半角建立精確旋轉薄層。延伸與縮短都沿原錐面。單一凸錐面相鄰的完整圓形端蓋採此路徑，其他幾何沿用既有移動面。跨越錐尖、零位移、非平行目標拒絕。圓角相切限制不變。

合併同域面會破壞錐面接縫，甚至修改共享輸入；錐面結果保留布林分面及來源，不執行該合併。零體積結果不得回報成功。不宣稱此修改消除 OCCT 記憶體成長。

## 驗證
- 真實 OCCT 100 組目標高度：有效性、解析錐台體積、端蓋面積及位置。
- 非平行、同位置、完全切穿基底、錐尖及越過錐尖；平行模型面目標；存檔讀回、目標修改、DAG、面與邊名稱數量。
- 本機使用者 TM0002138 樣本：端面延伸到前基準面，實體有效、體積增加、位置正確。原檔未修改；用 MOVE_FACE_SAMPLE 環境變數提供檔案重播。
- manual-move-face-target.js：實際建立錐台、圖形區選端面、樹選目標、確認並量體積。
