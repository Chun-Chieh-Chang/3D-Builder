# ADR 0067：檢具曲面的技術驗證（4b-0）

- 狀態：已驗證（2026-10-03）。測試：`tests/phase4b/surface-spike.test.ts`（17 項，用 OCCT 的原始綁定；`@3db/kernel` 還沒有曲面的方法，那是 4b-1）。
- 相關：[phase4b-plan](../phase4b-plan.md)、藍圖風險 6（檢具的偏移曲面在自由曲面上失敗）、[ADR 0003](0003-occt-binding-gaps.md)（綁定缺口）、[ADR 0017](0017-phase3a-technical-validation.md)（3a-0）。

## 做法

**工件**：用放樣（`BRepOffsetAPI_ThruSections`）穿過不同半徑的圓做出來，側面是 B 樣條曲面：錐台（解析面，對照組）、腰（Ø50、Ø30、Ø44，繞著凸、沿著凹）、鼓（Ø30、Ø50、Ø30）、S 形（四個圓）；另有兩端倒 R3 圓角的腰。**間隙的量測**與驗收用的一樣：取結果曲面網格的點（約 150 點），用 `BRepExtrema_DistShapeShape` 量到來源曲面的距離，與要求的間隙相比，最大差必須 < 0.05 mm。

**可用的 OCCT 類別**（綁定檢查）：`BRepOffsetAPI_MakeOffsetShape`、`BRepBuilderAPI_Sewing`、`BRepFill_Filling`、`BRepProj_Projection`、`BRepFeat_SplitShape`、`BRepOffsetAPI_MakeThickSolid`、`BRepAlgoAPI_Splitter`／`Section`、`BRepBuilderAPI_NurbsConvert`、`ShapeFix_Shell`；**沒有 `TColgp` 陣列**（不能自己建 B 樣條曲面的格點），也沒有 `BRepOffset_MakeOffset`（ADR 0003）。

## 結果

| 項目 | 結果 |
|---|---|
| **單一自由曲面的偏移**（`MakeOffsetShape.PerformByJoin`） | 錐台 +3：最大間隙誤差 1.1e-6 mm；腰 +3：1.2e-6；鼓 +3：1.3e-6；S 形 +3：2.4e-6；腰 −3（向內）：1.5e-6。**遠小於 0.05 mm** |
| **含圓角的區域**（側面加兩個 R3 圓角，縫成殼再偏移 +3） | 3 個面、有效、誤差 2.9e-5 mm；圓弧接合與交會接合結果相同（3.1e-5） |
| **整個實體偏移**（5 面） | 有效、體積 59733.6 → 91946.7、誤差 3.2e-5 mm。**結果是封閉的殼，不是實體**：布林拒絕當刀具（「除料失敗」），要先 `BRepBuilderAPI_MakeSolid(殼)`；包成實體後 `減除` 的體積等於手算（80³ − 91946.697，差 < 1e-6），空腔面距工件 3.2e-5 mm |
| **偏移曲面的型別** | 結果的面是 `offsetsurface`（OCCT 的精確偏移，不是近似）。`BRepBuilderAPI_NurbsConvert` 轉成 B 樣條：誤差 3.8e-5 mm、有效；STEP 輸出再輸入：體積 91946.696 → 91946.696；偏移曲面本身輸出 STEP 再輸入也讀得回 OCCT（其他 CAD 讀不讀得到沒有驗證，所以輸出前轉 B 樣條） |
| **失敗**（腰縮到 Ø8、向內偏移 5，超過曲率半徑） | **`IsDone` 為真、結果有效，但間隙誤差 1.99 mm**：形狀看起來正常、卻不是要的間隙。**必須量測結果，不能相信 `IsDone` 與 `isValid`** |
| **縫織**（三個面各自偏移再縫，容差 1e-4） | 2 個自由邊（區域的兩端）、0 個多重邊；面積 9856.898，與整個區域一次偏移的結果相同（到 3 位小數以上） |
| **填補**（球 R30 上 Ø16 的洞，`BRepFill_Filling`） | 邊線加球面的相切（G1，支撐面）：與球的最大偏差 **0.020 mm**（OCCT 回報 G0 1.5e-5、G1 5.3e-7）；只給邊線：**1.08 mm**。所以預設要有支撐面與相切 |
| **厚面**（偏移後的區域，`MakeThickSolidBySimple` 向外 20） | 有效、1 個實體、8 個面；網格點距工件 3.0000 到 23.0000（正是 3 與 3 + 20）；**結果的體積可能是負的（整個實體反向）**，要檢查並翻面（`Reversed`），之後 406992.8 在 A·20 與 3·A·20 之間 |
| **以曲面除料**（`BRepFill_Filling` 在方框上拉出的自由片，沿 +z 掃成刀具實體，方塊減刀具） | 下半 297457.0 + 上半 302543.0 ＝ 600000.0（＝方塊）；新的頂面距曲面 1.95e-6 mm |
| **分割線**（矩形沿 −x 投影到錐台側面，`BRepProj_Projection`＋`BRepFeat_SplitShape`） | 投影得到**兩條**線（視線穿過的近側與遠側各一，20.4 與 59.6 遠）：要取近的；區域穿過錐面的接縫時被分成兩個面：`UnifySameDomain` 合併、並保留分割線的邊（否則區域與其餘部分又合成一個面）→ 4 個面、**區域面積 213.15，手算積分 213.148（差 1e-5）**；有效 |
| **時間** | 區域偏移 2 ms、整體偏移 2 ms、100 點的間隙檢查 256 ms（Node） |

## 決定

1. **每個曲面特徵都量測自己的結果**（間隙 0.05 mm、有效、縫織的自由邊數、厚面的體積為正與厚度）；不合就失敗並說出量到的數字。這是對風險 1 的對策。
2. 偏移：區域先縫成殼；接合型式預設圓弧；結果是曲面本體；整個實體偏移要包成實體才能當布林的刀具。
3. 偏移曲面輸出前轉成 B 樣條。
4. 填補預設相切（G1）並貼著相鄰的面。
5. 厚面做完檢查體積為正，否則翻面。
6. 分割線只取最近一層的投影；合併接縫；保留分割線的邊。
7. 以曲面除料：把曲面沿方向掃成刀具實體再做布林，不用 `Splitter`。

## 沒有驗證的（不要當作已解決）

- **真實的沖壓件或塑膠件**：修剪過的 B 樣條面、很小的面、縫隙、公差大的 STEP。金樣是放樣出的光滑曲面；真實檔案的行為是未知（風險 2）。
- **偏移自我相交的偵測在大區域上**：失敗案例只用了一個曲面；多個面、凹陷處自我相交的區域靠量測把關，沒有大量的失敗案例。
- **延伸曲面**（C9.3）、**兩個曲面互相修剪**。
- **持久名稱**：偏移、縫織、厚面、分割之後的面名稱怎麼繼承，4b-1 到 4b-5 各自決定與測試；這裡沒有驗證。
- **STEP 在其他 CAD 讀不讀得到偏移曲面與 B 樣條殼**（只驗證了本程式往返）。
- 效能只量了小件（5 個面）；幾百個面的工件沒量。
