# ADR 0117：沒有在編輯時也能選邊線與頂點（Schema 不變）

- 狀態：**已實作並驗證（2026-10-07）**。來源：使用者回報「選擇濾器似乎沒有功能」。

## 問題與根因

「選擇濾器」的三個勾選（面、邊線、頂點）只是把指令要的種類再縮小一次：沒有在編輯時，程式只讓人選面，不讓人選邊線與頂點，所以「邊線」「頂點」在平常的畫面上勾或不勾都沒有差別；只有開了需要邊的指令時才有用。SolidWorks 的濾器任何時候都有用，而且可以先選好邊再按指令（預先選取）。

## 做法

1. **沒有編輯任何東西時**（也沒有在量測），圖形區可以點邊線與頂點；三個勾選各自生效（`Viewer` 本來就照濾器過濾）。點邊與點頂點的結果放在 `UiState.selectedElements`（邊與頂點的參照，Ctrl 或 Shift 加選或取消），與「選了一個面」「選了設計樹的一項」互斥；點面、點樹、點空白處、開始編輯、換檔案都會放掉它。
2. **畫出來**：選到的邊與頂點用同樣的選取顏色畫，圖形區底下寫「已選取 N 個邊線／頂點…」與名稱；滑過邊或頂點時寫它的名稱。
3. **預先選取**：圓角、導角、邊線凸緣、摺邊、填補／平坦／延伸曲面的指令一開始，已選的邊就是它要的邊（邊線凸緣與摺邊取第一條；頂點不用）；然後選取放掉。
4. 編輯中的行為完全沒變（點的元素仍然進指令的欄位）；量測用自己的選取。

## 驗證

瀏覽器腳本 `tests/e2e/phase3-select-elements.js`：沒有編輯時邊、面、頂點都可點；「邊線」關掉：邊不能點，面與頂點可以；三個都關：什麼都不能點；邊線點擊進選取而不是指令、面與樹項目沒有選、檢視器畫出選取；Ctrl 加第二條、再按第一條取消、加一個頂點；此時開圓角：圓角一開始就有那一條邊（頂點沒進去），選取放掉；點面清掉邊的選取、點空白處清掉全部。我也用真的滑鼠在畫面上點了一條邊：選到了、底下的提示寫出名稱。

## 限制

- 預先選取只有上面列的指令（圓角、導角、邊線凸緣、摺邊、三個曲面邊線指令）；量測、參考幾何、特徵的其他指令不吃已選的邊與頂點。
- 沒有框選邊線；沒有「選取其他」邊的右鍵選單（面有）；沒有在平常時選一整圈或相切的邊（指令裡的右鍵選單有）。
- 點的位置離邊很近時選到邊而不是面（和指令中一樣）。
