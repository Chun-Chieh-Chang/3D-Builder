# ADR 0056：定位銷孔（Phase 4a-3，C4.8，零件 Schema 27）

- 狀態：已實作並驗證（2026-10-03）。限制見最後一節。
- 相關：[phase4a-plan](../phase4a-plan.md)、[ADR 0030](0030-hole-wizard.md)（異型孔）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **異型孔多第五種 `kind: 'dowel'`**（零件 Schema 27，v26 → v27 不轉換，已補 v26 樣本）：沿用 `diameter`（標稱直徑）、`end`，多 `fit?: 'H6'｜'H7'｜'H8'`（缺省 H7）與 `chamfer?: Expr`（入口 45° 導角，缺省沒有）。指令檢查：只有定位銷孔可以有 `fit` 與 `chamfer`、`fit` 要在表裡；`chamfer` 是長度運算式，跟著變數 | 一個孔特徵就是一個孔特徵：第五種孔，不是另一種特徵 |
| 2 | **孔以標稱直徑做出，公差等級存在特徵裡**：不把孔做成公差帶的中值或上限。理由：(a) 這是 CAD 的慣例，公差是標註不是幾何；(b) 壓入的定位銷（標稱直徑相同）與孔壁剛好接觸，3b-5 的干涉檢查不會把設計好的過盈配合當成干涉（接觸不算干涉）；(c) 工程圖（Phase 5）需要的是「Ø6 H7」，不是 6.006 | 做成中值會讓每個壓入的銷都「干涉」幾微米 |
| 3 | **公差表**（`packages/model/src/dowel.ts`，ISO 286-1，尺寸範圍 1–3 到 80–120 mm，一個尺寸屬於「超過下界、到上界（含）」的範圍，所以 6 在 3–6）：孔 H6／H7／H8＝標稱起往上 IT6／IT7／IT8；銷 m6＝基本偏差往上 IT6、h6 與 h8＝標稱往下 IT6／IT8。`holeLimits`、`pinLimits`、`fitClearance`（最鬆與最緊的間隙，負的是過盈）；`ISO_DOWEL_DIAMETERS` 是 ISO 8734 的標稱直徑 | 表值手打自標準，測試逐項對手抄的值；使用前請對照公司標準 |
| 4 | **範圍外報原因**：標稱直徑不在 1–120 mm（表的範圍）時特徵出錯、說明範圍，不用外插 | 不編造表外的公差 |
| 5 | **入口導角做成孔剖面的一段**（沿用錐孔的做法）：從 R+c 在表面到 R 在深度 c；`c` 不小於半徑或深度時報錯。面的名稱 `h1:side:<草圖>.<點>.cone`，與錐孔相同 | 一個剖面旋轉出整個孔，持久命名照舊 |
| 6 | **介面**：異型孔屬性管理員的種類多「定位銷孔」；「標準規格」改列 Ø1…Ø50（ISO 8734），公差等級（H6／H7／H8）、入口導角；面板顯示「孔 H7：6.000 到 6.012 mm；搭配的銷 m6：6.004 到 6.012 mm（最鬆 0.008、最緊 −0.012 mm，負的是過盈）」。換成別的種類會拿掉 `fit` 與 `chamfer` | 使用者要看到配合，不只是一個數字 |

## 驗證（證據）

- **公差表**（`tests/phase4/dowel-hole.test.ts`，19 項之中的 4 組）：孔 Ø3 H7 上限 +0.010、Ø6 H7 +0.012（6 在 3–6 的範圍）、Ø6.5 H7 +0.015、Ø8 H6 +0.009、Ø10 H7 +0.015、Ø12 H8 +0.027、Ø25 H7 +0.021、Ø40 H7 +0.025、Ø100 H8 +0.054；銷 Ø6 m6 6.004–6.012、Ø8 m6 8.006–8.015、Ø2 m6 2.002–2.008、Ø6 h6 5.992–6.000、Ø10 h8 9.978–10.000；Ø6 H7 配 m6：最鬆 +0.008、最緊 −0.012，配 h6：最緊 0、最鬆 0.020；Ø0.5、Ø130 沒有值。
- **幾何**：Ø6 深 8 的孔使板失去 π·3²·8（對手算 6 位小數）；入口導角 0.5 的孔失去圓柱加上錐台再減去導角內的圓柱（手算）、有效、面名稱 `h1:side:s2.p1.cone`；貫穿的 Ø8 H6 兩個點各一個孔；標稱直徑 0.5／130 與導角 3（大於半徑）各報一句話；導角跟著變數（0.4 → 0.6，體積對手算）。
- **文件**：`setHole` 後 `fit`、`chamfer` 保留，存檔重開相等，版本號 27；直孔帶 `fit`、不明的等級、螺紋孔帶 `fit` 都被指令拒絕。
- **舊檔**：v26 樣本（`v26-derived.3dbx`，由 Schema 27 程式寫出再改版本號，README 如實寫了）開啟、衍生本體保留。
- **瀏覽器**（`tests/e2e/phase4-dowel.js`，0 Console 錯誤）：板、頂面草圖的點、直孔 Ø6 → 屬性管理員的種類選「定位銷孔」→ `fit` H7、`chamfer` 0.5、體積對手算、錐面有名稱、面板顯示 6.000 與 6.012 與 m6 → 換 H8（Ø6 的上限 6.018）→ 標準規格選 Ø8（體積對手算）→ 換回直孔拿掉 `fit` 與 `chamfer`。
- `npm run check`：1010 項通過。

## 限制與未做

- **表只到 120 mm、只有 H6／H7／H8 與 m6／h6／h8**；其他等級（N7、P7 等）不在。表值要使用者對照他們的標準。
- **孔的幾何不含公差**（決定 2）：要看配合只看面板的說明或之後的工程圖；沒有「以公差上限／下限建模」的選項。
- **銷與孔的配合沒有自動檢查**：圖庫的定位銷（4a-4）做好之後，面板只顯示 m6 的配合說明，不會比對實際插入的銷是什麼等級。
- 沒有銷孔的**排列對位**（同一組銷孔在兩個零件上的對應）；孔以草圖的點放置，與其他異型孔相同。
