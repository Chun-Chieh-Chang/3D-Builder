# ADR 0245 截面間隙

Schema 93 新增 `sectionClearance`。來源實體、截面平面與伸長終止參照都保留持久名稱。平面偏移沿所選平面的法向，以帶符號的長度指定。間隙預設向外，結果可除料、合併或建立新本體。重算沿用伸長的方向、終止與布林語意。

核心以 `Kernel.sectionEdges` 取得平面局部座標的直線、圓弧、整圓及 Bézier 段。偏移在局部 XY 平面完成，輪廓交回原平面伸長。完整圓以局部 +Z 重新建立。同心雙圓以半徑解析偏移，避開 OCCT 的內縮陷阱。孔洞與多區域以原生線框距離和面內分類判斷。原生截面回報為其他曲線種類時拒絕，包含直接回報為橢圓的截面。

樣條一律使用雙圓弧，擬合預算為 2e-6 mm。若原生直線與樣條的修剪端點在 2e-7 mm 內，會在擬合前將樣條端點接到解析邊，並把位移算入同一誤差預算。最多接受 1,000 個來源曲線段及 10,000 條近似邊。

間隙檢查包括原生線框的全域最小距離、偏移兩側的包含關係，以及逐邊的距離上界。對解析或已近似的輪廓使用研究門檻，最小距離為間隙減 1e-6 mm，最大距離為間隙加 1e-5 mm。原始樣條另有獨立的擬合誤差上界。輸入間隙須大於上界檢查的 1e-5 mm 餘量，且採用與曲面偏移相同的 1e6 mm 尺度上限。相切或自相交的線框、無法證明的偏移，以及消失的內縮區域會拒絕。具有同心整圓且另含其他孔洞的區域目前拒絕內縮。

在特徵面板停止計算會替換無法中斷原生呼叫的 Worker，並保留文件中的未完成標記。模型重算停在該項之前，保留先前的幾何。重試會清除標記並恢復重算。一般重算的時間與 Heap 高水位沿用現有 Worker 機制。
