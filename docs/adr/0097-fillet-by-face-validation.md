## 驗證了什麼，結果如何

| 問題 | 結果 |
|---|---|
| 對一個面的所有邊倒圓角，OCCT 在頂點做什麼？（計畫的手算假設是斜接） | 40 × 30 × 12 方塊頂面 4 條邊 R 2：**14282.890822**；手算 14400 − [(1−π/4)·r²·140 − 8·r³(5/6−π/4)] = 14282.890822，**差 2e-10**。斜接的假設正確 |
| 導角 2 × 2 同樣 | 14130.666667；手算 14400 − (2·140 − 8·8/6) = 14130.666667，**吻合** |
| 導角距離 1 量在選的面上（使用者確認 SW 也是這樣） | `MakeChamfer.Add(d1, d2, edge, face)` 的 `face` 就是量 d1 的面：頂面選 3 × 側面 1，頂面縮成 (40−6) × (30−6) = 816，**吻合** |
| 哪些邊是相切連續的（面展開時要略過） | 新增 `Kernel.smoothEdges(shape, edges)`：在邊的中點與兩端附近比較兩側面的法向（|n1·n2| > 1 − 1e-6）。方塊 20 條邊 0 條相切；頂面倒圓角後 20 條邊中 **8 條**相切（頂面與四個圓角、四個圓角與側面），新頂面的 4 條邊全是 |
| 完整圓角用兩條邊各倒寬度一半的圓角 | **失敗**：R 15（頂面寬 30）OCCT 回「圓角失敗」（兩個圓角剛好吃光整個頂面）；R 14.99 做得出來，但留下 0.02 寬的細條（8 個面而不是 6 個），體積 20142.32，比完整圓角的 20137.17 多 5 mm³，**不能用** |
| 完整圓角用布林（刀具＝頂面上方的條狀區域減去半徑 w/2 的圓柱） | **精確**：體積 20137.166941 = 手算 24000 − 40·(30·15 − π·15²/2)，**差 < 1e-9**；只多一個圓柱面，頂面消失（6 個面）。刀具用既有的 `extrude`（斷面＝兩條線、一條弧，沿長度拉伸）加 `boolean('cut')` |
| 凹邊（L 形支架內角）的圓角 | 補上的體積 77.256661 = (1−π/4)·3²·40，**吻合**（凸邊去料、凹邊補料用同一個 `fillet`） |
| 不相鄰的兩組面 | 方塊的前後兩面沒有共同的邊（`edge.faces` 找不到同時屬於兩者的邊），`MakeFillet` 只認邊，沒有滾球在兩個不相接的面之間的做法；這個 OCCT 版本沒有面圓角的 API |

## 決策

1. **選面（固定半徑圓角、導角）**：照計畫做。面展開成邊後用 `smoothEdges` 略過相切邊，再略過接縫與單鄰面的邊；導角的距離 1 量在**邊所屬的選取面**上。
2. **面圓角**：只做兩組面有共同邊的情況（共同邊倒圓角，凸凹都行）；沒有共同邊時明確拒絕並說原因（使用者已接受，F-5 取消，除非日後有便宜的做法）。
3. **完整圓角**：用**布林切除**，不用兩個圓角。限制（使用者已接受）：兩側面平行、中央面垂直於兩側面（半圓），其他情況明確拒絕並說原因。切出的圓柱面的命名：它取代中央面，所以它的來源記成「中央面被修改」，名稱沿用中央面（F-3 實作並驗收）。
4. **計畫的驗收數字不用改**：1、3、4、9、11 都已在核心層試出手算的值。

## 沒驗證、留給後面的
