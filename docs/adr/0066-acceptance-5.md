## 驗收中發現並修正的問題

- **倒角的孔被當成盲孔**：定位銷孔入口有 C0.5 倒角（一個圓錐面），`holeInfo` 把任何圓錐都當鑽頭尖端，所以兩個貫穿的 Ø6 孔被寫成「深 14.5」。改為：**只有一個圓邊的圓錐（收斂成一點）才是鑽尖，有兩個圓邊的圓錐（倒角、錐形沉孔）孔口仍是開的**。這是 5-4a 的測試（沒有倒角的孔）沒有碰到的，用真實夾具才出現。

## 限制與使用者的待辦（B 段）

- **還沒在真實的程式開過**：用 Chrome 開基板加工圖與組合圖的 PDF、用你的 CAD 開 DXF（ADR 0065 的限制）。
- **真人走一遍**：開夾具的基板零件與組合件 →「新工程圖」→ 自動尺寸、剖面、孔表、零件表與號球 → 輸出，回報不順的地方。
- **對照你的標準**：ISO 286 表、孔標註用語、標題圖塊。
- 這個驗收在 Node 裡用與 App 相同的核心與函式組出圖（沒有經過瀏覽器的 Worker 與面板）；App 本身的流程由 `tests/e2e/phase5-*.js` 各自驗證（組合件圖的 e2e 用的是金樣定位板與削邊銷，不是這個夾具）。
- 基板圖的視圖方向照模型的座標：板躺在前基準面（z 是厚度）時，「前視」看到孔的圓、「上視」看到厚度，剖面的上方是 −z（所以板的上面在圖的下方）；要換成「厚度朝上」的習慣，要在模型裡把板建在上基準面，或之後加「自訂視角」。
