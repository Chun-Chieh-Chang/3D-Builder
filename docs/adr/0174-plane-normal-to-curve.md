# ADR 0174：參考平面「垂直於曲線」（G5）

## 1. 背景
這是 2026-10-19 草圖參照盤點的 G5。

**現況**：參考平面（C3.2）有 7 種模式：偏移、夾角、三點、過點平行、過點垂直於軸、中間面、相切圓柱。沒有「垂直於曲線」。

**為什麼需要**：
- 掃出（C4.4）的輪廓平面最常見的放法，就是在路徑起點、與路徑垂直。螺旋彈簧（ADR 0169）、雲形線導管、彎曲的線材都是如此。
- 目前只能靠手算角度，或另建基準軸來湊。
- SolidWorks 有「垂直於曲線」，FreeCAD 的附著模式也有 NormalToEdge。

## 2. 決策
1. **`PlaneDefinition` 新增 `{ mode: 'normalToCurve'; curve: Ref; point: Ref; reverse?: boolean }`**，Schema 71：
   - `curve` 是模型邊，可以是直線、圓弧、雲形線，也可以是曲線本體的邊，例如螺旋；
   - `point` 是模型頂點或較前面的參考點；
   - 平面通過曲線上的那一點，法向為該點的切線方向；`reverse` 把法向反過來。
2. **點必須在曲線上**：用 kernel 的 `edgeNearest`（ADR 0173 已實作）找最近的位置，距離大於 1e-6 mm 就明確拒絕，不靜默投影到曲線上（AGENTS §2.1-1）。常見情況是選曲線的端點。
3. **方向**：法向取曲線參數遞增的方向。重建時這個方向必須固定，所以不依賴使用者點選的順序；需要相反方向時用 `reverse`。
4. **介面**：參考平面面板新增「垂直於曲線」模式，有兩個選取框：「曲線」收邊，「點」收頂點或參考點。沿用既有的 `datumSlots` 機制。

## 3. 設計
- 模型：
  - `schema.ts` 新增 `PlaneDefinition` 的成員；
  - `commands.ts` 的 `planeDefinition` 檢查：曲線必須是邊，點必須是頂點或較前面的參考點；
  - `defRefs`／`mapDefRefs` 以泛型方式處理，不必改動，所以 DAG 和參照修復都會自動涵蓋。
- 再生：`engine.refPlane` 新增分支，解出邊的索引與點，呼叫 `kernel.edgeNearest(view.shape, edge, p)`，再以 `planeFrame(point, ±tangent)` 建出平面。
- 介面：在 `datumSlots` 的 `slotsOf('refPlane')` 加上這個模式的兩個選取框；PropertyManager 的模式清單加一項；雙語。

**e2e 第一版的三個問題（都是測試寫錯，產品行為正確）**：
1. 視角動畫尚未停下就點擊；
2. 等角視下，第一圈的中點被第三圈擋住，點到的是較前面的第三圈；這是正確的 3D 點選，產品也正確拒絕了不在曲線上的點；
3. 點擊位置在畫面上離某個頂點太近，產品優先選頂點，這是設計如此。

改為：沿第一圈找畫面上看得到、而且離所有頂點都超過 20 px 的位置再點擊。

## 5. 已知限制
- 點不在曲線上時拒絕，不做投影。
