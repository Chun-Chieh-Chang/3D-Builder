# ADR 0051：評估工具——物質特性、測量、干涉檢查、檢查模型幾何（Phase 3b-5，E1.1、E1.2、E2.1、E3.1）

- 狀態：已實作（5a 到 5e 全部完成並推送），2026-10-03
- 相關：[phase3-plan](../phase3-plan.md) §4 的 3b-5；使用者 2026-10-02 確認：干涉的比對單位是**頂層零組件**（次組合件算一個，陣列與鏡射的每個複製品各算一個）；結果是**清單加圖面標出重疊體積**。組合件 Schema 不變。

## 決定

### 核心（5a）

1. **慣性矩由核心給。** `kernel.massProps` 多回一個 `inertia`（對質心、全域座標軸方向的 3×3，密度一的值，單位 mm⁵）。零件的值乘上密度（g/cm³ ÷ 1000）得 g·mm²。
2. **質量合成在 `@3db/model`（`mass.ts`），不在核心。** `placeMass`（R·I·Rᵀ）、`combineMass`（平行軸定理）、`principalMoments`（Jacobi）、`partBody`、`mirrorBody`（x → −x）、`assemblyPhysical`。放在 model 是因為主執行緒不能在執行期匯入核心，而這些全是純數學。
3. **精確距離、共同體積、檢查** 是核心的三個新方法：`distance`（BRepExtrema，傳回距離與兩個最近點）、`common(a, b, minVolume)`（傳回共同體積與形狀，小於門檻不算）、`check`（有效性、每個面各自的有效性、實體數、開放邊數、體積）。`subShape` 把面、邊、頂點取成自己的形狀。

### 物質特性（5b）

4. 零件：核心的屬性加零件檔的材質（沒有材質就沒有質量，只顯示體積、面積、質心）。組合件：每個零件的本體放在它的位姿上，鏡射的先反射，再合成。**用組裝位置（不是爆炸位置）**，所以爆炸視圖不影響。沒有材質的零件不計入質量並列出名字；還沒讀好的也列出。
5. **表面積是各零件表面積的總和**，不是組合件外殼的面積（介面兩邊都算）。對話框裡明說。

### 測量（5c）

6. 一次選 1 或 2 個元素（面、邊線、頂點）。單選：種類、面積／長度／半徑與直徑、座標。雙選：**精確最短距離**（BRepExtrema，不是點到點）、兩點差 ΔX／ΔY／ΔZ、**夾角**。
7. **夾角是兩個方向之間的銳角（0 到 90 度）**：平面取法線、圓柱圓錐取軸線、直線取方向、圓取其平面法線；任一邊沒有方向（頂點、自由曲面）就不給夾角。這是約定，不是 SolidWorks 的完全相同行為（它會分別給兩個補角）。
8. **座標系：** 零件在零件座標系，組合件在組合件座標系。做法是**先把零件放到組裝位置再讀數字**（`kernel.transformed`，面、邊、頂點的編號不變），所以所有數字已在組合件座標系。測量的是**畫面上看到的位置**（含爆炸視圖）。
9. 鏡射的零組件與排列的複製品也能量：鏡射用該零件檔的形狀先 x → −x 再放位姿（`placementRows` 翻第一欄），和畫面一致。這不經過配合用的元素名稱（鏡射件沒有名稱），只用編號。
10. 量測進行時，其他命令一律不可用（`assemblyFree`、`partIdle`、`idle` 都看 `measure`），Esc 結束，Delete 不動作。模型或組合件變了，已選的元素會重新量一次。

### 干涉檢查（5d）

11. **兩兩比對頂層零組件**（`interferenceGroups`）：次組合件的零件是同一個零組件，不互相比；排列的每個複製品與鏡射的複製品各是自己的零組件（葉子 id 的 `@` 後面是它們的身分）。**隱藏的零組件會比，被抑制的不會**（被抑制的本來就不在葉子裡）。
12. **只有接觸不算干涉。** `common` 的體積小於 `MIN_INTERFERENCE_VOLUME = 1e-3 mm³` 就不報。理由：核心的公差會讓緊貼的兩個面算出極薄的體積；1e-3 mm³ 以下的重疊對製造沒有意義。要更小的得改這個常數，它在 model 裡。
13. **效率：** 先用包圍盒（含 1e-6 的餘裕）篩，只有盒子相交的零件對才呼叫布林運算；每個零組件的零件先放到位一次。核心在 Worker，主執行緒只拿到每個重疊的網格。
14. **顯示：** 清單依重疊體積由大到小，每列「A × B」加體積；重疊在圖面用紅色（`Viewer.setHighlights`，不被滑鼠點到，不受深度遮住）；點清單的一列只顯示那一組並選取它的兩個零組件，再點一次或「全部顯示」回到全部。組合件改變後，視窗顯示「模型已經變更，請重新檢查」（以文件與解的參照比對），不自動重算。
15. 一組零組件有幾個零件對重疊，體積相加。某一組算不出來時整組放棄並列在「算不出這幾組」，不會報出一半的體積。

### 檢查模型幾何（5e）

16. 零件：開啟的本體。組合件：每個零件檔各檢查一次（排列與鏡射的複製品和它的種子同一個形狀，不重複）。「有問題」＝ OCCT 有效性檢查沒過、有開放邊、體積為零或負，或有壞面。壞面編號從 1 算起，和測量工具一樣。

## 已知限制與發現

- **夾具本身有干涉。** 夾具裡削邊銷的 r = 5 本體站在板的 r = 4 孔裡，每支約 405 mm³。這是測試夾具的幾何，不是工具的錯；因為它們在同一個次組合件裡，頂層比對看不到。**次組合件內部的干涉目前不檢查**（使用者的決定是頂層單位）；要檢查，把次組合件展開成頂層，或之後加選項。
- 干涉只用布林共同體積；不報「間隙過小」。尺寸很小的重疊（< 1e-3 mm³）不報。
- 距離只給核心找到的第一個最近點對，兩個元素有很多等距的點對時（兩個平行面）點在哪裡不固定。
- 質量與測量沒有用過第三方零件檔（只用自己寫的與金樣）。多本體零件的檢查是整個形狀一起，不分本體。
- 測量的夾角是銳角（見上）；沒有單位設定，數字固定顯示到 10⁻⁴ mm。
- 干涉檢查沒有進度，也不能中途取消；大組合件算的時候按鈕停用。
