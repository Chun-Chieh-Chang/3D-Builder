# ADR 0057：標準件圖庫（Phase 4a-4，F6.1，Schema 不變）

- 狀態：已實作並驗證（2026-10-03）。限制見最後一節。
- 相關：[phase4a-plan](../phase4a-plan.md)、[ADR 0013](0013-mate-ui.md)（插入零組件）、[ADR 0050](0050-parts-list-and-exploded-view.md)（零件表讀料號）、[ADR 0056](0056-dowel-pin-holes.md)。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **新套件 `@3db/library`**（依賴 `model`、`i18n`，登記在分層表）：三種標準件——內六角螺絲 ISO 4762（M3–M12）、圓柱定位銷 ISO 8734（Ø2–Ø10，m6）、平墊圈 ISO 7089（M3–M12，一般系列）。`standardPartDoc(spec)` 回傳**零件文件**，用一般的指令建出來 | 不另寫一種「圖庫件」：它就是零件檔，插入、結合、零件表、STEP 輸出全部沿用 |
| 2 | **尺寸是變數**：螺絲 `d dk k L s t`、銷 `d c L`、墊圈 `d1 d2 h`；草圖每個點用「到原點的距離」釘死，距離值是變數的運算式（`d/2`、`L-c`），所以草圖完全定義，改變數零件就跟著變 | 一個尺寸只存一處（標準的表在程式裡，件裡只有變數） |
| 3 | **每個件是一條剖面繞 y 軸旋轉**；螺絲頭上再切一個內六角（六邊形的點用 `s/sqrt(3)` 等運算式釘死）。面依剖面的線命名，名稱是常數 `STANDARD_FACES`（例如螺栓桿 `revolve1:side:sketch1.shank`、墊圈孔 `…bore`），結合直接用 | 持久命名文法本來就依產生它的線命名 |
| 4 | **原點在結合時最有用的地方**：螺絲的頭下面、墊圈的底面、定位銷的頂面（銷往下）；螺絲向下、頭向上 | 預設放在原點時方向就合理 |
| 5 | **不建螺紋**；螺絲沒有尖端導角、頭上沒有倒角，定位銷兩端是 45° 導角（c 取 ISO 8734 的值）；材質是碳鋼（7.85）；零件屬性有 `料號`（`ISO 4762 M6x20`，零件表直接讀）與 `Standard` | 「主要尺寸」的範圍：夠做干涉、餘隙與零件表，不為了螺紋的外觀把檔案做大 |
| 6 | **用的時候才做檔案**：「插入零組件」的屬性管理員多「標準件圖庫」：種類、規格、（長度）、「做出並選取」。按下去在專案資料夾的「標準件」資料夾寫出 `ISO 4762 M6x20.3dbx`（已經有就直接用），再當作清單中選到的零件，之後照一般插入。那一下點擊就是讓瀏覽器可以寫入的點擊 | 專案自己帶著它用到的標準件，換電腦、交給別人都不缺檔 |
| 7 | **廠商 STEP 圖庫＝專案資料夾**：插入清單本來就列出專案資料夾下的 `.3dbx`、STEP 與 `.3dba`（STEP 當作零件，3b-3），把廠商的 STEP 放進專案資料夾就在清單裡，也可以「瀏覽」。沒有另做一個「圖庫資料夾」索引 | 藍圖 F6.1 的「本機廠商 STEP 圖庫」要的是這個結果；多一個索引只多一份要同步的資料 |

## 驗證（證據）

- **零件**（`tests/phase4/library.test.ts`，32 項）：螺絲 7 個規格（長 20）、定位銷 7 個規格（長 24）、墊圈 7 個規格，各自重算沒有問題、形狀有效、**體積等於手算**（螺絲＝頭圓柱＋桿圓柱−內六角 (√3/2)·s²·t；銷＝圓柱−兩端導角環；墊圈＝環）到 6 位小數；M6 長 10／35／80；螺絲的範圍（頭下面在原點，桿向下 −30、頭高 8、頭 Ø13）；銷的範圍。
- **圖庫給的東西**：名稱依標準寫（`ISO 4762 M6x20`、`ISO 8734 6m6x20`、`ISO 7089 M6`）與零件表讀的料號相同、材質；尺寸是變數，改 `L` 25、墊圈 `h` 3 的體積對手算；存檔重開相等；規格與長度不合時的訊息；每種的 STEP 輸出再輸入體積不變。
- **結合**：每個命名的面都在；螺絲穿過墊圈：桿在墊圈孔內、頭下面貼墊圈上面，結合全成立、螺絲落在高 1.6（墊圈厚）、與軸心對齊。（同軸心要用「自動」的對正，也就是介面建議的那一種；兩個圓柱面的軸向在這兩個件上相反。）
- **瀏覽器**（`tests/e2e/phase4-library.js`，0 Console 錯誤）：新組合件→插入的屬性管理員有「標準件圖庫」→ 做出墊圈 M6（寫出 `標準件/ISO 7089 M6.3dbx`，第一個零組件固定）→ 清單裡有它→ 做出螺絲 M6×20 → 墊圈體積與料號正確 → 用結合的屬性管理員選面：同軸心與重合都是建議的類型 → 兩個結合成立、螺絲在 y = 1.6。
- `npm run check`：1042 項通過。

## 限制與未做

- **只有三種、尺寸有限**：沒有六角螺栓、螺帽、彈簧墊圈、肩螺絲、T 槽螺栓、夾鉗等；螺絲 M3–M12、長度 6–80；銷 Ø2–Ø10、長度 6–80。表值手打自標準，使用前請對照公司標準。
- **沒有螺紋、沒有銷的端面細節**；螺絲沒有頭下圓角與尖端導角。
- **圖庫件做出來之後是普通零件檔**：改尺寸要改它的變數；圖庫不會「更新」它做過的檔案（再按一次只會選到已有的）。
- **沒有廠商資料夾索引、沒有廠商料號資料庫**（決定 7）；零件表的廠商欄要使用者自己填（零件的屬性）。
- **沒有「螺絲穿過孔」的自動結合**：圖庫只做出零件，結合照一般流程（結合的屬性管理員會建議同軸心與重合）。
