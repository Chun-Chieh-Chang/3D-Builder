# ADR 0068：曲面本體與核心的曲面方法（Phase 4b-1，C9.2–C9.4、C8.1，零件 Schema 28）

- 狀態：已實作並驗證（2026-10-03）。限制見最後一節。
- 相關：[phase4b-plan](../phase4b-plan.md)、[ADR 0067](0067-surface-validation.md)（技術驗證，這裡把它做進 `@3db/kernel`）、[ADR 0003](0003-occt-binding-gaps.md)。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **核心的曲面方法**（`Kernel`）：`gapReport`、`offsetFaces`（面或區域，縫成殼再偏移）、`offsetSolid`（整個實體，包成實體）、`knit`、`fillSurface`、`flatSurface`、`thicken`、`cutWithSurface`、`splitByProjection`（分割線）、`toBSpline`。做法是 ADR 0067 驗證過的；每個方法用手算（圓柱、方塊、球、圓錐）測試 | 先有核心，特徵與介面接在上面 |
| 2 | **間隙量測是每個曲面方法的一部分**：偏移結果取網格點量到來源的距離（`BRepExtrema_DistShapeShape`，對實體量的是邊界，不是實體本身），與要求的距離差超過 `SURFACE_TOLERANCE`（0.05 mm）就失敗，訊息說出量到的誤差與距離。圓弧接合時每一點都該是 `distance`；交會（尖角）接合時角上本來就比較遠，只檢查「比要求的近」；厚面檢查最遠點是厚度、體積為正、一個實體 | ADR 0067：失敗時 OCCT 給「有效但錯」的形狀 |
| 3 | **曲面本體**：沒有實體的本體（`BodyState.surface`，只由特徵標記，不存進檔案）。**它不是零件**：實體特徵（填料的合併、除料、組合）不碰它；**質量特性**、**零件表**（`referenceOnly` 現在包含曲面）、**干涉與餘隙檢查**（`shapesOf` 只取非曲面的本體）、**工程圖的視圖**（與參考本體一樣被排除）都不算它；STEP 輸出時當殼輸出（`SHELL_BASED_SURFACE_MODEL`，沒有實體）；設計樹標「（曲面）」；本體的材質改為雙面顯示 | 與參考本體（工件）的處理一致：設計用的輔助，不是要做的東西 |
| 4 | **偏移曲面特徵 `offsetSurface`**（C9.2，零件 Schema 28）：`faces`（同一個本體的面）、`distance`（運算式，不能是 0）、`join`（圓弧或交會）；結果是一個新的曲面本體，編號是特徵的編號，原本體不動。面的名稱 `<特徵>:offset:<來源面的名稱>`，接合處加的面以產生它的邊命名 `<特徵>:offset:{…}`，所以改工件的尺寸之後偏移跟著走。指令 `setOffsetSurface`。**介面（選面、顯示間隙量測）在 4b-3**，這裡只有核心、模型與重算，所以沒有地方可以新建這個特徵（檔案裡有就能開、能重算） | 曲面本體的規則需要一個真的會產生曲面本體的特徵才能測；計畫原本把特徵放在 4b-3，現在把它的核心部分提前 |
| 5 | **投影分割**（`splitByProjection`）：投影沿草圖的方向、`BRepProj_Projection` 會同時給視線兩側的線，**只取視線指向的那一邊**（沿視線的距離為正），預設只取最近一層，可選穿透全部；穿過週期面接縫的區域被切成兩個面，用 `UnifySameDomain` 合併並**保留分割線的邊**；回傳區域面的編號 `regions`（邊全是分割線的邊的面）。命名在 4b-2 | ADR 0067 |
| 6 | **轉成 B 樣條**（`toBSpline`）：OCCT 的轉換器對「繞著自由曲面邊的圓弧接合面」（本身已是 B 樣條）會中止（`function signature mismatch`），所以包成錯誤（`轉成 B 樣條失敗`）；有圓角的工件的偏移（接合面是環面）轉得過去（誤差 < 1e-3 mm）。STEP 輸出時用不用它、失敗時怎麼辦，在 4b-5 接進輸出時決定 | 驗證時的意外：已轉成 B 樣條的面再轉會失敗 |
| 7 | **OCCT 的偏移結果要複製**：偏移得到的形狀引用建構它的物件所持有的資料，建構物件釋放後再讀（轉換、評估）會出錯；結果以 `BRepBuilderAPI_Copy`（連幾何）複製後才放進登錄；面的來源對應用 `Generated`／`Modified` 對到複製後的面（`ModifiedShape`） | 實測：釋放建構物件之後轉換就失敗 |

## 驗證（證據）

- **核心**（`tests/phase4b/surfaces.test.ts`，23 項）：間隙報告（兩平行面差 5：最小＝最大＝平均＝5、與期望的偏差）；圓柱 R10×20 的側面外偏 3 是 R13、面積 2π·13·20、間隙偏差 < 1e-5、來源是那個面，內偏 3 是 R7；方塊頂面外偏 5 保持大小、移動 5；圓柱頂加側（區域）偏 3：3 個面、面積＝頂 π·10² ＋ 側 2π·13·20 ＋ 四分之一環面（Pappus：(3π/2)·2π(10 + 6/π)），每個面都有來源；交會接合；拒絕（沒選、距離 0、面不存在）；**拒絕時說出量到的誤差**（腰縮到 Ø8 向內 5），柔和的腰（Ø50、Ø30、Ø44）內外 3 都通過（誤差 < 1e-4）；整個方塊 10³ 外偏 3：圓弧接合 10³ + 6·100·3 + 12·(π·3²/4)·10 + 4/3·π·3³ ＝ 3761.33、交會接合 16³ ＝ 4096、內偏 2 是 6³ ＝ 216、當刀具減掉的體積等於它的體積；縫織（方塊六個面縫成實體 1000；五個面是開殼，4 條自由邊、面積 500）；平坦曲面（頂面的四條邊是 100，不連成圈與不平都拒絕）；填補（球 R30 上 Ø16 的洞：相切時偏差 < 0.05 mm，只給邊線 > 0.5 mm）；厚面（圓柱側面向外 2 是 π(12² − 10²)·20、向內 2 是 π(10² − 8²)·20、最遠點 2；自由曲面的厚面有效、最遠點 20；實體與零厚度被拒）；以曲面除料（z = 25 的平面在 100×100×60 的方塊：下半 250000、上半 350000，方向為零與實體被拒）；轉成 B 樣條；投影分割（圓錐側面上的矩形：4 個面、區域面積＝積分 213.148（差 1e-2 以內）、其餘＝側面總面積減區域、來源正確；投影方向相反時說投影不到；穿透全部時兩個區域、5 個面）。
- **特徵**（`tests/phase4b/offset-feature.test.ts`，7 項）：圓柱旁多一個曲面本體（沒有實體、面積 2π·13·20、圓柱不變、名稱 `os1:offset:e1:side:s1.c`）；跟著模型（半徑 12、偏移 5 → R17）；實體特徵不碰它（頂面上的貫穿除料只切圓柱、曲面完整）；區域的三個面（名稱含以邊命名的接合面）；錯誤（沒選、面不見、兩個本體、距離 0 輸入時被拒）；腰 Ø8 向內 5 是錯誤且訊息有量到的誤差、可以承受的距離就成功；STEP 輸出是殼（`ADVANCED_FACE`、沒有 `MANIFOLD_SOLID_BREP`）。
- **瀏覽器**（`tests/e2e/phase4b-surface.js`，0 Console 錯誤）：開啟圓柱加偏移曲面：設計樹的本體標「（曲面）」、質量是圓柱的 π·10²·20、新工程圖的前視圖是圓柱（20 寬，不是曲面的 26）。
- **舊測試**：零件 Schema 27 → 28（`dowel-hole` 的版本檢查改用常數）。`npm run check`：1252 項通過。

## 限制與未做

- **沒有介面**：偏移曲面特徵要等 4b-3 才能從介面建立；沒有選區域、間隙量測結果的顯示。曲面本體在零件表、質量、干涉、工程圖、設計樹各處的規則已做；**衍生零件**（`derivedBody`）取曲面本體、**組合件中零件的顯示**（會把曲面當零件的一部分畫出來）還沒有決定。
- **轉成 B 樣條在自由曲面邊的圓弧接合會失敗**（ADR 上的第 6 點）；STEP 輸出怎麼處理在 4b-5。
- **偏移的命名**只測了簡單的區域；多個面、偏移後再被其他特徵引用的命名穩定性要到 4b-3、4b-4 用特徵串起來才知道。
- **效能**只量了小件；幾百個面的工件沒量（ADR 0067）。
- **雙面顯示是整個本體的材質**（所有本體都雙面），不只曲面本體；選取時會點到背面的情形沒有逐一確認（最近的面仍然先被選到）。
