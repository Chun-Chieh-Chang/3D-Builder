# ADR 0060：工程圖文件與標準視圖（Phase 5-1，C16.1、C16.2，工程圖 Schema 1）

- 狀態：已實作並驗證（2026-10-03）。限制見最後一節。
- 相關：[phase5-plan](../phase5-plan.md)（範圍、預設假設）、[ADR 0011](0011-assembly-skeleton.md)（組合件文件與專案資料夾）、[ADR 0054](0054-derived-bodies.md)（衍生零件的主模型也跟著讀）。

> 2026-10-26：新建工程圖的預設已依使用者要求改為第三角法；既有檔案保留儲存的投影設定。下文第一角預設為當時決策紀錄，最新現況見[產品現況](../project-state.md)。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **工程圖是第三種文件 `drawing`**（`@3db/model/src/drawing.ts`，Schema 1，檔案 `.3dbd`，容器同零件與組合件，`readAnyDocumentFile` 以內容分辨）。**文件只存意圖**：圖頁（A4–A0、橫直向、第一角或第三角、比例 n:d）、標題圖塊的 8 個欄位、視圖清單（`source` 是零件檔相對於工程圖檔的路徑、`direction`、可選的 `at`、`scale`、`hidden`）。**不存任何線條** | 一值一處：線條由模型重算，零件改了，開啟工程圖就跟著改 |
| 2 | **指令**：`setSheet`、`setTitle`（空字串＝拿掉）、`insertViews`、`setView`（`at: null`、`scale: null` 是「回到自動排版／圖頁比例」）、`deleteViews`；驗證 ID、路徑、視角、比例（1 到 1000 的整數比）；刪除的 ID 不再發出；復原與重做一步一個指令（`DrawingHistory`） | 沿用零件與組合件的做法 |
| 3 | **視角**：`viewVectors(name)`——前視從 +z 看（y 向上）、上視從 +y 看（零件的後方在圖紙上方）、右視從 +x 看（零件的前方在左邊）、左、後、下、等角。與 SolidWorks 的基準面（前基準面法向 +z、y 向上）一致 | 夾具與零件都是照這個座標建的 |
| 4 | **精確隱藏線**：`Kernel.projectView`（`HLRBRep_Algo`＋`HLRBRep_HLRToShape`）把形狀變成「可見」與「隱藏」的折線（x、y，圖紙座標，全尺寸 mm）；可見＝尖銳邊＋平滑邊＋曲面輪廓，隱藏同。**被可見線完全蓋住的隱藏線拿掉**（背面的外框、孔底的圓），否則圖上是實線底下多一條虛線，DXF／PDF 也重複畫。邊以 `GCPnts_TangentialDeflection` 切成折線（容差預設 1e-3 倍大小、最多 0.05，角度 0.1 rad）。`projectDrawingView`（`@3db/regen`）把幾個零件放到位置上（鏡射零組件也可）再投影 | 5-0 驗證；藍圖 A4.4 |
| 5 | **圖頁與排版**（新套件 `@3db/drawing`，只依賴 model 與 i18n，主執行緒可用）：`sheetMetrics`（ISO 5457：左邊 20、其他 10，A2 以上 20；標題圖塊 180×48 在框內右下，11 格四列；繪圖區在標題圖塊上方）、`layoutViews`（有自己位置的視圖照位置；其餘依正投影排成網格——**第一角：上視在前視下方、右視在前視左邊、左視在右邊、後視再右一格**，第三角相反；等角視圖放在最外側；視圖相距 25 mm；整組置中在繪圖區；視圖照比例量大小）、`suggestScale`（標準比例 50:1 … 1:100 中，整組放得進繪圖區的最大者） | ISO 128／5455；排版是衍生資料，不存 |
| 6 | **場景是唯一的輸出來源**：`buildScene(doc, lines)` 產生圖紙座標的折線（每條有線型 `visible｜hidden｜center｜thin｜frame｜dimension`）與文字；SVG（螢幕與輸出）、之後的 DXF 與 PDF 都從它寫出，所以三者不會不一致。線型的線寬與虛線依 ISO 128（可見 0.5、隱藏 0.25 虛線 3＋1、中心線點劃、框 0.7） | 5-5 的 DXF／PDF 要有同樣的幾何 |
| 7 | **Worker 與 App**：`drawingViews(requests)`（零件以內容鍵建好；排除參考本體，除非零件只有參考本體；每個請求一個結果，失敗是錯誤字串，不拖累其他視圖）；App 端 `DrawingStore`（同 `AssemblyStore` 的結構）：讀來源零件（含衍生零件的主模型，內容鍵與 4a-1 相同，視窗回來時重讀改過的）、請求線條（以「內容鍵＋視角」快取，一個一個來、只留最新）、新建圖時**線條都算出來後自動選最適比例**、存檔（另存時把視圖的來源路徑改成從新位置看到同一個檔）、`exportSvg` | 沿用既有的零件讀取與重算機制 |
| 8 | **介面**：檔案→「新工程圖」（目前開啟、已儲存、沒有未存變更的零件，在它所在的資料夾；前、上、右三視圖，標題圖塊填上零件名稱與材質）；左側面板：圖頁（大小、方向、投影法、比例、「最適比例」）、標題圖塊 8 欄、視圖清單（選取、改視角、刪除、顯示隱藏線、回到自動排版、加入視圖）、輸出 SVG；畫布：SVG 在灰色桌面上，滾輪縮放、拖曳紙張平移、**點視圖選取、拖曳視圖移動**（放開時位置成為它自己的）、符合圖頁、復原與重做。「開啟舊檔」可開 `.3dbd`；一次只開一份文件 | 沿用零件與組合件的文件模式 |

## 驗證（證據）

- **文件**（`tests/phase5/drawing-document.test.ts`，11 項）：初始值、插入與驗證（ID、路徑、視角、比例、名稱）、`setView` 的 `at: null`／`scale: null`、刪除後 ID 不再發出、圖頁與標題圖塊、復原重做、`.3dbd` 正典文字讀回相同、以內容分辨三種文件、拒絕非工程圖與較新版本。
- **圖頁與排版**（`tests/phase5/drawing-layout.test.ts`，14 項，位置手算）：A3 橫向的框 `{20,10,390,277}`、標題圖塊 `{230,10,180,48}`、繪圖區 `{28,66,374,213}`；11 格的面積合起來是 180×48；前視 100×60、上視 100×40、右視 40×60 的第一角排版——前視中心 (247.5, 205)、上視 (247.5, 130)、右視 (152.5, 205)；第三角相反；1:2 時大小減半、間距不變；有自己位置的視圖留在原處；等角與後視的位置；不存在的視圖不佔位置；最適比例（140×100 在 A3 是 1:1，小零件 10:1，800×500 是 1:5）；場景含框、標題、視圖線條（移到視圖位置的座標手算）、不畫隱藏線的視圖、SVG 的結構（尺寸、y 翻轉、文字跳脫、每條折線一個元素、虛線）。
- **真實零件的視圖**（`tests/phase5/drawing-views.test.ts`，7 項）：金樣定位板（120×80×15、4×Ø9、2×Ø8、R10 角、C1）：前視 120×15 且孔的隱藏線在 x = ±54.5、±45.5、±44、±36（全高）；上視 120×80、六個孔的圓都被可見線畫滿（> 99%）、沒有隱藏線；右視 80×15（圖紙 x ＝ 模型的 −z）；兩個零件放在一起、鏡射零組件；不洩漏形狀。
- **核心的 HLR**（`tests/phase5/hlr.test.ts`，5 項）：見 5-0。
- **瀏覽器**（`tests/e2e/phase5-drawing.js`，0 Console 錯誤）：開零件→「新工程圖」→ 三個視圖、標題是零件名、比例 1:1、視圖大小 120×15／80 深／80 寬、A3 橫向的 SVG 有線條與虛線與標題文字、上視在前視下方且相距 25 mm、右視在前視左邊；移動上視到 (300, 120) 再回到自動排版；A4 與回 A3、第三角時上視在前視上方；用面板寫材質 S45C，復原與重做；存成 `.3dbd` 並重新開啟，一樣；輸出 SVG。
- `npm run check`：1100 項通過。

## 限制與未做

- **只畫零件與 STEP 檔**：組合件當來源（組合圖）在 5-4 與零件表、號球一起做；目前選到組合件說明原因。
- **沒有剖面、投影、細部放大視圖**（5-2）、**沒有尺寸與註記與表格**（5-3、5-4）、**沒有 DXF 與 PDF**（5-5，目前只有 SVG）。
- **視圖的位置只有「自動」與「自己放」兩種**：沒有對齊父視圖的限制（投影視圖在 5-2 才有）；拖曳不貼齊。
- **一張圖頁、一個標準（ISO 128 線型、第一角預設）**；沒有圖層與線型的編輯、沒有多頁、沒有自訂圖頁格式。
- 視圖線條沒有「來自哪個邊」的資訊，所以尺寸要在 5-3 以三維元素為準（風險 4 的備案）。
- 比例限 1 到 1000 的整數比；`suggestScale` 只看標準比例。
