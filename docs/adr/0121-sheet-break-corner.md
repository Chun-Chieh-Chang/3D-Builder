# ADR 0121：鈑金斷開角落（C11.4，零件 Schema 50 → 51）

- 狀態：**已由 [ADR 0161](0161-sheet-metal-break-corner.md) 取代**（2026-10-21，使用者裁決）。本文件保留為當時的決定紀錄，現行的架構與驗證以 0161 為準。

## 決定

1. 新增獨立 `breakCorner` 特徵，以持久邊參考、`chamfer | fillet`、正尺寸記錄意圖；舊文件 50 → 51 空轉遷移。
2. v1 僅接受邊線凸緣自由端、與板厚方向平行且未縮短／未封閉／未斜接的外角邊。每筆角落逐一分類；無法唯一分類即拒絕整個特徵。
3. 折疊幾何重用 kernel 的倒角與圓角。成功的材料差沿用 `Engine.advance` 存為 `SheetInfo.cuts`；平板型式把切除剛性映射到展開後的平直凸緣區，DXF 沿用既有輪廓處理。
4. 不新增角落專用展開 metadata 或第二套 2D cutter。若 cut 無法映射，遵循現有 cut 資料流的錯誤處理。
5. PropertyManager 提供多邊選取、倒角／倒圓與共用尺寸；工具只在包含基材凸緣的零件啟用。

## 限制

不支援基材外角、內角、摺邊、凸緣面選取、縮短端、閉合角落、斜接角落、自動收集角落及一般非鈑金倒角／圓角。若切除跨入折彎區，展開映射會依通用鈑金切除流程回報。

## 驗證

`tests/phase7/break-corner.test.ts` 覆蓋 2 mm 倒角與倒圓的折疊體積差、平板面積差、有效實體及展開線／弧。完整 `npm run check` 尚待重新執行；人工手冊項目為 I5。
