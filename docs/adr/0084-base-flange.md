# ADR 0084：鈑金參數與基材凸緣（Phase 7-1，C11.1，零件 Schema 36）

- 狀態：已實作並驗證（2026-10-04）。限制見最後一節。
- 相關：[phase7-plan](../phase7-plan.md)、[ADR 0083](0083-sheet-metal-validation.md)（折彎是旋轉的矩形、K = 0.5 的體積守恆）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **特徵 `baseFlange`**（零件 Schema 36）：`sketch`、`thickness`（板厚）、`radius`（**內側**折彎半徑）、`kFactor`（0 到 1）、`depth`（板寬，開放輪廓才用）、`reverse`（沿法向的另一邊）、`flipSide`（板厚長在走向的右邊）。全是運算式（變數可用，例如 `gauge`、`gauge * 2`）；新的規則 `unitInterval`（0 到 1，K 因子）；指令 `setBaseFlange`（整組設定）；草圖要在特徵之前。**鈑金參數放在這個特徵上**，之後的凸緣繼承；一個零件只能有一個基材凸緣（第二個報錯） | 單一來源；SW 的鈑金參數也在第一個特徵 |
| 2 | **封閉輪廓是一片平板**：草圖的封閉區域（含孔）沿法向拉出 `thickness`，以填料合併；沒有折彎 | 最簡單的基材 |
| 3 | **開放輪廓是一條折過的板**：草圖是一條直線折線，轉角由 `bentPath`（`@3db/sketch`）倒圓，再用現有的 `ribbonOf`（薄件的偏移，線與弧都是精確偏移）向一側加厚，沿法向拉出 `depth`。**倒圓的半徑看轉角朝哪邊**：轉向板厚長的那一邊，路徑是折彎的外側，倒 `r + T`；轉離，路徑是內側，倒 `r`；兩個面的弧同心，所以板的**內側半徑永遠是 `r`**。切點離轉角 `ρ·tan(φ/2)`；一段太短放不下兩端的折彎報錯、說要多少；轉角接近 180°（折回去）、路徑裡有弧都報錯 | 重用薄件的偏移；內側半徑是工程圖與規格上的那個 |
| 4 | **折彎資料在這裡開始登記**：`RebuildResult.sheet`（`SheetInfo`）：板厚、半徑、K，每個折彎一筆（`SheetBend`：名字 `bend1`…、角度、內側半徑、板厚、寬度、K、**折彎裕度 = 角度·(半徑 + K·板厚)**），與開放輪廓的**展開長度 = 直段總長 + 折彎裕度總和**（封閉的平板是 `null`）；特徵的訊息（PropertyManager）說出來 | 平板型式從這份資料算（計畫的「特徵原生」）；7-2 起的凸緣會接著登記 |
| 5 | **命名**：路徑的直線面叫 `<特徵>:side:<草圖>.<線>`，它的另一面 `….<線>_l`（板厚往右時 `_r`），折彎的兩個面 `….bend<k>` 與 `….bend<k>_l`，板的兩端 `….<第一條線>_s`、`….<最後一條線>_e`，兩個側面 `<特徵>:cap:start`、`:end`。**改板厚、半徑、K 因子後名字集合不變** | 持久命名；沿用薄件的命名 |
| 6 | **介面**：功能區新的「鈑金」頁，「基材凸緣」（選一張草圖後可用）；PropertyManager：板厚、折彎半徑（內側）、K 因子（0 到 1）、板寬（開放輪廓）、板厚往另一側、反轉方向、說明；訊息裡有展開長度 | 計畫 §設計 |

## 驗證（證據）

- **特徵**（`tests/phase7/base-flange.test.ts`，11 項；T = 1.5、r = 2）：平板 60 × 40 × 1.5 = **3600 mm³**、一個實體、`sheet` 是無折彎的平板；有孔的平板 (2400 − 25π)·1.5；反轉往 −z。**U 形槽（路徑是外側面，外寬 60、外高 20、長 40）：T × (2(20 − R) + (60 − 2R) + 2·(π/2)(r + T/2)) × 40 = 5678.3 mm³**（R = r + T = 3.5）、4 個圓柱面、一個有效的實體、外包盒 0..60 × 0..20 × 0..40；折彎資料：兩個 90°、內側半徑 2、寬 40、裕度 (π/2)(2 + 0.5·1.5)，**展開長度 94.639**（K 0.5）、K 0.4 時 94.168（兩個裕度各短 (π/2)·0.1·T），折起來的體積不變；**三種形狀（U 形、45° 單折、兩個折彎的階梯）在 K = 0.5 時 體積 ÷ (T·寬) = 展開長度（1e-6）**；45° 的折彎：裕度 (π/4)(r + K·T)、切點長 (r + T)·tan 22.5°，體積對手算；板厚往另一側：路徑是內側面（腿 20 − r、底 60 − 2r），板長在路徑外面（x −1.5 到 61.5）；名字（直線面、`_l` 面、`bend1`、`bend1_l`、兩端、兩個側面）全有、不重複，**改成板厚 2、半徑 3、K 0.35 後名字集合相同、體積對手算**；拒絕：路徑裡有弧、一條腿太短（說「要 3.500」）、折回去、開放輪廓沒填板寬、兩個輪廓、第二個基材凸緣；K = 1.2、板厚 0、半徑 −1 在輸入時就被拒；變數 `gauge` 驅動板厚與半徑（`gauge * 2`），改變數後全部跟著；版本 36。
- **瀏覽器**（`tests/e2e/phase7-flange-ui.js`，全部通過）：開啟一張 U 形折線草圖、選草圖、「鈑金」→「基材凸緣」：預設的板；板寬 40、半徑 2：U 形槽體積 5678.3，PropertyManager 說「展開長度 94.639」；K 0.4：94.168、折起來的體積不變；板厚往另一側：路徑成為內側面的體積；半徑 20 太大：說「太短」；改回 2；✔ 後設計樹有基材凸緣。
- `npm run check`：1426 項通過、21 項略過（`tests/phase6/snap-vent.test.ts` 的版本斷言改成不釘死最新版）。

## 限制與未做

- **只有「第一個特徵」**：沒有邊線凸緣（7-2）、摺邊（7-3）、離隙與角落（7-4）、平板型式的顯示與輸出（7-5、7-6）；折彎資料只有基材凸緣的折彎。
- **開放輪廓只能是一條直線折線**：路徑裡的弧、分叉、多條開放輪廓都不行；折彎半徑對整個零件是同一個（個別折彎的半徑要等邊線凸緣的覆寫）；轉角接近 180° 的折回做不出來。
- **板厚往哪一邊**取決於折線的走向（草圖的哪一端先走），與薄件相同的限制：預覽看哪邊不對就按「板厚往另一側」。
- **平板的長度在板的寬度方向不變**：折彎資料假設整條折彎是矩形（寬度一致）；基材凸緣的輪廓本身有斜邊或寬度改變時（封閉輪廓的平板沒有折彎，不影響）以後再處理。
- K 因子仍是輸入：K = 0.5 以外的展開長度與公式一致，不是與實體一致（ADR 0083）。
