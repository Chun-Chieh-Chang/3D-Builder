# ADR 0139：座標尺寸、尺寸對正與自動排列（D-I4）

- 狀態：**已完成（2026-10-15）**，工程圖 Schema 15 → 16。
- 需求追溯：[ADR 0129](0129-drawing-interaction-roadmap.md) 的 D-I4；差距分析見 [docs/drawing-interaction-gap-plan.md](../drawing-interaction-gap-plan.md)。

## 背景

尺寸一個一個按需標上去以後（ADR 0134），數量一多就會互相交疊。SolidWorks 有三件工具處理這個問題：
- 「自動排列尺寸」（Auto Arrange）；
- 「對正」（共線對正、平行／同心對正）；
- 「座標尺寸」（Ordinate Dimension）：多個孔的位置從一個原點量起，每個值各在自己的延伸線上，原點寫 0。座標尺寸是 ISO 129-1 寫孔位的標準寫法。

本專案原本這三樣都沒有。

## 決定

1. **新的尺寸種類 `ordinate`**（`@3db/model`）：
   - 欄位：`axis: 'x' | 'y'`、`origin: DrawingRef`、`refs: DrawingRef[]`、`offset`。
   - 由命令層拒絕的情況：
     - 沒有量任何元素；
     - 同一元素出現兩次，或量到原點自己；
     - 超過 `ORDINATE_MAX = 64` 個元素；
     - 使用配合等級（座標尺寸量的是位置，不是尺寸大小）；
     - 方向不是 x／y；
     - `offset` 為 0 或不是有限值。
   - `dimensionRefs(d)` 是所有程式取得「尺寸指向哪些元素」的唯一入口，原點排第一。
   - 工程圖 Schema 升到 16。遷移不需要轉換任何資料；升版本是為了讓舊程式不去打開它畫不出來的檔案。
2. **畫法**（`@3db/drawing` 的 `ordinate`）：
   - 每個元素到原點的距離沿視圖的 x（或 y）量取，各自一條延伸線，延伸到視圖框外 `offset` 處的一排。
   - 文字太近時，延伸線會折一下，讓文字至少相隔 1.5 倍字高，且保持元素的順序。整排會重新置中在元素所在的位置，讓擠在一起的文字向兩邊散開。
   - 平面必須和量測方向垂直，否則說明原因（`drawing.ordinateNotAcross`）。
   - 拖曳把手和線性尺寸相同，所以整排可以拖遠或拖近。
3. **怎麼標**：
   - 「座標尺寸」工具：第一個點選的是原點，接著點要量的元素，最後點一下圖紙空白處。
   - 方向由游標位置決定：在視圖上方或下方就是 x，在旁邊就是 y；其他位置取元素分布較廣的方向。
   - 不接受輪廓線（它沒有位置可量）。
   - 規則都寫在純函數 `planOrdinate` 裡。
   - 「從模型標註」新增「座標尺寸」選項：勾選後，孔位改用兩個座標尺寸（x 從最左邊的平面量起，y 從最下面的平面量起，都包含最遠的那一側，所以總長也會寫出來）取代線性的位置尺寸和總尺寸。同方向、同原點的座標尺寸不會重複加入。
4. **自動排列與對正**（`arrange.ts`，純函數）：
   - 只改尺寸畫在哪裡（`offset`、`slide`），從不改它量的是什麼，所以任何數值都不會因此改變。
   - **自動排列**：
     - 範圍是同一視圖、同一方向、同一側的水平與垂直線性尺寸。
     - 依跨距由短到長往外排，最短的離視圖最近。各排從 `FIRST_OFFSET` 起，每排相隔 `OFFSET_STEP`，文字回到中間。
     - 排列的結果再排一次不會有任何改變（冪等）。
   - **共線對正**：選取的尺寸套用第一個的 `offset`。視圖、方向或側邊不同的尺寸留在原處，並列入 `skipped`。
   - **平行對正**：對選取的尺寸做自動排列。
   - 每一次排列或對正都是一個 `batch`，也就是一步復原。

## 驗證

- `drawing-arrange.test.ts`：
  - 黃金定位板的尺寸隨機打亂 100 次（同種子，打亂後原本就有 25 次交疊），排列後都是 0 交疊、數值不變、排第二次沒有變化。
  - 每一側各排依跨距排序。
  - 共線對正：skipped 名單正確。
- `drawing-ordinate.test.ts`：
  - 黃金定位板 x、y 各一個座標尺寸，值和手算一致，最後一個值分別是 120 和 80。
  - 100 組隨機的擠在一起的點：每個值都等於到原點的距離，文字相隔至少 1.5 倍字高，順序正確。
  - 命令層的拒絕條件；存檔再讀回不變。
  - `planOrdinate` 的方向判斷與拒絕。
- 瀏覽器（真實 UI）：
  - 座標尺寸工具點左平面和兩個孔，得到 `0 / 10 / 110`。
  - 勾選「座標尺寸」後自動標註：x 方向的座標尺寸已經存在而不重複，只新增了 y 方向的 `0 / 10 / 40 / 70 / 80`。
  - 自動排列按鈕可以使用。

## 後果

- 每個列舉尺寸參照的地方（store、測試工具、輸出）都改用 `dimensionRefs`，之後新增尺寸種類只需要改一處。
- 自動排列目前只處理水平與垂直的線性尺寸。斜向（aligned）尺寸、直徑和半徑的位置，以及座標尺寸的排與排之間，還不排列。座標尺寸若和線性尺寸在同一側，可以手動拖開。
