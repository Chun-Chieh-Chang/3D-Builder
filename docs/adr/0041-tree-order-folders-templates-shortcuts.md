# ADR 0041：設計樹的順序與資料夾與註解、文件範本、快速鍵（Phase 3a-9b）

- 狀態：已實作（2026-10-01）。
- 對應：B2.5 調整順序、D1.5 拖放、D1.7 重新命名／資料夾／過濾／註解與標籤、B1.4 文件範本、D3.3 快速鍵，見 [phase3-plan](../phase3-plan.md) §3 的 3a-9。
- **Schema 升為 25**：特徵多了選用的 `comment`、`tag`、`folder`。舊檔不需轉換；已補 v24 樣本 `tests/fixtures/old-versions/v24-material.3dbx`（由 `b4cea8c` 寫出）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **調整順序是一個指令 `arrange`**：給整個新順序（每個特徵恰好一次），和同時要改的資料夾；一個復原步驟。回溯控制棒前面的特徵不能跑到棒後面（先把棒推進到最後）。指令本身只管結構；**「特徵不能放在它依賴的特徵之前」由呼叫的人用 `orderProblem`（`@3db/regen/dag`，由父子關係算出）先檢查**，因為父子關係在 regen 套件（持久命名的擁有者在那裡），model 不能依賴它。放錯的順序若用別的方式進來，重算會在那個特徵上說明錯誤，不會藏起來。 | B2.5 要「受 DAG 約束」；層次規則（ADR 0001）讓檢查只能在上層。 |
| 2 | **拖放（D1.5）**：設計樹的列可以拖；放在別的列的上半是它之前、下半是它之後；放到清單最底下是最後。不能放的（會跑到它依賴的特徵之前、越過回溯控制棒）不動並說明（「『X』不能放在『Y』之前：它是以『Y』為基礎做的」）。編輯中、過濾中、在回溯棒之後的列不能拖。 | |
| 3 | **資料夾（D1.7）**：特徵的 `folder` 是資料夾名稱；**同一個資料夾的特徵在歷史裡要一個接著一個**（指令拒絕分開的）。設計樹在一串同名的特徵前畫一列資料夾（▾／▸ 收合，收合狀態不存進文件），雙按重新命名，右鍵可解散。右鍵特徵「放進新資料夾」、「移出資料夾」；把特徵拖進兩個同資料夾的特徵之間、或放在資料夾某一列的下半，就加進那個資料夾，放在第一列的上半或資料夾之外就離開。 | SW 的資料夾也要連續。 |
| 4 | **註解與標籤（D1.7）**：右鍵「註解與標籤…」；標籤是列後面的小標，註解是 ✎ 記號與滑鼠停留時的提示。**過濾**：設計樹上方的欄位依名稱、類型、標籤、註解篩（不分大小寫）；過濾時只列符合的特徵（不畫資料夾與回溯棒，不能拖）。註解、標籤、資料夾都不影響零件的幾何。 | |
| 5 | **重新命名**：右鍵「重新命名…」（早就有 `renameFeature` 指令，一直沒有介面），在列上改，Enter 確定。 | |
| 6 | **文件範本（B1.4）**：「檔案」→「新零件（範本）…」：空白、碳鋼零件、鋁件（6061）、塑膠件（ABS、細網格）、CNS 製圖（碳鋼、CNS、小數 2 位）。範本就是「選好材質和文件設定的空零件」（`createPartFromTemplate`）；基準面與原點每個零件都有，單位目前只有毫米與度（`displayUnits` 沒有任何地方讀，不提供英制，以免騙人）。使用者自己的範本留給之後。 | 範本要有實質差別才有意義：材質與設定是 3a-8 之後才有的。 |
| 7 | **快速鍵（D3.3）**：「工具」→「快速鍵…」列出所有動作；點欄位按組合鍵（Ctrl／Alt／Shift 加一個鍵）設定，Backspace 清除，與別的動作重複的拒絕並說是哪一個，「還原預設」。選擇存在瀏覽器的 `localStorage`（個人偏好，不進文件）。比對規則：Ctrl 與 Alt 要和寫的一致，Shift 只有寫了才要求（舊的預設快速鍵不受 Shift 影響）。按鈕提示顯示現在的快速鍵。 | 動作登錄（D3.1）是唯一的來源，預設在那裡，覆寫在 `shortcuts.ts`。 |

## 驗證

- `tests/phase3/arrange.test.ts`（11 項）：兩個互不依賴的特徵換位置，一個步驟、零件的體積不變；放到父特徵之前被 `orderProblem` 指出（草圖在它的面之前、伸長在它的草圖之前）；指令拒絕漏的／重複的特徵與越過回溯棒，棒之後的可以自己換；放錯的順序重算時在那個特徵上報錯；復原一步回原樣；資料夾加入、存檔讀回、移出，分開的資料夾被拒絕、不存在的特徵被拒絕；註解與標籤設定、取代、拿掉、存檔讀回、不改幾何；重新命名；範本：五種各自的材質與設定、存檔讀回、可以加特徵。
- `apps/web/test/shortcuts.test.ts`（5 項）：按鍵怎麼寫成組合、Shift 的規則、使用者的選擇蓋過預設／空字串是沒有、衝突、儲存與讀回（壞掉的內容當作沒有）。
- v24 樣本（材質、設定、柱的顏色）開啟、遷移到 25，全部照舊，沒有註解／標籤／資料夾。
- **瀏覽器**（Chromium，真的滑鼠拖放，0 個頁面錯誤）：三個互不依賴的草圖，把第三個拖到第一個上半 → 順序變成 sc、sa、sb；右鍵「放進新資料夾」出現資料夾列；把 sa 拖到資料夾列的下半 → sa 進了資料夾；過濾 "sc" 只剩一列；註解與標籤對話框儲存後列出標籤與 ✎，用標籤 "加工" 能過濾；重新命名在列上改；「新零件（範本）」選塑膠件 → ABS、細網格、沒有特徵；快速鍵對話框按 Ctrl+Shift+E 設到「伸長」，按 Ctrl+Z 被說已是「復原」的快速鍵，localStorage 存了選擇。
- `npm run check` 全過。

## 還沒做

- 同時選多個特徵一起拖／放進資料夾；資料夾收合狀態的記憶；使用者自己的範本（存成範本）；範本的單位（英制要等顯示單位真的有作用）。
- 組合件設計樹的拖放與註解；快速鍵匯出入。
