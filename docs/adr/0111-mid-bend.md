# ADR 0111：中間折彎（S-3，零件 Schema 48）

- 狀態：**已實作並驗證（2026-10-07）**。來源：sheet-metal-drawing-plan 的 S-3；技術驗證在 `tests/phase7/jog-spike.test.ts`（折彎區前不動、折彎區是旋轉的斷面、折彎區後先滑再轉，三塊融合）。
- 零件 Schema 47 → **48**（遷移是空的：新種類的特徵）。

## 決定與做法

1. 新特徵 `midBend { sketch, angle, radius?, reverse?, flipSide? }`（「鈑金」→「中間折彎」，選一張只有一條直線的草圖）：線把板分兩邊，**畫線方向的左邊不動**（`flipSide`：右邊），另一邊繞平行於線的軸轉 `angle`；往草圖法向折（`reverse`：反方向）；軸在折向的那一面外 `radius` 處。折彎**以線為中心**，折彎區寬度是折彎展開長 `BA = θ(r + K·T)`，所以**平板型式就是畫出來的板**。
2. **做法**：用兩個垂直於線的刀具柱把板切成三塊（`boolean common`）：不動的、折彎區、轉的。折彎區必須是單純的長條（斷面是長方形、板厚 × 板在線上的寬）：用體積檢查（`區的體積 = 寬 × BA × T`），否則說「折彎區的斷面不是一個單純的長方形」（折彎區裡有孔、缺口，或寬度在變）。折彎區重做成斷面繞軸旋轉的實體；轉的那一塊先滑到折彎區的起點、再繞同一個軸轉 θ（剛體運動：`Kernel.transformed`，面的順序不變所以名稱帶得過去）；三塊 `fuse`。結果檢查：一個有效實體、體積 = 兩塊 + 折彎體積。
3. **面名**：三塊從原來的板繼承名稱（`common` 的來源），折彎的面以 `<特徵>:side:<草圖>.mid.bend.*` 命名；融合後同一面合併。
4. **平板型式**：`SheetInfo.midBends` 記折彎線兩端（在板平面上）與折向；展開圖用原來的板（`base.regions`）加一條折彎線，方向 `up`／`down`。
5. **限制範圍（說在前面）**：只對「封閉輪廓的基材凸緣做的板」，前面不能有邊線凸緣或摺邊，**一個零件一個中間折彎**，之後也不能再做邊線凸緣或摺邊（這些的平板型式需要沿折彎鏈的剛體運動，這裡沒有）。板要與草圖平行、零件只有一個實體本體。折彎線的草圖要剛好一條直線。介面：面板「折彎角度」「折彎半徑」「固定線的右邊」「往草圖法向的反方向折」，動作在「鈑金」；說明主題 `mid-bend`；手冊 I1 多一步。

## 驗證

- `tests/phase7/mid-bend.test.ts`（8 項）。板 100 × 50 × 1.5、半徑 2、K 0.5、線 x = 50、90°：**體積 7500**（K 0.5 守恆）；折彎外側最大 x = 50 − BA/2 + r + T = 51.340；轉過去那一端的高 = 3.5 + (50 − BA/2) = 51.340；寬度不變；面名不重複；折彎記錄 `{ 90°, 半徑 2, 寬 50, 展開長 4.3197 }`。平板型式：100 × 50、5000 mm²、一條折彎線在 x = 50 長 50、展開體積同摺疊體積。60° 與（120°、半徑 4）仍是 7500；K 0.4、120°：`7500 − BA·50·T + θ·T·50·(r + T/2)`。反方向：最低點 −(2 + 47.84)；固定右邊：最大 x = 100。孔在折彎區外（兩邊都試）：`7500 − π·9·1.5`；孔在折彎區：被拒絕並說明。錯誤：線在板外、一邊沒有板、兩條線、不是平板、前面有凸緣、後面做凸緣、第二個中間折彎。跟著模型：線移到 x = 60、板 140 長。指令：`setMidBend` 的設定、版本號 48。
- 瀏覽器（`tests/e2e/phase7-midbend-ui.js`）：面板、體積 7500、展開長 4.320、換邊與換方向、60°、✔ 後在樹中；孔在折彎區被說明。

## 限制（已知，沒有掩飾）

- 範圍窄（見上）：矩形的板用既有的開放折線基材凸緣就能折；這個特徵只對有孔、缺口的板有用。
- 折彎位置只有「折彎中心線」；SolidWorks 的「材料在內、材料在外、折彎外側」沒有。
- 折過去的那一邊撞到不動的那一邊（折得很大、板很短）靠結果體積與有效性檢查說「撞到」，沒有更細的訊息。
- 折彎區裡的孔、缺口一律拒絕（不是自動做離隙）。
- 零件做完中間折彎後的其他特徵（孔等）在折過的板上；平板型式只用基材的輪廓，之後在板上切的孔不在展開圖裡（與原有的限制相同）。
