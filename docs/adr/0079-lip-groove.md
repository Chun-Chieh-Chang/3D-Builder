# ADR 0079：唇與溝槽（Phase 6-5，C4.11，零件 Schema 33）

- 狀態：已實作並驗證（2026-10-04）。限制見最後一節。
- 相關：[phase6-plan](../phase6-plan.md)、[ADR 0074](0074-plastic-validation.md)（驗證：線的偏移做出環）、[ADR 0078](0078-unequal-shell.md)（殼的邊緣面就是放唇的面）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **特徵 `lipGroove`**（零件 Schema 33）：`face`（一個平面，例如殼的邊緣面）、`kind`（`lip` 唇或 `groove` 溝槽）、`offset`（環離邊緣多遠，0 或更大）、`width`（環的寬度）、`height`（唇的高度，溝槽的深度）。運算式，`offset` 用新的 `nonNegative` 規則（0 可以，負的被拒），`width` 與 `height` 要大於 0；指令 `setLipGroove`；檔案只存意圖 | 與其他特徵一致 |
| 2 | **核心的 `Kernel.ringTool`**：面的外輪廓（`BRepTools::OuterWire`）用 `BRepOffsetAPI_MakeOffset`（`Intersection` 接合，角保持尖）向內偏移 `offset` 與 `offset + width`，兩條線做成有洞的面（外線加反向的內線）就是環，沿面的外法向（唇）或內法向（溝槽要切掉的）長出 `height`。**偏移的方向由結果決定**：線本身沒有「內」，兩個方向都試，取外包比較小的；偏移不出來（面沒有那麼寬、角太小）就說原因。`offset` 是 0 時環從輪廓本身開始 | ADR 0074 |
| 3 | **環要整個在面上**：面（連同它的洞）與環各長出同樣高度後求交集，體積要等於環的體積（1e-6）。殼的邊緣面中間是空腔，環蓋到空腔、或偏移加寬度比邊緣面寬，都被拒絕並說「環超出這個面」；否則唇會一半懸空、溝槽會一半切在空氣裡，體積看起來還是有值 | 安靜的錯誤比報錯更糟（ADR 0078 的教訓） |
| 4 | **工具像一般的填料與除料一樣接上或切掉**（`apply`）：唇是合併（與碰到的本體融合）、溝槽是切；環的面都有名字：**環外側的面叫 `<特徵>:side:ring.<輪廓邊的名字>`，內側加 `~`，遠端的面叫 `<特徵>:cap:end`**——由輪廓的哪條邊偏移出來的決定（最近的邊，從面所在的平面看），所以改尺寸後名字不變；弧線的輪廓（圓角的殼）也一樣，每段弧一個名字 | 持久命名 |
| 5 | **介面**：功能區「特徵」頁的「唇與溝槽」；PropertyManager：面（選擇框，圖面點平面換面，不是平面或特徵自己做出的面被拒）、種類（唇／溝槽）、離邊緣、環的寬度、高度（深度）、環的面積與體積；編輯時顯示特徵自己的結果（訊息框看得到「超出」的原因）。預設：離邊緣 0.5、寬 1、高 1 | 與 4b 的特徵一致 |

## 驗證（證據）

- **特徵**（`tests/phase6/lip-groove.test.ts`，10 項，60 × 40 × 30 殼 2 的盒子，邊緣面寬 2）：離邊緣 0.5、寬 1、高 1.2 的唇——**環的面積 192（59·39 − 57·37）、體積 230.4，本體 15552 + 230.4、一個實體、有效**；說明寫「唇：環的面積 192.00 mm²、體積 230.40」；遠端的面是面積 192、在 z = 31.2 的環，叫 `lg1:cap:end`；環的側面 8 個、其中內側（`~`）4 個、名字不重複；同樣的環往下切 1.2 的溝槽：15552 − 230.4，遠端面在 z = 28.8；離邊緣 0：環從輪廓開始，面積 60·40 − 58·38 = 196；**盒子改 70 寬：環 69·39 − 67·37 = 212、體積對手算、名字集合不變**；**輪廓有弧（四條垂直稜 R5 圓角）：環 192 − (4 − π)(4.5² − 3.5²) = 185.13 mm²（體積差 185.13·1.2、遠端面積 185.13）、16 個側面（每側四直四弧）、溝槽取走同樣的量**；拒絕：環蓋到空腔（0.5 + 2 超過邊緣面的寬）說「超出」、偏移 40 說偏移失敗、圓柱的側面說只限平面、不存在的面說找不到、寬或高不大於 0、離邊緣為負、參照不是面都在輸入時被拒；`setLipGroove`、版本 33。
- **瀏覽器**（`tests/e2e/phase6-lip-ui.js`，全部通過，沒有 Console 錯誤）：開啟殼的盒子、選邊緣面、按「唇與溝槽」：預設的唇，說明「環的面積 192.00」，本體 15552 + 192；改成溝槽：15552 − 192；環寬改 2：特徵出錯、訊息框說「超出」；改回 1；改回唇、高度 1.2：15552 + 230.4；點特徵自己做出來的面被拒（面不變）；✔ 後設計樹有它、體積 15782.4。
- `npm run check`：1368 項通過、21 項略過。

## 限制與未做

- **環只跟著外輪廓**（面的外線）；沿內輪廓（殼的空腔邊）做環、或兩條線之間任意位置的環，沒有做（離邊緣的偏移是從外線量的）。要放在蓋子上與殼的唇對齊，用同一個特徵、同樣的離邊緣，寬度與深度照配合的間隙加大；**這個配合沒有自動做**（沒有「配合間隙」的欄位，也沒有從殼自動產生蓋子的溝槽）。
- **偏移用 `Intersection` 接合**：向內偏移時凸角保持尖、凹角（輪廓向內凹）也是尖的，沒有圓弧過渡；偏移量大過輪廓上的小圓弧半徑時，OCCT 會讓那段消失，環的形狀跟著變，我只驗證了圓角矩形（半徑 5、偏移到 1.5）。
- **輪廓的哪條邊產生哪個面是「最近的邊」**：輪廓上兩條很近的邊（小於環寬的小凸出）可能對錯，名字會互換；沒有這樣的樣本。
- **唇不會自動避開別的特徵**（例如邊緣面上已經有的凸起）：與本體融合後有效就算成功。
- 螺柱、卡榫、排氣口在 6-6、6-7。
