# ADR 0089：平板型式的 DXF 輸出（Phase 7-6，C11.3、F3.1）

- 狀態：已實作並驗證（2026-10-04）。限制見最後一節；**平板型式進工程圖的視圖沒有做**（計畫的選項）。
- 相關：[phase7-plan](../phase7-plan.md)、[ADR 0088](0088-flat-pattern.md)（平板型式）、Phase 5 的 DXF（`toDxf`、`readDxf`、`checkDxf`）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **用工程圖的 DXF 寫法**（AC1015，毫米，控制代碼與表格都齊）：`toDxf(scene, extras)` 多一個 `extras`：自己的圖層（取代線型的那幾層）與在場景的實體之後再寫的實體（`entity`、`g`、`int`、`extent`）。工程圖的輸出不變 | 重用已經驗證過的檔案結構，不另寫一份 |
| 2 | **平板型式的 DXF**（`flatPatternDxf(pattern)`，`@3db/drawing`）：輪廓放 `OUTLINE` 層，用**真的** `LINE`、`ARC`、`CIRCLE`（不是折線；孔是圓、圓角是弧），折彎線放 `BEND` 層（`DASHED` 線型），每條折彎線旁一段註記（`UP 90° R2`／`DOWN …`，沿著折彎線）放在 `TEXT` 層，左下角下方一行 `T=1.5  K=0.5`。**圖形移到左下角在原點**（CAM 好用）。`ARC` 一定是逆時針從起點到終點：平板的弧如果是順時針，兩端對調 | 切割機與 CAD 讀得懂的慣例；折彎線要分層才能不切 |
| 3 | **讀回與檢查**：`readDxf` 認得 `LINE`、`ARC`、`CIRCLE`（`DxfLine`、`DxfArc`、`DxfCircle`），`checkDxf` 不再把它們當成未知的實體；工程圖的 DXF 檢查不變 | 檔案要能被自己檢查 |
| 4 | **介面**：平板型式視窗多一個「輸出 DXF」鈕，檔名 `<零件名>-flat.dxf`，由瀏覽器下載；用的是視窗現在這份報告，所以和畫面上看到的一致 | 同工程圖的輸出 |

## 驗證（證據）

- **特徵與檔案**（`tests/phase7/flat-dxf.test.ts`，6 項，用工程圖的 `readDxf` 與 `checkDxf` 讀回；板 100 × 50 × 1.5、半徑 2）：
  - 90° 凸緣：**檢查器沒有話說**、版本 AC1015；`OUTLINE` 層四條 `LINE`，包住 **x 0 到 127.3197、y 0 到 50**（四位小數）；`BEND` 層一條 `LINE` 在 x = 96.5 + BA/2、長 50；圖層有 `OUTLINE`、`BEND`、`TEXT`，**沒有**工程圖的 `VISIBLE` 等；`DASHED` 線型；標頭的 `$EXTMAX` 蓋住圖形。
  - 註記：`UP 90° R2`、`DOWN 90° R2`（往下折）、`T=1.5  K=0.5`；度的符號寫成 `\U+00B0`，`readDxf` 還原成 °。
  - 縮短與離隙的凸緣：輪廓的每一條線都是一條 `LINE`，端點的集合和平板型式的（移到原點）相同。
  - 板上有孔：一個 `CIRCLE`，半徑 5、圓心 (15, 20)，在 `OUTLINE` 層，外輪廓仍是四條線。
  - 展開的 U 形槽：94.639 × 40，`BEND` 層兩條線在 16.5 + BA/2 與 16.5 + BA + 53 + BA/2，兩條註記都是 `DOWN`。
  - 弧：圓心在原點、半徑 10 的四分之一圓，順時針與逆時針兩種給法都寫成同一條 `ARC`，從 0° 到 90°。
- **瀏覽器**（`tests/e2e/phase7-flat-ui.js`，全部通過）：開窗後按「輸出 DXF」，下載收到的檔案有 `AC1015`、`OUTLINE`、`BEND`、`DASHED`。
- `npm run check`：1474 項通過、21 項略過。

## 限制與未做

- **沒有真的用 CAD／CAM 程式開過**（沒有那些程式）：結構靠 `readDxf` 與 `checkDxf` 驗證，圖層、線型、`ARC` 的方向靠手算；第一步（給使用者）：用你的 CAD 或雷射切割軟體開一個輸出的檔案，看輪廓、折彎線的層與線型、註記、孔與圓角。
- **折彎註記只有方向、角度、半徑**；沒有 SW 的折彎表（折彎編號、順序）、沒有 K 因子與裕度的表；沒有折彎線的端點縮短（SW 的折彎線有時比輪廓短一點）。
- **平板型式沒有進工程圖的視圖**（Phase 5 的圖頁）：只能輸出獨立的 DXF；放進圖頁、標註尺寸要等之後。
- **輪廓沒有排成封閉迴圈**（一堆線、弧、圓，各自一個實體），切割軟體通常會自己接；有些要求迴圈的 CAM 要先接起來。
- 輸出用的是視窗那份報告：視窗沒有開（沒有報告）就沒有可以輸出的檔案。
