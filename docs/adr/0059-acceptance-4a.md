# ADR 0059：4a 驗收——不需要樣本的部分（Phase 4a-6 的 A 段）

- 狀態：A 段完成（2026-10-03）。**B 段（真實工件、廠商定位銷與螺絲、eDrawings 與 SW）沒做**，見最後兩節；4a 閘門因此是「有條件通過」，和 3a-10、3b-7 同樣處理（使用者 2026-10-03 決定：沒有 SW、沒有真實工件，先走完開發，對接時有問題再修正）。
- 對應：[phase4a-plan](../phase4a-plan.md) §驗收（藍圖 4a 四項的可量測版本）。

## 做了什麼

`tests/phase4/acceptance-4a.test.ts`（8 項）把藍圖 §2.9 的夾具工作流從頭到尾走一遍，工件是**這裡做的方塊（一個 STEP 檔）**：

1. **主模型**（零件，3 個本體）：輸入的工件（`importedBody`，標為參考本體，40×30×20，站在基板上）、基板（100×80×15，兩個 Ø6 H7 定位銷孔、入口導角 0.5）、壓板（30×20×10，貼著工件的 +y 側，Ø6.6 孔）。
2. **從本體產生組合件**（`derivedAssemblyFiles`）：3 個衍生零件檔 + 1 個組合件。
3. **圖庫**：2 支 ISO 8734 Ø6 m6 × 20 定位銷、1 支 ISO 4762 M6 × 10 螺絲，以持久名稱結合（銷的側面與基板孔壁同軸心、銷頂與基板頂面重合；螺絲桿與壓板孔同軸心、頭下面與壓板頂面重合）。
4. 干涉、餘隙、取放空間、零件表、STEP 往返；再把主模型的基板改成 20 厚重來一次。

## 驗收中發現的事（測試裡的）

- **面上草圖的原點是零件原點在該面上的投影，不是面中心**（`planeFrame`）。第一版的夾具把孔畫在「壓板頂面中心」，孔落到了別的零件上，工件體積少了 376 mm³；這是夾具設計時要小心的地方，不是程式的錯，但值得在介面上提示（還沒做）。
- **孔會切到它碰到的每個本體**（ADR 0022）：板加厚後，壓板孔的刀具切進了基板。這是設計上的行為，驗收裡照實算。
- **同軸心的對正方向**（同向／反向）要和後一個結合配合：測試用面的幾何算出該用哪一個（介面上就是使用者按的「同向對齊／反向對齊」）。

## 沒有顯示的（誠實的限制）

- **不是真實的工件與廠商件**：工件是這裡做的方塊；定位銷與螺絲是圖庫的主要尺寸（沒有螺紋、沒有廠商的細節）。真實的 STEP 工件（曲面、多實體、單位、修復）與廠商的標準件 STEP（多實體、名稱、顏色）要使用者提供。
- **沒有人工對照**：沒有在 SolidWorks 或 eDrawings 開啟輸出的組合件；沒有真人用滑鼠與鍵盤走一遍整個夾具工作流（各里程碑的瀏覽器腳本是用程式驅動屬性管理員的呼叫）。
- **衍生零件不即時更新**（ADR 0054）：驗收裡改主模型是重新開檔；在同一個編輯階段內不會跟著動。
- **沒有「夾鉗動作」的檢查**：限制結合（4a-2）與拖曳碰撞（4a-5）可以一起用來檢查夾鉗，但沒有拿一個真實的夾鉗機構驗證（旋轉的取放軌跡也沒有，ADR 0058）。
- **Phase 3 的補驗收仍然順延**（3a-10 真實零件、3b-7 B 段、桌面版人工驗收），4a 建在它們沒被真實檔案驗證的層上（輸入、組合件、評估）。

## 還沒做（需要你）

1. **一個真實的夾具案例**：工件 STEP（含曲面更好）、你在 SW 做的夾具截圖、你常用的廠商定位銷與螺絲的 STEP。拿到之後第一步是把真實工件放進主模型（`importedBody`）、標為參考本體，走 `tests/phase4/acceptance-4a.test.ts` 的同一條流程，看輸入修復、衍生零件、結合、干涉與餘隙的實況。
2. **eDrawings（或 SW）開啟輸出的組合件 STEP**，目測階層、位置與顏色。
3. 真人走一遍：新零件做主模型 → 「從本體產生組合件」→ 從圖庫插入 → 結合 → 干涉／餘隙 → 改主模型，回報不順的地方。
4. 對照你的標準：圖庫的尺寸表（ISO 4762／8734／7089）與定位銷孔的公差表（ISO 286-1 H6／H7／H8、m6／h6／h8）。
