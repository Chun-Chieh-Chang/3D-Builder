# ADR 0134：新工程圖從空白圖頁開始，先選主視圖，尺寸按需標註（D-V2）

- 狀態：**已完成（2026-10-14）**。
- 需求追溯：使用者在 2026-10-14 提出：「SW 的工程圖尺寸是按需標註，而不是自動產生，工程圖的生成應該保留更多用戶的自由度。而且 SW 的做法是，讓用戶先選定一個主視圖後，再從主視圖按需拉出其他視圖。」延續 [ADR 0131](0131-drawing-views-by-pointer.md)（D-V）。

## 事實核對（第一性原理）

- **尺寸**：「新工程圖」**本來就不會**自動產生尺寸（`store.newDrawing` 只插入視圖和標題）；尺寸只在使用者按「自動標註」時才產生。問題在介面：尺寸群組最上面就是四個自動標註勾選框和按鈕，看起來像主要流程。
- **視圖**：使用者說得對。「新工程圖」會直接放好前、上、右三視圖（組合件則是前視、等角加上零件表），使用者沒有機會選主視圖。

## 決定

1. **新工程圖是空白圖頁**（零件和組合件都一樣），只寫入標題欄（名稱、材質）。`DrawingSource.paletteSource` 讓空白圖頁的調色盤知道是哪個零件：`loadSources` 會載入這個來源，`paletteSource()` 在沒有模型視圖時就用它。這個值**不存進檔案**：存一張空白圖頁再打開，調色盤會顯示「還沒有零件」，要重新從零件建立。
2. **先選主視圖**：視埠的提示和 PropertyManager 的訊息框都寫著「先選主視圖」。從右側調色盤拖出主視圖後，自動進入投影模式（D-V），按需要拉出其他視圖。第一個視圖放好後仍會自動選擇比例（`autoScaleWhenReady`，比照 SW 放第一個視圖時決定圖頁比例）。
3. **「標準三視圖」**（SW 的 Standard 3 View）改成一個**按需使用的指令**（`addStandardViews`），放在工作窗格調色盤的下方。在空白圖頁上使用時，同樣會自動選擇比例。
4. **組合件的零件表**改成放好視圖之後，從註記群組加入（`addBomTable`，按鈕原本就有）。
5. **尺寸按需標註**：尺寸群組最前面是「智慧型尺寸」，附一句按需標註的說明。自動標註收進可展開的「依模型自動標註（模型項次）」；用下拉清單建立尺寸的那幾列也收進「從清單選元素建立」。欄位都留在 DOM 裡。
6. **e2e**：共用工具新增 `H.newDrawing(directions?)`。不帶參數時會**按下真正的「標準三視圖」按鈕**，所以這些腳本同時驗證了這個新指令；帶參數時就放指定方向的視圖。13 支假設「新工程圖 = 三視圖」的腳本都改用它；`phase5-assembly` 改成放前視與等角，再加入零件表。

## 驗證

- 瀏覽器（定位板）：
  - 新工程圖：0 個視圖、0 個尺寸；提示「先選主視圖」；「標準三視圖」可以按；標題是「定位板」。
  - 把前視拖到 (160, 200)：放在那裡，比例 1:1，並進入投影模式。
  - 游標移到它下方再點一下：多出投影視圖（下），主視圖沒有移動；尺寸仍然是 0 個。
  - 截圖確認畫面正常。
- 受影響的 17 支瀏覽器腳本 **17/17**；全量 vitest **2681 過、0 失敗**；typecheck 與三項 lint 通過。
