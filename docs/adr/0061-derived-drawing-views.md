# ADR 0061：投影、剖面與細部放大視圖（Phase 5-2，C16.3，工程圖 Schema 2）

- 狀態：已實作並驗證（2026-10-03）。限制見最後一節。
- 相關：[phase5-plan](../phase5-plan.md)、[ADR 0060](0060-drawing-document-and-views.md)（文件、排版、場景）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **視圖變成四種的聯集（Schema 2）**：`model`（來源檔與視角，Schema 1 的視圖原樣就是它，**v1→v2 沒有要轉換的東西**）、`projected`（`parent`、`side`）、`section`（`parent`、`line`、`flip`、`label`）、`detail`（`parent`、`centre`、`radius`、`label`）。衍生視圖**不存來源與視角**：來源是往上找到的根視圖的檔，視角由母視圖與種類算出（`sourceOf`、`axesOf`）。剖面線與細部圓的座標是**母視圖的視圖座標（全尺寸 mm）**，所以改比例或移動母視圖它們不動 | 一值一處；衍生視圖不可能與母視圖不一致 |
| 2 | **投影視圖的視角**（`projectedAxes`）：第三角，放在哪一側就從哪一側看（放在右側＝右視）；第一角相反（放在右側＝左視）。從衍生視圖再投影也成立（以母視圖的右向與上向算）。排版時它放在母視圖的那一側、相距 25 mm（同側的往外疊），**與母視圖對齊**：兩者共有的是模型原點，所以模型原點在圖紙上同高（左右側）或同一直線（上下側） | ISO 128-30；對齊靠幾何，不靠儲存的位置 |
| 3 | **剖面線與箭頭**：剖面線只能水平或垂直（`drawing.sectionAxisOnly`）；箭頭在「從第一點走向第二點的右手邊」（`sectionArrow`），`flip` 換邊；剖面視圖**順箭頭方向看**（`sectionAxes`），被拿掉的是觀看者那一側的材料；**切平面**（`sectionPlane`）過剖面線、與母視圖垂直、法向朝觀看者。第三角放在觀看者那一側（與箭頭相反），第一角放在箭頭指的那一側（`sectionSide`） | 與 SolidWorks 的剖面視圖方向一致 |
| 4 | **核心的剖面**（`Kernel.sectionView`）：一個遠大於零件的方塊放在平面的觀看者那一側，`boolean('cut')` 拿掉那一側，剩下的以 `projectView` 投影（隱藏線規則同 5-1），**切面的外框**（落在切平面上、朝向觀看者的平面的所有邊，含孔的內圈）以視圖座標折線給出（`ProjectedView.cut`）。切不到任何東西時 `cut` 是空陣列、整個零件照原樣看到 | 沿用已驗證的布林與 HLR；不另寫切割 |
| 5 | **剖面線**（`hatch`，`@3db/drawing`）：45° 細線、**奇偶規則**（外框與孔的內圈一起給，孔裡不畫）、半開區間（過頂點的線只算一次，不會有未成對的線）、間距 `HATCH_SPACING`（圖紙 mm，不隨比例變）。純 2D 函式，可以單獨測 | 切面積可用線長×間距手算驗證 |
| 6 | **細部放大圖**（`clipToCircle`）：不問 Worker，用母視圖的線條裁成圓內的部分（精確交點）；它的**範圍是圓的外接框**（不管裡面剛好有什麼），自己的比例（App 預設是母視圖比例的兩倍再取上一個標準比例）、放在母視圖旁。圓畫在母視圖上並標字母，標題是「字母 (比例)」 | 細部的大小不隨零件的細節而變 |
| 7 | **場景**：母視圖上畫剖面線（中心線型）、兩端的箭頭與字母；剖面視圖下方寫「A-A」、剖面線用細線；細部的圓與字母畫在母視圖上；剖面視圖預設不畫隱藏線（`showsHidden`，可以開）。`layoutViews` 與 `suggestScale` 認得衍生視圖；`resolveLines` 把細部的線條從母視圖裁出來 | 同一個場景給 SVG、DXF、PDF |
| 8 | **Worker 與 App**：請求改為 `{parts, axes, cut?}`；`DrawingStore` 以「內容鍵＋視角＋切平面」快取線條，衍生視圖的來源由根視圖決定，細部不問 Worker；`addProjected`、`addSection`（下一個沒用過的字母，預設線在母視圖範圍外多 5 mm）、`addDetail`。面板：選取視圖當母視圖，「投影視圖」（側邊）、「剖面視圖」（垂直或水平線與位置）、「細部放大圖」（圓心與半徑，空白用預設）；選取的視圖可改比例、字母、反向、側邊 | 先用數字輸入，不另做畫布上的拖曳 |

## 驗證（證據）

- **衍生視圖的向量與文件**（`tests/phase5/drawing-derived.test.ts`）：投影視圖的視角（第三角與第一角、從投影視圖再投影）、剖面箭頭（上下左右與反向）、剖面視圖的視角與側邊、切平面（線 x = 40 的前視 → 原點 [40, −5, 0]、法向 [−1, 0, 0]）、根與視角的解析、各種視圖的驗證與刪除連動、`setView` 的種類檢查、v1 檔當 v2 讀。
- **2D 幾何**：`clipToCircle`（弦、離開再回來是兩段、完全在內或在外）、`hatch`（正方形的行數與總長＝面積／間距、45°、挖孔後 84 面積）、`circlePolyline`。
- **真實零件的剖面**：金樣定位板沿 x = 40（過兩個 Ø8 孔）從左邊看：範圍 80×15、孔壁 x′ = ±4、外框都不在孔內，**剖面線覆蓋的面積在手算值 1079 mm² 的 ±1% 內**；不洩漏形狀；平面沒碰到零件時沒有切面。
- **排版與場景**：投影視圖在母視圖旁且模型原點對齊；同側疊放；剖面在第三角與第一角各在哪一側；細部的範圍與裁切；剖面線、字母 `A`×2 與 `A-A`、細線數、隱藏線預設；細部的圓（144 點）與「B (5:1)」。
- **瀏覽器**（`tests/e2e/phase5-views.js`）：用面板從前視圖做剖面（x = 40，字母 A，線 [[40,−5],[40,20]]）、切面外框找得到、範圍 80×15、SVG 有兩個 A 與 A-A 與大量細線、第一角在右側且與前視圖同高；反向後到左側；從前視圖往上投影（第一角即下視，120×80）；細部圓心 (50, 7.5) 半徑 8 比例 2:1、大小 32×32、有 B 與「B (2:1)」；刪除與復原；存檔重開後視圖種類與切面都在。
- `npm run check` 全過。

## 限制與未做

- **剖面線只能水平或垂直、只有單一平面**（沒有階梯剖面、旋轉剖面、半剖面）；剖面線與細部圓用數字輸入，沒有在畫布上拖曳的做法。
- **剖面線的填充是固定的 45° 細線**（不分材質、不分零件）；組合件剖面時不同零件的線方向也相同（組合件當來源在 5-4）。
- **剖面視圖的隱藏線**繼承 `projectView` 的規則；沒有「剖面視圖中肋與軸不剖」的標準例外。
- 細部放大圖是**裁切母視圖的線條**，不是重新投影：圓邊的圓弧折線取樣精度是母視圖的（放大後可能看得出折角，之後可依放大倍率重取容差）。
- 輔助視圖（斜向投影）與斷面圖沒有做。
