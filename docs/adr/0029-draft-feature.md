# ADR 0029：拔模特徵（Phase 3a-5c）

- 狀態：已實作（2026-10-01）。3a-5（特徵 I）到此完成。
- 對應：C5.5 拔模（中立面）；分模線拔模、階段拔模是 P2，不做。見 [phase3-plan](../phase3-plan.md) §3 的 3a-5。
- **Schema 升為 16**：新的特徵種類 `draft`（`neutral`、`faces`、`angle`、`reverse?`）。舊檔不需轉換；已補 v15 樣本 `tests/fixtures/old-versions/v15-shell.3dbx`（由 `bba1d3f` 寫出）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **拔模特徵＝中立面 ＋ 要拔模的面 ＋ 角度 ＋ 反轉**。中立面是本體上的平面（面的持久名稱）或基準面；要拔模的面是持久名稱的清單。 | 與使用者選的範圍相同（2026-10-01）。 |
| 2 | **方向的定義**：拔模的方向是從中立面指向本體裡面（中立面是面時為它外法向的反方向；基準面時為它的法向）；**角度為正，壁離中立面越遠越窄**（模具脫模的斜度）；`reverse` 讓壁離中立面越遠越寬。與伸長的拔模（ADR 0027）用同一個核心函式（`Kernel.draftFaces`，`BRepOffsetAPI_DraftAngle`，中性面是中立面所在的平面）。 | 一個方向的規則，伸長與拔模特徵一致。 |
| 3 | **面保持原來的身分**：核心用 `ModifiedShape` 找到每個被拔模的面變成哪一個，名稱完全不變；沒拔模的面原封不動。 | 後面的圓角、導角、草圖參考不會因為拔模而失效。 |
| 4 | **一串切線相連的面（圓角）要一起選**，一起拔模，圓角的面會變成圓錐面等，仍有效（ADR 0017 驗證過，現在有回歸測試）；不夠的面組（非切線相連）未驗證，OCCT 不做時報錯，不猜。 | 沿用 ADR 0017 的範圍。 |
| 5 | **錯誤**：沒選面（選取框空）、中立面不是平面、找不到（遺失參考）、與拔模方向平行的面（例如上蓋）不能拔模（「第 n 個面不能拔模」）、角度必須在 0° 到 90° 之間（指令拒絕）。 | 每個失敗都有可讀的原因。 |
| 6 | **介面**：「特徵」分頁的「拔模」；第一次在圖面點的面是中立面（若開啟前已選了一個面就是它），之後點的面加入或取消「要拔模的面」；「重選中立面」；角度與「反轉」。 | 一個選取框就能完成，不需要額外的步驟按鈕。 |

## 驗證

- **手算體積**（`tests/phase3/draft.test.ts`，6 項）：20×10×10 的塊，四個壁繞底面拔模 3°：W·D·H − (W+D)·t·H² + (4/3)·t²·H³；反轉為 + 號的那一個；繞頂面拔模得到同樣的窄的那個（離中立面越遠越窄）；只拔兩面時 W·D·H − W·t·H²。
- **名稱與命名回歸**：拔模前後每個面的名稱完全相同；一個壁加圓角（R3）後把壁與圓角面一起拔模 2°，結果有效、名稱不變，之後在上蓋邊緣再倒圓角找得到邊線。
- **改尺寸不壞**：塊加寬到 30，體積仍符合公式。
- **錯誤**：選取框空、與拔模方向平行的上蓋、不存在的中立面、95°。
- **舊檔**：v15 樣本（示範件加薄殼）開啟、遷移到 16，薄殼照常重算。
- **瀏覽器**（`tests/e2e/phase3-draft.js`）：點頂面（成為中立面）、四個壁（用 `store.execute` 放進清單，因為三個壁在任何一個視角都被擋住）、3° → 1846.439（手算 1846.4388），反轉 → 2160.885；0 特徵失敗。
- **一個在做樣本時發現的問題**（記在 ADR 0028 的未做事項之外，已修）：薄殼若開口的面旁邊有圓角，OCCT 會回報完成卻把原本的本體原封不動交回來，結果「薄殼成功」但什麼都沒變。現在沒有任何新產生的面就當作失敗，並說明（「開口的面旁邊有圓角時常見」，請改選別的面或先薄殼再倒圓角），有測試。

## 還沒做

- 分模線拔模、階段拔模（P2）、「面延伸」選項（沿切面）。
- 非切線相連的面組、曲面（例如球面）的拔模行為只有 OCCT 的成敗，沒有更聰明的處理。
- 拔模的預覽（編輯時顯示拔模之前的模型，按確定才看到結果，與圓角相同）。
