# ADR 0093：螺柱孔的拔模、摺邊不算「最小半徑」（鞏固 H-4，零件 Schema 41）

- 狀態：已實作並驗證（2026-10-04）。兩件事都是使用者選的（選項 A）。
- 相關：[hardening-plan](../hardening-plan.md)、[ADR 0080](0080-screw-boss.md)（螺柱）、[ADR 0082](0082-acceptance-6.md)（驗收找到孔沒有拔模）、[ADR 0090](0090-gauge-checks.md)（檢查）、[ADR 0091](0091-acceptance-7.md)（摺邊半徑不過）。

## 決定 1：螺柱孔另外給拔模角

`ScrewBossFeature.holeDraft?: Expr`（角度，要在 0 到 90° 之間）：孔往孔底縮小，`holeDiameter` 是**孔口的直徑**；空白＝直孔（和以前一樣，既有的檔案不變，所以不需要遷移）。孔壁於是是圓錐面（名字還是 `….hole`）；到孔底孔徑縮到零以下就說「孔的拔模太大」。外壁拔模（`draft`）照舊往頂端收，兩個角度各自獨立。介面：螺柱的 PropertyManager 多「孔的拔模（空白＝直孔）」，外壁有拔模而孔不同時，旁邊有「同外壁」鈕把外壁的角度填進去。

**為什麼是 A（另外給）**：不悄悄改既有零件的幾何（B 會讓已存的螺柱孔變斜）；外壁與型芯針的角度實務上常不同；「同外壁」鈕省掉填兩次。

### 驗證

- `tests/phase6/screw-boss.test.ts`：孔口 Ø2.5、深 10、拔模 1°：孔底半徑 1.25 − 10·tan 1° = 1.07545，孔的體積是圓台 π·10/3·(rh² + rh·rb + rb²)，螺柱的體積 = 外壁的圓柱 π·R²·10 − 孔的圓台（5 位小數）；孔壁是圓錐；孔與外壁同時有拔模時兩者各按各的算；孔拔模 15°（深 10 的孔收不到底）被說。
- `tests/phase6/acceptance-6.test.ts`（②b）：金樣外殼的螺柱孔拔模 1° 之後，拔模分析（拉 +z、要求 0.5°）**螺柱沒有任何一面需要拔模**，兩個孔壁都是「正拔模」、角度 **+1.000°**（和其他內壁一樣）。這是 ADR 0082 找到的缺口的證明。
- `tests/e2e/phase6-boss-ui.js`：孔拔模 1° 的體積對手算；外壁 2° 後按「同外壁」孔的拔模變成 2°；清空後回到直孔的體積。

### 注意

拔模分析的「要求的拔模角」預設 1°：孔拔模設 0.5° 時分析仍會標「需要拔模」，要把要求的角度調低。這是分析的設定。

## 決定 2：摺邊不參加「最小半徑」檢查

`sheetChecks` 的 `bendRadius` 略過 180° 的折彎（摺邊）：真實的摺邊不是用那個半徑彎出來的（預折再壓平），「內側半徑」對它不適用，ADR 0091 的金樣因此有一個假警報（半徑 0.5 對板厚 1.5）。摺邊折回的平直段仍由 `flangeLength` 檢查（≥ 4 倍板厚）。**沒有新增摺邊專屬的規則**：我沒有可靠的數值來源，等有工廠的規定再加（使用者同意，選項 A）。

### 驗證

- `tests/phase7/manufacturing.test.ts`：半徑 0.5 的摺邊沒有 `bendRadius` 檢查、有一個 `flangeLength`（7 對 6，過）；同樣小的半徑的一般折彎仍然被抓到（值 0.5，不過）。
- `tests/phase7/acceptance-7.test.ts`：金樣支架在起始比例下**九項檢查全過**（原本十項過九項）；半徑要求 1.5 倍板厚（2.25）時只有兩個一般折彎不過（90° 與 135° 的凸緣），摺邊不在其中。

## 限制

- 摺邊沒有半徑或間隙的檢查；孔的拔模沒有「和外壁的差」之類的建議值；孔徑指孔口，其他位置（孔底、中段）要自己換算。
