# ADR 0101：螺紋孔與錐孔的孔標註（D-1）

- 狀態：**已實作並驗證（2026-10-07）**。計畫：[drawing-callouts-plan](../drawing-callouts-plan.md) §2。
- 沒有改檔案格式（孔標註每次從零件算出來，不存進工程圖）。

## 決定與做法（第一性原理：形狀說得出的從形狀讀，形狀說不出的從特徵讀）

1. **錐孔讀形狀**：`holeInfo` 在孔口開著的那一端，若隔壁是圓錐、圓錐的另一個圓邊比孔大且同軸，就報 `countersink: {diameter（孔口）, angle（夾角，度）}`。圓錐的半角在核心裡帶正負號，取絕對值。
2. **螺紋讀特徵**：模型只做到攻牙底孔（沒有螺紋），形狀上它就是一個 Ø5 的孔。孔壁面的名字 `<孔特徵>:side:<草圖>.<點>.wall` 隨編輯保留，所以 `holeFeatures(doc, sources)` 建立「特徵 id → {種類, 規格}」表，`elementFacts`／`viewFeatures` 多一個選用參數 `features`，查到 `tapped` 就加 `thread: {size?}`。Worker 的 `BuiltPart` 帶這張表（包括衍生本體的主模型：衍生本體沿用主模型的面名，所以主模型做的孔也算）。
3. **定位銷孔的入口導角不是錐孔**：45° 的導角與 90° 錐孔在形狀上是同一種圓錐；特徵知道這個孔不是錐孔時，`withFeature` 把 `countersink` 拿掉。沒有特徵可查的形狀（匯入的 STEP）維持形狀的讀法，孔口的導角會讀成錐孔（已知限制）。
4. **字**：錐孔 `錐孔 Ø12 90°`（接在貫穿／深、沉頭之後）；螺紋孔的標註取代直徑：`M6 貫穿（底孔 Ø5）`、`M8 深 12（底孔 Ø6.8）`，規格是手填的孔寫 `螺紋底孔 Ø5 貫穿`；不勾「孔標註」的直徑尺寸仍是 Ø5（量到的圓）；螺紋孔的標註不帶公差。孔表同字。英文：`CSK Ø12 90°`、`M6 THRU (TAP DRILL Ø5)`、`TAPPED Ø5 THRU`。
5. **螺紋深度＝鑽孔深度**（模型沒有螺紋，不編造沒有的數字），寫在手冊 F4。
6. **自動尺寸的分組**（順手修的既有缺陷）：同直徑的圓原本一律併成 `N×Ø…`，註記只取第一個；有孔標註時，現在只併「註記相同」的（`holeSignature`：貫穿或深、沉頭、錐孔、螺紋），錐孔的 Ø6 與定位銷的 Ø6 不再併成一個。孔表原本就依此分組，改成共用同一個簽名。

## 驗證

- `tests/phase5/drawing-hole-callouts.test.ts`（15 項，手算）：夾角 82°／90°／100° 讀回誤差 < 0.01°、孔口 Ø12；`錐孔 Ø12 90°`；M6 貫穿、M6 深 12、M8（底孔 Ø6.8）跟著特徵變、規格手填、沒有特徵時就是 Ø5、4×與括號與公差、孔表、衍生本體的主模型、定位銷導角在有特徵時不當錐孔、沒有特徵時當錐孔、自動尺寸分組。
- 原有的 Phase 5 驗收（基板的定位銷孔 `2×Ø6 H7 (+0.012/0) 貫穿` 一字不差）通過；`tests/support/derivedProject.ts` 的 `OpenedPart` 與驗證包產生器都帶 `holes`，如同 worker。
- 瀏覽器（`tests/e2e/phase5-hole-callouts.js`，固定檔 `tests/fixtures/parts/hole-callouts.3dbx`，由 `npm run make:kit` 產生 `孔標註.3dbx`）：自動尺寸與孔表都寫出 M6、M8、錐孔、柱孔、定位銷孔、盲孔的字。

## 限制

- 螺紋深度與鑽孔深度分不開；沒有螺紋精度（6H）、沒有「攻牙深／鑽孔深」兩個深度。
- 匯入的模型孔口的導角讀成錐孔。
- 特徵查不到的螺紋（匯入的、或用「刪除面」改過又重新做的）仍是 Ø5。
- 用語（「錐孔」「底孔」）是我的建議，手冊 K2 待使用者決定。
