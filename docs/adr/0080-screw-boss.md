# ADR 0080：螺柱（Phase 6-6，C4.11，零件 Schema 34）

- 狀態：已實作並驗證（2026-10-04）。限制見最後一節。
- 相關：[phase6-plan](../phase6-plan.md)、[ADR 0074](0074-plastic-validation.md)、[ADR 0078](0078-unequal-shell.md)（殼的底厚改了，螺柱跟著）、[ADR 0079](0079-lip-groove.md)。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **特徵 `screwBoss`**（零件 Schema 34）：`sketch`（草圖，在它的自由點上各做一根柱子，與異型孔精靈同一種取點）、`diameter`（外徑）、`holeDiameter`（孔徑，先導孔）、`height`、`holeDepth`（從頂端往下，沒有就是整個高度）、`draft`（外壁拔模，往頂端收，沒有就是直的）、`ribs`（`count`、`thickness`、`length`、`height`、`angle`）、`reverse`（往草圖法向的另一邊長）。全是運算式，單位與角度照一般的規則；指令 `setScrewBoss`（整組設定，像 `setHole`）；草圖要在特徵之前 | 沿用異型孔的做法（ADR 0056 之前）：旋轉出來的刀具 |
| 2 | **柱子是一個旋轉的截面**：從草圖面下 0.5 mm 開始（埋進它站的本體，所以一定接得上，不會剛好共面而接不起來），沿外壁（有拔模就往頂端收）到頂、沿孔往下到孔底、回到軸；孔底在「高度 − 孔深」：孔深等於高度時孔底就在草圖面上，孔通到殼的底面。以填料（`apply('boss')`，合併）接上；**沒接到任何本體就是錯誤**（「螺柱沒有接到本體」） | 與異型孔、旋轉填料一致；浮著的柱子不能安靜地成功 |
| 3 | **肋是三角形的補強片**：在通過軸的平面上，從柱壁裡面（孔與外壁的正中間）往外沿底面長 `length`、沿壁往上到 `height`，以那個平面為中心拉出 `thickness`；`count` 片平均分布（1 到 8），第一片在 `angle`（0° 是草圖的 x）；肋高不能比柱高。一片一片合併上去 | 補強片是塑膠螺柱的標準做法；幾何簡單可算 |
| 4 | **命名**：柱子的面叫 `<特徵>:side:<草圖>.<點>.<部位>`（`wall` 外壁、`top`、`hole`、`bottom` 孔底，與 `foot`、`base`、`axis` 埋進本體的部分融合後消失）；肋的面是 `<點>.rib<k>.<邊>`（`slope` 斜面，`floor`、`wall` 在柱與底裡面融合掉），肋兩側的面是端面（`<特徵>:cap:start`／`end`，一個以上就以位置編 `#k`）。草圖在面上以名稱找面，所以**殼的壁厚改了，底面往上移，草圖跟著，螺柱跟著** | 持久命名；驗收「改殼的壁厚後螺柱跟著」 |
| 5 | **檢查**：孔徑要大於 0 且小於外徑、孔深不能比高度深、拔模太大以致頂端外徑小於孔徑、肋的數量要是 1 到 8 的整數、肋高不能比柱高，都說原因 | 安靜的錯誤比報錯更糟 |
| 6 | **介面**：功能區「特徵」頁的「螺柱」（選一張草圖後可用，與異型孔同）；PropertyManager：外徑、孔徑、高度、孔深（空白＝到底）、外壁拔模（空白＝沒有）、反轉方向、肋（沒有時一個「加肋」鈕，有時：數量、肋厚、往外長、肋高、起始角度與「去掉肋」） | 與異型孔的面板一致 |

## 驗證（證據）

- **特徵**（`tests/phase6/screw-boss.test.ts`，10 項，60 × 40 × 30 殼 2 的盒子，底面內側在 z = 2）：柱 Ø6、孔 Ø2.5 通到底、高 10：**π(3²·10 − 1.25²·10) = 233.656 mm³ 加在本體上**、一個實體、有效；外壁面積 2π·3·10、中心在 z = 7，頂面環 π(9 − 1.5625) 在 z = 12，名字不重複；孔深 8：π(3²·10 − 1.25²·8) = 243.47，孔底面在 z = 4、面積 π·1.25²；外壁 2° 拔模：圓錐面，體積是圓台 π·10/3·(R² + R·Rt + Rt²) − π·1.25²·10（Rt = 3 − 10·tan 2°）；**三片肋（厚 1、往外 3、高 6）：每片的體積是三角形在柱壁外面的部分，對厚度方向逐點積分算（4000 點），三片加柱的總體積對 1e-3**，肋 0、1、2 的斜面有名字、沒有第 3 片；兩個點：兩根柱子；**底厚改成 3：柱子升高 1（頂在 z = 13），加在本體上的體積不變，名字集合不變**；拒絕：孔與柱一樣寬、孔深超過高度、拔模 20°、肋 9 片、肋高 12 比柱高、草圖放在本體上方 100 的平面（浮著，說沒有接到本體）、高度 0 與外徑為負在輸入時被拒；`setScrewBoss` 改尺寸並拿掉肋、版本 34。
- **瀏覽器**（`tests/e2e/phase6-boss-ui.js`，全部通過，沒有 Console 錯誤）：開啟殼加底面草圖（一個點）、選草圖、按「螺柱」：預設的柱 +233.656；高度改 12、孔深 8、拔模 2°、拔模清空；「加肋」：三片肋、體積增加；數量改 4：第四片的面出現；「去掉肋」；孔徑改成 6：PropertyManager 說孔徑的問題、改回 2.5；✔ 後設計樹有螺柱。
- `npm run check`：1378 項通過、21 項略過。

## 限制與未做

- **孔徑要手填**：計畫的「用圖庫的螺絲查自攻螺絲的底孔」沒有做（圖庫的螺絲是機械螺絲，沒有塑膠用的自攻螺絲的底孔表）；介面上有說明。
- **柱子只站在草圖面上往一個方向長**：沒有「長到另一個面（例如蓋子）為止」的終止條件；柱子的頂端是平的、沒有圓角。
- **肋是三角形補強片**，沒有別的形狀（矩形、梯形、斜撐到內壁）；肋跟著柱，不會自己延伸到內壁或底的邊；肋的第一片的位置只由起始角度決定（沒有「朝向壁」的自動對齊）。
- **柱子與肋會被別的特徵（內壁、其他螺柱）擋到時**由布林處理，結果有效但沒有逐一驗證；兩根柱太近時肋可能重疊，沒有檢查。
- **埋進本體 0.5 mm** 是固定的：在很薄的底面上（< 0.5）埋進去的部分會穿出底的另一面；沒有針對這個的檢查。
