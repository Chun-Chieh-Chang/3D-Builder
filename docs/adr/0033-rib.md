# ADR 0033：肋材（Phase 3a-6d）

- 狀態：已實作（2026-10-01）。
- 對應：C4.7 肋材（一條線的草圖＋厚度＋方向，長到與本體接觸；備案是伸長加布林），見 [phase3-plan](../phase3-plan.md) §3 的 3a-6。**3a-6（特徵 II）到此完成。**
- **Schema 升為 20**：新的特徵種類 `rib`（`sketch`、`thickness`、`side`、`flip`）。舊檔不需轉換；已補 v19 樣本 `tests/fixtures/old-versions/v19-loft.3dbx`（由 `dee7dc8` 寫出）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **草圖要剛好一條直線**（圓弧、兩條以上、沒有線、有封閉輪廓，各報「肋材的草圖要剛好一條直線（現在有 n 條…）」）。肋材的寬度就是這條線的長度。 | 使用者選的範圍（2026-10-01）。折線與弧形的肋材要決定每一段的生長方向，不在這次範圍。 |
| 2 | **做法：把線加上厚度變成一個矩形，沿著「草圖法向 × 線的畫法方向」伸長，長到本體為止，再接上本體**＝既有的「伸長至本體」（`trimAtBody`：刀具減去本體，留下靠近起點的那一塊）加布林接合，**沒有新的 OCCT 呼叫**。矩形放在以線為 x 軸、草圖法向為 y 軸的輔助面上，所以厚度垂直於草圖面，生長方向在草圖面內垂直於線（SW「平行於草圖」的肋材）。伸長的長度取本體在那個方向上的最大延伸 ×1.01 ＋ 1。 | 備案本來就是伸長加布林；「至本體」已有並驗證過，遇到第一個碰到的面就停（有階梯的板，肋材在高的那一半停在塊上、低的那一半停在板上，測試手算）。 |
| 3 | **厚度的位置 `side`**：兩側（以草圖面為中心）、草圖法向的一側、另一側。**方向 `flip`**：預設往「草圖法向 × 線從第一點畫到第二點」的方向長（線畫反方向就反過來），`flip` 反轉。往這個方向本體整個在背後時，說「肋材往這個方向碰不到本體（本體在另一邊）：勾選『反轉方向』」；往這個方向前面有本體但肋材的牆碰不到它，說「肋材沒有碰到本體」。 | 沒有自動選方向：兩邊都有本體時自動選會猜；訊息直接告訴使用者怎麼辦。 |
| 4 | **面的命名**：`<肋材>:side:<草圖>.<線>.neg`／`.pos`（草圖法向負側與正側的牆面）、`.end1`／`.end2`（線的第一點與第二點那端）、`<肋材>:cap:start`（線所在的自由端）。與本體接觸的那一面合併消失。 | 與伸長同一條命名路徑；厚度、長度、本體改了，名稱不變。 |
| 5 | 肋材一律是填料、與接觸到的本體合併（沒有「合併結果」開關、沒有除料）。 | 肋材長到本體上，沒有接觸就不成立；不接觸是錯誤，不是第二個本體。 |
| 6 | **介面**：「特徵」分頁的「肋材」，選一張草圖後按；屬性管理員有厚度（數值框，可用運算式）、厚度的位置、反轉方向；用過的草圖預設隱藏。 | 與其他特徵一致。 |

## 驗證

- **手算**（`tests/phase3/rib.test.ts`，7 項，真的 OCCT）：板上方 15 的線，4 厚 × 20 長 × 15 高：16000 ＋ 1200，牆面的位置（x = ±2、自由端 z = 25）、五個面的名字不重複；厚度在一側（0..4、−4..0）；板下方的線，沒反轉時的訊息、反轉後 15×20×4；有階梯的板，肋材在兩半各停在第一個碰到的面（16000 ＋ 8000 ＋ 600 ＋ 1000）；之後的圓角（先倒板的邊、再倒肋材的邊）找得到、板加厚 2 時體積差 = 40×40×2 − 2×20×4。
- **錯誤**：肋材碰不到本體（線在板側邊）、之前沒有本體、兩條線、一段弧、沒有線、厚度 0；指令：只有肋材可以 `setRib`、厚度為負。
- **舊檔**：v19 樣本（示範件加疊層拉伸）開啟、遷移到 20，疊層拉伸照常重算（兩個本體，總體積 = 示範件 ＋ 20/3·(100+60+36)）。
- **瀏覽器**（`tests/e2e/phase3-rib.js`）：40×30×10 的板、右基準面上 y = 25 的一條線，用 UI 做肋材：12960（手算 12000 ＋ 15×16×4），厚度改 6 → 13440，勾「反轉方向」出現「碰不到本體」的訊息、取消後回到 13440，✔ 之後有 `rib1:cap:start` 等 5 個面的名字、0 個特徵失敗。
- `npm run check` 全過（型別、分層、i18n 基準不增加、全部測試）。

## 還沒做

- 折線與弧形的肋材、「沿著草圖法向」的肋材（線沿厚度方向長）、拔模、肋材兩端延伸到本體的牆（SW 的「延伸輪廓」）。
- 自動選方向；肋材的預覽。
