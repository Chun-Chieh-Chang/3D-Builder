# ADR 0103：爆炸線與爆炸動畫（E-1）

- 狀態：**已實作並驗證（2026-10-07）**。計畫：[assembly-explode-plan](../assembly-explode-plan.md) §2。
- 沒有改檔案格式（兩者都只是顯示）。

## 決定與做法

1. **爆炸線**：每個被爆炸的零組件一條折線，從它的零件（含次組合件的零件與排列的實例）在組裝位置的包圍盒中心（`leavesCentre`：每個零件的局部包圍盒八個角轉到組裝位置再取整體的中心，不依賴零件原點放在哪裡）出發，依序經過每個步驟之後的位置。`explosionOffsets` 多回傳 `paths`（每個步驟之後的累積位移，最後一個等於位移）。`AssemblyStore.explodeGuides()` 算出折線（隨進度縮放），`Viewer.setGuides` 畫成深藍色虛線（`LineDashedMaterial`、不被零件遮擋）。面板「顯示爆炸線」勾選（預設勾、`explodeLines`），只是顯示選項，不存檔。
2. **動畫**：狀態 `explodeT`（0 到 1）是畫面走到哪裡，`exploded` 仍是目標狀態（展開時不能移動零組件、不能編輯結合的規則看目標）。`setExploded` 以半秒（`EXPLODE_MS`）、緩入緩出的 `requestAnimationFrame` 把 `explodeT` 走到 0 或 1；沒有 rAF 的環境（測試）直接跳到終點（`frameRequest` 可替換）。`explodeLeaves(leaves, offsets, progress)` 依進度縮放位移；`leaves()` 的快取鍵改用 `explodeT`；`assembledLeaves()` 在進度為 0 時才等於 `leaves()`（質量與干涉用組裝位置，動畫中也是）。需要組裝位置的操作（`leaveExplode`）立刻把進度歸 0，不播動畫。
3. 開啟「爆炸視圖」面板時視圖以動畫展開；STEP 輸出永遠是組裝位置（不變）。

## 驗證

- 單元（`packages/model/test/explosion.test.ts`，手算）：先沿 Z 爆 50、再沿 X 爆 30 → 折線 (0,0,50)→(30,0,50)、最後一點等於位移；方向找不到的步驟不進折線；進度 0.5 時 (10,0,5) 的銷在 (25,0,30)，進度 0 等於組裝位置、1 等於完整爆炸 (40,0,55)；包圍盒 10 × 4 × 2 轉 90° 放在 (10,0,5) 的中心 (8,5,6)，與原位的同一零件合起來的中心 (5,5,3.5)，沒有盒子時為空。
- 瀏覽器（`tests/e2e/phase3-explode.js`，金樣夾具兩個定位組）：打開時進度走過 0 與 1 之間的值、最後 1；兩個被爆炸的零組件各一條線（移動兩次的有兩段、一次的一段）；關掉「顯示爆炸線」線消失；收合後進度 0、線消失、每個零件的位置與原來逐位元相同、文件的位置位元組不變；其餘（拖曳被拒、STEP 是組裝位置、編輯／搬動／刪除／復原、存檔重開）照舊通過。截圖看得到藍色虛線。

## 限制

- 瀏覽器分頁在背景時（`document.visibilityState === 'hidden'`）`requestAnimationFrame` 暫停，動畫等分頁回到前景才走完（顯示時已經是終點，沒有錯誤狀態）。
- 線從包圍盒中心出發，不是零件的某個特徵點；沒有帶角度或曲線的路徑（每步都是直線）。
- 動畫只有展開與收合，加步驟與改距離時視圖直接跳到新位置。
