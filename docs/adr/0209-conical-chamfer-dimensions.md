# ADR 0209：錐面側視輪廓的連動導角尺寸

2026-10-26。採用。工程圖Schema33；零件84、組合件7不變。現況只維護於[產品現況](../project-state.md)。

## 問題與範圍

使用者先回報平面角落，後續帶邊線塗彩截圖顯示圓軸端部的短斜輪廓。前次短直邊修正只驗證斜角輪廓板，未處理此情境；不能把它的通過當成圓軸導角已修復。錐面投影的側輪廓通常不是模型真正的直線邊，因此舊viewFeatures無參照、planChamfer亦要求along直邊，兩處都缺支援。

SolidWorks／FreeCAD具工程圖導角標註能力是功能參考，這次沒有另行桌面實測或認證；SolidCraft未取得足以確認同等功能的依據，不冒稱三者功能相同。先前實際可讀的資料及讀取限制見ADR0206／0207。

## 幾何、參照與單一真值

原生Topology的cone面必須有兩個完整、同軸的圓形邊界。由原生圓心、半徑、錐軸求端部與軸向距離；不由網格、畫面斜線、特徵名稱或包圍盒猜尺寸。鑽尖、缺完整圓邊的裁切錐面、B-spline近似錐面不合成支援。

錐軸平行圖面時產生兩側有限slant輪廓，附原生面Ref／fingerprint與cone資訊；命中須對應真正可見投影，不能選到無限延長線。它們在元素右鍵只提供可成立的倒角模式。智慧型尺寸的下拉選「倒角尺寸」，點斜輪廓，再點空白處放置；沿用先前短線排除端點搶選。

ChamferDimension新增coneSide=±1，保留選中哪一側；32→33不改舊檔數值。命令與存讀驗證側別／面Ref，不容0、小數、NaN或頂點。沒有新增模型幾何Ref種類，命名／依賴仍是來源面，組合件保留in與局部fingerprint。

ElementFacts新增原生錐面兩圓心／半徑；組合件先變換事實，再依視圖軸與coneSide求輪廓中點。鏡射原生錐軸可能反向，placedViewFeatures將側別對齊來源錐軸，確保選取與重建後的引線在同一側。

錐面尺寸每次求值使用當前模型：size是**軸向退距**，角度是斜輪廓相對錐軸的銳角atan(半徑差／軸向距離)。45°且等退距可用C；非45°強制距離×角度，角度依文字精度排版。模型修改後數字及引線連動，不能取保存時size冒充新量測。面板大小／角度唯讀並顯示求值結果，命令也拒絕覆寫；格式、引線角度／長度及個數仍可編輯。舊平面直邊標註保持既有行為，尚未取得同樣的幾何參數連動。

## 驗證

- 7個相關原生／文件測試檔111項通過，其中新增錐面4項：實際圓柱與原生chamfer、C1與引線側別／存讀、實際模型重建1→2得C2、非等退距的原生圓邊探針與距離×角度、端視拒絕及100組真實旋轉／平移／鏡射（兩側共200次側別／量測比較）。另外新增損壞側別存讀斷言後只重跑該1項通過。沒有放寬容差或期限。
- 瀏覽器兩個流程各有通過紀錄：原平面短邊，以及新建真實圓軸、選原生端面建立0.5mm模型導角、帶邊線塗彩側視圖、公開倒角下拉／實際指標選輪廓建立C0.5、引線位置、唯讀欄位、存檔後將來源模型導角改1mm、重啟原生Worker再開圖顯示C1。最終另加文字位於圖紙內的斷言並調整放置位置，只跑新流程通過。證據`out/cone-chamfer-ui.json`、`out/cone-chamfer-ui-final.json`；最終畫面已檢視。
- 初版測試用錯solver工廠／命令單複數、migration誤插零件鏈與NumberBox尚無disabled支援由型別／測試攔截後修正。模型重建曾得到value=2但text=C1，驗收抓出dimensionText仍取保存size；已改成同一有效尺寸，僅重跑失敗案例，再做相關回歸。失敗後舊形狀控制代碼已釋放的測試隔離問題，以每項重新重建處理，未更改原生門檻。
- Heap使用真實oc.wasmMemory.buffer.byteLength且基準>0；liveShapes只驗暫存變換釋放，不宣稱100次為零洩漏證明。沒有新增核心布林算法，建模沿用原chamfer。
- 型別／Web建置、三靜態守門、文件盤點於提交前驗證。新增檔納入三平台CI，尚未讀取本輪遠端結果，不宣稱三平台已通過。使用者截圖對應原檔未提供，測試使用真實合成圓軸，未全量重跑。

## 能力邊界

支援兩完整圓邊界的解析錐面、真正側視輪廓，以及可見位置與其吻合的剖面輪廓；這次未實機驗收所有剖面種類。任意斜視圖、自由曲面、裁切錐面與螺旋牙邊不在此交付內。沒有以線性投影斜率冒充非真實形狀的製造尺寸；不支援時保持明示失敗。
