# ADR 0129：工程圖交互改進路線（提前 C16 的 P2 項）

- 狀態：**已決定（2026-10-13）**，尚未實作。
- 需求追溯：`docs/blueprint.md` **C16.1、C16.3–C16.6**；分析與規劃見 [docs/drawing-interaction-gap-plan.md](../drawing-interaction-gap-plan.md)（§3 根因、§9 使用者決定）。

## 背景

和 SolidWorks、FreeCAD TechDraw 的工程圖交互逐層比較之後，差距歸納成 4 個根因：
- R1：視圖的線沒有來源邊的身分；
- R2：選取只能選單一 id，沒有依實體切換的屬性頁；
- R3：文件缺少一般註記的元件，也沒有多圖頁；
- R4：一次只能開一份文件。

使用者的圖同時要交給外部加工廠和內部使用，加工圖、組合圖、鈑金圖都要出。

## 決定

1. **提前藍圖的 P2 項**：註解＋引線、基準、ISO 1101 幾何公差（14 個基本符號，含 Ⓜ、Ⓛ）、手動中心線、3/4 圈螺紋線、輔助視圖、斷裂／裁剪／局部剖視圖、任意角度／階梯／對正剖面、座標尺寸、多圖頁、修訂表。
2. **順序是資訊優先**：D-I2 spike → D-I1a 統一選取 → D-I3 註記 → D-I2 有名字的邊 → D-I4 座標尺寸與排列 → D-I7(a) 右鍵開啟零件 → D-I1b 工具列、右鍵選單與工程圖樹 → D-I5 視圖強化 → D-I8 小功能 → D-I6 多圖頁。
3. **尺寸繼續用持久名稱（`Ref`）掛載**，不改用視圖線條的索引（FreeCAD 的斷尺寸問題）。
4. **不做驅動尺寸**：工程圖只存設計意圖，從不改模型（ADR 0060 的不變式）。
5. **不做多文件同時開啟**：關聯修改改用右鍵「開啟零件」，回到工程圖時自動重新整理。
6. 熔接符號維持不做（同 C12）。

## 後果

- Phase 5 的剩餘範圍粗估增加 13–17 週。
- 工程圖 schema 會在 D-I3（`annotations`）與 D-I6（`sheets`）各升一次版，每次都要寫遷移與遷移測試。
- D-I2 的時程取決於 spike：HLR 的邊能不能回推到來源的 `TopoDS_Edge`。做不到就改用幾何比對回推名稱的備案。
