# ADR 0231：伸長除料可「保留輪廓內」

日期：2026-11-03。狀態：已實作。

## 問題與選擇

使用者問：伸長除料只能移除草圖輪廓內的材料，能否選擇移除草圖輪廓**外**的材料。

「輪廓外」在草圖平面上是無界的（沒有框可以框住它），所以「移除輪廓外的材料」若照字面做，需要一個外框——那不是使用者要的。使用者自己把選擇收斂成一句話：**只做「保留輪廓內」的除料選項**。

因此本功能定義為：**除料的結果是本體與伸長所掃過區域的交集**——輪廓內的材料留下，輪廓外的刪掉。這正是 `boolBodies` 早已有的 `common`（交集）運算，`Engine.apply` 因此多了一個 `keep` 動作；一般的除料仍是 `cut`。

既有可直接達成同一結果的路徑是「填料（合併取消）＋組合（交集）」，但那是兩個特徵、兩個本體，且合併取消後的填料是獨立本體；本功能是一個特徵、一步完成。

## 語意

- **交集的是「伸長所掃過的區域」**，不是無限延伸的柱體。方向 1 往材料內（與草圖法向相反）掃，方向 2 往另一邊掃，兩者皆可。掃到哪裡就保留到哪裡：草圖平面另一側的材料不在掃描範圍內，會被刪掉。要兩側都保留，就把方向 2 也設成「完全貫穿」。
- **終止型態必須是「完全貫穿」**。給深度時，深度之外、輪廓內的材料會一併刪掉，與「保留輪廓內」的字面意義相反；這不是可以默默照做的情形，故在命令層與引擎層都明確拒絕（與 `refuseMid2`、`feature.draftNotMid` 同一路數）。命令層的拒絕讓使用者在改壞之前就看到原因，引擎層的拒絕則讓結構性文件（不經命令層進來的文件）失敗時看得到原因。
- **輪廓有孔洞時，保留的是「輪廓區域」**：草圖的區域模型是「外圈減孔」，所以交集只留下環帶，孔中央的孤島（落在輪廓之外）被刪掉。這與一般除料相反——一般除料刪掉環帶、留下孤島。兩者的差異是定義使然，不是例外。
- **拔模（draft）適用，且不必改動拔模的路徑**：拔模是在 `Kernel.sweep` 內對工具實體施加的，發生在任何布林運算之前（`kernel.ts` 的 `sweep`）。因此「保留輪廓內」＋拔模＝一根上粗下細（或反向）的保留柱，語意一致。實測（`tests/phase3/keep-inside.test.ts`）：拔模 3°、方格置於本體內，保留體積 1000 + 2000t + (4000/3)t²（t = tan 3°），與同樣拔模的一般除料所挖走的體積相同。
- **錐度（taper）不適用**：本專案的錐度是螺牙（`ThreadFeature.taper`）與螺旋（`HelixFeature.taperAngle`／`taperOutward`）的參數，不是伸長的參數；獨立的拔模特徵（C5.5）作用於既有本體的面，與本功能無關。

## 資料與命令

零件 schema 87→88 新增可選欄位 `ExtrudeFeature.keepInside`（缺省＝一般除料，舊檔不用改）。新增命令 `setKeepInside`：

- 只有伸長特徵有這個選項（`cmd.onlyExtrudeHasKeepInside`）；只有除料能用（`cmd.keepInsideOnlyCut`）。
- 開啟時若任一方向不是「完全貫穿」則拒絕（`cmd.keepInsideNeedsThroughAll`）；開啟之後改終止型態同樣被拒絕（`refuseKeepInside`，與 `refuseMid2` 並列）。關閉一律可以。

引擎 `Engine.extrude` 在 `keepInside` 時走 `apply(..., 'keep', ...)`：`boolBodies` 改用 `common`，其餘（名稱繼承、本體分裂成多塊時的編號）與一般除料共用。失敗訊息分開說明：輪廓內就是整個本體（`feature.keepInsideNothing`）、輪廓內沒有材料而整個本體被刪掉（`regen.keepInsideAll`）。

屬性面板在除料時多一個「保留輪廓內」勾選框，下方說明其語意與「完全貫穿」的要求。

## 驗證與邊界

- `tests/phase3/keep-inside.test.ts`：保留柱 1000（一般除料為 11000）、孔洞語意相反、單一方向只保留該側（500）與方向 2 也貫穿時保留整根（1000）、拔模的保留柱與一般除料挖走的是同一塊體積、整個本體落在輪廓內時的錯誤訊息、輪廓內無材料時的錯誤訊息、落在輪廓外的本體被整個刪掉並留下警告、命令層的接受與三種拒絕、引擎層對結構性文件的拒絕。
- `tests/phase8/help-examples.test.ts`：說明文字裡手算的 1000 mm³ 由真實模型算出。
- 瀏覽器（`tests/e2e/manual-keep-inside-extrude.js`）：在屬性面板勾「保留輪廓內」，一般除料留下 1440 mm³、勾選後留下 560 mm³（體積由真實模型量出），提示文字說明「全部貫穿」的要求；兩種拒絕都出現在狀態列（改成給定深度被拒、給深度時勾選被拒），而文件維持原狀（終止型態仍是「完全貫穿」、選項仍關著）。
- 邊界：目前只做伸長除料。旋轉除料（`RevolveFeature`）、掃出除料與「組合」的交集不在本功能範圍（組合的 `common` 本來就能做交集）。
