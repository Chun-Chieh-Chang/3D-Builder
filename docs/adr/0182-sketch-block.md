# ADR 0182：固定整個圖元（Block，G8a）

## 1. 背景
2026-10-19 草圖參照盤點的 G8，第二批。2026-10-21 使用者選「做」，並裁決：固定要能一次選多個圖元，每個圖元各加一個。G8 的另一半（圓弧條件的最近／最遠距離）是 ADR 0183。

**現況**：關係「固定」（`fix`）只能固定一個點。要固定一條線得對兩個端點各加一次；圓的半徑、圓弧的弧度完全固定不了，只能再加尺寸。

**別的軟體**：
- SolidWorks 的「固定」可以直接套在線、圓、圓弧上，圖元的位置與大小都鎖住；
- FreeCAD 的 Block 限制條件：把一個圖元的全部自由度鎖在原處。

## 2. 決策（使用者已定：可多選，每個圖元各一個）
1. **新增限制條件 `block`**（`entity`：線、圓或圓弧），Schema 74；一個條件、一個 id，刪除、衝突、過多定義都以它為單位。原有的點的 `fix` 不變。
2. **求解器對應：每個圖元的自由度剛好鎖滿，一個不多一個不少**（多了求解器會報「重複」，少了草圖就定義不足）：
   | 圖元 | 自由度 | 對應 |
   |---|---|---|
   | 直線 | 4 | 兩個端點的座標 |
   | 圓 | 3 | 圓心座標，加半徑 |
   | 圓弧 | 5 | 圓心座標、起點座標，加「圓心到終點的方向」 |
   圓弧不直接固定三個點：圓心加起點已經決定半徑，再固定終點座標會多出 1 個重複限制；終點本來就在圓上（圓弧自己的規則），只要再鎖方向。
3. **值取自文件裡儲存的位置**，與 `fix` 一致；不取求解器的起始值。
4. **選取與一次復原**：
   - 選到的全是直線、圓、圓弧時，面板與右鍵選單提供「固定」，只要還有一個沒被固定就提供；
   - 按下去，每個還沒被固定的圖元各加一個 `block`，**同一個 `addSketchItems`，一次復原全部取消**；已被固定的不再加第二個；
   - 選取裡有點或軸時不提供（點有自己的「固定」）。
5. **固定的圖元不能被移動、旋轉、縮放**（草圖移動／旋轉／縮放，ADR 0178）：圖元本身或它的任一端點在選取裡，一律拒絕並說明原因，與「固定的點」相同；**複製**時複本不帶固定（否則複本會被鎖在原圖元的位置）。
6. 加尺寸、半徑、角度到已固定的圖元，結果是過多定義，由現有的「過多定義」機制回報並說明是哪一個。

**反向對照**（皆已還原）：
- 求解器：不鎖圓弧終點方向，2 項轉紅；圓半徑多鎖一次（重複），1 項；允許移動固定的圖元，1 項；複製帶著固定，1 項；`blockTargets` 忽略已固定的，1 項；`entity` 不算參照欄位，2 項。
- 瀏覽器：把「每次呼叫都新建分配器」放回去，e2e 轉紅；只固定選取中的第一個，e2e 轉紅。

**測試與實作第一版的錯**：
- **實作的錯**：控制器一次產生多個 `block` 時，每次呼叫 `allocator()` 都新建一個分配器，兩個固定拿到同一個 id（`object with id c1#0 already exists`）。單元測試沒有碰到控制器，是瀏覽器腳本抓到的。已改成一個分配器產生全部。
- 測試的錯：`IdAllocator` 建構子要兩個參數；e2e 借用了組合件腳本才有的 `H.ctrl`，改成腳本內自己送 Ctrl+Z。
- 既有測試的預期更新：`interact.test.ts` 選一條線、兩條線、線加圓時，提供的關係清單多了「固定」，這是這項功能預期的改變。

## 5. 已知限制
- 只在選取全是直線、圓、圓弧時提供；選取裡混有點時，要分開加（點有自己的「固定」）；
- 圖元已經被其他限制完全決定時，再按「固定」會變成過多定義，與其他關係一樣被拒絕並提示（`addRelation` 先試算）；只有「已經有 `block`」的才不再提供按鈕；
- 圓弧的「終點方向」以文件裡儲存的終點算出；圓弧很接近整圓（掃過 2π 附近）時終點與起點幾乎重疊，方向仍可算，但這種圓弧的終點本來就難以辨識（隨機壓力測試範圍到 2π − 0.1）。
