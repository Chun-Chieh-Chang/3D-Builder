# ADR 0190：D5 曲面工具

2026-10-24，零件 Schema 79，新增直紋曲面、放射曲面與取代面。

直紋曲面以兩條真正 B-Rep 邊線作軌線，OCCT BRepFill.Face 建立直母線曲面；可反轉第二軌線。先檢查軌線距離及五個對應母線交叉，後檢查有效性與正面積。此有限取樣防線不代表任意複雜自由曲線的全域無自交證明，失敗不放寬容差。

放射曲面以參考平面的法向決定垂直切線方向。支援平行於該平面的直線、圓與圓弧；直線平移、圓形精確改半徑，再建立直紋面，向內塌陷明確拒絕。距離為模型運算式，合法範圍 (0, 1,000,000] mm；反向獨立控制。

取代面以原始實體平面與平行的目標面／基準面求真實位移，沿用既有 moveFace 對鄰面的伸縮／裁切與面命名。目標面視為支撐平面，並非它的有限修剪外框；非平行／非平面與曲面本體拒絕，不以單純替換開放拓樸假裝有效實體。目標基準改變後重算，沒有另一份距離真值。

五項實體／命令案例、兩項壓力案例（100 組直紋＋放射、100 組伸縮）均有通過結果；解析面積、體積、有效性、DAG、參照名稱及版本均有斷言。新增 UI 1/1、help 40/40、型別／lint／build 通過。原始軌線方向相反的測試必須明確使用反向選項，交叉防線保留。未跑全套，只重試失敗項。
