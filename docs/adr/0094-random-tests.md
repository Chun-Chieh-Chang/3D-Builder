# ADR 0094：隨機產生的零件（鞏固 H-5）

- 狀態：已實作並驗證（2026-10-04）。使用者說短期內沒有 STEP 樣本、但想繼續：沒有真實檔案時，能做的最有價值的驗證是**不依賴手算的數字、對任意參數都必須成立的性質**。
- 相關：[hardening-plan](../hardening-plan.md)。

## 做法

四個測試檔（`tests/phase8/fuzz-*.test.ts`）用種子固定的亂數產生器（mulberry32）產生零件，失敗訊息帶種子與參數，重跑同一個種子就得到同一個零件。每個零件檢查：

1. **特徵要嘛成功、要嘛說出原因**：狀態只有 ok／error，error 一定有訊息，而且訊息是程式會說的那幾種；沒有例外、沒有安靜地做壞。
2. **做出來的是有效的實體**，每個面的名字只出現一次。
3. **同一個零件重算一次、存檔讀回再重算，名字集合與體積完全相同。**
4. **鈑金**：K 0.5 時平板型式的體積 = 摺疊的體積（任意參數）；平板型式的面積 × 板厚 = 它的體積；平板型式的 DXF 讀回檢查器沒有話說、範圍與平板型式相同、`BEND` 層的線數 = 折彎數；改 K 因子，摺疊的實體與名字不變。
5. **塑膠**：拔模、底切、厚度三個分析各回一個每個面的結果，類別的面積加起來是整個零件的面積。
6. **一般零件**（塊、圓角、凸台、圖樣、鏡射、貫穿孔）：壓抑一個特徵再恢復，零件與名字回到原來。
7. **有手算公式的兩組**：凸緣上的摺邊（長度、體積、平板大小、父片）；隨機折過的基材（任意轉角與方向，展開長度、體積、折彎資料，含板厚往另一側）。

規模：鈑金 36 個溫和的加 60 個「嚴苛的」（凸緣可以貼在一起、太短、太深：許多被拒絕，這是它們存在的原因：23 個做成、37 個說了原因，三種原因都是對的：凸緣太短、這條邊附近放不下折彎、凸緣撞到板）；鏈與折過的基材各 24 個；塑膠 40 個；一般零件 40 個。全部約一分半鐘。

## 補充（H-7）：STEP 來回與更多特徵

- **STEP 來回**（`tests/support/viaStep.ts`）：每個做成功的隨機零件（鈑金、塑膠、一般、其他特徵共約 190 個）輸出成 STEP、再當成輸入本體讀進來：特徵成功、**體積相對誤差 < 1e-5、面數相同**。沒有真實檔案時，這是唯一能測「輸出再輸入」那條路的方法；全部通過（沒有找到問題）。
- **另一組產生器**（`tests/phase8/fuzz-features.test.ts`，48 個：方塊或圓柱加異型孔（直孔、沉頭孔、錐孔）、倒角、移動面、薄殼）：39 個做成、9 個被拒（都是「孔的點沒有材料可鑽」：薄殼之後從開口那面往下打的盲孔沒打到材料，合理）；重算、存檔讀回、STEP 來回、壓抑再恢復都一致。**沒有找到新問題。**

## 補充（H-8）：疊層拉伸、掃出、旋轉、除料

`tests/phase8/fuzz-solids.test.ts`（72 個，八種）：兩個矩形的疊層拉伸（柱狀體公式 h/6·(A1 + 4Am + A2)，中間斷面是平均的矩形）、兩個圓（圓錐台）、三個斷面的疊層拉伸、矩形與圓與偏在一邊的矩形的混合疊層拉伸、沿直線或「直線加四分之一圓弧加直線」的掃出（Pappus：斷面積 × 路徑長）、**彎比斷面還緊的掃出**（可能穿過自己）、繞軸旋轉（任意角度，Pappus）、方塊上的盲孔除料（體積 = 方塊 − 孔深 × 面積）。有公式的都對手算（相對誤差 < 2e-5），全部再檢查有效、名字唯一、重算與存檔讀回與 STEP 來回相同、最後一個特徵壓抑再恢復。**全部通過，沒有新問題**（彎得很緊的掃出也不是做出無效的實體就是被說了）。

## 找到的兩個真問題（都已修）

1. **自己穿過自己的鈑金輪廓安靜地做出無效的實體**（狀態是成功）。例：路徑 (0,0) → (40,0) → (40,40) → (20,40) → (20,−20)，最後一段穿過第一段。引擎從來不檢查結果是否有效。**修**：基材凸緣的折過的板，拉伸後檢查有效，無效就說「板的輪廓自己交疊」。（一般特徵沒有加這個檢查：檢查整個零件是否有效相當貴，見限制。）
2. **螺柱的肋四片以上時面的名字重複**（六個隨機零件中出現，`sb:cap:start#1` 出現兩次）。原因：每片肋的兩個側面用核心給的名字 `<特徵>:cap:start|end`，每片肋各自融合，融合只在那一步裡編 `#k`，到第四片就和前面編好的撞名。這個缺口從 6-6 就有（測試只做了 3 片）。**修**：兩個側面以點與肋命名（`….rib<k>.side0|side1`），名字穩定。

## 沒找到的（也是結果）

- 鈑金：96 個隨機零件（含 60 個嚴苛的）、24 個鏈、24 個折過的基材，其餘全部通過上面的性質，沒有其他問題；錯誤訊息都是對的，沒有安靜的錯。
- 塑膠與一般零件：其餘通過。

## 限制

- **隨機測試證明「沒有找到反例」，不證明對**；它只檢查性質，沒有的性質（例如幾何與 SW 一致）它不會發現。產生器偏向能成功的零件；嚴苛的版本涵蓋了被拒絕的路徑，但沒有涵蓋所有特徵的所有組合（鈑金的曲線邊、折過的基材上的凸緣不存在）。
- **引擎仍然不檢查每個特徵的結果是否有效**：檢查貴（整個零件）；隨機測試目前沒有找到其他會做出無效實體的特徵，但這不是保證。若要加，建議做成設定或只在存檔時檢查。
- 鈑金的鏈只測了「90° 凸緣加摺邊」一種；沒有隨機測試的有：成形的圖樣在鈑金上、鈑金上的除料。
- `npm run check`：1736 項通過、21 項略過。

## 補充（H-9）：組合件與工程圖

- **組合件**（`tests/phase8/fuzz-assembly.test.ts`，24 疊 + 2）：2 到 4 個隨機方塊疊起來，每個以「底面與下面那個的頂面重合（反向）」結合，起始位置亂放在上方。檢查：每個結合都是 ok、第一個固定、其餘各剩 **3 個自由度**（兩個滑動加一個轉動，狀態 under）、每塊的底與頂 z 等於下面各塊高度的總和且方塊站正（不歪）、接觸的不算干涉、把最上面那塊壓進去 δ 之後干涉體積 = 兩個佔地的共同面積（用求解器給的位置與轉角，Sutherland–Hodgman 裁切求得）× δ（相對誤差 < 1e-4；佔地沒有重疊的就必須沒有干涉）；指到不存在的面的結合說「遺失」，不會綁到別的面。
- **工程圖**（`tests/phase8/fuzz-drawing.test.ts`，30 個）：隨機方塊加 0 到 3 個通孔，建前、上、右三個視圖和一個通過孔中心的剖面圖：視圖外框 = L×W、L×H、H×W；剖面面積 = L·H − Σ d·H（< 1e-5）；自動標註至少有整體尺寸與每個孔一個（文字含整體 L、W 與 Ø 值）、孔表列數 = 孔數、每個標註都畫得出來；整張圖輸出 SVG、DXF（`checkDxf` 無問題、折線數相同）、PDF（`checkPdf` 無問題，一頁）；圖面檔存檔再讀回後再存檔位元組相同。
- **全部通過，沒有找到新問題。** 一個測試寫法的教訓：標註參照的面資訊含 −0，JSON 讀回成 0，`toEqual` 會當成不同；改比存出的文字。
- 限制：組合件只測了「重合」結合與方塊（同心、距離、角度、對稱、鏡像、陣列沒有隨機測試）；工程圖只測了方塊加孔（沒有圓角、倒角、斜面、薄殼的視圖，也沒有隱藏線與細部放大圖）。
- `npm run check`：1944 項通過、21 項略過。
