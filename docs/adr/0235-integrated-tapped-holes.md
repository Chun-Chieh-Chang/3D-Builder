# ADR 0235：異型孔整合裝飾螺紋及孔位建立

日期：2026-11-04。狀態：已實作並通過最終回歸。

## 行為與資料

標準螺紋孔可直接勾選裝飾螺紋線，並指定有效牙深或孔壁全長。HoleFeature 的 cosmeticThread 與 threadDepth 儲存選擇，規格與公差沿用孔資料，不建立可獨立失同步的螺紋規格副本。Schema 89；舊檔缺欄位時保留原行為。自訂底孔直徑會移除標準與整合表示設定。

重建沿用孔的持久面名，從實際圓柱壁推導裝飾線，再走既有 CosmeticThreadInfo 與工程圖 elementFacts 通路。反向取孔的實際鑽入方向。重疊孔位在整合孔布林前拒絕；超過實際孔壁的給定牙深報錯，不默默截短。命令與引擎皆檢查整合標準規格，底孔徑須符合標準表。

選平面可直接啟動異型孔的點定位草圖，確認後接續孔面板。兩個階段共用 History 交易：取消不殘留草圖及孔，確認後一次復原／重做處理兩者。既有草圖與獨立裝飾螺紋入口保留。

## 驗證與邊界

- 原生核心 100 組固定種子參數：正反方向、盲孔／貫穿、多孔、M3 至 M8；核對實際體積、孔壁長度與工程圖標註資料，各變體皆成功。
- 規格由 M6 改 M8、表達式牙深、公差、序列化、抑制，以及非法深度／底孔徑驗證。
- 瀏覽器專項：選面放點、取消移除兩特徵、面板開啟裝飾線、復原／重做後標註恢復；已檢視結果截圖。
- 這是輕量表示整合，不產生真實牙形，也不宣稱既有 OCCT 底孔布林無記憶體洩漏。
- 完整回歸結果記於 DEV_LOG.md；本文件不預先宣稱通過。
