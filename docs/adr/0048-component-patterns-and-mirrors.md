# ADR 0048：零組件的複製排列與鏡射（Phase 3b-2，**組合件 Schema 4**）

- 狀態：2a（資料格式與純數學）已實作（2026-10-02）；2b 求解與畫面、2c 介面、2d STEP 與驗收進行中，完成後在此補寫。
- 對應：[phase3-plan](../phase3-plan.md) §4 的 3b-2（C15.13）。使用者 2026-10-02 確認：實例是衍生位姿、跟著種子（不另存、不能再加結合）；鏡射零件在載入時由原件算出、**不另存檔**（取代 2026-09-30 的決定 4「產生一個鏡射零件檔」，理由：沒有第二份要同步的檔案，永遠跟著原件）；驗收標準 1–9。

## 決定

1. **只存定義。** `AssemblyDoc.patterns?: ComponentPattern[]`（可省略，沒有排列的檔案沒有這個鍵，所以舊檔原封不動，遷移 3→4 是恆等）。`ComponentPattern`：`kind`（`linear`／`circular`／`mirror`）、`seed`（零組件 ID）、`axis1`／`count1`／`spacing1`／`flip1`、`axis2`／`count2`／`spacing2`／`flip2`（線性的第二方向，格子）、`equal`（環狀：`spacing1` 是總角度）、`plane`（鏡射面：前、上、右基準面）、`skip`（要跳過的實例，標籤 "2" 或 "2x1"）。間距是運算式（長度或角度），實例數是整數。
2. **方向與軸**是組合件的 X／Y／Z 軸，或某個零組件的一個元素（`MateRef`，同結合，可帶次組合件內的路徑）：直線邊線、圓柱或圓錐的軸、平面的法向。
3. **實例的位姿是種子位姿的一個剛體運動**：線性是沿軸平移、環狀是繞軸（通過給定的點）轉動，`componentPatternInstances` 回傳每個實例的運動（`Pose`，用在種子位姿之前：`composePose(運動, 種子位姿)`）。環狀的「等間距」：總角度 ≥ 360° 時除以 n，否則除以 n − 1。標籤 "1"／"1x1" 是種子，不能跳過。上限 500 個實例。
4. **鏡射件仍用剛體位姿。** 鏡射件的零件是原件在**零件自己的 x = 0 平面**的鏡射（零件座標 x → −x，面的順序不變），位姿是 `R · 位姿 · M`（`mirroredPose`：R 是組合件基準面的反射，M 是零件座標的反射，兩個反射成一個旋轉，行列式 +1），所以 STEP 不必有行列式 −1 的位姿（ADR 0046）。次組合件的鏡射逐個葉零件做同樣的事，次組合件內部各零件的位姿是 `M · I · M`（`mirroredInside`），用於 STEP 輸出的鏡射次組合件產品。
5. **種子被刪或被抑制：** 刪除種子，或刪除提供軸的零組件，排列一起刪（同結合隨零組件刪除）；種子被抑制，實例也不存在（2b）。
6. **命名：** `componentPattern*` 與零件的 `patterns`／`patternInstances` 分開（兩者都從 `@3db/model` 匯出）。

## 2a 的驗證

- `packages/model/test/componentPatterns.test.ts`（14 項）：線性（間距、反轉、跳過、格子、任意直線）、環狀（點繞軸轉到手算的位置、等間距 360° 與 180°、跳過、反轉）、定義的 12 種拒絕理由；鏡射：三個平面 × 四個姿態 × 三個點，鏡射件的點（x 取負）經 `R · 位姿 · M` 與「原件的點對基準面反射」相差 < 1e-9、行列式 +1；次組合件內部的位姿；矩陣轉四元數（含 180° 的邊界）；指令（新增、修改、刪除、各一個復原步驟、ID 不重用、拒絕不合法的定義而不改變文件、刪種子與刪提供軸的零組件）；序列化往返、Schema 3 的文字原樣讀入、計數器涵蓋排列的 ID。
- `tests/fixtures/old-versions/v3-assembly.3dba`：次組合件用兩次、帶路徑的結合、透明旗標；**不是 Schema 3 的程式寫的**（Schema 4 的程式寫出再把版本設成 3，理由見該目錄 README）。
