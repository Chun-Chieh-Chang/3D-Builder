# ADR 0172：基準軸、基準點、基準面進草圖（G3）；草圖參照補入 DAG

## 1. 背景
這是 2026-10-19 草圖參照盤點的 G3。

**現況**：基準軸（C3.3）、參考點（C3.5）、參考平面（C3.2）與預設三基準面都無法進入草圖：
- `references.ts` 和 sketcher 都沒有處理 `datum` 的分支；
- `store.convertPicked` 只收邊、面、頂點。

對照：
- SolidWorks 可以對基準軸、參考點直接加關係，也可以把側看的平面當成一條線使用；
- FreeCAD 的外部幾何可以選基準線、基準點、基準面。

**盤點時另外發現一個既有缺口**（AGENTS §2.1-3 依賴鏈完整性）：`dag.ts` 計算草圖的父項時只看 `plane`。投影邊、貫穿邊，以及 G2 新增的頂點都不算父項，所以刪掉一個被草圖投影的特徵時，「刪除會影響哪些項目」不會列出那張草圖。

## 2. 決策（沿用使用者已定的「FreeCAD 式可見參照圖元」與「只參照較前面的特徵」）
1. **`ref.kind = 'datum'` 的圖元**，Schema 70：

   | 參照的基準 | 產生的圖元 | 位置 |
   |---|---|---|
   | 參考點 | 點 | 沿草圖法向投影到草圖平面 |
   | 基準軸、`axis:x/y/z` | 直線 | 投影到草圖平面 |
   | 基準軸垂直於草圖平面 | 點 | 軸與草圖平面的交點 |
   | 參考平面、預設三基準面、座標系統的 XY 平面 | 直線 | 該平面與草圖平面的交線；兩平面平行時拒絕 |

   - 基準產生的直線一律是**建構線**：它是無限長的參照，不能成為輪廓的一部分。
   - 直線的端點以投影原點為中心、沿方向各延伸 25 mm，與模型大小無關，以保持決定性。對求解器來說，直線本來就是無限長；相關的關係（共線、對稱、距離、角度）都不依賴端點。
   - 端點也一起被固定，所以吸到端點得到的位置是固定的，但它不是設計上有意義的點（§5）。
2. **只能參照較前面的特徵**：新增或編輯草圖的指令會檢查每個 `datum` 參照。可以參照的是預設平面、`axis:*`，以及**在草圖之前**的參考平面、軸、點或座標系統。種類也要對得上：點只收參考點與軸；直線收軸與平面。
3. **DAG**：草圖的父項 = 草圖平面 + 所有圖元以 `modelRefOf` 參照到的元素：邊、頂點、貫穿邊與基準。這一項同時補上 G2 以前就存在的缺口。
4. **介面**：開著轉換實體引用工具時，在設計樹或圖形區點參考平面、軸、點、預設平面或座標系統，就把它轉進草圖。圖形區在這個工具下也開放點選平面和基準。

## 3. 設計
- `references.ts`：
  - `ReferenceScope` 新增可選的 `datums`，提供 `axis(name)`、`point(name)`、`plane(name)` 三個查詢；
  - `datumItem(scope, ref)` 產生 `Converted`：投影後是直線的，以 `projected` 加 `ref.kind === 'datum'` 表示；是點的，沿用 G2 的 `vertex` 項目；
  - `followReferences` 處理點與直線的 `datum` 參照，種類改變時沿用既有的 `changedKind` 錯誤。
- engine：以 `this.axes`、`this.points`、`planeOf` 提供上述查詢。重建依序進行，所以草圖只會看到它之前的基準。
- worker：`lastModel` 一併保存 `axes`、`points`、`frames`。
- `ops.referenceEntities`：`datum` 直線一律建成建構線。

## 5. 已知限制
- `axis:x/y/z` 在介面上沒有入口，設計樹沒有列出它們；只在模型層支援。
- 基準直線的端點是約定（±25 mm），不是設計上的點。
- 座標系統只取它的 XY 平面。
