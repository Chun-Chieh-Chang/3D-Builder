# ADR 0141：工程圖的 CommandManager 頁籤、右鍵選單與特徵樹（D-I1b）

- 狀態：**已完成（2026-10-15）**。純介面，工程圖檔案格式不變。
- 需求追溯：[ADR 0129](0129-drawing-interaction-roadmap.md) 的 D-I1b（使用者決定 Q7：D-I1 縮小範圍，工具列、右鍵選單與工程圖樹移到 D-I1b）；計畫書 §4 的 D-I1 內容。

## 背景

D-I1b 之前有三個問題：
- 開著工程圖時，頂端的 CommandManager 仍然是零件的頁籤（特徵、鈑金、草圖⋯⋯），而且幾乎全部不能用。工程圖的工具擠在側邊欄的一條指令列裡。
- 右鍵只能開視圖的選單（D-I7(a)）。
- 工程圖樹只顯示視圖，尺寸和註記只用數字徽章表示。

SolidWorks 的做法：工程圖有自己的 CommandManager 頁籤（視圖配置、註記⋯⋯）；右鍵按到什麼，就打開什麼的選單；樹裡的每個視圖下面有自己的註記。

## 決定

1. **工程圖的頁籤**（`CommandBar` 的 `DRAWING_TABS`；`actions.ts` 新增 `drawing` 和 `annotation` 兩組）：
   - **視圖配置**：標準三視圖、投影視圖、剖面、細部、最適比例。
   - **註記**：智慧型尺寸、座標尺寸、自動排列尺寸、註解、基準、幾何公差、中心符號線、中心線、表面粗糙度、孔表、零件表。
   - **檔案**：原本的檔案指令，加上輸出 PDF、DXF、SVG。
   - 工具類的按鈕再按一次就關閉，啟用中的工具會標示。打開工程圖時，預設顯示「視圖配置」。
   - 每個指令都有一句說明。說明測試會讀原始碼裡的 `id:`，所以指令必須逐條寫出，不能用 `.map` 產生。
   - 側邊欄的指令列（`CommandStrip`）移除。屬性頁裡各群組自己的工具鈕保留，例如「尺寸」群組的「智慧型尺寸」、「座標尺寸」，以及剖面、細部的工具鈕。
2. **右鍵選單**（`DrawingMenu`，取代 D-I7(a) 只處理視圖的選單）：
   - 選單的對象和左鍵點選的優先順序相同：尺寸 → 註記 → 表面粗糙度 → 視圖 → 空白圖紙。
   - 按到的東西如果還沒選取，就改成只選它；如果已經在選取裡，選取不變，選單的指令作用在全部選取上（比照 SW）。
   - 各對象的選單項目：
     - **視圖**：開啟零件／組合件／這個零件、投影視圖、隱藏線（打勾表示目前狀態）、自動排版、自動排列尺寸、刪除。
     - **尺寸**：參考尺寸（打勾）、文字回到中間、自動排列尺寸、共線對正、刪除。
     - **註記**：解除附著（有附著時才出現）、刪除。
     - **表面粗糙度**：刪除。
     - **空白圖紙**：標準三視圖、最適比例、自動排列尺寸（全部）、輸出 PDF。
   - 刪除走 `deleteSelection`，所以刪除多個是一步復原。不能用的項目會反灰。
3. **工程圖樹**：
   - 每個視圖下面有「尺寸（n）」和「註記（n）」兩個資料夾，預設收合，比照 SW 的 Annotations 資料夾。
   - 尺寸列顯示種類和畫出來的文字，例如「線性 120」。註記列沿用註記面板的名稱。
   - 點一下選取，Ctrl 加選；右鍵打開和圖紙上相同的選單。

## 驗證

- `tests/e2e/manual-drawing-menus.js` 共 8 步，全部通過：
  1. 從零件換到工程圖，頁籤從「特徵⋯⋯」換成「視圖配置、註記、檔案」。
  2. 按「智慧型尺寸」啟用工具，按鈕標示啟用；再按一次關閉。「剖面」也一樣。
  3. 樹裡的「尺寸（n）」資料夾預設收合；打開後每個尺寸一列，點一列就選取它。
  4. 在尺寸文字上按右鍵，選取它並打開尺寸選單；設成參考尺寸後可以復原。
  5. 選取兩個尺寸，在其中一個上按右鍵，兩個都維持選取；刪除兩個是一步，復原也是一步。
  6. 視圖選單可以切換隱藏線。
  7. 在空白圖紙上按右鍵，出現圖紙選單，而且不選取任何東西。
  8. 新增一個註解後，樹裡出現「註記（1）」；用它的右鍵選單可以刪除。
- 反向檢查：把第 4 步的預期故意改錯，腳本確實判定失敗。
- `tests/phase8/help.test.ts`：每個新指令都有說明，而且說明裡沒有多出不存在的指令。

## 後果與限制

- 「反轉箭頭」和「公差」子選單還沒有做：模型裡沒有反轉箭頭的欄位；公差目前在屬性頁裡設定。
- 表格（孔表、零件表）在圖紙上按右鍵，目前打開的是圖紙選單（表格疊在視圖上時是視圖選單），還沒有表格自己的選單。
- 工程圖時沒有「工具」頁籤：「選項」和「快速鍵」只能在零件或組合件裡打開。
