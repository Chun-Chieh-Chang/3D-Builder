# ADR 0069：分割線特徵（Phase 4b-2，C8.1，零件 Schema 29）

- 狀態：已實作並驗證（2026-10-03）。限制見最後一節。
- 相關：[phase4b-plan](../phase4b-plan.md)、[ADR 0067](0067-surface-validation.md)（投影分割的技術驗證）、[ADR 0068](0068-surface-bodies.md)（核心的 `splitByProjection`）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **特徵 `splitLine`**（零件 Schema 29）：`sketch`（一張草圖，在它之前）、`face`（要分割的面，一個參照）、`reverse`（投影方向，預設沿草圖法向，反轉就逆向）、`throughAll`（穿透全部，預設只切最近一層）。檔案只存意圖：哪張草圖、哪個面、哪個方向；區域是重算出來的。指令 `setSplitLine`；草圖不在前面或選的不是面，輸入時就被拒 | 與其他特徵一致（意圖存檔，導出的東西重算） |
| 2 | **投影的線**：草圖每個封閉區域的**外圈**（`profiles.regions[].outer`）。洞的圈不另外投影——洞若自成一個區域（草圖裡另有那個圓），它自己的外圈就會被投影；這樣不會把同一圈加兩次（`BRepFeat_SplitShape` 重複加同一條線會壞） | 重複的線是實際會出事的情形，不是理論 |
| 3 | **核心的 `splitByProjection` 改成收多個圈**（`loops: Segment[][]`），回傳 `regions`（區域面的編號）與 `regionLoops`（每個區域是哪一圈的）。每一圈各自投影、各自取視線指向那一邊的最近一層（或穿透全部），再逐條加進 `BRepFeat_SplitShape`；分割線的邊在合併週期面接縫時都保留。「區域」是邊全是分割線的邊的面 | 一張草圖常有好幾個輪廓 |
| 4 | **命名**：區域面叫 `<特徵>:side:<草圖>.<圈>`，與草圖產生的側面同一個文法（`faceBaseName` 的 `profileEdge`）；「圈」是圍住它的那一圈裡**最小的實體編號**（排序後第一個，不依賴圈從哪裡起頭）。同一圈在穿透全部時切出兩個區域，兩個名字以 `#1`、`#2`（幾何順序）區分。**其餘的面保留原本的名字**（被分割的面剩下的部分仍叫原名） | 改草圖的尺寸、工件的尺寸，名字不變，後面的特徵（偏移曲面等）跟著走；改成別的實體編號才會改名（草圖刪掉再畫新的本來就是新東西） |
| 5 | **失敗說原因**：投影不到（方向反了、面不在草圖的那一邊）、選的面不見了、草圖沒有封閉區域、結果不是有效的形狀（說出「分割線失敗：」）；分割沒有圍出任何區域也是錯誤 | 投影的失敗在介面上要看得懂 |
| 6 | 曲面本體也能被分割，結果仍是曲面本體（`surface` 標記保留） | 與其他特徵對曲面本體的規則一致 |

## 驗證（證據）

- **特徵**（`tests/phase4b/split-line.test.ts`，6 項）：圓錐台（Ø50 到 Ø30，高 30）的側面，沿草圖的法向（反轉）投影一個 20 × 10 的矩形：結果有效、4 個面、**區域面積對手算積分 ∫√(1+r′²)·r·(asin((2+h)/r) − asin(2/r))dz（差 5e-3 以內）**、其餘的側面＝整個側面減區域、保留原名；矩形改成 12 高，**面的名字集合不變**、面積是新的積分；**選區域做偏移曲面 3**：一個面、面積對手算（同一個角範圍、半徑 r + 3·cosφ 的圓錐，差 0.05 以內），改草圖後偏移跟著走；穿透全部：兩個區域（`#1`、`#2`）、5 個面；錯誤：方向反了（投影不到）、面不見、草圖沒有封閉區域，與指令的拒絕（草圖不存在、選的不是面）；`setSplitLine` 改方向、版本是 29。
- **核心**（`tests/phase4b/surfaces.test.ts`，3 項投影分割）：改成收多個圈，原本的值不變。
- 驗證時發現：**投影的線貼著圓錐的接縫（y = 0，沿母線）會讓結果不是有效的形狀**——退化情形，不是方法的錯；測試的矩形改成離開接縫（y 從 2 起）。穿過接縫的區域（ADR 0067 的情形）仍能合併。

## 限制與未做

- **沒有介面**：選草圖、選面、方向、顯示區域要等 4b-3；現在只有核心、模型、重算、命名與指令，所以沒有地方可以新建這個特徵（檔案裡有就能開、能重算）。
- **貼著接縫的線**（沿著週期面的接縫走）會失敗並說「結果不是有效的形狀」，沒有自動避開或修復；真實工件上的接縫位置要到真實樣本才知道會不會常碰到。
- **只投影外圈**（第 2 點）；洞圈的區域要靠草圖裡有那個圈自成區域。
- **一次只切一個面**；多個面要用多個分割線特徵。
- **開放的線**（不封閉的草圖線）不投影；要用它們把面一分為二（SolidWorks 的分割線可以）還沒做，需要另外驗證 `BRepFeat_SplitShape` 對開放線的行為。
- **區域的名字用最小的實體編號**：草圖實體被取代成新編號時會改名（與草圖側面的行為一致）。
