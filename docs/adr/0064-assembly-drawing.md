# ADR 0064：組合件工程圖——零件表與零件號球（Phase 5-4b，C16.6、C15.16，工程圖 Schema 4 不變）

- 狀態：已實作並驗證（2026-10-03）。限制見最後一節。
- 相關：[phase5-plan](../phase5-plan.md)、[ADR 0063](0063-annotations-and-hole-table.md)（表格的框架）、[ADR 0050](0050-parts-list-and-exploded-view.md)（零件表 `buildBom`）、[ADR 0011](0011-assembly-skeleton.md)（組合件）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **組合件可以是視圖的來源**：視圖的 `source` 指到 `.3dba` 檔就行，文件格式不變。App 端 `buildAssemblySource` 讀組合件與它用到的次組合件與零件（每個檔一次；循環與缺檔或讀不了的檔是**說出檔名的錯誤**，不會悄悄少畫一個零件），零件照單零件的方式建好（`buildSource`，現在也回報零件的屬性、是否只有參考本體、是否沒有本體），再用 Worker 解出結合後各零組件的位置；組合件的內容鍵由每個檔的內容雜湊而來，所以任何一個零件或組合件改了，視圖的線條就重算 | 沿用已有的組合件讀取、求解與 `leavesOf` |
| 2 | **畫哪些零件**：`leavesOf`（次組合件展開）加 `patternLeavesOf`（複製排列與鏡射的實例；軸是組合件軸的才排得出來，要指到零組件元素的排列與零件表一樣「沒有實例」），去掉**隱藏的零組件**、**只有參考本體的零件**（如工件）與**沒有本體的零件**；鏡射件是原零件鏡射後放在位置上。Worker 的 `drawingViews` 本來就能收多個零件與位置，所有零件一起做精確隱藏線 | 零件表與圖是同一批零件 |
| 3 | **零件的位置**（`drawingAnchors`）：每個零件的質心（放到位置上、從視圖看過去），視圖座標，與請求的零件同順序；Worker 在 `anchors: true` 時一併回傳，存在 `ViewLines.anchors` | 質心比包圍盒中心更可能在零件的輪廓內 |
| 4 | **零件表是一種表格**（`BomTable`：視圖、可選的左上角 `at`、`balloons`）：列是 3b-4 的 `buildBom(...).flat`，與零件表對話框與 CSV 同一個來源；欄是項次、名稱、（任何零件有才有的）料號與廠商、數量；表在繪圖區的右下角（標題圖塊上方）或使用者給的位置。表依視圖的組合件算，所以零件表與圖不會不一致 | 一值一處 |
| 5 | **零件號球**：每個零件表的項目，在視圖有它的零件（檔與鏡射相同的第一個）時，畫一個半徑 4 mm 的圓、裡面寫項次，圓在視圖範圍外 12 mm、在「視圖中心到零件質心」的射線上，與已有的號球太近（< 9 mm）就沿著邊滑開；引線從圓連到零件上的一個實心小點。視圖裡沒有零件的項目（例如全被隱藏）沒有號球 | ISO 6433 |
| 6 | **「新工程圖」從開啟的組合件**：前視與等角視、前視附零件表與號球、圖名是組合件名稱；組合件要先存檔且沒有未存變更；指令與選單的啟用條件跟著改。面板：選到組合件的視圖時，「註記與表格」只顯示零件表（加入、號球開關、放回右下角、刪除） | |
| 7 | **組合件視圖的尺寸**：指到單一零件的面與圓，組合件的視圖還沒有，所以尺寸說明原因（`drawing.dimAssembly`），不畫；自動尺寸與孔表也不提供（視圖沒有可標註的元素） | 說原因，不要畫一個沒意義的東西 |

## 驗證（證據）

- **零件表與號球**（`tests/phase5/drawing-assembly.test.ts`）：定位板加兩支削邊銷的零件表（1 定位板 ×1、2 削邊銷 ×2）；欄（有料號與廠商時五欄，都沒有時三欄）；表高 3 列×7＝21 mm、右下角（右 402、下 66）與給定的左上角；表中的文字與線；號球：兩個（項次 1、2）、圓在視圖範圍外、半徑 4、小點在零件的位置（(30, 10) 的點在圖紙 (230, 160)）、重疊的三個號球彼此 ≥ 9 mm、沒有零件的項目沒有號球、沒有位置資料時沒有號球、鏡射件是另一個項目。場景：表與號球一起畫（項次與數量與號球的數字都在）、關掉號球只剩表、不是組合件的視圖沒有表。文件：零件表的插入、號球、移動、存檔重讀相同、不收公差等級（孔表不收號球）、刪視圖連動。
- **零件的位置**：定位板放在 x = 0 與 200：前視圖的位置是 x = 0 與 200、同高、在厚度 15 之內；上視圖往 +z 移 30 的往下 30（圖紙 y 是 −z）；兩塊板一個視圖，範圍 −60 到 260 ×0 到 15；不洩漏形狀。
- **瀏覽器**（`tests/e2e/phase5-assembly.js`，0 Console 錯誤）：用模型與 io 套件寫一個組合件（金樣定位板 x = 0、兩支金樣削邊銷 x = ±100）；開啟後「新工程圖」→ 前視與等角視、零件表帶號球、圖名「夾具」；零件表 1 定位板 ×1、2 削邊銷 ×2；前視圖有三個零件（範圍 > 200 寬、三個位置 0、100、−100）；表與兩個號球畫在圖上與 SVG；面板：號球關與開、刪除表與再加入、移動與放回；組合件視圖上的尺寸說原因；存檔重開後零件表與號球由組合件重算。
- `npm run check`：1171 項通過。

## 限制與未做

- **號球不能拖**：位置自動算（沿視圖外緣滑開），沒有使用者自己放的位置；引線可能穿過別的零件。
- **質心可能不在零件的輪廓內**（環形零件），小點就會落在孔裡。
- **組合件視圖沒有尺寸、中心線、孔表**；沒有爆炸視圖（3b-4 的爆炸可以之後接進視圖）；剖面視圖可以做（切整個組合件），但剖面線不分零件。
- **單層零件表**（縮排的含次組合件的版本與對話框同源，還沒有放到圖上）；欄固定，不能選別的屬性（材質等）。
- 排列的軸若指到零組件的元素，組合件工程圖不畫那個排列的實例（零件表也不算，兩者一致，但與組合件視窗看到的不同）。
- 隱藏線在零件互相貼合的地方（共面、共線）可能有雜線。
