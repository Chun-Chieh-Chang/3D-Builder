# 0184：孔／裝飾螺紋標註的顯示樣式

日期：2026-10-23。接續工程圖 Phase 3。圖紙 Schema 26。

## 決策

每個直徑尺寸新增 `calloutStyle: 'text' | 'symbols'`。未設定時保留既有語系文字；只儲存格式，不儲存模型深度。勾選孔標註後可在尺寸面板切換。`null` 清除設定，支援儲存、復原與重做；舊圖升級不改其顯示。

符號模式使用 `THRU`、`↧`、`⌴`、`⌵`，例如 `Ø9 ↧ 15 ⌴ Ø15 ↧ 8`。這是顯示選項，沒有宣稱通過完整 ISO／ASME 規範認證。

`CosmeticThreadInfo` 經持久參照解析，轉成共用的 `ThreadCallout`，傳入 `ViewFeature`、`elementFacts` 與 worker。圓柱面、相鄰圓邊皆可取得標註；多個競爭的裝飾螺紋不任意挑一個。自動尺寸會區分不同螺紋的規格與長度，避免把不同工步合併成同一數量。

標準公制裝飾螺紋顯示既有規格與模型評估的牙距（`M8×1.25`）；英制代號維持原樣。自訂螺紋明確寫「自訂螺紋」，不冒充標準。攻牙孔的符號模式可由模型標準表提供公制粗牙牙距；既有文字格式不變。沒有資料的公差等級不補造，亦不從真實螺旋布林拓樸反查規格。

內螺紋的有效長度與底孔鑽深分開，例如 `M8×1.25 ↧ 12（底孔 Ø6.8 THRU）`。內螺紋只有在裝飾螺紋為全長且孔的實際幾何貫穿時才顯示 THRU；盲孔上的全長螺紋仍標示有效深度。外螺紋即使長度使用 through 條件，也顯示評估後的實際長度，不把軸端稱為貫穿孔。尺寸關閉孔標註後仍顯示實際幾何直徑。圖頁用英寸時只換算長度，標準螺紋代號及其公制牙距保持不變。

DXF 的 DIMENSION 覆寫文字及匿名圖塊 TEXT 一律將三個製造符號轉為 `DEPTH`、`CBORE`、`CSINK`，避免舊 SHX 字型缺字。PDF 僅在所用字型沒有對應符號時採相同文字回退；其他未知字元沿用缺字警告。SVG 保留符號。回退文字較長，可改用文字模式並調整引線排版。

## 驗證與範圍

真實 OCCT／PlaneGCS 測試覆蓋模型重建、內外螺紋、面與圓邊、有效長度與底孔深度分離。格式與文件測試覆蓋樣式儲存、復原、舊版升級、錯誤輸入、150 組深度，以及 DXF／PDF 讀回。瀏覽器尺寸驗收新增以真實孔尺寸切換樣式並還原的操作。

本次不增加圖紙全域預設、公差等級輸入、真實 ThreadFeature 的幾何反查或獨立的側視圖螺紋引線工具。孔表沿用既有語系格式；外部 AutoCAD／SHX 的實機顯示仍待使用者驗證。既有自由文字覆寫功能未變更；本次未新增可覆寫模型深度的欄位。

## main 整合補充

main 的 E5 Phase 2 與本分支各使用 Schema 26。合併後使用 Schema 27，保留兩類版本 26 文件的內容，並避免較舊的 Phase 2 程式遺失標註樣式。直徑切換為半徑會移除只適用直徑的 callout 與 calloutStyle，切回後可重新設定。
