# ADR 0191：E2+ 延展與連動草圖陣列

2026-10-24，零件 Schema 80，79→80 無損升級。

## 行為

延展圖元以已選的草圖端點為目標（可先框選一組點），兩次點選或輸入 ΔX／ΔY。共享該點的線／曲線隨端點改變，未選部分仍遵守既有關係；固定點與不適用選取明確拒絕。沿用真實求解器預覽及單次 editSketch／復原。

陣列面板新增「副本與種子連動」，預設開啟。每個副本點的 patternPoint 約束保存來源點及剛體變換；圓半徑沿用等半徑。支援點、線、圓、圓弧、樣條。橢圓／文字尚不支援連動，可關閉建立獨立副本；關閉時既有「保持關係」的獨立副本語意不變。刪除連動關係可使副本自由。

線性陣列可啟用不平行的第二方向。兩方向的副本數均不含種子，總格數為 (n+1)(m+1)，排除原始一格後最多 200 個副本；小數、NaN、零向量、平行方向與超量明確拒絕，不做整數四捨五入。

## 原生求解與修正

真實 WASM 探針證明這版 PlaneGCS 對兩個可變參數的 proportional 約束會以普通 Equal 化簡，旋轉位置錯誤，雖回報 fully。沒有採用該分支。最終使用有界半角式：

- U=(ay+by, bx−ax)，固定直線通過 (2cy+dy, dx)，方向 (cos(θ/2), −sin(θ/2))；
- V=(ax+bx, by−ay)，固定直線通過 (2cx+dx, dy)，方向 (cos(θ/2), sin(θ/2))。

四個 difference 與兩個 point-on-line 約束精確給出旋轉加平移，θ=180°、零半徑及種子在中心亦不退化。相較最初四個乘積輔助點的作法，減少未知量／矩陣規模，實測修掉複合種子環狀陣列的原生 OOM。無弱化容差／延長逾時。

圓弧三個點已由同一剛體變換連動時，原始弧的等半徑條件已隱含保證副本端點半徑。再加完整 arc_rules 會多一個冗餘條件。檢查真實點關係及源弧鏈有根後，副本改以源弧等半徑加兩個角度參數約束，仍保持圓弧參數和點一致；非這種完整連動仍保留普通 arc_rules。

建立前的保守求解規模預算為 360 個新增參數：平移點 2、旋轉點 6，另計弧 3、圓 1。超量先提示減少種子／副本或取消連動，不把可預見的大型密集求解丟給 WASM。不是所有 200 副本組態都能連動。

## 驗證與紅隊

新增 8 個核心案例各有通過結果：5 個連動／輸入案例（含 100 組剛體變換、100 組線性／環狀連動）、2 個實際控制器延展案例、1 個複合弧種子的連動回歸。原有獨立副本 6 個案例明確關閉新連動預設後全過，既有斷言與容差保留。新增 UI 3/3，含實際副本點、源圓半徑變動、第二方向與一鍵復原。完整套件未跑；只重試失敗項，演算法修正後驗證受影響分支。

紅隊四問：非法小數／數值／規模在操作或模型層拒絕；沒有新增布林，矩陣規模先行限制；內部約束依賴透過 constraintRefs、刪除及版本升級完整接線，外部種子參照沿用原有 DAG；所有預期由實際 PlaneGCS 求解與解析剛體變換核對，弧半徑／端點另有探針，不用成功狀態代替正確數值。不宣稱 PlaneGCS Heap 零成長。
