# ADR0204：可重算盤點、文件責任與無功能變更清理

日期：2026-10-26。狀態：採用。使用者要求全面盤點、整合過時文件、移除死碼與無效資源，依SSOT／MECE和跨平台一致性維護；保留功能與驗收真值。

## 決策

1. 目前產品能力只在[產品現況](../project-state.md)維護；環境與命令操作在[開發操作](../development.md)，接手只讀短版[handoff](../../handoff.md)。舊完整交接與清理清單封存，不把原來的Schema、批准條件或通過數改造成今天的事實。
2. Schema、工作區、npm命令、UI／手冊數與鎖定npm依賴從程式和lockfile產生[盤點](../repository-inventory.md)。`docs:sync`生成，`lint:repo`唯讀比對並檢查文件唯一主要角色與本地路徑大小寫；納入`check`。不另維護第二份數字表。
3. UI呼叫發現從`verify-ui.mjs`抽到`ui-jobs.mjs`，執行器與盤點共用同一函式，保留檔頭40行、去重、helper排除、排序與regex篩選語意。跨平台只用Node路徑API、Git結構化參數與LF／UTF-8，不改lockfile或平台資源。
4. 移除TypeScript確認未使用的匯入和私有無呼叫方法，啟用`noUnusedLocals`；不啟用`noUnusedParameters`，不任意改呼叫契約。非平凡的初始化／驗證呼叫保留，只移除未使用的接收變數。公開匯出、驗收讀取器、技術探針、授權原稿與動態圖示不憑字面搜尋刪除。
5. 歷史計畫與驗證文件明示記錄時點；藍圖技術棧按實作校正，原路線圖／驗收目標保留。第三方聲明中的舊Rust人工審閱標為歷史，最新lock條目數不冒充授權重審。沒有本地wiki，不宣稱遠端wiki已同步。

## 保護邊界與驗證

不改產品命令、持久格式、幾何演算法、套件版本、測試容差／期限或測試略過條件。追蹤的金樣、STEP、圖示、字型、二進位、授權原稿、鎖檔及桌面設定逐位元比對基準；原生與實際瀏覽器案例補驗影響面。只跑新／相關與失敗重試，遵循使用者偏好，不宣稱本版全套已過。

工具測試驗證Windows也能攔截錯誤大小寫、Unicode／空白路徑、路徑逃逸、原發現語意及分類失敗；讀取Git失敗時明確失敗，不靜默變成空盤點。新增Linux／Windows／macOS的同指令CI矩陣，含原生幾何smoke與Web建置；配置存在不等同已取得全部runner通過報告。文字連結守門不證明外部網址可讀、所有歷史語句已獨立認證或法律合規。

實際結果與過程失敗見[DEV_LOG](../../DEV_LOG.md)本次清理條目；依據不是刪除行數，而是保留呼叫／輸出／資源與可重建事實。
