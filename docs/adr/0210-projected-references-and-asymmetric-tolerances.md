# ADR 0210：投影輪廓參照與非對稱公差

日期：2026-10-27。狀態：已實作；遠端三平台 CI 待本次執行結果。

## 問題與決策

工程圖原先主要從原模型的解析邊／面建立命中候選，會漏掉剖切後新生的邊與自由曲面投影。現在以實際顯示的原生 HLR 輪廓補足選取：直線可作長度、距離、角度參照；曲線可取投影參考點量距。顯示中的隱藏線與相切線可選；剖面填線、細部框與折斷裝飾線不是模型參照。既有解析圓仍使用原生半徑／直徑資料，不從任意曲線猜半徑或倒角。

工程圖 Schema34 新增獨立 `ProjectionRef`（`kind: projection`、`name`、可選 `at`）；33→34 不改舊值。名稱是全尺寸 HLR 點列量化後的正規化幾何簽名，消除線段方向／排列差異。它僅供定位，不反解析保存的簽名作量測；每次求值都匹配目前重新生成的 HLR。`at` 為目前折線的弧長比例，必須有限且在 [0,1]；不是原生 B-rep 頂點或精確曲線參數。

原生 Ref 仍走 Worker 拓樸查詢，投影 Ref 不送入原生命名解析器；對應 facts 槽位留空，由尺寸求值端取得目前投影資料。幾何、切面或離散化變更導致簽名不能匹配時，明示參照失效並要求重選，不以最近邊或舊座標靜默替代。因此尚非完整的生成邊拓樸歷史追蹤。

選取與求值共用細部／裁剪／折斷後的輪廓；折斷視圖使用真正的紙面反變換。原生端點及圓心吸附優先，距目標較遠的原模型輪廓不能攔截真正剖切邊。斜視方向在幾何查詢及尺寸求值入口正規化，修正命名等角方向 [-1,-1,-1] 導致斜視橢圓被誤判正圓的問題。

## 公差操作

單一與批次尺寸屬性明列「對稱偏差（±）」及「非對稱／單向偏差」。上下偏差是相對基本尺寸的帶號數，允許 +0.02/-0.01、+0.03/+0.01、-0.01/-0.03；下偏差不能大於上偏差。沿用既有 `bilateral` 資料型別與驗證，避免雙重事實來源。輸出沿用現有行內上下偏差文字，未新增上下堆疊排版。

## 驗證與限制

- 15 個相關檔案 205 案例通過；後補真正剖切邊優先案例單獨通過，合計 206 個不同案例各有通過紀錄。非法參數防禦補強後只重跑對應案例。
- 真實公開定位板、原生螺紋 B-spline 的投影／剖面、細部裁剪、折斷座標、存讀及失效參照；每視圖 100 個指標位置不等於 100 個新實體壓測。真實 WASM heap 基準存在，不宣稱零洩漏。
- 新瀏覽器流程驗細部新邊、等角曲線取點、單一／批次非對稱及同號公差、冷 Worker 重開。最終證據 `out/projected-references-ui-final.json`；舊錐面倒角與六種舊格式參照流程在 `out/projected-references-ui.json` 各自通過，該初輪整體並非全綠。SVG／DXF 與 PDF 讀回由原生測試覆蓋。
- 初版測試前置視角選錯、螺紋面型名稱誤寫已修正；實際瀏覽器暴露等角方向未正規化及近鄰輪廓攔截後修正產品，只重試新增／失敗案例，未放寬容差或期限。
- 不宣稱使用者截圖原檔、全量回歸、大型組合件效能或 SW／FreeCAD／SolidCraft 全功能等效已驗收。新測試納入 Repository integrity，遠端結果另驗。
