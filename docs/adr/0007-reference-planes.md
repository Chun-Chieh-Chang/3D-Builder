# ADR 0007：基準面（Phase 1C）

- 狀態：已採用（Phase 1C，2026-09-28）
- 依據：藍圖附錄 C 的 C3.2（偏移、角度、三點，P0）、C1.1、A5.1、D4.6；[handoff.md](../../handoff.md) 的里程碑 1C

## 決策

| # | 決策 | 理由 |
|---|---|---|
| 1 | **Schema v4 新增 `refPlane` 特徵**，定義是聯集 `PlaneDefinition`：<br>• 偏移：`{ mode: 'offset', plane, distance, reverse? }`<br>• 角度：`{ mode: 'angle', plane, axis, angle, reverse? }`<br>• 三點：`{ mode: 'threePoint', points, reverse? }`<br>v3 → v4 的遷移不需改內容（舊檔沒有基準面） | 一種定義方式一個型別，不會出現「偏移模式卻帶著旋轉軸」這種不合法的組合 |
| 2 | **基準面參考（`kind: 'datum'`）的名稱**：<br>• 預設基準面：`plane:front`、`plane:top`、`plane:right`<br>• 基準面特徵：它的特徵 ID<br>草圖的 `plane` 與基準面的 `plane` 用同一套規則 | 不必另外發明一種參考。父子關係直接從 ID 推導，所以抑制與刪除會沿用 ADR 0006 的連帶處理 |
| 3 | **只能參考在它之前的基準面**：指令層檢查。面、邊線、頂點則在重新計算時，以「它之前的模型」解析 | 相依圖永遠不會有環；語意與 SW 的歷史順序一致 |
| 4 | **基準面的座標框架是衍生資料**：重新計算時依歷史順序求出，放在 `RebuildResult.frames`（以特徵 ID 為鍵），不寫回文件 | SSOT：文件只記錄「怎麼定義」。上游改尺寸時，基準面與它上面的草圖會一起移動 |
| 5 | **框架規則**：<br>• 偏移：沿參考面的法向平移，保留參考面的軸向<br>• 角度：繞直線邊線旋轉；0° 與參考面平行，90° 與參考面垂直<br>• 三點：法向 = (B−A)×(C−A)，依點選順序，符合右手定則<br>「反轉方向」讓偏移改往另一側、角度改往另一個方向旋轉、三點的法向反向。角度與三點的軸向使用 `planeFrame` 規則（與模型平面上的草圖相同） | 同一個平面不論怎麼得到，放在上面的草圖都有相同的 X/Y 方向 |
| 6 | **頂點也使用持久命名**：`<a\|b\|c>`（相鄰三個面的名稱）。解析順序與面、邊線相同：完整名稱 → 去掉 `#k` 的基底名稱 → 幾何指紋（點的位置，會發出警告） | 三點基準面需要頂點參考；沿用 ADR 0002 的文法，不另立規則 |
| 7 | **錯誤訊息分成兩種**：<br>• 選取方塊還沒填（空名稱）：「請選擇旋轉軸」「請選擇終止面」<br>• 參考遺失：「遺失參考：…找不到，請重新選擇」<br>其他錯誤：三點共線、旋轉軸垂直於參考面（與法向同向）、參考面不是平面、參考的基準面已抑制或失敗 | 「還沒選」不是錯誤的設計，不應被說成「遺失」 |
| 8 | **拾取優先順序：頂點 > 邊線 > 面**（同 SW）。點到的元素**種類**決定它填入哪個選取方塊：<br>• 面或基準面 → 參考面<br>• 直線邊線 → 旋轉軸<br>• 頂點 → 三點（再點一次可移除，最多三個）<br>定義基準面時，在設計樹點選基準面，就是選它當參考面（同 SW 的快顯設計樹） | 一次只有一種元素被高亮，點下去的就是看到的那一個；不需要先切換選取方塊 |
| 9 | **圖面顯示（D4.6 的一部分）**：<br>• 基準面特徵：半透明方框，大小是模型沿平面法向看過去的範圍，再加邊距<br>• 選取或編輯中的基準面：高亮顯示<br>• 預設基準面：只在設計樹中選取、或被當作參考時顯示 | 對應 SW 的預設：新建的基準面會顯示，預設基準面是隱藏的 |
| 10 | **編輯基準面時**，畫面顯示它之前的模型，基準面本身也會計算，當作預覽 | 參考只能選在它之前的元素；預覽讓使用者看到結果 |
| 11 | **PropertyManager 頂端顯示特徵目前的錯誤訊息**，適用所有特徵 | 對應 SW PropertyManager 的訊息方塊。例如「這個方向上沒有本體（試試反轉方向）」會直接告訴使用者下一步 |

## 驗證

- 行為測試（`tests/phase1/planes.test.ts`，11 項，1C 的完成條件「基準面上的草圖與特徵正確重建」）：
  - 偏移預設基準面，在上面畫圓並「成形至某一面」往下長到板上，體積與解析值一致；
  - 偏移模型面，板變厚時基準面跟著移動；
  - 抑制基準面時，它上面的草圖一起抑制；草圖單獨留在被抑制的基準面上時，回報原因；
  - 以 90°、45° 繞邊線旋轉，基準面通過該邊線；旋轉軸還沒選時要求選擇；旋轉軸與參考面法向同向時拒絕；
  - 三點通過頂面三個角，上面的除料體積正確；三點共線時回報；點不足三個時要求補齊；
  - 參考面是曲面時拒絕；草圖不能參考在它之後的基準面。
- 瀏覽器實測（只用 UI；示範件是 20×10×5 的塊加一個圓角）：
  1. 在上基準面上建偏移 10 mm 的基準面，再改成 25 mm，框架位置正確。
  2. 改點選模型頂面當參考，基準面跟著改。
  3. 切成「角度」，點選頂面前緣：45° 的平面通過該邊線。
  4. 切成「三點」：點選三個頂點；點選已選的點會移除，第四個點會被拒絕並提示。
  5. 確定一個「頂面上方 10 mm」的基準面 → 在上面畫 R2 的圓 → 伸長「成形至某一面」到頂面並反轉方向。體積 1117.080 mm³，等於 991.416 + π·2²·10。
  6. 把底座深度從 5 改成 8：基準面移到 y = 18，凸柱仍從頂面長到基準面，體積 1717.080 mm³，與解析值一致。
  7. 刪除對話框列出子特徵（草圖2、伸長2）；父子關係顯示父特徵伸長1；抑制基準面時連帶抑制草圖2與伸長2，復原後恢復。

## 範圍外

- 平行、垂直、中間、相切等其他基準面類型（C3.2 的 P1 部分）。
- 基準軸（C3.3），以及用草圖直線當旋轉軸：目前旋轉軸只能是模型的直線邊線。
- 在圖面中直接點選基準面：目前從設計樹選。
- 基準面與草圖的顯示/隱藏切換（D4.6 的其餘部分）。
- 一次建立多個等距基準面（SW 的「基準面數」）。
