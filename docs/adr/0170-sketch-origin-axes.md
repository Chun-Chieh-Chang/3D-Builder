# ADR 0170：草圖內建水平軸與垂直軸（G1）

## 1. 背景
2026-10-19 對比 SolidWorks／FreeCAD 的草圖參照缺口盤點（G1–G9），使用者決定第一批先做 G1–G5，並且維持 FreeCAD 式「看得見的參照」。G1 是這一批的第一項。

現況：每張草圖只內建一個原點 `@origin`（固定在 (0, 0)）。要對稱於中心、量到中線的距離、量單一直線對水平的角度，或者旋轉，都得先畫一條中心線、讓它與原點重合，再加上垂直。FreeCAD 每張草圖都內建 `H_Axis` 和 `V_Axis`；SolidWorks 則可以直接選原點的軸。

## 2. 決策
1. **兩個保留 id**：`@axisH`（草圖的 x 軸）、`@axisV`（草圖的 y 軸），都通過原點、固定不動，和 `@origin` 一樣不存進 `entities`。兩者都視為**無限長的直線**，對求解器來說本來就是如此。
2. **可以參照它們的限制條件**（新增 `RefKind` `'axis'`，`sketch-rules.ts`）：
   - 共線、平行、垂直、角度
   - 對稱（作為對稱軸）
   - 點在曲線上、交錯
   - 相切（與圓或圓弧）
   - 距離（點、圓心或平行線到軸）

   **拒絕**的情況（各有明確錯誤，不靜默修正）：
   - 水平、垂直（軸本身已經是水平或垂直）
   - 相等、中點、單一參照的距離：軸沒有長度，也沒有中點
   - 水平距離、垂直距離：軸不是點
   - 同一個條件裡出現兩條軸：兩軸之間的關係永遠固定，加上去只會冗餘或衝突
3. **旋轉與螺牙的軸**：`RevolveFeature.axis`（以及用草圖線當軸的螺牙）可以是 `@axisH`／`@axisV`，不必再畫中心線。
4. **鏡射草圖圖元**可以選軸作為鏡射軸。
5. **畫面**（FreeCAD 式可見）：編輯草圖時，兩條軸以原點色的細虛線畫滿整個可見範圍；滑過或選取時才會亮起。可以選取，不能拖曳，也不會被框選。
6. **只在「挑參照」時選得到，不參與繪圖吸附**：
   - 選得到軸的地方：選取工具（優先順序是草圖圖元 → 模型邊 → 軸）、智慧尺寸、鏡射線。
   - 看不到軸的地方：修剪、延伸、草圖圓角、偏移，以及畫圖時的吸附。`hitTest` 的 `axes` 預設是 false，沒有接線的呼叫端屬於安全失效。
   - **第一版改過一次**：第一版讓軸參與「在圖元上」吸附，全套測試有 7 項轉紅（`apps/web/test/sketcher.test.ts`）。RCA：軸是無限長的，沿著 x = 0 或 y = 0 處處都吸得到，因此搶走了：
     1. 置中零件落在軸上的模型邊吸附（模型吸附排在草圖曲線之後）；
     2. 沿 y = 0 畫線時的「水平」推斷（變成「點在軸上」）；
     3. 選取模式中，軸上的模型邊也選不到。

     原點對齊本來就能表達同樣的幾何意義，所以改成軸不參與繪圖吸附。
   - **智慧尺寸**：只有在第一次點選、或第一個點選的圖元單獨無法標尺寸（例如一個點）時，才選得到軸。如果先點了直線、圓或圓弧，下一下就是放尺寸的位置，軸不能把它搶走。
     - 來由：`verify:ui` 有 3 支腳本（c11、c13、sketch-dimension-label）紅了。它們把尺寸放在 x = 0 上，結果被當成「線＋軸」的角度。零件常以原點置中，這在實際使用中一定會遇到。
     - 要標直線與軸的夾角：先點軸，再點直線。
7. **Schema 68**：限制條件可以參照 `@axisH`／`@axisV`。沒有要轉換的資料；版本升級是為了讓舊程式拒絕開啟，而不是開啟後解不出來。

## 3. 設計：「查得到，但不混進解」
- 求解結果 `SolvedSketch.geometry` **不包含**兩條軸。全 repo 有 17 處以迴圈走訪 geometry：畫圖、輪廓、框選、吸附、拖曳、工程圖。如果把軸混進去，每一處都得排除，漏掉一處就會多出一條 1 mm 的線；不放進去，沒有接線的地方頂多是「選了軸，什麼都沒發生」，屬於安全失效。
- `@3db/model`：新增 `SKETCH_AXIS_H`、`SKETCH_AXIS_V`、`isSketchAxis()`、`sketchAxisDir()`。
- `@3db/sketch/interact`：
  - `axisGeometry(id)` 傳回該軸的 `SolvedGeometry` 直線，從 (0, 0) 到方向上 1 mm 處。
  - `geometryOf(geometry, id)` 等於 `geometry.get(id) ?? axisGeometry(id)`。
  - 需要「依 id 查詢」的地方改用它：`kindOf`、量測點、智慧尺寸、尺寸版面、關係符號、鏡射、旋轉／螺牙的軸。
  - `hitTest` 在草圖的點與曲線之後才看兩條軸，以無限長直線計算距離：草圖自己的圖元優先。
- `planegcs.ts` 的 `toPrimitives`：
  - 只有當某個條件參照到軸時，才推入固定點 `@axisH.end`／`@axisV.end` 和軸線本身（端點之一是 `@origin`）。
  - 沒用到軸的草圖，送進求解器的資料與以前**完全相同**，保住 B3.1 重建決定性。
  - 送進求解器的 id 都以 `@` 開頭，`unique()` 原本就會濾掉，不會被回報成冗餘或衝突的條件。

## 5. 已知限制
- 智慧尺寸只選一條軸時不給尺寸：軸沒有長度。
- 刪除鍵對軸無效，與原點相同。
- 畫圖時不會自動加「點在軸上」。需要時，先畫好，再選點和軸加「重合」。FreeCAD 會自動加，這裡不做，原因是與既有的推斷順序衝突（見 §2.6）。
- 修剪、延伸、草圖圓角、偏移都不會選到軸；只有選取、智慧尺寸和鏡射會。
