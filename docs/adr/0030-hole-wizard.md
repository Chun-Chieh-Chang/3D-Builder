# ADR 0030：異型孔精靈（Phase 3a-6a）

- 狀態：已實作（2026-10-01）。
- 對應：C4.8 異型孔精靈（直孔、柱孔、錐孔、螺紋孔；ISO／CNS 表），見 [phase3-plan](../phase3-plan.md) §3 的 3a-6。定位銷孔的公差等級是 Phase 4a。
- **Schema 升為 17**：新的特徵種類 `hole`。舊檔不需轉換；已補 v16 樣本 `tests/fixtures/old-versions/v16-draft.3dbx`（由 `3ec02db` 寫出）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **孔位＝草圖裡每一個單獨的點**（不是線的端點或圓心，不是幾何建構線）；草圖放在面上，孔從草圖面往材料裡鑽（背著草圖法向，`reverse` 反過來）。沒有點是錯誤。 | 使用者選的做法（2026-10-01）；定位銷孔（Phase 4a）要靠草圖點的位置。 |
| 2 | **孔是一個旋轉出來的刀具，再除料**：把孔的剖面（半徑 × 深度）轉 360°。剖面的每一段有自己的來源名稱：`top`、`wall`（孔壁）、`cbwall`／`cbfloor`（沉頭的壁與底）、`cone`（錐孔的錐面）、`bottom`（盲孔的底）。刀具從表面上方 1 mm 開始，除料才乾淨。每個點各做一次除料，所以面的名稱是 `<孔>:side:<草圖>.<點>.<部位>`，**每個孔的每個面都有自己的名稱**，不會因為加了別的孔而改變。 | 與伸長除料同一條命名路徑（`apply`），不新增命名規則。 |
| 3 | **四種孔**：直孔；柱孔（`cbDiameter`、`cbDepth`，沉頭要比孔大且比總深度淺）；錐孔（`csDiameter`、`csAngle` 夾角，預設 90°，錐到孔徑的深度要比總深度淺）；螺紋孔＝**只做底孔**（鑽到內建表的底孔直徑，不做真實螺紋，裝飾螺紋線是 P2）。終止型態：給定深度（平底）或完全貫穿。 | 使用者選的範圍；平底與錐底的鑽尖角留待之後。 |
| 4 | **內建 ISO 表**（`@3db/model` 的 `holes.ts`）：M3–M20 的底孔、一般與緊配的通孔、柱孔（ISO 4762）與錐孔（ISO 7046）尺寸；CNS 先用同一份並標明來源，介面上註明「參考值，使用前請對照公司標準」。特徵**只存孔徑等運算式**（`size` 只是一個標籤），所以表之後換掉，舊零件不會變。改孔徑會讓規格變成自訂。 | 設計意圖是尺寸本身，不是表的版本。 |
| 5 | **角度的限制是 (0°, 180°)**（新增 `includedAngle`）：錐孔的 90° 夾角不能用拔模角度的 (0°, 90°)。 | 在測試裡踩到。 |
| 6 | **介面**：「特徵」分頁的「異型孔」（選取一張草圖後可用）；屬性管理員選種類、規格、孔徑、沉頭或錐孔尺寸、終止型態、深度、反轉。 | 與其他特徵一致。 |

## 驗證

- **手算體積**（`tests/phase3/hole.test.ts`，7 項，真的 OCCT）：Ø6 深 5：12000 − π·9·5；貫穿：− π·9·10；柱孔 Ø11 深 3 加 Ø6 到 8：− π(5.5²·3 + 9·5)；錐孔 Ø12、90°、到 Ø6 是深 3 的錐台（π/3·3·(36+18+9)）再加直的 5；螺紋孔 M6（底孔 5）深 8：− π·6.25·8；兩個點兩個孔。
- **命名**：每個面的名稱不重複；`h1:side:s2.p1.cbwall` 等存在；板上先倒圓角、孔之後再倒圓角，找得到邊線；板加寬後孔仍在（體積 50×30×10 − π·90）。
- **錯誤**：沒有點、點在板外（「點 p1 的位置沒有材料可以鑽」）、柱孔沉頭不比孔大、錐孔太深、孔徑 0（指令拒絕）。
- **舊檔**：v16 樣本（示範件加拔模）開啟、遷移到 17，拔模照常重算。
- **瀏覽器**（`tests/e2e/phase3-hole.js`）：板頂面上的草圖放一個點，「異型孔」貫穿 Ø6 → 11717.257（手算 11717.2567），改成 M6 柱孔（Ø6.6、Ø11 × 6.5）→ 11262.543（手算 11262.5425）；3 個面的名稱；0 特徵失敗。

## 還沒做

- 鑽尖角（錐底）與孔底的倒角；多個規格的孔在同一個特徵裡；孔的公差與配合註記（Phase 4a 的定位銷孔）。
- 真實螺紋與裝飾螺紋線（P2）；沉頭／錐孔在非平面上的行為（草圖要放在平面上）。
- 「反轉」讓孔往草圖法向鑽時，刀具上方那 1 mm 會在材料裡留下淺窩（沒有材料可鑽時不報錯）。
