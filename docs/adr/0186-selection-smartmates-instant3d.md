# ADR 0186：3D 框選、SmartMates 與 Instant3D

2026-10-23，完成 E4 第一項。無文件版本升級。

框選左至右須完整包含、右至左可交叉，按實際投影幾何判斷；組合件按已放置 leaf 聚合，排除隱藏件。Escape 取消保留先前選取。

Alt 拖曳可建立結合。預覽沿用普通 MateDraft，Tab 翻轉、Escape 取消；放開先完整求解，成功後 insertMates 一次提交。圓邊座面由 Worker 真實 edgeFaces 鄰接資訊挑選唯一平面，無座面時只同心。

Instant3D 為選中單向盲擠出的深度尺。只支援 mm、數值深度；運算式不覆寫。預覽不寫 SSOT，放開一次命令。模型變更或取消時放棄拖曳。尚無即時幾何重建或任意特徵控制柄。

新測試：4 個框選數學案例、2 個深度投影案例，5 個實體瀏覽器流程（零件／組合件框選、平面／圓座 SmartMates、深度拖曳）各有通過結果。失敗只重試失敗項。型別、lint、build 通過；依使用者要求未跑完整 UI。
