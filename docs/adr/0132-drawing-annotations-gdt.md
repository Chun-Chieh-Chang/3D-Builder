# ADR 0132：工程圖的註解、基準、幾何公差與手動中心線（D-I3，工程圖 Schema 11 → 12）

- 狀態：**已完成（2026-10-13）**。
- 需求追溯：`docs/blueprint.md` **C16.5**（原本排在 P2，依 [ADR 0129](0129-drawing-interaction-roadmap.md) 提前）。使用者的決定（2026-10-13）：Q4 採 ISO 1101，先做 14 個基本符號；Q14 把 3/4 圈螺紋線併進這一階段。

## 背景

一張要交給加工廠的夾治具圖，必須寫得出「多平、怎麼定位、去毛邊、熱處理」。原本的文件只有尺寸、表格、表面粗糙度，所以技術要求只能塞進標題欄，幾何公差和基準則完全沒辦法標。

## 決定

1. **Schema 12** 新增 `DrawingDoc.annotations`，有五種註記：
   - `note`：註解，可以分行，可以帶引線，`$PRP:key` 會帶入標題欄欄位或屬性。
   - `datum`：基準特徵符號（ISO 5459）。
   - `fcf`：幾何公差框（ISO 1101）。
   - `centreLine`、`centreMark`：手動中心線與中心符號線。

   位置都記在**視圖座標**裡，所以會跟著視圖移動；大小在圖紙上是固定的。舊檔的遷移 `11 → 12` 補上空的清單；註記的 id 也納入計數，不會重用。
2. **命令層依 ISO 1101、ISO 2692 明確拒絕不合規的組合**（`CHARACTERISTIC_RULES`）：
   - 形狀公差（直度、平面度、圓度、圓柱度）不可有基準。
   - 方向公差、跳動、同心度、對稱度至少要一個基準。
   - 輪廓度與位置度的基準可有可無。
   - Ø 只能用在直度、方向公差、位置度、同心度。
   - Ⓜ／Ⓛ 只能用在尺寸特徵：直度、方向公差、位置度、同心度、對稱度。
   - 公差值必須大於 0；基準最多 3 個，不可重複。
3. **基準的一致性**：
   - 字母必須是 1～2 個大寫字母，不用 I、O、Q（ISO 5459 不建議，容易和 1、0 混淆），全圖不可重複。
   - 公差框只能引用圖上存在的基準。同一個命令裡先插入的基準也算數。
   - 基準改名時，引用它的公差框跟著改名。
   - 基準還被保留下來的公差框引用時，不能刪除，連同它所在的視圖一起刪也不行；會說明有幾個公差框在用。
   - 基準和引用它的公差框一起刪，則可以。
4. **符號一律畫成向量線條**（`characteristicSymbol`），不依賴字型：PDF 的標準字型和 DXF 閱讀器都沒有這些字元，同一張圖在哪裡打開都要長得一樣。Ⓜ、Ⓛ 是圓圈加上字母。
5. **3/4 圈螺紋線（ISO 6410-1）**：螺紋孔從端面看時，在大徑畫約 3/4 圈的細實線，右上角留開。大徑從規格讀取（`M6` → 6，`M10x1.25` → 10）。讀不出來的規格（自訂孔徑、英制）**不畫**，不自己編一個數字。
6. **介面**：
   - 五個工具都是點兩下：註解、公差框、基準是「先點特徵，再點放置位置」，兩下點在同一處就不加引線；中心線是兩點，會貼齊圓心；中心符號線是點一個圓。
   - 點在視圖外框線外一點點（在點選容許距離內）也算點在該視圖上，因為特徵最常就是外框線。
   - 註解點在圖紙空白處時，歸給最近的視圖。
   - 可以點選、Ctrl 加選、框選、拖曳（引線的端點留在特徵上）、Delete。
   - 公差框編輯器只提供該公差種類允許的選項；切換種類時，自動拿掉不允許的 Ø、Ⓜ、基準。

## 限制

- 位置記在視圖座標，**沒有綁定模型元素**。模型改變時，註記跟著視圖移動，但不會跟著特徵移動，這點和表面粗糙度（ADR 0125）一樣。要等 D-I2 讓視圖的線有名字之後，才能綁定到邊或面。
- 螺紋只畫端面的 3/4 圈；側視圖的螺紋細線還沒畫。
- 基準框拖曳時是整個移動；要改方向和距離，得在面板輸入角度和長度。

## 驗證

- `tests/phase5/drawing-gdt.test.ts`（14 項）：
  - 14 種公差逐一檢查基準（無／可有可無／必須）、Ø、Ⓜ 的允許與拒絕。
  - 公差值、基準數量與重複、實體條件的非法輸入。
  - 基準字母的規則；公差框只能引用存在的基準；改名連動；刪除被拒（單獨刪、隨視圖刪）與一起刪成功。
  - 註解的字數、字高、座標非法值；`$PRP` 的帶入與查不到時保留原文；中心線與中心符號線的非法值；欄位的權限。
  - 存檔讀回內容相同，v11 舊檔讀進來是空清單，id 計數正確。
  - 14 種符號都畫得出來；公差框寫出 Ø0.05、A、B、M。
  - 3/4 圈螺紋線：大徑的解析；M6 的弧每一點都在 R3 上，右上象限沒有點，線型是細線；規格讀不出來或不是螺紋孔時不畫。
- 瀏覽器（定位板，真實 pointer 事件）：
  - 基準點在外框線外 0.3 mm 也成立。
  - 公差框加上 Ø、Ⓜ、基準 A；切換成平面度時，基準、Ø、Ⓜ 自動拿掉。
  - 刪除使用中的基準被拒；改名 A → B 時公差框跟著改；兩者一起選取後按 Delete 成功，復原一次全部還原。
  - 註解（帶入「材質 S45C」）、中心符號線貼齊 Ø9 孔（半徑 4.5）、中心線貼齊兩個孔的圓心。
  - 拖曳公差框 10 mm，引線端點不動；框選選到全部 6 個註記、0 個視圖。
  - DXF 裡有公差值和技術要求文字；中文依 DXF 慣例以 `\U+XXXX` 寫入。
  - Console 沒有錯誤。
- 全部測試：2654 項通過。唯一一項失敗是 `drawing-linked.test.ts` 釘住了 schema 版本號 11，這次是刻意升版，所以改成 12（之前每次升版也都這樣更新，例如 ADR 0128 從 10 改成 11）。
