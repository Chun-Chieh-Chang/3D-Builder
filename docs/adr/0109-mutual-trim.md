# ADR 0109：互相修剪曲面（P-3，零件 Schema 46）

- 狀態：**已實作並驗證（2026-10-07）**。來源：手冊 G3／G4 的已知沒做「曲面互相修剪」；小驗證與計畫見 [surface-trim-plan](../surface-trim-plan.md)。
- 零件 Schema 45 → **46**（遷移是空的：新種類的特徵，舊程式會因版本號拒絕開啟而不是略過它）。
- 特徵種類取名 `mutualTrim`，不是計畫裡的 `trimSurfaces`：已有 `trimSurface`（修剪曲面，用草圖），兩個只差一個 s，搜尋與打字都容易弄錯。

## 決定與做法

1. **核心**：`Kernel.trimSurfaces(a, b)`。兩個曲面本體當參數做一次一般融合（`BRepAlgoAPI_BuilderAlgo`，記歷史），再 `SimplifyResult`（把同一個曲面上的面合回去：洞跨在圓柱接縫上是一片，不是兩片）。回傳兩個結果（`a`、`b`），各是自己那一側的片的 compound，每一片帶 `faceOrigins`（來自輸入的哪個面；被切過是 `modified`，沒動是 `same`）。兩邊有疊在一起的片（同一個平面給兩次）直接拒絕：一片不能同時屬於兩個本體。
2. **特徵**：`MutualTrimFeature { a, b, discard? }`。兩個曲面本體原地變成各自的片（id 不變，仍是曲面）；`discard` 是要去掉的片（面的參照）。
3. **面名**：片沿用原來那個面的名字（`modified`／`same` 在命名層就是輸入的名字）；同一個面分成幾片時加 `#1`、`#2`，按片的重心座標排序（x、y、z；與分割線同一套規則）。去掉某片後其他片的名字不變。
4. **去掉的片**：在引擎裡先算出全部的片並命名，再用 `resolveRef` 對照 `discard`，用 `keepFaces`（修剪曲面也用的）留下其餘。找不到的片連同其他找不到的一起報告（附候選）；一個本體的每一片都去掉會被拒絕。`discard` 的名字是更早的特徵產生的，所以它們是依賴圖裡的父節點，特徵自己不是（排除自己的 id）。
5. **失敗時說原因**：選到實體、兩個選同一個、本體不見、沒有交線（面數都沒變：不相交或只是相切；不會靜靜地原樣回傳）、兩個面疊在一起、去掉的片找不到、一個本體全去掉。
6. **介面**：「特徵」→「互相修剪曲面」（至少兩個曲面本體才可用）；面板兩個下拉選本體、「去掉的曲面片」清單（✕ 取回）、狀態列說各有幾片、去掉幾片；在圖面點一片就去掉、再點取回，點到不是這兩個本體的面會說明。編輯時顯示修剪後的模型（所以點得到片）。說明主題 `mutual-trim`，手冊 G3 多一步。

## 驗證

- `tests/phase4b/mutual-trim.test.ts`（11 項；方塊 40 × 30 × 20，頂面偏移成 z = 12 的平面，側面偏移成 x = 25 的平面）：交線 x = 25、z = 12，第一個曲面 **750 + 450**、第二個 **360 + 240**（容差 1e-4）；名字 `…#1`、`…#2` 且全模型的面名不重複；去掉 `#2` 後剩 750、360 且名字不變；第二個平面移到 x = 30，要去掉的那片（x 較大的）跟著模型走：剩 900；兩片縫織成一個兩個面的曲面本體；單一片加厚 1 是 **750 mm³**；七種失敗訊息；兩個疊在一起的面被拒絕；指令的增減與型別檢查。核心層：細圓柱（R6）穿過粗圓柱（R10，接縫在 x = 10）是 3 片加 3 片，不是 4 片，面積不少（容差 1e-1 mm²，數值積分），每一片的來源是 `modified`。
- `tests/phase4b/surface-trim-spike.test.ts`（8 項）：小驗證，含自由曲面（放樣的 B 樣條面）對平面。
- 瀏覽器（`tests/e2e/phase4b-mutual-trim-ui.js`）：開面板、兩個下拉預選、片數、點一片去掉、清單取回、再去掉各一片、點方塊的面不會被去掉、✔ 後縫織成一個兩個面的本體。

## 限制（已知，沒有掩飾）

- **兩個自由曲面互相相交沒有測**（只測了平面對平面、圓柱對圓柱、自由曲面對平面）。偏移、填補曲面的相交同樣沒測。
- 同一個面分成幾片的 `#k` 是按位置排的：改了尺寸讓片數變了，原來點的片可能對不上，會走既有的指紋重新對應並提示，找不到時報錯。與分割線相同的限制。
- 沒有交線（相切、不相交）一律失敗，沒有「什麼都不做」的選項。
- 只有兩個本體；三個以上要連做幾次。
- **曲面彎折處的厚面**：原本把交線兩側各留一片縫成 L 形再厚面，會得到體積 924 mm³ 的「實體」，而它的面並沒有把實體封閉（用網格算是 880）。根因與處理見 [ADR 0112](0112-thicken-sharp-edge.md)：現在厚面遇到尖角會拒絕並說明。單一片加厚是準確的（750）。
