# ADR 0023：草圖工具 P1（Phase 3a-4a）——狹槽、多邊形、圓角／導角、修剪／延伸、偏移、鏡射

- 狀態：已實作（2026-10-01）。4b（P1 限制條件與從動尺寸）、4c（衝突診斷與草圖檢查）、4d（參考圖元）接在後面，各有自己的紀錄。
- 對應：C1.8 狹槽、C1.9 多邊形、C1.15 草圖圓角與導角、C1.16 修剪與延伸、C1.17 偏移圖元、C1.19 鏡射圖元，見 [phase3-plan](../phase3-plan.md) §3 的 3a-4。
- **Schema 不變（仍是 10）**：這些工具做出來的都是既有的點、線、圓、圓弧與限制條件，舊檔照開，新檔也能被舊版讀（只是沒有任何新種類的圖元）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **每個工具都是純函式，回傳一個 `SketchEdit`**（`packages/sketch/src/ops.ts`）：要新增的圖元與限制條件、要改的參照、要刪的項目。控制器用一個新指令 `editSketch` 套用，所以每個操作是一次復原。 | 操作的幾何要能不靠畫面測試；一次一個指令才能一次復原。 |
| 2 | **`editSketch` 的順序是「改參照 → 新增 → 刪除」**，刪除放在新增之後。 | `removalSet` 會把「只被被刪曲線用的端點」一起刪掉；新增放前面，新圖元用到的點就不會被當成孤兒。 |
| 3 | **求解器先放所有點，再放線與弧**（`planegcs.ts`）。 | PlaneGCS 要求被參照的物件先定義；編輯可以讓一條線指向後面才新增的點。 |
| 4 | **圓角與導角用「虛擬交點」**：原來的角點 P 留著，兩條線各加「點在線上」，線的端點換成切點。圓角加半徑尺寸；導角加兩個距離尺寸；原本量到角點的線長尺寸改量「遠端點到 P」。 | 角點上原有的尺寸與限制條件不會掉；自由度算得出來：P 固定時圓角與導角都完全定義。 |
| 5 | **狹槽**：兩條平行線 + 兩段弧，四個相切 + 兩弧半徑相等，剩五個自由度（兩個圓心與寬度）。 | 與 SolidWorks 相同的自由度；沒有多餘限制條件。 |
| 6 | **多邊形**：構造圓 + 各頂點「點在圓上」+ 各邊等長，剩四個自由度（中心、大小、轉角）。「以邊的中點定大小」只改第二次點擊怎麼換算大小，不改限制條件。 | 外切圓的相切寫法在 n ≥ 4 時有多餘限制條件。 |
| 7 | **鏡射是靜態鏡射、以「對稱」限制保持連動**：每個點有一個鏡射的分身，用 `symmetric` 連到鏡射軸；圓弧的起迄顛倒；圓的半徑相等；軸上的點是自己的分身；原圖元之間的限制條件不複製，由對稱帶過去。 | 使用者選的方式（4a 開工時確認）；複製限制條件會與對稱重複。 |
| 8 | **修剪**：點到的那一段，在與其他曲線的最近交點之間（或到端點）刪掉。沒有交點就整條刪除。中間一段被切掉時，線分成兩條，第二條複製「水平／垂直／平行／垂直／共線」；弧分成兩段，第二段與第一段半徑相等；圓剩下的是一段弧（原圓的尺寸改掛到這段弧）。新端點「點在切斷它的曲線上」。整條曲線的線長與相等、中點關係會刪掉。 | 不留懸空的限制條件：被刪的點連同掛在它上面的東西一起刪。 |
| 9 | **延伸**：靠點擊較近的那一端，延伸到路上第一條曲線；新端點「點在那條曲線上」，舊端點連同掛在上面的東西刪掉，整條曲線的線長與相等關係刪掉。**端點若被其他圖元共用就拒絕**，因為延伸會把它們一起拖走。 | 與其默默改了別的東西，不如明說拒絕。 |
| 10 | **偏移**：選取的線與弧若首尾相接就當一條鏈一起偏移、往同一側（點擊的那一側）；轉角在偏移後的兩條線的交點。每條偏移線「平行 + 距離」，**第一條的距離是驅動尺寸，其他的距離寫成 `D<n>@<草圖名稱>`**，改一個全部跟著變；弧與圓與原來同圓心（共用圓心點），新半徑是數字尺寸。**開放鏈的兩個端點沿曲線的方向不釘住**（欠定義，使用者可以再標註）。 | 與 SolidWorks 的行為相近，限制條件數量剛好，不會冗餘。 |
| 11 | **相切接續的轉角要用「相切」代替一條線的「平行」或「距離」**：偏移後兩條相切曲線的交點，「點在線上」與「點在圓上」兩個式子的梯度同向，會被求解器判為冗餘。線與弧相切接續時，線改用「相切」限制條件（兩端都相切就不需要距離）。線與線、弧與弧的相切接續目前**拒絕**（回報「偏移後在轉角處接不起來」）。 | 在狹槽偏移時實測出的冗餘；其他組合少見，先明說做不到。 |
| 12 | **控制器先在副本上試解，過多定義或失敗就拒絕**，與尺寸、限制條件相同；試解用「套用後的文件」解開運算式（偏移的 `D<n>@…` 只存在於套用後的草圖）。 | 與既有的做法一致，不讓使用者把草圖弄成過多定義。 |
| 13 | **鏡射與偏移用「先選取、再選工具」**（預選），沒有選取就提示並留在選取工具。偏移會把選取的曲線沿共用端點延伸成整條鏈。其他工具（修剪、延伸、圓角／導角）是直接點圖元；圓角／導角可以點角點，也可以依序點兩條線。 | SolidWorks 也支援預選；避免「選圖元」與「選軸」兩個階段需要額外的確認按鈕。 |
| 14 | **工具選項**（多邊形邊數與外切、圓角半徑、導角兩個距離、偏移距離）放在屬性管理員，存在控制器、不進文件。 | 它們是操作的輸入，不是設計意圖。 |

## 驗證

- **單元測試**（`packages/sketch/test/ops.test.ts`，31 項，用真的 PlaneGCS）：狹槽自由度 5 並可被完全定義；多邊形 3、4、5、6、8 邊自由度 4、邊長 = 2r·sin(π/n)；鏡射的分身位置、弧的方向、拖曳連動；圓角與導角的切點與圓心（手算）、矩形圓角後仍是封閉輪廓；修剪（端、中間、整條、圓變弧、弧）與延伸（線、弧、拒絕）；偏移（內縮矩形 2 mm 完全定義、改一個尺寸四邊一起變、外擴、狹槽、開放鏈轉角、圓、拒絕分岔）；`editSketch` 的拒絕條件。
- **控制器測試**（`apps/web/test/sketcher.test.ts`，新增 8 項）：每個工具的流程、一次復原、沒選取的提示、試解拒絕。
- **瀏覽器**（`tests/e2e/phase3-sketch-tools.js`）：狹槽伸長體積 (300 + 25π)×10 = 3785.398、六邊形 2598.076、圓角矩形 7965.664、偏移內縮 2 的框 2240，與手算值一致（相對誤差 < 1e-9）；修剪後一次復原回到原樣；每個腳本 0 Console 錯誤、特徵無失敗。
- `npm run check`：510 項通過、20 項需樣本而略過；i18n 的基準沒有增加（628 行）。

## 還沒做（4a 之外）

- 圓角／導角、修剪、延伸、偏移、鏡射的預覽只有狹槽與多邊形有（其餘在點擊後立刻出現結果）。
- 偏移的「雙向」與「端點加蓋」、修剪的「修剪到最近的交點之外的選項」（強力修剪、修剪到最近端）；延伸到共用端點。
- 偏移的弧半徑是數字尺寸，不隨偏移距離連動（線會連動）。
- 線與線、弧與弧相切接續的偏移（決定 11）。

## 2026-10-24：決定 9 的共用端點限制更新

使用者確認保留原矩形並接續新增共線延伸段。共用端點不再直接拒絕；實作、約束、重疊攔截與真實求解／UI 驗證見 [ADR 0194](0194-extend-shared-sketch-endpoints.md)。非共用端點仍沿用原長度修改行為。
