# ADR 0192：尺寸文字與標註線連動拖曳

2026-10-24。修正草圖與工程圖尺寸位置操作，Schema 不變（零件 80／工程圖 28）。

> 2026-10-26：工程圖文字拖曳決策已由[ADR0206](0206-drawing-dimension-interaction.md)調整為文字沿線／弧獨立滑移；下文保留原實作歷史，草圖行為不變。

## 問題與決定

草圖原本只儲存 `labelPosition`，標註線仍照自動排版，另加一條引線到文字，因此使用者只能搬數字。現在 `layoutDimension` 由同一文字位置推導線性尺寸的標註線與延伸線，半徑／直徑引線方向及角度／弧長標註弧亦跟隨位置。既有檔案的文字位置保留，標註線會隨之重排；未手動定位仍採自動排版。

草圖選取工具用實際顯示線段作命中判斷，容差依目前縮放換算；實際草圖點／線重疊時優先操作幾何。標註線、箭頭及延伸線皆可拖曳；抓取位置保留相對差，不讓文字跳到抓線位置。拖曳時僅預覽，放開以既有 `setDimensionPosition` 寫一次，單次復原；點擊選取、雙擊開尺寸編輯，Esc 或離開繪圖區取消未提交的線拖曳。原有文字拖曳放開也使用同一排版。

工程圖原已有線／文字命中與線拖曳；此次讓線性尺寸的文字同時改 offset 與 slide，角度文字同時改 arc 與 slide。改以相對於按下位置的變化量加回原值，讓抓延伸線時尺寸線不跳到滑鼠位置。單抓線保持原有文字沿線位置，放開寫一次命令。半徑／直徑仍沿用既有引線拖曳。

只修改顯示位置，不改尺寸數值、驅動／參考性質或幾何參照。沒有為螺紋邊導角宣稱修復；使用者確認普通面問題由未拉取修正造成，螺紋邊另待原始模型重現。
