# ADR 0099：草圖吸附與推斷（S-1 到 S-4）

- 狀態：**已實作並驗證（2026-10-06）**。計畫與行為依據：[sketch-snapping-plan](../sketch-snapping-plan.md)（SW 2010 繁中說明的「推斷」「草圖抓取」「快速抓取」）。
- 沒有改變檔案格式（吸附只影響畫的時候加進草圖的點與關係）。

## 做法（第一性原理：只加使用者看得到、關得掉的東西）

1. **一個決定點**：`SketchController.updateSnap`（`apps/web/src/sketcher/controller.ts`）；純幾何在 `@3db/sketch`：`interact.ts`（`snap`、`alignments`、`inferLine`、`snapModel`）與新的 `snaps.ts`（交點、四分之一點、切點、垂足、網格、角度、長度；設定的型別與預設）。控制器不做幾何，只決定順序與要加什麼關係。
2. **優先順序**（從強到弱）：草圖的點與中點 → 模型的端點／圓心／中點 → 交點 → 四分之一點 → 切點（畫線，從起點）→ 垂足（畫線，從起點）→ 草圖圖元上的最近點 → 模型邊上的位置 → 〔自由的點上〕相切（從圓弧端點）、水平／垂直、共線／平行／垂直（畫線）→ 水平點／垂直點（與其他草圖點對齊，5 像素）→ 長度（Shift）、角度、網格。吸到的那一種決定標示（名稱在游標旁、亮顯）與按下去加的關係；這個順序寫在 `help.conceptSketchSnaps`。
3. **按下去加的關係**（都在同一個復原步驟）：點重合（合併）、中點、在圖元上；水平點／垂直點＝新點與目標點水平／垂直；模型邊＝跟著模型走的圖元加重合；**交點**＝`intersection`；**四分之一點**＝`pointOnCurve`＋與圓心水平／垂直；**切點**＝直線與圓的 `tangent`；**垂足**＝直線與那條線 `perpendicular`＋終點在那條線上；共線／平行／垂直、水平／垂直、相切（從圓弧端點）如 S-1。網格、角度、長度只改座標，不加關係。
4. **設定與開關**（`SnapSettings`，存在瀏覽器的系統選項，不進零件檔）：「啟用抓取」總開關（關掉時什麼都不吸、什麼關係都不自動加，與 SW 的「啟用抓取」清除「自動給定限制條件」一致）、每一種個別的開關、網格（預設不啟用，間距預設 5 mm）、角度（預設不啟用，間隔預設 15°）。**快速抓取**：在畫圖的工具中按右鍵 →「快速抓取」選一種，其他全部暫時關掉（連網格與角度）；換工具時結束，左邊面板寫著目前的快速抓取並可取消。
5. **模型幾何**（S-2）：背景是工作者列出草圖面上的模型邊（`planarEdgeItems`），商店在每次重算後更新；點到時 `anchorModel` 把那條邊做成跟著模型走的圖元，與「轉換實體引用」同一套。

## 副作用與限制

- 自動加的關係會讓之後手動加的關係變成多餘（例如圓心與另一圓心被推成水平後再加「同心同徑」）：這是 SW 也有的行為；可以在選項關掉那一種或整個關掉。
- 兩條共用端點的線做共線，求解器原本說多餘，現在只要求平行（`planegcs.ts`）。
- 沒做：「平行」抓取（畫出與某條線平行的線，SW 的「平行」抓取要先把游標停在那條線上；我們用推斷的方式做，不要先停留）、橢圓與不規則曲線的抓取（草圖沒有這些圖元）、網格的畫面顯示（只吸附，不畫格線）、快速抓取「雙擊保留」（我們的快速抓取一直保留到換工具）。
- 模型邊的吸附只吸「在草圖面上」的邊；與草圖面不共面的邊與頂點不吸。
