# ADR 0078：不等殼厚（Phase 6-4，C5.4，零件 Schema 32）

- 狀態：已實作並驗證（2026-10-04）。限制見最後一節。
- 相關：[phase6-plan](../phase6-plan.md)、[ADR 0074](0074-plastic-validation.md)（驗證：殼加移動面）、`Kernel.shell`、`Kernel.moveFace`（Phase 3a）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **薄殼特徵多一個 `faceThickness`**（零件 Schema 32）：`{ face: Ref, thickness: Expr }[]`，保留的面與它後面的壁厚；沒列到的面用 `thickness`。壁厚是運算式（跟著變數），要大於 0；檔案只存意圖 | 與其他特徵一致 |
| 2 | **做法：先用 `thickness` 做整個殼，再逐一把「由這個面長出來的內側平面」沿它的法向移動 `指定厚度 − thickness`**（`kernel.moveFace`；往空腔移動是變厚、往外是變薄）。內側面由殼的來源（`faceOrigins` 裡「由第 i 個面生成」）找到，之後用**名稱**追蹤它（移動保留名稱），所以移動一個不會找不到下一個；每次移動後的名字用同一個命名流程（`<特徵>:shell:<面名>`，被移動的面與它旁邊的面照舊，移動時新長出的側面取鄰面的名字） | 6-0 驗證：OCCT 的殼只有一個厚度；`moveFace` 是現成的 |
| 3 | **每一步都檢查結果**：被移動的內側面要真的在指定的位置（沿法向移動了 `指定 − thickness`，1e-6），**而且本體的外包不能比殼做完時大**。驗證時發現：地板 40 厚放進 30 高的本體時 `moveFace` 回「有效」的本體，只是把板長到本體上方（體積變大、面也在要的位置），沒有報錯；沒有外包檢查就會安靜地給出錯的答案。不合就失敗，說「這個壁厚放不進本體」 | 驗證時發現的安靜錯誤 |
| 4 | **只限平面的壁**（`moveFace` 的限制：曲面或與它相切的面會被拒），訊息說「個別壁厚做不出來：只能移動平面…」；被移除（打開）的面不能有自己的壁；面不見了、沒有對應的內側面都有訊息 | 計畫與 ADR 0074 |
| 5 | **指令** `setShell` 多一個選用的 `faceThickness`：沒給就照舊（所以別的呼叫端不會把它洗掉）、給空陣列就拿掉、只能放面。參照（改名、取代）、相依圖（父特徵）、運算式（變數）都處理了 | 沿用薄殼指令的形狀 |
| 6 | **介面**：薄殼的 PropertyManager 多一個「在圖面點選的面是」——「要移除（打開）的面」（原本的）或「壁厚不同的面」；選了後者，在圖面點保留的面會放進「壁厚不同的面」清單（厚度先是上面的壁厚），清單每一列有自己的厚度輸入與 ✕；再點一次已在清單的面取消；點被移除的面會被拒絕並說明；被選的面也在圖面上標示。新建薄殼時模式回到「要移除」 | 一個選取框兩種用途，用模式分開，比兩個框少一次游標移動 |

## 驗證（證據）

- **特徵**（`tests/phase6/unequal-shell.test.ts`，11 項，箱子 60 × 40 × 30、殼 2、頂開口）：原樣 72000 − 56·36·28 = 15552；**地板 4：72000 − 56·36·26 = 19584、有效、面數與均勻殼相同**；+x 壁 3：72000 − 55·36·28 = 16560；−x 壁 1（比其他薄）：72000 − 57·36·28 = 14544；**地板 4 加 +x 壁 3：72000 − 55·36·26 = 20520**（一次移動不會讓下一次找不到）；壁給的厚度與其他相同時不動；**箱子改 70 寬、地板 4：名字集合不變、體積 84000 − 66·36·26**；被打開的面不能有壁、不存在的面說找不到；圓柱殼的側壁給 3 說只限平面（沒給時照常做得出）；**地板 40 厚（放不進 30 高）被拒絕並說「個別壁厚…放不進」**（修正前是安靜地成功）；厚度 0 與負的在輸入時被拒；`setShell` 沒給 `faceThickness` 保留、給清單改、給空陣列拿掉、放邊被拒、版本是 32；壁厚是運算式 `floor`：4 時 19584、改成 3 時 72000 − 56·36·27。
- **瀏覽器**（`tests/e2e/phase6-shell-ui.js`，全部通過，沒有 Console 錯誤）：開啟箱子、選頂面按「薄殼」：頂面被移除；選「壁厚不同的面」模式、點地板：清單有地板（厚度 2）、PropertyManager 列出；厚度改 4；點頂面被拒絕；✔ 之後**體積 19584**；重新編輯改 40：**✔ 之後這個特徵出錯，訊息說個別壁厚放不進**；改回 4：19584；再點地板：拿掉、體積回 15552。
- `npm run check`：1358 項通過、21 項略過。

## 限制與未做

- **只限平面的壁**；曲面（圓柱、球）或與它相切的面的壁不能不等厚。要做曲面壁不等厚需要另一個做法（例如偏移不同距離再布林），沒有驗證。
- **編輯時看不到結果**：薄殼編輯時顯示的是殼之前的模型（要在上面選面），所以「放不進」的訊息在 ✔ 之後才出現在特徵上，不在 PropertyManager 的訊息框；其他面特徵（圓角、導角）也是這樣。
- **加厚的壁要放得進本體**（外包不能變大）：判斷是外包，不是「壁與別的特徵相交」；形狀複雜時（內側有肋、凸起）移動可能碰到它們，由 `moveFace` 的布林負責，結果有效但沒有逐一驗證。
- 往外的殼（`outward`）的個別壁厚用同一個公式，只有公式（沒有針對它的測試）。
- 移動的順序是清單的順序；兩面共用一個邊（相鄰的壁）時彼此的角怎麼接是 `moveFace` 的行為（20520 的案例驗證了地板加一面牆）。
