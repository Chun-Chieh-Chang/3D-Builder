# ADR 0227：尺寸線畫在視圖上

日期：2026-11-02。狀態：已實作。

## 問題與選擇

使用者問：階梯銷的 Ø10.54（軸向水平的圓柱段）能否標註在左右兩端面之間。

線性尺寸的尺寸線原本只能畫在視圖**外**：`offset` 是視圖框外的距離（正為一側、負為另一側，0 不合法）。因此「畫在兩端面之間」不是畫得準不準的問題，而是根本沒有這個位置可畫。

要能畫在視圖上，尺寸線得有一個「在視圖上的哪裡」。選擇：線性尺寸新增 `insideAt`——**視圖本身的毫米**（水平尺寸是視圖的 y、垂直尺寸是視圖的 x），也就是零件上的一個地方；視圖縮放時位置跟著零件走。沿用 `offset` 重新解讀會讓既有圖檔的外觀與意義漂移，故採新增欄位。

## 畫法與操作

畫在視圖上時（ISO 129-1「尺寸線畫在視圖上」）：箭頭尖直接接觸被量的輪廓，**不畫延伸線**——延伸線此時會壓在輪廓上，等於在同一條線上疊兩條線。量測的仍是同一對特徵，數值不變（Ø10.54 仍是 10.54）。

**修正（2026-11-02 同日）**：上句只在「被量的輪廓經過尺寸線所在位置」時成立。輪廓停在尺寸線之前（圓角、較短的階梯），或特徵是點（頂點、孔中心）時，箭頭會懸在空白處（真實定位板 R10 圓角處量到距輪廓 2.81 mm）。因此每一端分別判斷：可見輪廓經過尺寸線 → 不畫延伸線；否則自輪廓最近的端點（點特徵則自該點）留 `GAP` 畫延伸線，超出尺寸線 `OVERSHOOT`。面、邊或圓柱輪廓在視圖線尚未取得時範圍未知，不畫（不猜）。

**文字滑出箭頭之外（2026-11-02 同日，三階圓柱實例）**：使用者把凹入中段的 Ø12 尺寸線畫在視圖上，再把數字拖到輪廓外；尺寸線只畫在兩箭頭之間，數字因此孤立在外。線性尺寸（視圖上與視圖外皆然）的文字中心滑出兩箭頭之外時，尺寸線向該側延伸到文字的遠端（ISO 129-1）。文字中心仍在兩箭頭之間、只是比尺寸線寬（例如 Ø10.54 寬於 10.54）時不延伸，既有圖面外觀不變。

操作有兩條，任選其一：

- **拖曳**：把尺寸線拖進視圖即畫在視圖上；拖出視圖即回到視圖外，距離以指標所在為準。拖曳時抓的是尺寸線本身（不是數字），數字仍只沿線滑。
- **屬性面板**：「尺寸線畫在視圖上」開關（勾選即畫在視圖上），加「位置（視圖的毫米）」欄位可精確指定；開啟時的位置預設是被量的兩點在該軸上的位置（水平尺寸取 y、垂直尺寸取 x）。

對齊（aligned）尺寸沒有這樣的位置（它的尺寸線不與視圖垂直），不提供。

`offset` 與 `insideAt` 並存：畫在視圖上時 `offset` 仍保留，拖回視圖外時回到原處。`offset` 原有的意義（視圖外一側的距離）不變；給 `offset` 就取走 `insideAt`，給 `insideAt` 不動 `offset`。

## 資料與命令

工程圖 schema 38 新增可選欄位 `insideAt`；37→38 遷移不改舊值（舊檔的尺寸線都在視圖外，但舊程式讀到新欄位會把尺寸線畫在視圖外，故仍升版）。`setDimension` 只接受線性尺寸用它；非有限值與對齊尺寸以 `drawing.dimBadInside` 拒絕，非線性尺寸以 `drawing.notForKind` 拒絕。

座標尺寸（ordinate）另有一種 handle（`kind: 'ordinate'`）：它的「行」本來就在視圖外，不該與線性尺寸共用「畫在視圖上」的路徑。排列（arrange）仍把它與同側的線性尺寸疊在一起（B2.5），不受影響。

## 驗證與邊界

- 單元（`tests/phase5/drawing-dimension-inside.test.ts`）：尺寸線落在指定的視圖位置、兩端箭頭接觸輪廓、輪廓經過時沒有延伸線、輪廓未達或點特徵時延伸線的起訖點、文字滑出箭頭外時尺寸線延伸到文字遠端（只懸出時不延伸）、數值不變、視圖縮放後位置仍對、視圖外的排版與原來一致、拖曳的內外切換、文字仍只沿線滑、命令的接受與拒絕、存檔讀回。
- 瀏覽器（`tests/e2e/manual-drawing-dimension-on-view.js`）：真實定位板，指標拖尺寸線進視圖、拖出視圖、復原，屬性面板的開關與位置欄位；圓角處（y = 輪廓下緣 + 2）箭頭離輪廓時的延伸線。
- 瀏覽器（`tests/e2e/manual-drawing-dimension-stepped.js`）：實建三階圓柱（Ø20／Ø12／Ø20），Ø12 畫在視圖上、指標把數字拖出輪廓，尺寸線延伸到數字遠端、箭頭仍貼輪廓。
- 邊界：只支援水平與垂直的線性尺寸；直徑、半徑、角度、座標尺寸維持原行為。尺寸線畫在視圖上時，文字壓在零件上（與 ISO 的畫法一致，排位由使用者自行安排）。
