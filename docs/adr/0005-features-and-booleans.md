# ADR 0005：特徵與布林（Phase 1B）

- 狀態：已採用（Phase 1B，2026-09-27）
- 依據：藍圖附錄 C 的 C4.1–C4.3、C5.3、A1.5、C1.1；[handoff.md](../../handoff.md) 的里程碑 1B

## 決策

| # | 決策 | 理由 |
|---|---|---|
| 1 | **布林結果的面來源**：核心回報的索引，指向「目標的面 + 工具的面」串接起來的清單；命名層用同樣串接的名稱清單來繼承 | 兩個輸入的名稱都能保留，不需要改命名文法 |
| 2 | **工具先命名，再做布林**：伸長或旋轉的實體先依掃掠規則命名（`side`/`cap`），再併入或除去本體。特徵自己的面名稱（例 `cut1:side:sketch2.ci1`）會一路保留到結果裡 | 下游特徵引用的是「這個特徵產生的面」，不是布林的中間產物 |
| 3 | **每次布林後都合併共面**（`ShapeUpgrade_UnifySameDomain`）。合併出的面保留所有來源，名稱取第一個來源，也就是目標（較早的特徵） | SW 同樣會合併共面；取較早特徵的名稱，指向它的參考不會因後來的特徵而斷掉 |
| 4 | **比對基底名稱時，去掉每一層的 `#k`**：`{e1:cap:end#2\|e1:side:s1.al1}` 與 `{e1:cap:end\|e1:side:s1.al1}` 視為同一個基底。唯一時直接解析；有多個時用指紋判斷；仍無法分辨就回報模稜兩可 | 面被切開之前建立的參考，在之後插入的除料切開這個面後，仍能找到同一條邊。原本只去掉最外層的後綴，這種情況會變成遺失參考 |
| 5 | **伸長方向**：填料沿草圖法向，除料往材料內部（法向的反方向）；「反轉方向」可以翻轉 | 與 SW 的預設相同。在面上畫的除料草圖，不必設定就會切進去 |
| 6 | **完全貫穿、成形至某一面**：角柱長度取本體外框在該方向上的延伸再加餘量。成形至某一面，是用該面的底層曲面（平面即為無限大）建立半空間來修剪，修剪出的端面命名為 `cap:end` | 用有限的面建立半空間，只會修剪到面正下方的輪廓。這是實測時發現並修正的 |
| 7 | **除料沒有移除任何材料就報錯**，並提示「試試反轉方向」；除料移除整個本體也報錯 | 把「方向打錯」變成看得見的錯誤，而不是一個沒有作用的特徵 |
| 8 | **旋轉**：軸是同一草圖裡的一條直線，預設取第一條中心線。兩側對稱的做法是先把草圖平面繞軸轉 −θ/2。輪廓跨過軸時報錯。`MakeRevol` 一律以 4 個參數呼叫 | 3 個參數時，多載分派無法區分「角度」與「是否複製」 |
| 9 | **導角**：第一距離量在相鄰兩面中，持久名稱排序較前的那一面；勾選「反轉方向」則改量另一面 | 不依拓撲順序決定，重建後不會自己翻過來 |
| 10 | **在模型平面上繪製草圖**：草圖平面是一個面參考。座標系規則見 `planeFrame`：原點是零件原點在平面上的投影；非水平面的 y 軸取世界 +Y 的投影，水平面的 x 軸取世界 +X 的投影 | 與前、上、右基準面平行的面，得到的軸和該基準面完全相同。Worker 和 UI（建立新草圖時用面的指紋計算）共用同一個函式，兩邊結果一致 |
| 11 | **Schema v3**：新增旋轉與導角。遷移本身不轉換任何資料 | 版本號讓舊版程式拒絕開啟含有它不認得之特徵型別的檔案 |

## 驗證

- **核心**：以下操作的體積都與解析值一致：
  - 合併、共面合併、除料；
  - 成形至某一面，包含輪廓不在該面正下方的情況；
  - 旋轉 360°（無端面）與 90°（有端面）；
  - 導角的距離-距離與角度-距離。
- **特徵**：以下情況都驗證過：
  - 各種終止型態；
  - 在面上畫草圖，且面會跟著上游尺寸移動；
  - 編輯中的草圖回報座標系；
  - 曲面上的草圖被拒絕；
  - 導角反轉方向。
- **TNP 回歸（1B 的完成條件，`tests/phase1/tnp.test.ts`）**：
  - 模型：板 → 在板面上長凸台 → 從凸台頂面貫穿的孔 → 凸台頂邊圓角 → 板邊導角。10 組參數變化下，圓角和導角都留在同一條邊上，體積與解析值一致。
  - 被槽切開的面：4 個槽位置下，`#1`/`#2` 都依幾何順序穩定。
  - 先做好圓角，之後才在它前面插入除料切開那個面，圓角仍留在原來的邊上。
- **瀏覽器，只用 UI 操作**：體積全部等於解析值：
  - 選面 → 在面上畫草圖 → 伸長除料：11214.602 mm³；
  - 點選邊線做導角：11194.602 mm³；
  - 繞中心線旋轉：7736.172 mm³；
  - 在 PM 點選終止面的成形至某一面：18565.487 mm³。

## 已知限制

- 一條被參考的邊被分割成多段時，只會選指紋最接近的那一段；SW 可能兩段都做。
- 方向 2、拔模、薄件、「反轉除料邊」屬於 P1。
- 在基準面草圖上做除料，預設方向可能打不到本體，這時要按「反轉方向」（錯誤訊息會提示）。
- 沒有接觸本體的填料會變成多個實體，放在同一個本體狀態裡；多本體管理是 P1（C7.1）。
