# ADR 0196：圖示工具列與工具使用說明彈窗

2026-10-25。使用者要求工具名稱改成小圖示，名稱及使用說明在滑鼠懸停時出現。Schema 不變。

## 行為

- 主要工具選單、復原／重做、說明按鈕、開發用關閉伺服器、零件／組合件／工程圖的視圖工具列、剖面及 Instant3D 改用小圖示。工具分類分頁、表單標籤與顯示模式等目前設定值仍顯示文字。
- 功能圖示共用特徵樹的 SVG；草圖、檔案、視向、操作等補專用圖形；切除工具加減號徽記。圖示跟隨主題文字色，保留啟用／停用與作用中狀態。
- 停留 300 ms 顯示名稱、目前快捷鍵、摘要與完整使用段落；鍵盤焦點立即顯示。內容使用既有 help catalog，不另維護第二份操作說明。剖面及 Instant3D 等在地控制使用各自的使用說明。
- 停用按鈕的外層也可接收懸停，因此可先讀使用方法；不會因此啟用指令。所有工具保留 `aria-label` 與隱藏文字，彈窗透過 `aria-describedby` 關聯，切換按鈕保留 pressed／checked 狀態。
- 彈窗以 portal 放在 document body，不受可捲動選單裁切。水平限於視窗內，空間不足時往上顯示；長說明可捲動。游標移入彈窗可繼續閱讀；Esc、執行工具、離開、外部點擊、視窗調整或背景捲動會關閉，彈窗自己的捲動不關閉。
- 既有命令、停用條件、幾何、復原及模型參照不變。開發用關閉伺服器仍只在開發版出現，沿用原有關閉流程。

## 驗證

`manual-icon-tools.js` 的三個案例各有通過紀錄（前兩項與第三項分別執行，非全套驗收）：

1. 真實特徵選單每個工具均有 SVG 與可存取名稱、名稱不常駐顯示、沒有重複原生 title 提示；停用伸長工具仍可懸停讀到草圖與深度用法，點擊不會執行。驗證視窗邊界、移入彈窗繼續閱讀、長文捲動、Esc 及鍵盤焦點關聯。
2. 從圖示工具畫圓，經真實 Worker 伸長，實測圓柱體積 `π × 10² × 10`。確認視圖工具圖示／說明及實際前視切換，模型體積不變。
3. 建立真實齒輪；剖面圖示開關實際切面控制，Instant3D 顯示適用特徵說明與作用狀態，開關不改模型。新組合件顯示相同圖示視圖工具。

前兩項：`out/icon-tools-ui.json`；第三項：`out/icon-view-toggles-ui.json`。已視覺檢查工具選單及使用說明截圖（`out/icon-tools-shots/`）。help 40 項通過。型別、反模式、分層、i18n、production build 及 diff whitespace 通過。沿用使用者不重跑全部套件的指示，未執行完整 UI／單元套件，未以分項結果宣稱全套通過。

## 紅隊四問

1. **輸入與生命週期**：說明以 React 純文字呈現，無 HTML 注入；按鈕停用條件不變。timer、全域事件與 portal 隨元件卸載清理，焦點名稱不依靠純裝飾 SVG。
2. **幾何與相交**：沒有更動幾何演算法、選取命中、相機投影或布林；操作驗收仍以真實圓柱／齒輪與體積為證。純介面變更不新增參數化核心，不適用 100 組核心幾何 fuzz 要求。
3. **接線**：CommandBar、零件／組合件／工程圖 heads-up、剖面及 Instant3D 都使用同一 ToolButton；標籤、快捷鍵、說明資料及啟用狀態仍來自原有來源。
4. **真實性**：瀏覽器實際 DOM、懸停／焦點及模型操作驗證；未替換求解結果、未放寬精度或期限。舊的工具名稱腳本仍可透過隱藏文字辨識工具；新案例使用穩定 data-action 與可存取名稱。
