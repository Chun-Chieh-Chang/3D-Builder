# ADR 0169：沿螺旋曲線掃出（彈簧）

## 1. 背景
C8.3 螺旋曲線（ADR 0168）交付時宣稱「可作為彈簧掃出的導引」，但掃出（C4.4）的 `path` 只收草圖 id，審查時（ADR 0168 §5）改為照實寫「尚不支援」。本 ADR 補上這個能力。

## 2. 決策（2026-10-19，使用者確認）
1. **引用方式**：沿用 `SweepFeature.path: Id`，可指**較早的草圖或螺旋曲線特徵**。不新增欄位、不改檔案格式（使用螺旋曲線的檔案本來就是 v67）；DAG 原本就以 `path` 為父項。未採「任意 3D 邊線作路徑」：需 Schema 68 與新的 Ref 路徑，而螺旋每圈一條邊，反而不好選全。
2. **斷面姿態**：副法線固定為螺旋軸（`BRepOffsetAPI_MakePipeShell.SetMode(gp_Dir)`，與螺牙特徵相同），斷面繞軸做螺旋運動、彈簧線不扭轉。未沿用草圖路徑的修正 Frenet：圓柱螺旋下兩者相同，錐形時 Frenet 會讓斷面隨曲率翻轉。
3. **範圍**：圓柱、錐形、平面渦捲線都支援。

## 3. 設計
- **幾何資訊的流向**：螺旋曲線的 `BodyState` 帶 `helix: HelixAxisPath`（軸、起訖點、螺距、圈數、旋向、是否渦捲、帶號錐角），掃出由本體取用；不另開快取，資訊隨本體在歷史中前進。再生以 `helixIds`（本次重建文件中的螺旋特徵）判斷 `path` 指的是哪一種。
- **Kernel `sweepAlongHelix`**：
  - 起點：螺旋的一端必須在輪廓平面上；在遠端則反向走（與草圖路徑相同的規則），兩端都不在則 `sweepPathOffPlane`。在該端切線不得平行輪廓平面。
  - **前置攔截（AGENTS §2.1-2）**，以輪廓點在「該端的徑向線＋軸」座標中的範圍判斷：螺旋沿軸寬度 ≥ 螺距、渦捲線徑向寬度 ≥ 螺距 → 相鄰圈相碰；輪廓在任一端碰到或越過軸 → 拒絕。重疊的螺旋實體每次會吃掉數百 MB WASM heap（`threadProfileTooWide` 的記錄），不可丟給 OCCT。
  - **體積後擋**：以斷面穿過其運動的通量推得——在隨斷面轉動的座標（X 徑向、Y = Z×X）中，斷面面積 A、法向 n、形心 c = O + r_c·X + t·Y 固定，r_c 每弧度變 ±dr。每弧度旋轉帶 h·A·(n·Y·r_c − n·X·t)、上升帶 A·dz·(n·Z)、半徑變化帶 A·dr·(n·X)。圓柱是精確的螺旋運動，量測值與此式差 1e-3 以上即拒絕；錐形與渦捲斷面會隨切線傾角微轉，只套用與草圖路徑相同的 0.7 下限。
  - 面命名沿用 `pipeOrigins`：側面 `<輪廓來源>@<id>:helix:<k>`。
- **介面**：掃出面板的路徑清單列出之前的草圖與螺旋曲線；`newSweep` 取歷史中最新的路徑候選（螺旋或有線／弧的草圖）；`canSweep` 有螺旋時一張輪廓草圖即可。

拒絕情境：沿軸寬 5.2 ≥ 螺距 5、渦捲徑向寬 5.2、輪廓越過軸、錐形內縮到輪廓碰軸（末端半徑 0.67、輪廓半徑 1）、兩端都不在平面、螺旋被抑制。反向對照：關掉過軸檢查 → 2 項紅；`newSweep` 不選螺旋 → e2e 紅。

## 5. 已知限制
- 彈簧與既有實體「合併」時走布林運算，運算元含 B-spline 面，依 AGENTS §3.5 每次重建會佔用 Heap（由 ADR 0126 的高水位重啟限制）。單獨的彈簧不經布林，量測 0 成長。
- 曲線本體在 FeatureManager 的本體清單仍顯示在實體/曲面一類（ADR 0168 §5 已列）。
