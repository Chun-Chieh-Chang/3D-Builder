# ADR 0110：邊線凸緣的斜接（S-2，C11.4，零件 Schema 47）

- 狀態：**已實作並驗證（2026-10-07）**。來源：手冊 K4／sheet-metal-drawing-plan 的 S-2；ADR 0095（閉合角落）的限制「斜接沒有做」在這裡解掉。
- 零件 Schema 46 → **47**（遷移是空的：選用欄位 `miter`，沒有就是角落開著，和以前一樣）。

## 決定與做法

1. `EdgeFlangeFeature.miter?: { start?, end? }`（與 `corner` 同樣的稱呼：起端／末端），值是兩個凸緣之間留的**間隙**（≥ 0，0＝貼合）。同一端不能同時閉合角落與斜接。
2. **只做**：兩個凸緣都是 90°、半徑相同、材料在內（折彎從邊內側開始，`trim = 半徑 + 板厚`）、往同一邊折、在互相垂直的相鄰邊上；旁邊的凸緣要**先做**，而且要到角落（沒有縮短、沒有閉合角落、那一端沒有斜接過）。找不到這樣的鄰居說「這一端旁邊沒有可以斜接的凸緣」，其餘各條件各有訊息（角度、半徑、位置、方向、角落）。
3. **幾何**（平面圖上，α 沿鄰居的外向、β 沿這個凸緣的外向，原點在兩個外側面的交線，s = 間隙／√2）：斜接面是垂直的、過那條交線的 45° 面（α = β，間隙時各移 s）。
   - **鄰居**：用一個多邊形柱（`α ≥ −(R) 且 β > α − s`，`R = 半徑 + 板厚`）從本體切掉斜接面另一邊的部分；柱只蓋鄰居的折彎區與平直段，不碰板。
   - **這個凸緣**：折彎與平直段的刀具都延長到鄰居的外側面（多 `R`），再各自用另一個柱（`β < α + s`）切回斜接面（`boolean cut`，名稱由刀具與柱合成），再像原來一樣接進本體。
   - **檢查**：從鄰居切掉的體積對照手算公式，這個凸緣接上的體積對照兩個刀具的體積；不符說「斜接的結果與手算的體積不符」。
4. **平板型式**：兩個凸緣各自的展開條在角落以一條曲線結束：在折彎上，斜接面與折彎中立層相交是 `x(v) = (半徑 + K·T)·sin(v / (半徑 + K·T))`，折彎之後是直的；折線取 24 段。每個展開條先單獨切好才接進平板（不然一個凸緣的切刀會切到另一個）。折彎線畫到曲線上。`SheetFlange.miter` 兩端各記 `{ s, xOuter }`，被斜接的鄰居也記。
5. 介面：邊線凸緣面板多「起端斜接」「末端斜接」兩欄（空白＝不斜接）與說明；手冊 I2 多一步；說明主題 `edge-flange` 加一段。

## 驗證

- `tests/phase7/miter.test.ts`（15 項）。板 100 × 60 × 1.5、半徑 2、K 0.5（R = 3.5）；第一個凸緣長 40（高 36.5）、第二個長 30（高 26.5）。**手算**（凸緣的斷面是 R、rb 的四分之一環加厚 T 的牆）：從第一個凸緣切掉 `c·π(R² − rb²)/4 − (R³ − rb³)/3 + H·(c·T − (R² − rb²)/2)`，`c = s + R`；第二個凸緣多得 `(R³ − rb³)/3 − s·π(R² − rb²)/4 + H·((R² − rb²)/2 − s·T)`；總體積等於各部分的和（容差 1e-3 mm³）。間隙 0 與 1 都對；一個有效實體；沒有斜接時的差就是兩個公式的差；留在外面的斜面是 √2·1.5 × (36.5 − 26.5)，在過角落 (100, 60) 的 x − 100 = y − 60 平面上；沒有東西伸出外側面（最大 x、y 剛好 100、60）。
- **其他尺寸**（5 組：板厚 0.8 到 2.5、半徑 0.8 到 4、K 0.33 到 0.5、凸緣 15 到 50、間隙 0 到 1.2）：體積同一組公式；平板型式是一個有效的片、面積差等於手算（`(R + s)·A − Rn² + (R − Rn + s)·H₁` 是第一個凸緣少的，`Rn² − s·A + (Rn − s)·H₂` 是第二個多的，A 是折彎展開長，Rn = 半徑 + K·T）。
- **四邊的盒子，四個角都斜接**（四個凸緣高 40、30、35、25，後做的各對前面做的斜接，第四個兩端都斜接）：體積 = 板 − 四次切邊 + 四個凸緣 − 四個角各自從先做的那個切掉的 + 後做的那個多出來的（同一組公式，容差 0.01 mm³）；一個有效實體；平板型式是一個有效的片、四條折彎線。
- 平板型式：面積差 45.5 mm²（手算）；展開體積與摺疊體積相差 0.57 mm³（0.0035%）。
- 錯誤：鄰居沒有、鄰居有縮短、半徑不同、角度不是 90°、同時閉合角落、負的間隙、折彎在外。
- 瀏覽器（`tests/e2e/phase7-miter-ui.js`）：面板填 0 後體積 = 手算公式；清空回到角落開著；末端斜接被說明。
- 也跑過原有的閉合角落、凸緣、平板型式、隨機鈑金測試（共 282 項），沒有退步。

## 限制（已知，沒有掩飾）

- **平板型式在折彎上的曲線是中立層的近似**：折彎區裡折疊的體積與展開的體積不完全相等（本例差 0.57 mm³，0.0035%），因為斜接面在折彎上不是沿著展開方向切的。
- 只做 90° 的相鄰凸緣；斜的凸緣、不同半徑要另外設計。一端只斜接一個鄰居（四邊的盒子：每個角各是一對凸緣，順序做就行，見驗證）。
- 凸緣高度不同時，高的那一個留下一個斜的端面（這是對的，真實的鈑金也是這樣），沒有自動把它切平。
- 斜接的鄰居不能再被別的凸緣以閉合角落接在同一端。
