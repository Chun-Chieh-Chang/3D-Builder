# ADR 0088：平板型式（Phase 7-5，C11.3）

- 狀態：已實作並驗證（2026-10-04）。**沒有改檔案格式**（平板型式是派生資料，不存進文件）。限制見最後一節；**畫面上的「展開／摺疊」切換沒有做**（只有平板型式視窗）。
- 相關：[phase7-plan](../phase7-plan.md)、[ADR 0083](0083-sheet-metal-validation.md)（特徵原生）、[ADR 0084](0084-base-flange.md) 到 [ADR 0087](0087-insets-reliefs.md)（折彎資料的來源）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **平板型式從折彎資料算，不展開實體**（計畫的特徵原生）。`RebuildResult.sheet`（`SheetInfo`）多記了：`base`（平板：草圖的框架、區域、長出的方向；折過的板：寬度、直段與折彎依路徑的順序、每個折彎轉向板厚那邊還是離開）與每個凸緣的 `parent`（長在哪一片的平直段上，-1 是基材）和 `fold`（摺疊時的幾何：邊的中點、折彎起點、折彎中心與軸、邊／外／折彎方向、沿邊的範圍、板厚範圍、trim、離隙缺口、折彎後平直段的起點與方向） | 展開需要的資料，在做的時候最清楚 |
| 2 | **用剛體運動把每個凸緣放回去**：凸緣 k 的平直段的 3D 位置 → 平板位置，是「把折彎轉回去（繞折彎的軸轉 −θ）再往外移一個折彎裕度」，再接上長出它的那一片的運動（`Rigid`：旋轉 + 平移，`compose`）。基材在原處不動。**父片用邊的中點在各凸緣平直段的方塊裡找**（最後做的先找；都不在就是基材） | 凸緣上的凸緣（摺邊接在凸緣末端）自然成立；任意層數 |
| 3 | **平板型式在核心裡做成一片薄實體**：基材（平板的區域拉伸一個板厚；折過的板展成 `展開長度 × 板寬` 的長方形）依序「切掉 trim 與離隙缺口（同摺疊時，只是放回平板位置）→ 接上折彎裕度加平直段的長條」；布林、面積、輪廓都是核心的。**輪廓**是看得到的那一面（法向與框架的法向同向、面積最大的平面）邊界上的邊：直線、圓弧（起點、終點、經過的中點）、整圓；**外包尺寸**由輪廓（弧取樣）算 | 用核心的布林，不另寫多邊形運算；體積、面積免費 |
| 4 | **折彎線**在折彎裕度那一條的正中（離切口 裕度／2），寬度是凸緣的寬度；`direction` 是 `up`（折彎朝向看圖的這一面）或 `down`；帶角度、內側半徑、K、裕度。折過的基材：折彎線在 `前面的直段 + 前面的裕度 + 自己的裕度/2`，路徑轉向板厚那邊（草圖面在折彎外側）就是 `down` | 平板圖與折彎表要的資料 |
| 5 | **不支援**（說原因，不做錯）：折過的基材凸緣上再長邊線凸緣或摺邊（`flat.bentBaseFlanges`，要追蹤沿路徑展開的每一段的運動）；沒有基材凸緣（`flat.noBase`）；找不到父片（`flat.noParent`） | 範圍 |
| 6 | **介面**：功能區「鈑金」頁的「平板型式」（開／關）；圖面上的視窗：輪廓與折彎線（紅虛線）的 SVG、外包尺寸、面積、板厚、折彎表（角度、內側半徑、方向、裕度、位置）；模型改了視窗重算；什麼也不存；Worker 的 `flatPattern()` 用最後一次重算的結果 | 同三個分析的視窗 |

## 驗證（證據）

- **平板型式**（`tests/phase7/flat-pattern.test.ts`，11 項；板 100 × 50 × 1.5、半徑 2、K 0.5）：
  - 單獨一片板：100 × 50、5000 mm²、4 條線、沒有折彎。
  - **90° 凸緣、長 30 從外側量、材料在內：長度 100 − 2(r + T) + 30 + BA = 127.3197**（BA = (π/2)(2 + 0.75)）、寬 50、面積 6365.98；折彎線在 x = 96.5 + BA/2、y 0 到 50、朝上、角度 90°、裕度 BA；**K 0.5 時平板的體積 = 摺疊的體積**（體積守恆）。
  - K 0.4：127.0841（短 (π/2)·0.1·T）；折彎在外：100 + BA + 26.5；往下折：折彎線說 `down`；**45°：100 + 30 − 2(r + T)·tan 22.5° + BA(45°) = 129.2604**；**摺邊（間隙 1、折回 10）：100 − 2 + π(0.5 + 0.75) + 10 = 111.927**。
  - **凸緣上的凸緣**（摺邊接在 90° 凸緣末端）：137.2467 長、體積守恆、兩個折彎、`parent` 是 [-1, 0]。
  - **縮短與離隙**：面積 5000 − 3.5·35 − 2·1.5·5 + (BA + 26.5)·35 = 5941.19，折彎線 y 從 10 到 45；兩條相鄰邊的凸緣在角落留縫：127.32 × 77.32、沒有重疊、體積守恆。
  - **折過的 U 形槽**展開：94.639 × 40，折彎線在 16.5 + BA/2 與 16.5 + BA + 53 + BA/2，都是 `down`（路徑是外側面）；體積守恆。折過的基材上有凸緣被擋下來；沒有基材報錯。
- **瀏覽器**（`tests/e2e/phase7-flat-ui.js`，全部通過）：開啟板加凸緣的零件、「鈑金」→「平板型式」：視窗說 127.319 × 50、面積 6365.98，一個 90° 往上的折彎、畫了輪廓與折彎線；基材的 K 因子改成 0.4，視窗跟著變成 127.084；關閉視窗。
- `npm run check`：1468 項通過、21 項略過。

## 限制與未做

- **K 因子是輸入**：K = 0.5 以外，平板長度與公式一致，不是與實體一致（ADR 0083）。與 SW 的對照要等樣本；**定義**（凸緣長度量到哪裡、折彎裕度的算法）是可能的差異來源。
- **畫面上的「展開／摺疊」切換沒有做**：平板型式只在視窗裡以 2D 畫出，沒有在 3D 視圖裡顯示平板的實體（要在 viewer 換網格，和分析的顏色是不同的機制）；平板型式實體本身是有的（核心裡的 `shape`），之後要顯示不需要重算。沒有「展開後在平板上做除料」的特徵（C11.3 的展開／摺疊特徵）。
- **折過的基材凸緣上的凸緣的平板型式沒有做**（上）；基材是封閉輪廓的平板時，任意層的凸緣與摺邊都行。
- **父片靠邊的中點找**：邊的中點恰好落在兩個凸緣的平直段交界處時取最後做的；曲面的凸緣（沒有）不會出現。
- **輪廓沒有排序成迴圈**（一堆線、弧、圓）：DXF 輸出（7-6）是一個實體一個實體寫出，不需要；之後要做加工路徑才需要。
- 視窗的 SVG 不縮放不平移（固定最大高度 220）；沒有標註尺寸。
