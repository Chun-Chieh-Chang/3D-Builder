# ADR 0119：號球與表格可以用滑鼠拖（工程圖 Schema 8 → 9）

- 狀態：**已實作並驗證（2026-10-09）**。來源：handoff §8「Phase 5 工程圖的待辦 D：號球與表格的拖曳」。

## 做法

1. `BomTable.balloonAt?: Record<item, [x, y]>`：使用者放的號球圓心（圖紙毫米）。沒有記的號球仍由程式排（`balloonSpots`），並且避開使用者放的。`setTable` 的 `balloonAt` 整份取代，`null` 清掉（面板的「號球自動排列」）。孔表沒有號球，給了就拒絕；座標必須是有限數。
2. `buildScene` 多回傳 `tableBoxes`（每個表格在圖紙上的框）與 `balloons`（每個零件表的號球：項次、零件上的點、圓心），工程圖視窗用它們做點選，不必猜表格多大。表格的位置本來就有 `at`（左上角）和「放回右下角」，這次只是接上滑鼠。
3. 視窗：在尺寸、剖面線之後、視圖之前判斷；號球圓圈（半徑加六像素）優先於表格框，表格框優先於視圖；拖動時畫面即時跟著，放開才寫入文件（一次可復原）。
4. 檔案版本 9；8 → 9 沒有要轉換的東西（新欄位選用），版本號讓舊程式不開會把號球排到別處的檔。

## 驗證

`tests/phase5/drawing-moved-tables.test.ts`（號球位置、其他號球避開、指令與讀寫、舊檔、表格框）；瀏覽器腳本 `phase5-assembly.js` 用真的指標事件拖號球與表格、按「號球自動排列」與「放回右下角」。

## 沒做

號球引線不能彎折；一次選多個號球一起拖；零件表以外的表格（目前只有孔表與零件表）。
