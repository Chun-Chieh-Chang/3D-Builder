# ADR 0215：草圖選取候選與取消預覽

2026-10-28。使用者核准[草圖互動方案](../design/sketch-interaction/plan.md)後的P0第一批，完整進度見[驗收表](../design/sketch-interaction/acceptance.md)。

原先hitTest只給單一點優先命中，重疊線及端點旁短線沒有明確選取入口。新增hitCandidates共享幾何候選，保留原有預設順序，Controller在選取模式提供Tab／Shift+Tab預覽及面板選取。候選ID來自目前原生求解資料；文件變更、離開3畫面像素保持區或換工具解除顯式鎖定，不儲存到文件。面板選取會驗證文件版本，失效候選不可操作。模型外部邊未轉換前仍走原有路徑，不宣稱已完整統一所有選取工具。

目前工具與參照清單移到屬性面板前端。Esc取消拖曳／框選時清除手勢與待提交按壓；host收到空dragPreview重求已提交草圖，透過既有LatestRunner讓過期預覽失效。提交仍用最後實際求解位置，成功拖曳回歸已驗。文件Schema不變。

原生及相關測試151個不同案例有通過結果；新增瀏覽器流程和既有尺寸文字拖曳通過。舊平面流程三項失敗於未修改78faeda重現，尚待追查，P0未全通過。取消Worker與隱藏CSS失敗都寫入驗收表，未放寬容差／期限，新增可見性及命中驗收避免DOM click假綠。數據、範圍與未驗項不在本ADR重複維護。
