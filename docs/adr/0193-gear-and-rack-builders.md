# ADR 0193：參數式直齒外齒輪與齒條

2026-10-24。零件 Schema **81**；80→81 保留原有設計意圖，舊程式拒絕未知的新版本。

## 操作與範圍

「特徵」新增「直齒齒輪」「直齒齒條」，不需先畫草圖。可用預設平面、先前的基準面或模型平面；平面原點是齒輪中心／齒條節線中點。齒條沿平面 X，齒頂朝 Y，齒寬沿法向。可在面板或設計樹更換平面，新增獨立實體，再用移動／複製本體定位。參數可用既有運算式、變數及尺寸參照；存檔、重算、編輯、復原／重做沿用模型命令。

共同參數：模數、齒數、壓力角、齒寬、齒厚減量；齒輪另有軸孔直徑，齒條另有齒根下底座厚度。面板顯示節距與節圓直徑／齒條長度。齒厚減量是此零件的節線齒厚減量，兩個配對零件的減量會相加，並非每個零件各自填入總配對背隙。

此版是未變位直齒外齒輪／直齒齒條。齒輪齒根為徑向線與齒根圓的簡化過渡，齒條為銳角齒根；未建構滾刀生成齒根、製造圓角、內齒、斜齒、變位或機械運動結合。不宣稱製造精度等級或完整嚙合干涉認證。

## 幾何

- 節距 `p=πm`，節圓半徑 `rp=mz/2`，基圓 `rb=rp cos α`；齒頂 `rp+m`、齒根 `rp−1.25m`。
- 節線齒厚 `s=πm/2−b`。半齒角 `s/(2rp)+tan α−α−(t−atan t)`，其中 `r=rb sqrt(1+t²)`。
- 工作齒面採漸開線解析式 `rb(cos t+t sin t, sin t−t cos t)` 的 17 次級數，轉成 Bernstein 控制點，用原生 `Geom_BezierCurve` 建立；齒頂／齒根採原生圓弧。保留解析取樣點供共用輪廓介面使用，但真正實體的齒面由 Bezier 控制點建立，非多邊形鋸齒。
- 齒條節線厚 `s`；齒頂厚 `s−2m tan α`，齒根厚 `s+2.5m tan α`。長度 `zp`，兩端各在完整節距邊界。
- 用單一閉合輪廓直接拉伸；軸孔是輪廓內環，不逐齒 Fuse/Cut。每齒左右工作面、齒頂與齒根有來源名稱；名稱數量與實際拓樸對齊。

通用樣條擬合的預設誤差曾使原生齒面探針失敗；收緊擬合後的多節點曲線也使積分耗時與體積誤差變大。隔離比較了原生 GK 積分，最終改用無內部節點的解析級數 Bezier 表示。**未保留對全專案 massProps 積分路徑的變更**，未放寬既定曲線／體積斷言。

## 邊界與全鏈路

模數 0.1–100 mm，齒寬 0.1–1000 mm，壓力角 15–30°，整數齒數 1–200，總尺寸 ≤10000 mm；齒條底座厚度 0.1–1000 mm。外齒輪另須 `z≥ceil(2/sin²α)`，拒絕此版未處理的根切；軸孔須保留齒根壁厚。拒絕負背隙、齒頂消失、齒根角域重疊；齒根交疊判斷用實際起始半徑的角度，高齒數不會誤用基圓半齒角而遭拒。

齒數使用專屬 `gearCount` 規則：嚴格整數、無單位，允許一齒齒條，不借用實例數最少為 2 的陣列規則，不四捨五入。非法輸入在命令／運算式解析前置拒絕，重建再次驗證幾何條件。

`schema → setGear → mapExprs / Parameters → mapRefs → DAG → regen → 面板 / 選面與基準面 / 雙語說明` 全鏈路接線。無草圖依賴時不吸收草圖。BRep 與導出幾何不寫入模型 Schema。

共用 ValueInput 同時修正「錯誤輸入改回原值仍殘留紅色／通知」：回到已驗證的文件值時清除錯誤狀態。齒數欄無長度單位，壓力角欄顯示角度。

## 驗證

9 項新核心案例各有通過紀錄：

- `gears.test.ts` 7 項：原生有效齒輪／齒條實體、獨立解析體積、原生齒面探針、節圓齒厚／背隙／壓力角、極端邊界、軸孔、持久名稱、平面 DAG／運算式／序列化／升級／復原、非法參數、嚴格整數與一齒齒條。
- `gear-fuzz.test.ts` 100 組實體與原生曲線取樣；`rack-fuzz.test.ts` 100 組實體。齒輪體積相對誤差 <2e−6，取樣點對漸開線的切向誤差 <模數×1e−4；齒條體積相對誤差 <1e−8。這是所測組態與取樣點的驗證，非任意自由曲線的全域製造公差證明。
- 每個隔離壓力測試先斷言實際 `wasmMemory.buffer.byteLength >0`，再驗證成長低於產品 512 MiB 高水位；每次釋放實體，不宣稱零洩漏。
- `manual-gear-rack.js` 2 項瀏覽器案例各有通過結果：真實特徵選單、參數面板、原生齒面數量／軸孔／齒條長度／體積、更換建構平面、非法數值拒絕及修正、一次復原／重做。齒條初輪通過，齒輪以暫存單案例 wrapper 僅重跑失敗項，原始與最終報告及 wrapper 留存 `out/gear-rack/`。
- help 40 項各有通過結果。型別、分層、i18n、反模式與正式建置檢查；未跑完整測試或完整瀏覽器套件。
