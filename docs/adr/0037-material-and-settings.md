# ADR 0037：材質、質量與文件設定（Phase 3a-8a）

- 狀態：已實作（2026-10-01）。
- 對應：C14.1 材質（密度、自訂）、B8.4 文件屬性資料（製圖標準、尺寸精度、影像品質）、D8.2（屬性對話框），見 [phase3-plan](../phase3-plan.md) §3 的 3a-8。
- **Schema 升為 24**：`PartDoc.material`、`PartDoc.settings`（都是選用，沒選就不存）；8b 的外觀目標也在 v24。舊檔不需轉換；已補 v23 樣本 `tests/fixtures/old-versions/v23-mirror.3dbx`（由 `b1b00b4` 寫出）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **材質存名稱與密度（g/cm³）**：`{ id?, name, density }`。內建表（`MATERIALS`，14 種常用的鋼、鑄鐵、不鏽鋼、鋁、銅、黃銅、鈦、六種塑膠）只提供 id 與密度，名稱走 `t()`；選了就把名稱與密度**複製**進文件，所以表日後改了，舊檔的質量不變；「自訂」自己輸入名稱與密度（0 < 密度 < 30）。 | 文件自給自足（SSOT：質量的來源就是文件裡的密度）。密度是常用牌號的整數值，要精確請自訂。 |
| 2 | **質量 ＝ 體積 × 密度**，體積是不含參考本體的所有本體（`Worker.massOf` 早已排除參考本體）；狀態列在有材質時多顯示「質量」（不到 1 kg 用 g，其餘 kg）。質量不存進文件（衍生資料）。 | 不變式 1。 |
| 3 | **文件設定**（`DocSettings`）：製圖標準（ISO、CNS、ANSI、JIS、GB，目前只記下來，給 Phase 5 的工程圖用）、尺寸小數位數（0–6，預設 4，影響由運算式算出的尺寸 Σ 的顯示）、顯示與輸出品質（粗／一般／細，預設一般 ＝ 核心原本的預設）。只存使用者選過的，`settingsOf` 補預設。 | B8.4。品質是真的有效果的設定，不是空殼。 |
| 4 | **品質怎麼用**：畫面的網格（Worker 的 `meshOf`）、之後的 STL 與影像（8c）都用同一組 `MESH_QUALITY`：粗 ＝ 弦誤差 2e-3 倍尺寸、角度 0.5 rad，細 ＝ 1e-4 倍、0.1 rad。改設定會重算，所以新網格是新的形狀上網的（OCCT 的形狀會保留最細的網格，同一個形狀不會因為改成粗而變粗）。 | 一個來源。 |
| 5 | **介面**：「工具」分頁的「檔案屬性」對話框最上面加「材質」（下拉選單，內建加「自訂…」，自訂時有名稱與密度，下面顯示算出的質量）與「文件設定」。 | D8.2：屬性編輯器本來就在那裡。 |

## 驗證

- `tests/phase3/material.test.ts`（8 項，真的 OCCT）：表裡每個材質只出現一次、密度合理；60 × 20 × 5 的鋼板 ＝ 47.1 g（手算 6000 mm³ × 7.85 / 1000），一公升水 ＝ 1000 g，格式；質量與核心量到的體積一致；`setMaterial` 取表中的、自訂的、拿掉，名稱空白與密度 0／31 被拒絕；材質存檔讀回；設定只存選過的、其餘補預設、小數位數 −1／7／2.5 被拒絕；**同一個圓柱，細的網格比一般的三角形多，一般的比粗的多**。
- v23 樣本（板、柱、鏡射）開啟、遷移到 24，沒有材質、設定是預設，鏡射照常重算。
- `npm run check` 全過（型別、分層、i18n 基準不增加、全部測試）。

## 還沒做

- 材質的外觀（顏色）、彈性模量等其他物性；使用者自己的材質資料庫（跨文件）。
- 零件表（3b）讀材質與質量。
