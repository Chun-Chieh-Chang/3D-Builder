# ADR 0205：由孔口選取建立加工入口錐面的通用工具

- 日期：2026-10-26。
- 狀態：已實作；一般合成模型與使用者原始螺紋模型均以正式工具驗證。
- 接續：[ADR0098](0098-fillet-by-face.md)。先前的個別零件修改檔與錯誤提示沒有完成通用操作，本次補齊正式工具。

## 操作與幾何定義

選取一個平面孔口，或同一孔口的一條／多條邊，執行「特徵 → 螺紋入口錐面」。工具使用原生內輪廓識別孔口，排除真正的外輪廓，不以螢幕、網格或包圍盒猜軸。需有同心且同軸的可追蹤圓弧；可與真實螺紋的B-spline段混合。多孔端面須改選目標孔的邊；橢圓、槽孔、只有外緣、非平面及遺失／不唯一參照均拒絕。

入口以保留孔徑 d、入口直徑 D 與夾角 A 定義；錐深 h=(D−d)/[2 tan(A/2)]，90°夾角為單側45°。初值的孔徑來自中心至原生輪廓的最短距離，入口直徑由識別圓弧直徑加直徑餘量0.4mm，盲深比90°錐深多0.001mm，均為可修改的建議，不推測標準牙代號。量測的B-spline小徑可能與理想牙型參數有微小表示差，不能把初值冒稱標準尺寸。

工序提示同時說明：切削牙可先入口導角再切牙；加料造牙須在加牙後修整，否則加料會填回錐面。面板給出幾何公式、有效牙保留與盲深檢查；改直徑／角度後須一併確認盲深。自由曲面一般導角失敗的訊息也有上述工序提示和正式工具入口。

## 單一來源與資料鏈

不是新做一套布林或錐面演算法。工具自動建立既有的三個模型特徵：

1. `RefPointFeature`：追蹤原圓邊中心。
2. `SketchFeature`：依入口面放置，原點附著參考點，含同軸獨立點。
3. `HoleFeature.kind='countersink'`：使用既有面板、錐孔再生、尺寸與方向驗證。

中心／平面依持久參照連動；孔徑、入口直徑、角度及深度是獨立可編輯參數，原孔尺寸變更後仍須確認。圓中心參照若變為非圓曲線會明確失敗，不能改取中點。既有commands／refs／DAG／存讀鏈完整保留，不新增Schema欄位或版本。

新worker查詢從現有模型辨識入口，檢查rebuild序號；主執行緒在查詢返回後再次核對文件、文件序號、結果及編輯狀態，過時回覆不能修改新文件。三個特徵納入同一編輯交易；取消整組移除，確認後一次復原／重做，面板內可預覽並重編。

## 驗證範圍

- 4項核心測試：持久參照／存讀／取消／一次復原與重做／原孔位改動跟隨；多孔面拒絕、內邊消歧與外緣／非法值／遺失參照；圓變橢圓拒絕；100組固定種子原生幾何（半徑、正負偏心、三基準面方向），去料體積對解析旋轉三角截面公式、有效單實體與Heap批次成長上限。
- 私有原始模型：以原存檔的選面與整圈B-spline／圓弧邊辨識相同入口，正式factory建立特徵，原生存讀及解析錐面驗證。私有設計與探針不進Git。
- 真實瀏覽器：普通草圖／伸長建模後選面取消、選邊建構、一次復原重做、參數編輯及工序提示；另從原始上傳檔啟動同一正式工具，未載入預製修正版，並驗錯誤提示與有效重建。原檔原有不支援的一般導角須明確停用，工具不擅自刪除或停用其他特徵。
- 雙語help、圖示registry、手冊同步、型別、依賴與反模式／i18n守門；只驗新／受影響案例，未跑全套。只取得本輪Linux證據；跨平台runner結果須看對應提交。

Heap只記錄真實wasmMemory與有界批次，不宣稱零洩漏。一般沿螺旋邊的等距導角仍受OCCT限制；本工具解決同軸加工入口，不是任意自由曲面邊的導角修復。先前私有STEP嚴格體積比較未過仍保留，本次以原生模型操作驗證，不以新工具掩蓋。
