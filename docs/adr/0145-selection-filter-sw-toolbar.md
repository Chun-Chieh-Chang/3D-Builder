# ADR 0145：選擇濾器比照 SolidWorks 工具列（隱藏預設、F5/F6、單選）

- 狀態：**已完成**（2026-10-15）。
- 對應：D5.4 選擇濾器——只改**呈現與交互**，不改「只縮小不放大」的語意（ADR 0043 決定 2 的核心）。
- 修訂：ADR 0043 決定 2 的「在圖面左上的選項列、四個獨立勾選」由本 ADR 取代。

## 背景

ADR 0043 把選擇濾器做成圖形區選項列上**常駐的四個獨立勾選**（AND 縮小）。使用者要求比照 SolidWorks 的選擇濾器工具列：SW 裡該工具列**預設隱藏**（檢視→工具列→選擇濾器，或 F5），列上按鈕為**單選**（啟用一種就關掉其他，再點已選者不取消），**F6 清除所有濾器**＝全部種類恢復可點。

一個本平台特有的權衡：**F5 在瀏覽器是重新整理**。快捷鍵 handler 比對成功即 `preventDefault()`（既有行為），但輸入框聚焦時 handler 提前 return（`actions.ts`），該處 F5 仍是重新整理——行為與桌面 SW 不可能完全一致。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **列預設隱藏**。`SystemOptions.pickFilterBar`（預設 `false`）記住狀態；F5（action `filter-bar`）切換，也從「系統選項→顯示選擇濾器列」開。組合件無此列（維持 ADR 0043）。 | 比照 SW 工具列預設隱藏；SW 會記住工具列狀態。 |
| 2 | **radio**。`store.setPickFilterKind(kind)`：選一種 ⇒ 只剩該種類可點；**再點已選者為無操作**（SW 按鈕保持按下，不取消）。**F6**（action `clear-filters`）＝四種類全開＝全部可點。 | SW 的濾器按鈕即單選；「只留一種」是濾器最典型的用法（圓角只對邊線）。 |
| 3 | **傳輸結構不變**：`pickFilter` 仍是 `{faces, edges, vertices, planes}` 四布林，viewer 協議與 `picking()` 交集邏輯（只縮小、不放大）完全不動；radio 只是 store 產生的布林組合（`{faces:false,…,[kind]:true}` 或全 true）。關掉的種類立即清 hover（viewer 維持）。 | 最小衝擊面；語意核心（ADR 0043 決定 2）不變。 |
| 4 | **舊資料相容**：localStorage 裡舊勾選 UI 存的**混合**四布林（如 faces+edges 同 true）保留原樣；列上無按下的種類（等同無濾器視覺），第一次點選即收斂到 radio，F6／「全部」立即歸位。`parseOptions` 不「修正」混合值——種子語意（下一份零件的起手）以選項為準。 | 不悄悄改使用者存的值；顯示層不發明新狀態。 |
| 5 | **F5/F6 走既有 D3.3 action registry**：自動出現在快捷鍵對話盒、可自訂重綁、有衝突檢查。**F5 攔截瀏覽器重新整理**為已知差異：輸入框聚焦時 F5 仍是重新整理（handler 提前 return）；不接受的使用者可自訂快捷鍵。 | 與 SW 肌肉記憶一致；差異透過既有自訂機制可解。 |
| 6 | **「開始時可以點選的元素」改 radio（含「全部」）**：種一種或全不限制；仍是「程式啟動時種入 live 濾器、不動已開頁面」的語意（manual-c22 驗）。 | 與 live 濾器的 radio 語意一致；seed 語意不變。 |
| 7 | **列首兩顆按鈕比照 SW 工具列**：✕（隱藏列＝F5）與「清除」（＝F6）。 | 與 SW 工具列首的切換／清除鈕對應。 |

## 驗證

- **單元**（`apps/web/test/options.test.ts`）：`pickFilterBar` 預設 `false`、非布林退預設、round-trip；既有 pickFilter 解析測試不變。
- **e2e**（`npm run verify:ui`，真實瀏覽器照 UI 操作）：
  - `manual-c21.js` 步 2 重寫：F5 顯示列 → radio「邊線」（state 驗證只剩 edges）→ 點頂面無反應、點邊線選到 → F6 四種類全開 → F5 隱藏。其後步驟（選取相切／迴圈／選取其他）不變。
  - `manual-c22.js` 的 `optionOff`／`startedOff`：選項種「邊線」→ 已開頁面與「新零件」的 live 濾器不動；重載後起手只有邊線；勾回「全部」。
  - `manual-sketch-plane.js` 步 11：radio「基準面」點得到基準面、radio「面」同一點點不到、F6 恢復（ADR 0127 的閘門驗證，改用新交互證同一件事）。
- **手冊**（`docs/manual-verification.html`）：概觀與 C20／C21／C22／C23 的濾器段落同步改寫；help 主題「選取」「系統選項」同步。

## 已知差異（不打算修）

- 輸入框聚焦時 F5＝重新整理（瀏覽器行為，見決定 5）。
- 舊混合種子值的過渡顯示（見決定 4）。
