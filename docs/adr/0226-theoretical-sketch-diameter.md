# ADR 0226：工程圖標註草圖截面的理論直徑

## 問題與選擇

錐面上的倒角會移除草圖平面原本的圓邊。其後留下的實際圓邊可能稍大或稍小；例如 TM0002138 的草圖是 Ø10.41，倒角後另一截面約為 Ø10.411。選擇後者時不能把它當成草圖尺寸。使用者選擇保留實體幾何，另標註草圖截面的理論直徑。

選取零件工程圖視圖後，在尺寸面板「草圖截面理論直徑」中明選草圖與圓。圓正對視圖時建立直徑尺寸；草圖平面垂直於視圖時，建立兩個對徑點的線性尺寸並加 Ø。尺寸線的參照點在原草圖平面，不使用倒角後的圓邊。斜向視圖無法顯示真實直徑，不提供此選擇。組合件及展開視圖尚未提供清單。

## 參照及重建

工程圖 v37 儲存 `kind: sketch` 和 `草圖id:圓id`，側視另存對徑點。Worker 從來源零件的求解結果重新解析，沒有儲存求解坐標或以顯示精度強制覆寫實際幾何。草圖或圓消失時回報遺失；求解失敗或視角不符時不產生錯誤尺寸。舊版軟體不會誤讀新參照。單位和公差繼續由工程圖尺寸格式化處理。

## 驗證與邊界

以真正求解和 OCCT 建出的倒角實體測試草圖更動後重算、正視和側視、錯誤參照、存檔讀回及英吋轉換。使用者的 TM0002138 真實零件確認數值與兩端落在草圖截面上；瀏覽器測試從介面建立、換單位及重開。未以零件邊的近似值或手填數字充當草圖真值。
