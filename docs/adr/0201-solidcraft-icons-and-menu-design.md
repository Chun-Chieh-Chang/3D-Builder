# ADR 0201：SolidCraft工具圖示與選單重新規劃

2026-10-25。使用者指定參考 `tangency-labs/solidcraft`，接著要求重建較直觀的工具圖示並指示繼續。這是新授權：保留文字名稱並增加具語意的圖示；不恢復已撤回的0196純圖示版本。

## 交付範圍

正式程式已接入圖示＋文字的工具選單與快速復原／重做。205個既有action ID均有圖示對應；包含生成式草圖工具、尺寸子類型及右鍵專用ID，但本批只在CommandBar表面渲染，不把右鍵專用動作擴成一般工具。點選仍呼叫原來的`run`，可用性仍呼叫`enabled`，說明仍是同一份`actionTooltip`，主執行緒不載入新的WASM或幾何套件。圖示alt為空、aria-hidden，可見文字提供無障礙名稱。

圖示使用125份上游原創SVG，MIT授權。固定上游提交 `bbc3aa4301380f4d6180ccbb12c35162d1fd98a1`；原始SVG不改，manifest保存來源路徑與SHA-256、205個action映射及語意配色。完整MIT聲明放進public/licenses並確認進入dist；專案THIRD_PARTY_NOTICES同步更新，不使用上游品牌標誌。

保留SolidCraft立體幾何、結果高亮與平面草圖的語彙；藍色建模、綠色草圖、橘色曲面。四種除料加減料提示、部分展開加部分選取提示；裝飾螺紋使用虛線柱面、滾花增加表面紋理。尺寸的角度、半徑、直徑、倒角、基線與座標及圖紙符號有3D-Builder專用向量表示；垂直／對齊尺寸旋轉原有表示。沒有用一個通用方塊冒充所有工具。相同或相近操作可共用原始圖形，但完整名稱始終可見。

每個圖示由內嵌SVG image隔離，避免多個相同mask ID污染彼此，也不注入外部HTML。固定64×64 viewBox，正式選單顯示32px、快速列20px；只在選單範圍增加flex配置，英文長名稱可換行。停用圖示灰階淡化，保留文字停用色。

[完整規劃](../design/menu-redesign/plan.md)、[205指令配置](../design/menu-redesign/command-map.json)、[可操作獨立預覽](../design/menu-redesign/preview.html)。參考的是上游實際workspace／toolbar資料和官方設計文件；上游ux-redesign圖片明示為提案，不宣稱其全部功能已實作。

建議零件分成建模／曲面／鈑金／插入／檢查／管理／檢視；草圖情境頁、組合件及工程圖各有對應工作列。少數常用按鈕＋組名完整下拉、搜尋與收合，保留左側FeatureManager／PropertyManager。預覽可切四種文件情境、開分組、搜尋、查看雙底色16／24／32／48px圖示總覽，但不執行CAD。

**本批沒有把新Ribbon／搜尋／情境切換邏輯接入正式程式**。這些屬於下一里程碑；選取關係與Viewport現有控制需要同源Adapter，不能以尚未接線的按鈕宣稱新能力。模型／組合件／圖紙Schema均不變。

## 驗證與實際限制

- 新增4項檢查通過：125原檔逐一SHA-256與MIT聲明；對照現有registry的205個ID完整性；除料／部分展開／螺紋與7種尺寸語意區分、草圖與曲面配色；所有明暗圖示都有正確viewBox，無外部資源、腳本、事件屬性及未解析色彩。
- 3個實際瀏覽器案例各有通過紀錄：空白與有本體的enabled切換、可見文字／說明／裝飾語意、由圖示＋文字選單建立真實OCCT伸長體7200mm³、繁中／英文配置及存檔；工程圖7種尺寸圖示與實際啟動半徑工具；設計稿情境分組／搜尋／205圖示載入與32／16px總覽。截圖已檢視。
- 型別、反模式／分層／i18n、建置通過；help40與既有右鍵20項通過，未跑全套CAD或全套UI。
- 另兩項既有右鍵測試失敗，已在乾淨`0a9b2ec` worktree只重跑同兩項並重現：`context-menus`的明細預期未納入`tool-stretchEntities`；移動圖元案例仍取得`select`。本批未更動contextMenus、controller或原測試來掩蓋，後續需另外修復／更新。不能宣稱所有相關測試全綠。
- UI首輪工具名稱誤用「伸長」而非真正的「伸長填料/基材」，改腳本後只重試workflow。檢視設計稿發現緊湊CSS隱藏完成草圖，修正並只重驗設計稿；已通過的drawing未重跑。原始失敗／基準重現／重試證據保留`out/action-icons/`與`out/action-icons-retry/`；自製尺寸線條的深底對比以line色角色修正後，4項檢查及僅設計稿UI再通過，證據`out/action-icons-final-design/`。

紅隊四問：① ID明確映射，不認識的ID保留文字，不硬套無關圖示；原檔完整性與SVG靜態內容檢查，不讓外部資源或腳本進入；② 純UI不新增布林／幾何參數，仍用真實OCCT體積確認點選後原流程；③ 原registry→圖示→CommandBar／子選單／快速列→help與雙語接線，既有啟用、參數、快捷鍵與文件格式維持；④ 實際SVG載入／畫面／點選與native體積驗收，不把設計稿當已完成的CAD功能。未做新的Heap量測、不宣稱零洩漏。

## 2026-10-26：兩項舊右鍵測試失敗處理

清單明列已上線的`tool-stretchEntities`，同時更新C27的完整子選單預期。移動失敗的根因是測試只替換`store.sketcher`、未建立編輯狀態；`7805a57`加入重複指令的live enabled檢查後，這種閒置狀態正確被拒絕，並非產品不能移動。案例現在先斷言閒置拒絕且選取保留，再提供真實草圖編輯狀態啟動，finally還原store／spy。未繞過或刪除產品guard。

僅重跑受影響草圖選單4項通過（其餘20項由篩選未執行，沒有改skip或期限）；新增[真實瀏覽器案例](../../tests/e2e/manual-context-transform.js)驗完整子選單、右鍵預選、兩次pointer click後兩個端點的原生求解位置＝原值＋指定向量，1項通過並檢視截圖。CI加入`context-menus.test.ts`，防止後續再次忽略這個契約。
