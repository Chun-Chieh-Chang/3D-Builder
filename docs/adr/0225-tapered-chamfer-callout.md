# ADR 0225：錐面倒角的端面退距標註

工程圖對圓錐倒角原以倒角面兩個端點的軸向距離作為尺寸。相鄰側面也有錐度時，倒角前的端面與側面的交線不在倒角面與側面的交界處：TM0002138 的端面退距為 0.5 mm，但倒角面的軸向長為 0.5174165 mm，誤標為 C0.52。

對可唯一確認的完整圓形倒角面、垂直於軸的平面及同軸錐面，在截面上延伸側面的解析錐線至端面，量其交點到倒角端點的半徑差。新建標註預覽及既有標註重算均使用此真實幾何；引線位置與倒角角度仍由倒角面幾何決定。一般圓柱壁、不能確認的相鄰面沿用既有行為。此為端面退距，並不假設一定等於模型中在另一側面輸入的數值。

驗證使用真實 OCCT 圓錐台、解析倒角及 100 組不同尺寸與正負錐度；提供 CHAMFER_SAMPLE 時也驗證使用者模型 0.5 與重建為 0.6。參照、尺寸檔案格式均不變，重開既有工程圖後會重新量測。
