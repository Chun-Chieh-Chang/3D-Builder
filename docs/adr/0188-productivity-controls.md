# ADR 0188：操作改善 E6

2026-10-24，不升文件 Schema。

Enter 重複建立特徵／草圖工具／插入與結合；檔案、刪除、復原與切換不進重複清單。優先採目前合法選取，否則採同一文件中原指令的選取；切換文件不沿用。面板或輸入框先處理 Enter。普通結合草稿 Tab 翻轉方向並阻止焦點跳轉；SmartMates 既有手勢仍自行處理。

選取欠定義圖元讀實際 PlaneGCS entityStatus，未分析時明確提示，不用整張草圖的 DOF 猜。automaticRelations 是獨立瀏覽器選項；抓取仍定位但不自動建立點合併／外部參照與推論關係，明確畫出的折線仍共用鏈端點。矩形、切線弧等工具本身定義保留。

3D 雙擊實際面，圖形區旁顯示擠出／旋轉／定半徑圓角／倒角及其草圖驅動尺寸；Enter 經既有命令一次更新、Esc 還原未提交輸入。尚不涵蓋所有特徵參數；無尺寸時顯示說明，不假造量測。

新增單元 3 項皆有通過結果，選項／help 相關 49 項通過。新增瀏覽器 2/2：3D 編輯、真實幾何位移、一次復原、Enter 重複、欠定義圖元與獨立開關；普通結合 Tab 翻轉。初輪 UI 誤用 Z 座標作擠出方向，改讀實際草圖法向後證實幾何；後續找到重複指令取消後遺失輸入選取，已修並通過。舊 manual-e6 碰撞腳本保留，新檔為 manual-productivity。只重試失敗案例，不跑完整套件。
