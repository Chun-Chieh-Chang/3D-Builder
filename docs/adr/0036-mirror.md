- 狀態：已實作（2026-10-01）。**3a-7（參考幾何與複製排列）到此完成**（7a ADR 0034、7b ADR 0035）。
- 對應：C6.3 鏡射（特徵、本體），見 [phase3-plan](../phase3-plan.md) §3 的 3a-7。
- **Schema 升為 23**：新的特徵種類 `mirror`（`target`、`plane`、`seeds`、`bodies`、`merge`）。舊檔不需轉換；已補 v22 樣本 `tests/fixtures/old-versions/v22-pattern.3dbx`（由 `245f3d7` 寫出）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **一個特徵、兩種對象**（`target`）：`features` 鏡射種子特徵對本體加上與移除的材料；`bodies` 鏡射整個本體。 | SW 的鏡射也是這兩種；一個按鈕、一個屬性管理員，用下拉選單切換。 |
| 2 | **特徵的鏡射就是只有一個實例的排列**：同樣的「之前與之後的本體相減」（ADR 0035 決定 1），把加上與移除的材料用鏡射矩陣（`placements.mirror`，過平面上一點、法向 n：x′ = x − 2(n·(x − p))n）轉成鏡像，再照種子的方式接上或減去；與排列共用 `repeat`（引擎裡把排列與鏡射共同的部分抽出來）。鏡射**不做實例互相重疊的檢查**（種子跨過鏡射面時，鏡像和種子重疊是合併，不是錯誤）。 | 一個做法，兩個功能；鏡射的材料是 `Kernel.transformed` 的鏡射矩陣，驗證過體積與表面積不變、有效、可接合（`packages/kernel/test/transform.test.ts`）。 |
| 3 | **本體的鏡射**：每個選取的本體鏡射一份（`Kernel.transformed`），用既有的 `apply(…,'boss',…)` 放進本體清單：`merge`（預設開）時與碰到的每個本體連成一塊，包括原來的那個（本體剛好貼在鏡射面上時兩半連成對稱的一塊）；`merge: false` 時成為另一個本體（編號 `<鏡射>#<第幾個>`）。 | 與填料的「合併結果」開關一致（ADR 0022）。 |
| 4 | **面的名稱：`<鏡射>:mirror:<原名>`**（特徵與本體都是）。第一段是鏡射的 ID，所以相依、抑制連帶、遺失參考的處理照舊。鏡射的面不是左右手互換：名稱對應原來的面（鏡射出來的柱子的側面叫 `mir1:mirror:e2:side:s2.k`），之後的圓角、草圖參考找得到。 | 與排列同一條命名路徑。 |
| 5 | **鏡射面**：預設基準面、基準面，或模型上的平面（`planeOf`）；不是平面（例如圓柱面）說「鏡射面必須是平面」。鏡射面動了（基準面的偏移改了）或種子改了尺寸，鏡像跟著動。 | 與草圖平面的參考同一套規則。 |
| 6 | **可讀的錯誤**：鏡射出來的除料沒有碰到本體（「鏡射面把它帶到本體外面了」）、鏡射出來的填料沒有接觸到本體而成了分開的一塊、沒選特徵或本體、本體不存在（遺失參考，可以「改用這個」）、種子被抑制／失敗／不連續／沒變任何材料。 | 驗收標準（4）。 |
| 7 | **介面**：「特徵」分頁的「鏡射」（先選一個特徵再按；模型裡沒有可排列的特徵時改為鏡射第一個本體），屬性管理員有「鏡射什麼」下拉選單、種子勾選清單或本體勾選清單、「合併結果」（本體）、鏡射面的選取方塊與基準按鈕。編輯時顯示鏡射完的結果。 | 與排列一致。 |

## 驗證

- **手算與等值**（`tests/phase3/mirror.test.ts`，15 項，真的 OCCT，板 60 × 20 × 5 加半徑 2 高 5 的柱，鏡射面 x = 30 在板的正中）：柱子鏡射成第二根，體積 = 板 + 2 柱，鏡像頂面在 x = 55，側面面積與原來的相同；孔鏡射成第二個孔；改種子半徑 2 → 3 兩根都跟著變；基準面偏移 40 時鏡像落到板外並說明，偏移 20 時在 x = 35；鏡像柱頂邊的圓角找得到；凸台與圓角一串種子一起鏡射；**本體鏡射成獨立本體：第二個本體的體積、表面積與原來的相等、質心 x 座標相反、有效、所有面名稱不重複、編號 `mir1#1`；合併時板和它的鏡像沿 x = 0 接成一塊，體積是兩倍，表面積是兩倍減去貼在一起的兩個面（2 × 20 × 5）**。
- **錯誤**：鏡射到板外的填料與除料、鏡射面不是平面、沒選特徵、沒選本體、本體不存在；指令：種子不能鏡射的種類或在鏡射之後、對象與參考不符、不是鏡射特徵、鏡射面不是平面。
- **相依**：鏡射是種子（或本體由哪個特徵做的）與鏡射面的子特徵；抑制鏡射面或種子連帶抑制鏡射；修復參考時 `mapRefs` 替換鏡射面與本體。
- **舊檔**：v22 樣本（板、柱、線性排列跳過第 2 個）開啟、遷移到 23，排列照常重算，實例名稱不變。
- **瀏覽器**（`tests/e2e/phase3-mirror.js`，Chromium，0 個特徵失敗）：板 60 × 20 × 5、柱在 x = −25；選柱按「鏡射」，右基準面預設：第二根柱在 x = 25（6125.66 = 6000 + 2 × 62.83）；改成「本體」沒選時說「請選擇要鏡射的本體」，勾選本體後合併（板是自己的鏡像，6125.66、1 個本體）、取消「合併結果」變兩個本體（12125.66）。
- `npm run check` 全過（型別、分層、i18n 基準不增加、全部測試）。

## 3a-7 驗收標準（使用者 2026-10-01 確認）逐項

1. 排列實例的面有穩定唯一的名稱：`tests/phase3/pattern.test.ts`（名稱不重複、實例數改了留下的名稱不變、之後的圓角找得到）。✓
2. 種子改尺寸所有實例同步，實例數與間距改了重算 0 失敗：同上（半徑 2 → 3、變數驅動、`setPattern` 改數與間距）；鏡射同樣。✓
3. 鏡射的本體體積與表面積相等、名稱唯一：本檔「驗證」。✓
4. 實例碰到本體外或互相干涉有可讀的錯誤：排列的三種訊息與鏡射的兩種訊息，都指出第幾個實例。✓
