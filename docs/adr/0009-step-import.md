# ADR 0009：STEP 輸入（Phase 1F）

- 狀態：已採用（Phase 1F，2026-09-28）。最終驗收需要使用者的 SolidWorks STEP 樣本（見「驗證」）。
- 依據：藍圖 §2.4 第 5 點、§2.8「輸入」、附錄 C 的 F2.1、F2.2；[handoff.md](../../handoff.md) 的里程碑 1F

## 決策

| # | 決策 | 理由 |
|---|---|---|
| 1 | **Schema v5 新增 `importedBody { blob }` 特徵**；`BlobRef` 多一個只供顯示的 `fileName`。<br>資料以 SHA-256 識別，隨 `.3dbx` 存檔（ADR 0008）。v4 → v5 的遷移不需改內容 | 輸入的檔案是設計意圖的一部分（藍圖 §2.3）。零件檔自給自足，不需要原始 STEP 檔也能重建 |
| 2 | **指令 `importBody` 一次加入資料與特徵**，是一個復原步驟。刪除最後一個使用某份資料的特徵時，一併移除該資料（ID 仍算已發出） | 文件裡不會留下沒人使用的資料；復原會把兩者一起帶回 |
| 3 | **幾何核心 `importStep`**：<br>• 讀成實體，單位一律換算成 mm（以英制檔驗證過）<br>• **只有通過有效性檢查失敗時才用 ShapeFix 修復，並發出警告**<br>• 不屬於實體的面略過並警告；完全沒有實體時報錯 | 實測發現 ShapeFix 對乾淨的檔案也會回報「已修改」。若每次都修復並警告，警告就失去意義，也會無故改動幾何。曲面縫合成實體屬於 F2.2（P1） |
| 4 | **面的名稱是 `<特徵>:f<k>`**：k 是面在讀入形狀中的順序；邊線與頂點沿用相鄰面名稱的文法（ADR 0002）。名稱中不含雜湊 | 同一份資料、同一版讀取程式，順序就固定（藍圖「拓撲索引 + 指紋」）。一個特徵的資料不會改變（目前沒有「置換輸入檔」），特徵 ID 已足以區分。將來若加入置換，名稱必須跟著改 |
| 5 | **金樣測試固定一個 STEP 檔的面順序**（`tests/fixtures/step/`） | 名稱完全相符時，解析不會再比對指紋。萬一升級幾何核心改變了讀入順序，這個測試會先失敗，而不是讓零件中的參考默默指到別的面 |
| 6 | **重新計算時，每份資料只讀一次**：依 SHA-256 快取讀入的形狀（衍生資料），文件不再使用時釋放。本體一律用快取的複本控制代碼，快取不會隨結果一起被釋放 | 讀 STEP 很慢，而且只取決於資料本身。測試確認重複重建不會洩漏形狀 |
| 7 | **輸入本體併入現有本體** | 目前是單一本體；多本體（C7.1）屬於 P1。夾治具的「參考本體」在 Phase 4 處理 |
| 8 | **兩個入口**：<br>• 「特徵」分頁的「輸入 STEP」：插在回溯控制棒的位置，一個復原步驟，完成後全部顯示<br>• 「開啟舊檔」選 STEP 檔：建立以檔名命名、尚未儲存的新零件，同 SW | 對應 SW 的「插入 > 特徵 > 輸入」與直接開啟 STEP |
| 9 | **資料先送進 Worker，再執行使用它的指令**：開檔時整批送（`setBlobs`），輸入時送一份（`addBlob`） | 第一次重新計算就找得到資料；大檔不必每次重算都傳送 |

## 驗證

- 幾何核心（`packages/kernel/test/import.test.ts`，6 項）：
  - 輸出再輸入：單一實體、體積相同、每個面都標上順序，乾淨的檔案沒有警告；
  - 同一檔案讀兩次，面的順序相同；
  - 英制檔換算成 mm；
  - 多個實體一起保留；
  - 不是 STEP 或沒有實體時報錯；
  - 複本控制代碼在原本的被釋放後仍可用。
- 零件層（`tests/phase1/import.test.ts`，9 項）：
  - 從文件資料重建，面依檔案順序命名；
  - 在輸入的頂面上畫草圖做凸台、在輸入的邊線上做圓角，體積與手算值一致，父子關係正確；
  - 輸出再輸入後體積不變（「輸入 → 加特徵 → 輸出」）；
  - 併入既有本體；
  - 每份資料只讀一次、重複重建不洩漏形狀；
  - 缺資料或不是 STEP 時說明原因；
  - 一步加入、復原、刪除時一併移除資料；
  - 存成 `.3dbx` 後，全新的程式實例重建出相同的名稱與體積；
  - 金樣：固定 STEP 檔的 7 個面，名稱與幾何的對應不變。
- 瀏覽器實測（檔案對話框以替身取代，理由見 ADR 0008）：
  - 新零件 → 輸入 STEP（示範件輸出的 STEP）→ 「輸入1」，體積 991.416 mm³，與原件相同；
  - 用 UI 在輸入的邊線上加圓角：982.832 mm³ = 991.416 − (4 − π)·10；
  - 另存的 `.3dbx` 內含 `blobs/<sha256>.step`；重新開啟後重建相同；
  - 「開啟舊檔」選 STEP：建立尚未儲存的新零件「demo-block *」；
  - 復原與重做正確。
- **尚待使用者驗收（藍圖 Phase 1 ③）**：用你的 SW 零件 STEP 走一次「輸入 → 加特徵 → 輸出 → 在 SW 開啟」，並核對物質特性。

## 已知限制與範圍外

- 只收實體：曲面模型的縫合屬於 F2.2（P1）；STEP 組合件結構屬於 F2.8（P1）。多個實體會成為一個本體。
- 不讀 STEP 中的顏色與名稱（XCAF）。
- 沒有修復選項 UI（F2.2，P1），也沒有「置換輸入檔」。
- 輸入的資料在這個工作階段中，主執行緒與 Worker 各存一份；大檔會占用兩倍記憶體。
- 修復的路徑（檔案有缺陷時）還沒有真實的缺陷檔可以測，等使用者的樣本。
