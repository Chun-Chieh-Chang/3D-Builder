# ADR 0100：工程圖的角度尺寸（工程圖 Schema 5）與下拉選單

- 狀態：**已實作並驗證（2026-10-07）**。手冊 F3 多一步；說明主題 `concept.drawing-dimensions`。
- 工程圖 Schema 4 → **5**（遷移是空的：新的 `angle` 尺寸種類只是多一種，舊檔原樣讀）。

## 做法（第一性原理：角度是兩條線的夾角，數字從模型算）

1. **種類**：`AngleDimension { kind:'angle', a, b, arc, supplementary? }`，`a`、`b` 是元素參考（面或直線邊），`arc` 是弧半徑（紙面 mm，> 0）。公差只有上下限（沒有配合）；不能加「相同個數」。
2. **數值**：兩個元素在這個視圖裡都要是一條線（平面與視線平行、直線垂直於視線，否則「不是一條線」）；平行時沒有夾角（說明原因）。夾角 = 從兩線交點朝各自元素「中間」（面：`ElementFacts.center`，邊：中點）伸出的兩條射線所夾的角（0°–180°）；`supplementary` 取補角。
3. **畫法**：弧畫成折線（交點為圓心、半徑 `arc`）、兩端箭頭（弧太短時箭頭在外面）、延伸線從離交點 `GAP` 畫到 `arc + OVERSHOOT`、文字在角平分線上。
4. **斜面**：視圖特徵新增 `slant`（邊視成線、但不與 x 或 y 對齊的平面），尺寸面板的列表列出「斜面 θ°」，才有東西可以選。
5. **新增**：`DrawingStore.addAngle(viewId, a, b)`，弧半徑 18 mm 起、每多一個加一個 `OFFSET_STEP`。

## 驗證

手算：方塊的頂面與側面 90°、與 45° 導角面 135°（補角 45°）、30° 斜邊；弧半徑 20 時文字在平分線上、延伸線到 22；平行與非邊視的說明。`tests/phase5/drawing-angle.test.ts`（17 項）；瀏覽器 `tests/e2e/phase5-angle.js`：金樣支架右視，平面與斜面 45°、兩斜面 90°、補角 135°、改弧半徑。

## 限制

- 尺寸面板只列平面（垂直於 x／y 的與斜面）；直線邊在計算上支援，介面沒列。
- DXF 輸出仍是線與文字，不是 DIMENSION 圖元（角度尺寸也一樣）。
- 角度只量一個視圖內的兩條線；兩線交點離圖很遠時的畫法（弧與延伸線）沒有專門處理，也沒有實機驗證。

## 同日的介面改動：命令列改成下拉選單

使用者看到各分頁的按鈕全橫排在右邊，要求「按需展開」。`CommandBar`：每個名稱是一個選單，按下去那一組的按鈕在下方排成欄；點按鈕、Esc、點別處就收起；展開時滑到別的名稱就換成那一個。收起來的選單仍留在頁面（`display: none`），所以 e2e 與說明仍找得到按鈕。e2e 的選單選擇器從 `.tabs button` 改成 `.tabs .tab`。
