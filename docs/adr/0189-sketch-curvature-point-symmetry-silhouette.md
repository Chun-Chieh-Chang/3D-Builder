# ADR 0189：D3 草圖關係與側影

2026-10-24，零件 Schema 78。新增 symmetricPoint 以 PlaneGCS 的 p2p_symmetric_ppp 解三點中心對稱，選取最後一點為中心；equalCurvature 適用圓／圓弧，曲率 1/r，因此映射原生相等半徑。未支援樣條端點曲率關係，選單明確標示圓／圓弧，不宣稱任意樣條 G2。

側影輪廓線在草圖編輯中點模型面，由 OCCT HLR 擷取真正投影側影，無內部側影時採邊界。週期面接縫恰是側影時，HLR 會把它列成接縫而漏一側；以接縫參數曲線上五點的實際曲面法向判斷是否與視向垂直，僅補真側影的直線接縫。圓柱在不同視向都回傳兩側，不把內部接縫當側影。

每支保留目標面的持久參照與 silhouette 分支號，參照進 DAG／重算／worker／UI。直線、圓與圓弧保留解析表示；其他曲線以 65 個原生參數樣點插值，未聲稱任意自由曲面的精密輪廓公差。分支種類或點數改變報失效，沒有默默留下舊座標。

實體測試 4 項各有通過結果，包含 100 組求解器關係與 100 組真實圓柱側影、半徑變動、旋轉視向及解析圓外框。UI 1/1、help 40/40、型別／lint／build 通過。只重試失敗項，不重跑全套；量測實際 Heap 並印成長，不宣稱零洩漏。
