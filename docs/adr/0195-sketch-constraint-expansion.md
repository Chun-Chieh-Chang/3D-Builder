# ADR 0195：草圖拘束六項擴充

2026-10-25。使用者指示依建議順序實作。零件 Schema 81 → **82**；組合件 7、工程圖 28 不變。

## 最終範圍與操作

1. **批次拘束**：選取多條線後加入平行、等長、水平／垂直；多圓／圓弧加入同心、等徑、同心同徑；多點可重合或對齊。用已有拘束的傳遞閉包建立最少缺少的連結，共用圓心不再加重合，同心同徑拆成各自必要的圓心與半徑連結。整批試解成功才一次提交、一次復原；失敗不留下前半批。
2. **等距與比例**：依順序選 3–32 個點或圓／弧中心，加「等距」；首尾決定整列位置，中間點按序插值，含共線條件。兩條線可加「長度比例（第一／第二）」，預設 2，可在現有拘束清單改為分數或表達式；定義為 `length(a) = ratio * length(b)`。
3. **整個圖元對稱**：先選兩個同種類、互相獨立的線／圓／圓弧，最後選軸線或中心點／原點。線段儲存端點對應方向；線鏡射的圓弧交換首尾以維持 CCW 語意，點對稱不交換。軸線及中心參照須獨立於被對稱圖元；尚不提供橢圓／樣條的整個圖元對稱拘束。
4. **相切操作**：兩個開放圖元可用「最近端點重合＋相切」，自動選最近的端點對，整個關係一次復原。已存在的重合路徑不再重複加入；線／圓弧的法線相切方向存入模型。圓／圓弧另有明確「內相切」「外相切」，不是依圖形猜測；使用 native `tangent_circumf.internal`，修改半徑甚至交換大小關係仍維持指定模式。
5. **橢圓與 Bézier**：新增橢圓工具（中心、長軸端點、短軸大小），以及四控制點的三次 Bézier。橢圓可加雙軸半徑表達式、點在曲線及與直線相切；中心和長軸端點可用既有點拘束。未加軸半徑拘束時，短軸沿用建立值。Bézier 的端點 G1 可連至線、圓弧或另一條 Bézier；控制點交由 PlaneGCS 聯解，真實曲線導數由解析式決定。**既有擬合樣條不重新解讀成控制點；G2 曲率連續、任意擬合樣條相切、部分橢圓與拋物線仍未支援。**
6. **診斷**：選點可查看經原生求解確認的有限 X／Y 位移；這不是獨立自由度基底，也不把兩次探測當成兩個自由度。逐項移除選取範圍的拘束，顯示恢復多少 DOF，最多 24 項，數值不可相加。過度定義先測單項修復，單項都不夠時才測雙項組合；最多 12 個 solver 回報候選、共 78 次試解。這是有界最少編輯方案，不宣稱求得一般的最小不可滿足衝突集合。只有重新求解成功的方案才列出；尺寸改被動、關係刪除，整組一次復原。診斷期間或套用前文件變更，舊方案失效。

## 模型與求解表示

新增 `equalSpacing`、`lengthRatio`、`symmetricEntity`、`symmetricEntityPoint`、`endpointTangent`、`tangentExternal/Internal`、`ellipseAxes`；樣條新增可選 `bezier` 標記。v81 → v82 為加法升級，舊曲線及舊文件不強制轉換。所有輸入經命令驗證，計算結果仍是衍生幾何。

- `constraintRefs` 包含等距的有序陣列；移除、合併點、複製、縮放皆完整處理其參照。比例不隨縮放改值；橢圓兩軸會縮放。帶表達式的尺寸縮放依既有政策明確拒絕，不改寫使用者表達式。
- 比例及橢圓軸表達式走 `mapExprs`／Parameters、`expressionParents`／DAG 與 Worker 求解；有跨草圖來源尺寸修改的真實測試。比例使用無單位數值角色，允許小數，不沿用要求整數的陣列 count 角色。
- 兩個變數之比例不使用已知可能退化成相等的 native `proportional`；以距離參數和固定輔助直線表達。等距使用兩座標的插值方程，不只要求相鄰距離相等（後者容許折返及不共線）。
- 完整對稱的目標圓弧，其中心及首尾已剛體連動；確認來源鏈有根才保留源半徑與兩角必要規則，避免多加第四條弧幾何規則產生冗餘。
- 橢圓使用 native ellipse 的焦點／短軸參數，以長軸點在曲線及與焦軸共線連接既有 major point。軸值改變時，只調整求解初值至尺寸所指定的長軸位置，避免初值在焦點間平坦殘差區無法收斂；不改 SSOT 點座標或固定拘束的真值。
- Bézier 以首兩控制點／末兩控制點的精確導數方向表達 G1。顯示及輪廓探測用解析取樣；製造輪廓另傳 `bezierPoles`，OCCT 建立真實 Bezier，不把控制多邊形擬合成另一條曲線。舊擬合樣條仍走舊路徑。
- 診斷用實際 Worker 試解，沒有假造 DOF。`applySketchFix` 僅接受一或兩個有效拘束；不可把幾何 ID 當修復目標，不會刪除尺寸而破壞其表達式使用者。方案以文件物件版本驗證，拒絕套用過期結果。

## 邊界與紅隊四問

1. **輸入破壞**：比例無單位且 0.001–1000；等距 3–32 個互異中心，新增輔助參數總額 ≤128。橢圓短半徑 ≥1e-6 mm，長半徑須大於短半徑 +1e-6 mm、≤1e6 mm、長短比 ≤10000。Bézier 開放、2–4 個不同控制點（工具建立 4 點），端點控制柄不可為零；求解後若控制柄退化也回報失敗。不偷偷取整或修改數值。
2. **幾何與相交**：未新增布林演算法；點的批次連結採最小森林，避免冗餘；共享對稱點／軸與目標重複會顯式拒絕。Bezier 進入既有輪廓與有效性流程；不宣稱任意自交曲線可作實體。兩個閉合實體案例以實際有效性和體積驗證。
3. **依賴鏈**：schema → commands → refs／刪除／合併／複製／縮放 → Parameters／DAG → PlaneGCS → profiles → OCCT → UI 及說明完整接線。跨草圖表達式、序列化、修改、原子復原與過期試解有驗證。
4. **真實性**：原生求解幾何逐值比對，包含 100 組批次等長、100 組比例、100 組旋轉等距、100 組對稱弧、100 組明確相切、100 組旋轉橢圓、100 組橢圓改軸、100 組旋轉 Bézier G1。OCCT 探針比對解析體積、真實曲線位置和端點 `D1` 切向；不用模型輸入點或顯示網格充當匯出真值。沒有進行 heap 洩漏量測，也不宣稱零洩漏。

## 失敗萃取

- 初版逐座標 ellipse alignment 的使用方式留有額外自由度，解析幾何比對失敗；改以點在橢圓與焦軸共線後，才取得正確 DOF 和點在橢圓／相切真值。
- 放大軸時僅初始化焦點、仍把 major point 放在焦點之間，native 殘差出現平坦區而不收斂。以表達式目標初始化 major point，驗證 10 →20 →40 的軸長與分項復原，並補 100 組軸尺寸變動。
- 診斷 effect 只依文件變更而不依求解狀態時，文件先更新、Worker 後回傳 over 會漏掉診斷；須同時依文件與求解衝突狀態更新，並拒絕過期修復。
- 分析點的拘束貢獻須納入相連圖元，否則線段上的水平拘束不會在端點分析列出。測試只對結果列斷言，不能把說明文字中的「X／Y 探測」誤判為測到 Y 位移。
