# 0185：圖紙標註預設、側視螺紋引線與公差等級

日期：2026-10-23。接續 ADR 0184。零件 Schema 76，圖紙 Schema 28。

## 決策

圖紙 `sheet.calloutStyle` 指定文字／製造符號預設。尺寸未設定 `calloutStyle` 時動態繼承；有指定時覆寫，清除後恢復繼承。孔表同樣遵從圖紙預設。每頁各有圖紙設定，新增頁面沿用既有的複製規則。舊圖缺少欄位時維持文字格式。

側視圖的螺紋引線使用獨立尺寸 ID 與持久圓柱面參照，以 `DiameterDimension.threadLeader=true` 區別一般直徑尺寸。尺寸面板提供螺紋面選單與「螺紋引線」按鈕，支援內外裝飾螺紋及標準攻牙孔。沿用既有尺寸的選取、刪除、引線拖曳、角度、樣式、復原／重做與存檔機制。

只有側視圓柱及有效模型螺紋資料能產生此引線。引線落在模型圓柱的投影輪廓，裝飾螺紋使用其實際起點、方向及有效長度定位；模型參照失效或螺紋被移除時回報錯誤，不留下舊規格。禁止以自由文字取代此模型規格，也不允許將它切成半徑。它在 DXF 中是引線幾何及 TEXT，不輸出虛假的直徑 DIMENSION；SVG／PDF 由同一場景繪出。

`CosmeticThreadFeature.toleranceClass` 與標準攻牙孔 `HoleFeature.toleranceClass` 儲存使用者明確選定的公差。未指定時不補造。支援範圍是目前內建螺紋表中的規格：

| 類別 | 內螺紋 | 外螺紋 |
|---|---|---|
| 公制 | 4H、5H、6H、7H | 4g、5g、6g、6h |
| UNC／UNF | 1B、2B、3B | 1A、2A、3A |

這是規格註記，未新增數值極限尺寸計算或改變螺紋實體。自訂尺寸沒有可聲稱的標準等級。命令層及再生層都拒絕不符標準／內外類型的值。面板切換標準、內外類型或改成自訂時，若原等級不再相容則清除；API 直接傳入不相容值則明確拒絕。

資料經評估結果、`ThreadCallout`／`HoleInfo`、`elementFacts`、`viewFeatures`、worker 到尺寸與孔表。組合件的元素變換同步變換螺紋起點與方向。自動尺寸及孔表的分組包含公差等級，排除只用來放置引線的座標，避免相同規格因位置不同失去數量合併。

## 相容與驗證

75→76 與 27→28 為無損升級，不補預設公差或重寫尺寸樣式；較舊程式會拒絕它不能完整表達的新文件。

新功能單元測試覆蓋真實拓樸、模型修改連動、樣式繼承與覆寫、孔表／數量分組、存檔升級、復原與錯誤輸入。4 個新模型案例 × 中英文 × 兩種樣式，共 16 組製造值、DXF/PDF 讀取與 FreeCAD 幾何檢查通過；另有 20 份 PDF（含回退）與 DXF 渲染目視證據。瀏覽器測試經模型公差面板、存檔、新工程圖、側視引線與樣式面板完成一次真實流程。

依使用者先前限制，測試採新增／相關案例與失敗重試，未重跑完整單元／UI 套件。瀏覽器初輪誤用既有伺服器的舊 worker；比對 HTTP 回應與目前源碼後改用獨立新伺服器，維持相同驗收與等待時間，最終通過。

外部證據在 `out/thread-extensions/`，流程見 `docs/automated-acceptance.md`。外部 DXF renderer 有公開 Unicode 解碼與字型註冊適配；FreeCAD 無介面匯入只證明幾何。未宣稱原生 AutoCAD／SHX 或完整 ISO／ASME 認證。
