# ADR 0075：拔模分析（Phase 6-1，E3.2）

- 狀態：已實作並驗證（2026-10-03）。限制見最後一節。
- 相關：[phase6-plan](../phase6-plan.md)、[ADR 0074](0074-plastic-validation.md)（驗證：用曲面本身的法向）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **核心的 `Kernel.draftAnalysis(shape, pull, required, { angular? })`**：回傳每個面的最小與最大拔模角（弧度，asin(法向 · 拔模方向)）、取樣數、面積與分類，另有每一類的面數與面積。分類：`positive`（每個取樣都 ≥ 要求角度）、`negative`（都 ≤ −要求角度）、`straddle`（兩種都有）、`required`（其餘：接近垂直，要加拔模）、`unknown`（取不到樣；平面的面用拓樸的法向，其他的標 unknown）。方向不必是單位向量；零向量與負的要求角度被拒 | SW 的四類（ADR 0074） |
| 2 | **法向用曲面本身在網格節點 (u, v) 上求值**（`BRepLProp_SLProps`，反向的面翻回外側，有位置變換的面套用變換）；**網格做在形狀的複本上**（`clone`，`angular` 預設 0.1 rad），因為同一個形狀的網格只做一次（ADR 0074 發現 2）：分析的結果因此不受圖面上的網格粗細影響 | 精度 2e-15°；網格自己的法向差 0.1°（ADR 0074） |
| 3 | **分析不是特徵、不存進文件**：`DraftState`（方向、要求角度、結果）在 store 裡，關掉視窗就沒了；模型改了（`result` 變了）自動重算；換檔案清掉 | 計畫的假設 |
| 4 | **介面**：「工具」頁的「拔模分析」開一個圖面視窗：方向（±X、±Y、±Z 的下拉、「反轉方向」、「用選取的平面的法向」——圖面選一個平面後按）、要求的拔模角（度，預設 1，打錯會說並保留上一個結果）、四類的面數與面積表、每個面的名稱與角度（點一列選到那個面）。**圖面上的面依類別上色**：正拔模綠、負拔模紅、需要拔模黃、跨越橘（取代零件原本的面顏色，關掉視窗就還原）；結果與畫面上的模型面數不同時（剛改模型還沒重算完）不上色 | 計畫與 SW 的慣例 |
| 5 | **模型是顯示出來的那個**：分析的是 worker 最後一次重算的整個本體檢視（含參考本體與曲面本體，面的編號與圖面一致）；編輯特徵時看到的是編輯中顯示的模型 | 面的編號要和圖面一樣，點選、上色才對得上 |

## 驗證（證據）

- **核心**（`tests/phase6/draft-analysis.test.ts`，9 項）：塊 40 × 30 × 20 畫 3°（向內收），沿 +z、要求 1°：**四面牆各 3.000°（1e-9 以內）、正拔模；頂 90° 正、底 −90° 負**；五個正、一個負，面積加起來 = 本體面積，負的是 40 × 30；要求 5° 時牆變「需要拔模」；沿 −z 牆是 −3.000° 負拔模、頂底互換；方向給 [0, 0, 7] 同樣；沿 x：朝 +x 的牆 87°、朝 −x 的牆 −87°、兩面沿 x 的牆（±y）是需要拔模；圓柱沿拔模方向 0° 需要拔模；圓錐 5°：**5.000°（1e-9 以內），即使這個形狀先被粗的網格（容差 0.5、角度 0.6）做過**；球：跨越（< −80° 到 > 80°）；塊的 R5 圓角（軸沿 y）從 0° 到 90°：需要拔模；零向量、負角度被拒；分析後形狀的面數與體積不變。
- **瀏覽器**（`tests/e2e/phase6-draft-ui.js`，全部通過）：開啟畫 3° 的塊 →「工具」→「拔模分析」：視窗開、五個正一個負、模型上有綠與紅；要求改 5：牆（4 面）變黃；打 `x`：說「不小於 0」、欄位標錯；改回 1；「反轉方向」：五面負、一面正；選 +x 牆再按「用選取的平面的法向」：方向變成牆的法向、那面牆量到 90°；關閉：顏色拿掉。
- 發現一個我自己的錯：面板用 `useStore((s) => s.result?.faceNames ?? [])`，每次回傳新陣列，React 無限重繪（「The result of getSnapshot should be cached」）；改成取 `s.result?.faceNames` 再補預設。**寫 `useStore` 的選擇器時不能在裡面建新物件。**
- `npm run check`：1321 項通過、21 項略過。

## 限制與未做

- **取樣只在網格節點**：節點之間（大面、曲率變化大的面）的極值可能漏掉；`angular` 0.1 rad 時圓柱、錐的極值沒有問題（它們的角度是常數或單調），自由曲面的極值只到取樣的準度。取樣數在核心的報告裡有，面板沒顯示。
- **沒有拔模角的色階圖**（SW 有連續的顏色顯示拔模角的選項）：只有四類；每個面的最小與最大角度列在清單裡。
- **沒有「分模線」**：跨越的面標橘色，但不畫分模線（E3.3 的 X 項，不在範圍）。
- **方向只有六個軸與選取的平面法向**：沒有基準面的下拉、沒有任意向量輸入。
- **底切與厚度分析**在 6-2、6-3。
- 效能只量了小件（塊與圓錐，毫秒級）；幾千個面的件的時間沒量（每個面一次網格節點掃描加曲面求值）。
