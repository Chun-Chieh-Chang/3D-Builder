# ADR 0199：鈑金連續折彎、展開加工／摺回與加工圖

2026-10-25。依使用者採納的順序完成第1、2、6項：多道折彎與特徵混用 → 可編輯展開加工／摺回 → 折彎註記、折彎表及展平尺寸。零件Schema83、圖紙Schema30，組合件仍7。歷史單次折彎限制見ADR0111；唯讀展開預覽見ADR0115，與本次加工特徵分開。

## 1. 連續折彎與真實板片映射

封閉輪廓基材的每塊平直材料記錄原生B-rep與剛體 `toFlat`。中間折彎不再限制一個零件一次：每次切出固定區、折彎帶、移動區；僅折彎帶要求一個板厚、矩形整寬、無孔槽，既有彎曲區不能穿過新折彎帶。旋轉面附著草圖也可再折彎。

固定片保留映射，移動片的映射組合新運動的逆變換；彎曲帶以原始平板展開裕度區存入製造座標。凸折記錄兩個彎曲帶與中間平腹板，後者也有獨立剛體映射。新凸緣／摺邊從實際選取邊所屬板片取得映射；修剪後的宿主平直材料必須在融合新彎曲區**之前**保存，否則共同運算會把新圓柱彎曲區的一部分誤放回宿主板片（新增末端凸緣原生回歸已重現並修正）。

映射只屬於再生派生資料，不寫進文件。平板型式由各平直材料逆變換加上彎曲帶原始平片融合，檢查有效性、單一實體及片段體積和，拒絕重疊／錯連。普通切孔同步修剪板片；0.01mm半徑小孔不得被相對整板體積門檻漏掉。沒有可映射的彎曲帶除料仍明示notIncluded；工程圖及可編輯展開拒絕輸出遺漏加工的圖，而非靜默當作完整下料資料。

原來只有邊線凸緣／摺邊或開放折線基材的傳統平板型式仍保留原路徑；不強迫所有舊檔切換演算法。關聯的普通凸緣與摺邊現在可在中間折彎前後建立。

## 2. 可編輯的展開加工與摺回

「鈑金 → 展開加工」加入 `sheetUnfold` 特徵，保存再生時的折疊實體／名稱與加工前平板快照，再以真正平板實體作為目前本體。可選平板面畫草圖，拉伸除料切孔／開槽。它不是替換顯示用的網格。

「鈑金 → 摺回」加入帶明確 `unfold` 來源ID的 `sheetRefold`。由加工前後的實體差取得移除材料，與各平板片段求交，經各片段的逆映射轉回折疊位置，在原折疊本體上除料；名稱隨布林歷史更新。檢查所有移除體積都被映射，避免加工一部分被漏掉。禁止展開狀態新增材料、巢狀展開、未配對摺回及尚未摺回便新增折彎。可以再次展開、加工、再次摺回。

活動展開狀態從特徵順序推導，按鈕隨狀態啟用。指令驗證來源是先前的展開特徵；DAG將展開之前的本體操作、展開到摺回間的加工納入依賴。支援文件存讀、復原／重做與抑制；Schema83為無損前向升級。

## 3. 加工圖

展平視圖現在向Worker請求**展開實體**的特徵、邊及尺寸事實，與折疊實體分開快取。原生平板轉至統一XY／左下角原點，與輪廓線的座標完全一致。

外形極限面使用語意參照名稱；孔柱面透過板片映射對回原模型的持久面名。驗證板長100→140、孔半徑3→4時，既有尺寸參照仍得到140／R4。其他邊界使用包含拓樸簽章的名稱；不承諾任意拓樸編輯都保持關聯，無法解析時應修復參照。展平參照使用保留命名空間；有尺寸時不能把展平視圖直接換成折疊投影，載入／新增時也驗證來源空間，避免把展開值標到折疊圖上。

在展平視圖「屬性」可獨立啟用：

- 折彎編號／方向註記：B1、B2、UP／DOWN（隨圖紙語系）、角度、內半徑。
- 折彎表：編號、方向、角度、R(mm)、BA(mm)；可改表格左上角的紙面X/Y。
- 原有自動／手動尺寸可標外形、孔徑與位置，數值由原生平板取得。

註記與折彎表取同份native bend資料，模型改動後更新；值不可在圖紙硬改。表格位置與開關持久化、可復原。SVG／PDF／DXF共用scene；半徑與裕度明示mm，即使尺寸選用英吋也不混淆。舊圖預設不新增註記，Schema30遷移不重寫原資料。

## 邊界

這次開放的是**封閉輪廓基材、單一鈑金實體、可辨識平直板片**。每道新折彎帶仍必須為無孔槽的完整矩形條，不能跨已有彎曲區。混用斜接或封閉角落尚未支援；原有普通斜接流程仍保留。由開放折線基材建立的鈑金維持原平板功能，尚不能進本次可編輯展開流程。

展開加工目前只接受可映射到平直片段的除料。跨彎曲帶的孔槽／曲面加工明確拒絕；尚無選擇部分折彎展開、非線性彎曲區材料變形或加工後加料。不是任意STEP／實體轉鈑金，也未新增成形工具、工廠補償表或折彎順序碰撞模擬。

## 驗證

14個新核心案例各有通過紀錄：`sequential-bends`5、`sheet-unfold-refold`6、`flat-manufacturing-drawing`3。含100組雙折彎、100組展開孔加工／摺回的原生參數組態；實際有效性、單實體、體積、展開寬高、孔坐標與摺回後孔軸／高度驗證；旋轉面再折與移動板片末端凸緣、凸折後折彎、凸緣／摺邊混用、微小孔、命令拒絕、依賴、原子性、存讀與復原、原生展平尺寸、關聯更新、輸出文字與向量。

相關舊測試分項驗證，包含37項原先通過、移除單次範圍限制後更新預期的失敗重試，以及另外38項摺邊／斜接／折後除料／開放基材凸緣回歸與flat-view；help40項及型別／分層／反模式／i18n／build通過。依使用者要求只跑新、受影響及失敗案例，不宣稱全套通過。

兩項新瀏覽器流程各有通過結果：真正兩道折彎的實體經選單展開、加工、摺回、復原／重做、再次展開／摺回、存檔重開；加工圖120×50、Ø4、折彎註記／表格位置、DXF下載解析、圖紙存讀。實際檢視截圖。首輪舊Vite快取未更新語系而失敗，重啟後workflow通過；drawing初輪缺測試用data-field定位，補後僅重跑該項，保留所有失敗及通過報告於 `out/sheet-manufacturing/`。

資源驗證斷言再生後的shape handles全數釋放，並從唯一真實路徑 `wasmMemory.buffer.byteLength` 讀取Heap、斷言存在且大於0；不把handles當Heap，不斷言原生Heap零成長。沿用AGENTS §3.5原生布林洩漏與Worker高水位回收限制。
