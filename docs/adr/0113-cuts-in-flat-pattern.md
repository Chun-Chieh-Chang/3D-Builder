# ADR 0113：折彎之後才切的孔進平板型式（Schema 不變）

- 狀態：**已實作並驗證（2026-10-07）**。來源：你在選擇題選「做：把這些除料映射回平板」。

## 問題

平板型式是從基材的輪廓與每個凸緣記下的資料算出來的（ADR 0088）。基材凸緣之後用「伸長除料」等特徵切出的孔和缺口不在這份資料裡，所以不會畫進平板型式、輸出的 DXF 與工程圖的展平圖；雷射切割拿這份 DXF 會漏孔。

## 決定與做法

1. **記錄**：重算時，基材凸緣之後的每個特徵（基材凸緣、邊線凸緣、摺邊、中間折彎本身除外），如果零件前後都是一個實體而且體積變小，就算出「前一個本體減後一個本體」，也就是這個特徵拿走的材料，存在 `SheetInfo.cuts`（形狀歸這次重算，下次重算時釋放）。沒有拿走材料的特徵（凸台等）不記。
2. **放回平板**：平板型式把每一塊被拿走的材料（分成各個實體）用它所在的那一塊板的運動放回去：平板上的不動；凸緣的平直段用該凸緣的「折彎展開」運動（平板型式本來就有，`maps`）；中間折彎轉過去的那一邊用它的反運動（反轉、滑回）。然後從展開的薄實體切掉。輪廓、孔的圓、DXF 都從這個實體讀，所以孔自然出現在平板型式視窗、DXF、工程圖的展平圖。
3. **哪一塊板**：用那一塊材料的頂點與重心判斷：在某個凸緣的平直段範圍、在某個折彎裡、或在基材平板（有中間折彎時分固定側、折彎區、轉過去的一側）。**同一塊材料的各點必須在同一個部分**。
4. **做不到的，明說，不假裝有**：在折彎裡（展開後沒有固定的形狀）、跨過幾個部分（例如孔橫跨平板與凸緣）、基材是折過的板（這種還沒有做）、放回去之後沒有切到板（位置對不上）；平板型式視窗的下面列出「這些除料沒有畫進平板型式（輸出的 DXF 也沒有）」，每項寫特徵名稱與原因。報告多一個 `notIncluded`。

## 驗證

`tests/phase7/flat-cuts.test.ts`（8 項；板 100 × 60 × 1.5、半徑 2、K 0.5，邊線凸緣在 x = 100，長 40）：
- 平板上的孔（R3，圓心 (30, 30)）：平板型式少 π·9 = 28.274 mm²，圓在 (30, 30)；
- 凸緣的牆上高度 20、y = 30 的孔：圓在 x = 96.5 + BA + 16.5 = **117.3197**、y = 30（平板在 96.5 結束，接折彎展開長 BA = 4.3197，再沿牆 16.5），面積少 π·9；
- 折彎裡的孔（高度 2）：不在平板型式，`notIncluded` 說「在折彎」，其他不變；
- 平板 3 個孔加牆上 1 個孔：4 個圓都在；
- 中間折彎（100 × 50，x = 50 折 90°）：轉過去那一側的牆上高 30、y = 25 的孔：圓在 x = 50 + BA/2 + 26.5 = **78.66**、y = 25；固定側的孔在原位；
- 凸台不是除料，不記；
- DXF 讀回來有一個 R3 的 `CIRCLE`，位置與平板型式一致（平板型式移到原點之後）。

## 限制

- 摺邊（180° 的折彎）後面的摺回去那一片上的孔：位置用與凸緣相同的運動，但沒有單獨驗證；斜接過的凸緣、閉合角落延長的平直段：用它們的範圍判斷，沒有單獨驗證。
- 圓角、導角也是「拿走材料」：它們會被記下來，通常在折彎裡或跨過幾個部分，所以平板型式會列為沒有納入；這是對的（它們不改變下料）但訊息會多。
- 每個特徵多算一次體積；邊線凸緣之後有很多特徵的零件會變慢一點（沒有量）。
- 孔放回去只檢查「切掉的體積等於那塊材料的體積」；孔的形狀不是用手算逐一核對（圓孔核對了位置與面積）。
