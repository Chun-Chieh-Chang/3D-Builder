# ADR 0043：選取——濾器、選擇其他、迴圈與相切、BVH（Phase 3a-9c-2）

- 狀態：已實作（2026-10-01）。
- 對應：D5.4 選擇濾器、D5.5 選擇其他與穿透選取、D5.6 選擇迴圈／相切／連續，A5.3 BVH 空間索引，見 [phase3-plan](../phase3-plan.md) §3 的 3a-9c。
- **Schema 不變**（選取與濾器是檢視狀態）。新的相依套件：`three-mesh-bvh`（`packages/render`）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **BVH**：實體的幾何建立時做 `computeBoundsTree({ indirect: true })`，`Mesh.raycast` 換成 `acceleratedRaycast`。`indirect` 讓樹有自己的順序，三角形編號與重算結果共用的索引緩衝區都不變（`triangleFace`、面的範圍照舊）。18 萬個三角形：一條射線從 10.5 ms 降到 0.13 ms（量測，建樹 109 ms）。 | 滑鼠移動一次要射好幾條線（面、被實體擋住的判斷）；匯入的大型 STEP 會卡。 |
| 2 | **選擇濾器**（`pickFilter`，在 store）：面／邊線／頂點三個勾選，在圖面左上的選項列。它只縮小指令要的東西，不增加：指令要邊線而濾器關掉邊線就點不到。關掉的種類立刻清掉懸停。 | D5.4。目前圖面上只有指令要的種類可點，所以濾器是「再窄一點」；自由選取（不在指令中）仍然只有面，等有量測／屬性用到邊線與頂點的選取時再放寬。 |
| 3 | **右鍵選單**（圖面，草圖工具不在用時）：游標下有面時，若這個位置疊了不只一個面，出現「選取其他…（共 N 個面）」，展開成由前到後的面的清單，點哪個就當作點了那個面（在指令中就是加入／切換，自由狀態就是選取）。`Viewer.facesAt` 用雙面射線，所以實體背後的面也在清單裡；剖面切掉的不算。 | D5.5「選擇其他」。穿透選取（從透明中選擇）：顯示類型「線架構」與「顯示隱藏線」本來就可以點被擋住的邊線與頂點（ADR 0042），這次不另外做。 |
| 4 | **迴圈與相切**（`apps/web/src/state/selectionSets.ts`，`Topology`）：只用重算結果裡有的東西——邊線的名稱由兩側的面名組成（`edgeFaces`），再加網格。• `loop(面, 邊線)`：這個面的邊線中，和該邊線首尾相接的那一圈（外框或某個孔）；• `tangentEdges(邊線)`：首尾相接而且方向延續的邊線，一路接下去（直線接圓弧、圓弧接直線）；• `tangentFaces(面)`：和這個面平滑相接（三個取樣點上法向差 < 10°）的面，一路擴張（圓角和它連著的面）。端點用 1e-6 倍模型大小的格子對齊。 | D5.6。不需要回頭問核心。**10° 是量出來的**：網格把曲線／曲面切成一段一段（角度偏差上限 0.25 rad），弧端點的方向和法向差半段（圓角量到 3.5°），2° 的門檻連圓角都認不出。代價：10° 以內的拔模面被當成相切。 |
| 5 | **選單項目只出現在指令要的清單上**：圓角／導角在邊線上：「選取相切的邊線」「選取迴圈（面 …）」（邊線兩側各一項）；刪除面／薄殼／拔模在面上：「選取相切的面」。`store.pickMany` 把一組元素加進清單（已在清單的留著，不像點一下會切換；拔模不加中立面），一個復原步驟。 | 圓角整圈外框是最常見的用法。 |

## 驗證

- **核心**（`tests/phase3/selection-sets.test.ts`，4 項，真的 OCCT）：板 60 × 20 × 5 加半徑 3 的孔——頂面有兩圈（外框 4 條、孔 1 條），`loop` 各自只回自己那一圈；四個直角的板沒有相切的邊線，四個垂直邊倒 R3 之後頂面外框 8 條（4 直線 4 圓弧）首尾相接成一串、孔的圓不在其中；倒圓角後側面的相切面是 4 個側面加 4 個圓角共 8 個，頂面、底面、孔壁不在其中；直角板每個面都沒有相切的鄰居。
- **瀏覽器**（無頭 Chromium，示範件，臨時腳本）：圓角指令中右鍵一條邊線，選單出現三項；「選取相切的邊線」把直線—圓弧—直線 3 條加進清單，畫面上變藍；自由狀態右鍵頂面出現「選取其他」，展開後點第 2 個面選到側面；把「面」濾器關掉之後點面沒有反應；0 個頁面錯誤。
- `npm run check` 全過（777 項測試）。

## 還沒做

- 自由狀態選邊線與頂點（要有量測或屬性可看）；框選、多選面。
- 迴圈／相切的預覽（先高亮再加入）；在組合件的元件上選取其他。
- 選單裡的面名是持久名稱（`extrude1:side:sketch1.l3`），沒有「側面」「頂面」的白話名稱。
