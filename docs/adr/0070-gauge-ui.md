# ADR 0070：分割線與偏移曲面的介面（Phase 4b-3，C8.1、C9.2）

- 狀態：已實作並以瀏覽器驗證（2026-10-03）。限制見最後一節。沒有改檔案格式（Schema 仍是 29）。
- 相關：[phase4b-plan](../phase4b-plan.md)、[ADR 0068](0068-surface-bodies.md)、[ADR 0069](0069-split-line.md)。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **功能區「特徵」頁多兩個指令**：`分割線`（有本體且有草圖時可用）、`偏移曲面`（有本體時可用）。新建時：分割線用選取的草圖（沒選就用最後一張草圖）與圖面中選取的面；偏移曲面用圖面中選取的面，距離預設 3 mm（檢具的間隙） | 與其他面特徵（薄殼、拔模）同一個開法 |
| 2 | **PropertyManager 面板**：偏移曲面——選擇框（面清單，遺失的參照可「用最近的」）、偏移距離、轉角接合（圓弧／交會）、**量測結果**；分割線——草圖下拉（只列特徵之前的草圖）、面選擇框、反轉、穿透全部。圖面的點選：偏移曲面是切換面（也吃「選到相連的面」的批次選取，D5.6），分割線是換面 | 與 DeleteFace／Shell 的面板一致 |
| 3 | **編輯時顯示特徵自己的結果**（`until` 取到這個特徵為止，別的面特徵是取到前一個）：這樣訊息框看得到失敗的原因（投影不到、間隙超差），偏移曲面也看得到偏移出來的曲面 | 這兩個特徵的失敗是使用者要看得懂的主要回饋；別的面特徵只顯示前一個特徵為止的模型（輸入要在那上面選）。這兩個也在改之前的模型上選面，但選的面在結果裡仍然找得到（分割後剩下的面保留原名、偏移不動原本的面），所以可以多顯示自己的結果 |
| 4 | **特徵自己做出來的面不能被選回去**：編輯偏移曲面或分割線時，點到名字以 `<特徵編號>:` 開頭的面（偏移出的面、分割出的區域）會被拒絕並說明 | 否則特徵的輸入依賴自己的輸出，重算時找不到 |
| 5 | **量測的間隙是特徵結果的一部分**：`FeatureResult.info` 新欄位，偏移曲面把核心量到的最小、最大、平均與最大偏差（與容許值）寫進去，PropertyManager 顯示；失敗時仍是錯誤訊息（ADR 0068） | 計畫的驗收是「間隙量測誤差 < 0.05 mm」，使用者要能在介面上看到這個數字 |

## 驗證（證據）

- **瀏覽器**（`tests/e2e/phase4b-gauge-ui.js`，兩次執行都全部通過，沒有新的 Console 錯誤）：開啟圓錐台加一張矩形草圖 → 選草圖、功能區按「分割線」→ PropertyManager 顯示分割線並要一個面 → 點圓錐的側面 → 預設方向訊息框說「投影不到」→ 勾「反轉」→ 區域面 `…:side:s2.rl0` 出現、共 4 個面 → ✔ → 功能區按「偏移曲面」→ 點區域面 → **PropertyManager 顯示「量到的間隙：最小 … mm、最大 … mm」，最小與最大都在 3 ± 0.05 以內**→ 點自己做出來的面被拒絕 → 距離 −40 是錯誤、改回 3 → ✔ → 本體清單多一個曲面本體、設計樹標「（曲面）」。
- `npm run check` 通過（型別、分層、i18n、測試）。

## 限制與未做

- **介面只用程式驅動的瀏覽器腳本驗證**：點選是呼叫 `store.pick`，不是真的在畫布上點；視覺的高亮（選到的面的顏色）、畫布上的點選沒有人眼確認。
- 預覽的**視覺**沒有確認（螢幕截圖在視窗被隱藏時逾時）：偏移出的曲面是不是畫得出來、雙面顯示的樣子，由使用者看一下。
- **沒有「選到相連的面」的專用按鈕**：批次選取走既有的（`pickMany`），區域是以邊界的面清單選。選一個區域的所有面是手動的（區域通常只有一個面，所以影響不大）。
- 其餘曲面特徵（縫織、填補、修剪、厚面、以曲面除料）的介面在 4b-4、4b-5。
