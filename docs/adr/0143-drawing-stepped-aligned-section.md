# ADR 0143：階梯剖面與對正剖面（D-I5 第一部分之二）

- 狀態：**已完成（2026-10-15）**。**工程圖 Schema 17 → 18**（遷移空轉，舊程式拒開新檔）。
- 需求追溯：[ADR 0129](0129-drawing-interaction-roadmap.md) 的 D-I5（使用者決定 Q9：任意角度＋階梯＋對正剖面）；任意角度見 [ADR 0142](0142-drawing-slanted-section.md)。使用者 2026-10-15 指示沿用第一部分的驗收標準。

## 背景

夾治具板常要一張剖面同時剖過錯開的孔（階梯剖面），法蘭要剖過不在同一直線上的孔（對正剖面）。ADR 0142 之後剖面線仍只有兩點。

## 決定

1. **文件**（`SectionDrawingView`）：
   - `line` 由兩點改為**至少兩點**（型別 `[P, P, ...P[]]`，既有兩點的檔案原樣有效）。
   - **階梯剖面**＝超過兩點、未設 `aligned`：線段依序為「剖切段、轉折段、剖切段…」，剖切段與第一段**同向平行**、轉折段與第一段**垂直**（單位向量內積誤差 1e-9），第一段與最後一段都是剖切段（線段數為奇數）。違反者由 `checkView` 明確拒絕並指出第幾段。
   - **對正剖面**＝`aligned: true`，剛好三點（一端、轉折點、另一端），兩段夾角不得在 1° 內共線。`setView` 可開關 `aligned`，並重新檢查線。
   - Schema 17 → 18：`parseDrawing` 不檢查視圖，舊程式會只用第一段切，**默默畫錯**；比照慣例升版。
2. **切割**（`Kernel.sectionViewPath`，純幾何規劃在 `packages/kernel/src/sectionPath.ts`）：
   - 觀看者那一側＝剖面線箭頭的反側。在剖面線所在平面上，以折線、兩端沿各自端段延伸、再於右側以大圓弧閉合，得到要拿掉的區域（`rightOfPolyline`）；沿母視圖視向拉成稜柱，從零件切掉。
   - 填剖面線的面＝平面、與視向垂直、落在任一剖切段平面上的面。
   - **對正**：保留的材料在轉折點以「保留楔形的角平分面」切開；第二段那一側繞「過轉折點、沿母視圖視向的軸」旋轉，使第二段的方向轉成第一段的方向（展開到第一段平面），再與其餘部分合成後投影。
   - **轉折線不畫**（ISO 128-44：剖切面的轉折在剖面視圖中不表示）：落在轉折平面投影線上、且兩端都是切面輪廓角點的可見／隱藏線剔除。
   - 剖面線沒切到零件時回傳空的 `cut`（沿用 ADR 0142 的「沒有切到零件」訊息）。
3. **模型與流程**：`sectionCut(parent, v)`＝`sectionPlane` 加上（多於兩點時）整條線的 3D 點與 `aligned`；worker 的請求 `cut` 型別改為 `SectionCut`；`projectDrawingView` 有 `path` 時走 `sectionViewPath`，兩點的剖面仍走原本的 `sectionView`（行為不變）。
4. **圖面**：母視圖上畫整條折線；兩端箭頭各自垂直於自己那一段（`sectionEndDirections`）。剖面視圖的看法、放置側仍由第一段決定。
5. **介面**（剖面工具第四、五個選項）：
   - 「階梯剖面」：點第一段剖切的起點、終點（離水平／垂直 3° 內會對齊）；之後每點一下，就加一段與第一段垂直的轉折，以及下一段剖切；在最後一點再點一下或按 Enter 完成。
   - 「對正剖面」：依序點一端、轉折點、另一端，第三下即完成。
   - 兩者完成後兩端各沿自己的段延伸到視圖外框外 5 mm（`finishSectionLine`）；沿軸向的線放到 0.01 mm 格點，斜的保持原值以維持垂直。點選過程有虛線預覽（`data-path-preview`）。之後與一般剖面相同：移動游標預覽、點一下放置、Ctrl 放在任意位置。拖曳既有的折線剖面線時，整條線一起平移。

## 記憶體（量測，AGENTS.md §3.1、§3.5）

- 新路徑自己建立的形狀全部釋放（`liveShapes` 前後相同；這是控制代碼，不是記憶體的宣稱）。
- **Emscripten Heap 不是平的，原因在 OCCT 的布林運算**：以 `wasmMemory.buffer.byteLength`、每種情境各自一個全新 Heap、1000 次量測（少於數百次會被 Heap 餘裕吸收而量成 0）：單純 `BRepAlgoAPI_Cut`（半空間方塊切零件）約 0.14 MiB／次；**既有**直線剖面 `sectionView` 約 0.25；階梯約 0.42；對正約 1.0（多兩次布林）；`topology`、`projectView` 單獨為 0。產品側由 worker 高水位重啟（ADR 0126）限制。

## 已知限制

- 轉折線的剔除依「在轉折平面的投影線上、兩端都是切面角點」判斷；若零件恰有一條真實的邊與它完全重合，也會被剔除。
- 對正剖面：旋轉後的材料可能與其餘材料在空間上重疊，隱藏線計算照實處理；角平分面切開處，在切面外框以外可能出現線。
- 階梯剖面的剖切段必須與第一段同向（不能折返）；轉折段只能垂直。
- 拖曳既有的折線剖面線是整條沿 x 或 y 平移，不能單獨移動某一段。
- 側邊欄「依數值」新增剖面仍只有水平／垂直。
