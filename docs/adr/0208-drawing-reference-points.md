# ADR 0208：工程圖持久磁吸點與組合件解析參照

2026-10-26。採用。工程圖 Schema 32；零件84、組合件7不變。現況只在[產品現況](../project-state.md)維護。

## 問題與決策

使用者確認舊工程圖輪廓正常，仍無法建立尺寸，且缺少端點／中點等磁吸。程式檢查發現組合件選取資料僅回傳邊與頂點，未提供解析面與圓柱側輪廓；另外多處以name單獨判斷重複，將同來源不同實例誤認成相同元素。

Worker對已定位零件取得原生解析拓樸，將plane／circle／axis等ViewFeature傳回；Ref與fingerprint保留來源零件的局部定義，另帶實例in。暫存變換形狀在finally釋放。圓柱端點順序從來源拓樸沿軸排序後變換，避免鏡射時交換Start／End。選取、預覽、連續及座標尺寸以kind／name／in／point判斷完整身分，不再只比較name。

新增DrawingRef.point選擇器：直線邊中點、圓的四分點，以及完整圓柱輪廓的起點／終點／中點。它們依附真正來源邊／面；文件不保存畫面座標或假造頂點。每次量測先取得最新原生ElementFacts，再依實例定位與視圖軸求點；半徑改變會連動，來源變型無法再求指定點則明確回報參照失效。既有真實頂點及圓心仍可磁吸，只有落在可見投影上的新輪廓點才提供選取。

智慧／水平／垂直／對齊及座標尺寸啟用點磁吸，固定像素標記與雙語提示區別端點／中點／四分點／圓心。先選一點再選另一點建立點距；若只選一個新磁吸點便到空白處放置，仍採來源邊長／圓直徑／圓柱直徑，保留原本單元素流程。明確半徑、直徑、角度、導角工具與右鍵元素選單仍取來源幾何。

Schema31→32為無改值升級，保留舊投影與尺寸；命令與存讀拒絕未知選擇器、頂點附加選擇器、錯誤邊／面類型及不相容尺寸種類。快取只存來源幾何真值，不能把某個點的求值覆蓋其他同來源尺寸。

## 驗證與邊界

- 7個相關原生／文件測試檔85項通過。新增5項涵蓋真實投影、持久化、兩四分點直徑、模型半徑4→6重建得12、非法選擇器／來源變型、100組指標抖動與100組定位（旋轉／平移／鏡射）。後補原生對照與定位斷言僅重跑對應2項通過。
- 原生對照：只給舊邊／頂點資料時，圓柱側輪廓無參照；加上真實解析面後可選取。另隔離舊版完整瀏覽器比較未完成：一輪來源隔離無效，另一輪在開啟組合件前置階段逾時；兩者都不作修正前功能驗收證據。
- 新瀏覽器流程實際寫出v24、v30、v31的零件與組合件共6個舊格式檔，各重啟真實Worker後開啟並建立Ø8尺寸；另驗同名不同實例點距20、圓心／四分點／輪廓端點提示、兩四分點距8，以及儲存後冷重開。它們是原生生成案例，尚未取得使用者實際出問題的舊工程圖及其來源，不冒稱原檔實機通過。
- 5個既有瀏覽器流程：caption重疊、草圖與工程圖尺寸線拖曳、drawing-annotate先通過；dimension-kinds初輪因新中點與右鍵選單失敗。前者改為核對真實來源邊與中點，後者修正產品右鍵取來源幾何，再只重跑失敗流程與新增舊檔流程，2/2通過。證據為`out/drawing-reference-point-final-ui.json`、`out/drawing-point-regressions-ui.json`；沒有放寬期限或容差、沒有全量重跑。
- Heap使用真實wasmMemory.buffer.byteLength且基準>0；liveShapes只驗暫存釋放，100次變換不代表OCCT零洩漏。未新增布林。尚不含任意曲線交點、虛交點／尖角、B-spline中點、一般剖切新生頂點或跨尺寸對齊磁吸。
- 本次延續ADR0206的CAD參照原則，但沒有新增SW／FreeCAD桌面實測或宣稱全面等效。

型別檢查、Web建置、規則／分層／語系靜態守門與文件同步／盤點通過。新增原生測試檔已納入三平台CI清單；遠端本輪執行結果尚未查驗，不宣稱三平台已通過。驗收末張存讀畫面已檢視。
