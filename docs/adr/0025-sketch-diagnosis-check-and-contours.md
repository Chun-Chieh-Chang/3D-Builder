# ADR 0025：草圖的衝突診斷、檢查與修復、輪廓選取（Phase 3a-4c）

- 狀態：已實作（2026-10-01）。
- 對應：A2.5／D7.2 衝突診斷（過多定義的草圖能列出並解出衝突）、C1.35 檢查草圖用於特徵與修復草圖、C1.34 輪廓選取，見 [phase3-plan](../phase3-plan.md) §3 的 3a-4。
- **Schema 升為 12**：伸長與旋轉特徵可有 `contours`（要用的輪廓）。舊檔不需轉換（沒有 `contours` 就是用全部，和以前一樣）；已補 v11 樣本 `tests/fixtures/old-versions/v11-relations.3dbx`（由 `f774c3b` 寫出，有交錯、同心同徑、弧長、從動尺寸）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **衝突診斷只提供「求解器證實有效」的處理**：求解器回報衝突或冗餘的限制條件與尺寸，逐一試算「刪掉它」（尺寸是「改為從動」），草圖不再過多定義的才列出，一個按鈕套用。單獨一項都不夠時明說「需要同時處理兩項以上」。 | 列出來的按了就有用，不靠猜；求解器只說「哪些參與衝突」，不說「刪哪個會好」。 |
| 2 | **診斷是主執行緒對求解器的一串試算**（每個候選一次，通常不到十個），不是求解器的新功能。 | 不改求解器；候選數量是衝突涉及的限制條件數，很小。 |
| 3 | **檢查草圖**（`@3db/sketch/check`）從求解後的幾何找六種問題：開放端點、間隙（兩個開放端點相距不超過「間隙容差」，預設 0.1 mm）、分岔點、重複圖元、長度為 0 的直線、相交或互相穿過（含「T 形接頭」）。每個問題帶著要顯示的圖元，按一下就選取它們。幾何建構線不檢查。 | `findProfiles` 只回報第一類問題的文字且遇到問題就不給任何輪廓；使用者要的是「哪裡、為什麼」。 |
| 4 | **修復草圖只做不需要決定的事**：刪除重複的第二個與長度為 0 的直線，合併間隙的兩個端點（`mergeGroups`，與「合併」共用）。有尺寸在兩個端點之間、或合併會讓還留著的圖元縮成一點時，那一處不修並計入「沒有修」。一次復原。相交與分岔不自動處理（要刪哪一條是設計決定）。 | 自動修復不能默默改設計。 |
| 5 | **輪廓用「圍住它的外圈圖元的 ID」記住**，而不是位置或索引（`contours: Id[][]`）。找回時，每個記住的輪廓取與它共用圖元最多的區域，**共用至少一半（交集比聯集）才算**，所以給選取的矩形加了圓角（多一段弧）仍是同一個輪廓；找不到就是特徵的錯誤，說明「選取的輪廓有 n 個找不到了，請重新選取」，不是默默改用別的。 | 草圖的 ID 是永久的，改幾何不會變；位置會變；索引一加一個輪廓就全亂。 |
| 6 | **沒有 `contours` 就是全部輪廓**；全部都勾選時清掉 `contours`（回到預設），至少要留一個。 | 預設行為不變；選了又全選回來不該留下一個「我選過」的痕跡。 |
| 7 | **輪廓清單在伸長與旋轉的屬性管理員裡**（面積、中心、孔數），只有兩個以上輪廓才出現；用勾選而不是在圖面點選。清單讀的是目前草圖的解（主執行緒用 `@3db/sketch/profiles` 的純 TS 算出輪廓），文件一改就重讀但不閃爍。面積圓是 πr² 精確值，其餘用輪廓取樣的多邊形。 | 圖面點選區域要在草圖上畫出可點的區域，是另一個工作；清單已經能做出每個輪廓的選擇與預覽（預覽的網格隨選擇更新）。 |
| 8 | **面的名稱不因選輪廓而改變**：名稱來自草圖圖元的 ID，沒被選的輪廓只是不產生面。 | 後面特徵參考的名稱不會因為少選一個輪廓而失效。 |

## 驗證

- **單元測試**：`packages/sketch/test/check.test.ts`（6 項）：乾淨的方形沒有問題、間隙與開放端點、分岔／重複／長度 0／相交（含 T 形與圓）、建構線不看、修復後輪廓封閉且沒有問題、有尺寸的間隙不修、沒有可修的就說沒有。
- **控制器測試**（`apps/web/test/sketcher.test.ts`）：診斷列出的每一項都被求解器證實，一次套用後草圖完全定義；檢查與修復一次復原。
- **輪廓**（`tests/phase3/contours.test.ts`，9 項）：三個分開的輪廓（20×10、10×10、半徑 4 的圓）的面積（手算）、全部伸長 = (200 + 100 + 16π)×10、只選一個 = 2000、選兩個、面的名稱相同、除料只選一個圓 = 少一個圓柱、比對（多一個圖元、少一個、太少、找不到、同一個選兩次）、找不到時的錯誤、`setContours` 指令與存檔往返。
- **舊檔**：v11 樣本開啟、遷移到 12、重算，體積不變。
- **瀏覽器**（`tests/e2e/phase3-sketch-checks.js`，每個一次頁面載入）：衝突診斷列出「垂直 ×2、距離 30、距離 25」，按「改為從動」後完全定義；檢查列出 4 個問題（兩個分岔、間隙 0.05、重複），「修復草圖」一次後沒有問題，伸長 = 2000；輪廓清單兩項（面積 200 與 100），取消一個 = 2000、全選 = 3000 並清掉 `contours`，最後一個不能取消。

## 還沒做

- 在圖面上點選輪廓（要畫出可點的區域）；輪廓清單項目的滑鼠移過去時在圖面上亮起。
- 草圖內互相相交的輪廓（SolidWorks 會把它們切開成子輪廓）：目前 `findProfiles` 遇到分岔或相交就不給輪廓，檢查草圖會說明，但不會自動切開。
- 「共用草圖」除了多個特徵各用不同輪廓之外的情形（例如把草圖共用到別的零件）。
- 「間隙容差」不會存在文件裡（它是這次操作的輸入）。
