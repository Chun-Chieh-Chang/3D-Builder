# ADR 0256：與 AI agent 協作出工程圖：完全定義、自主建視圖與剖面、公差與註記可任意追加

- 狀態：**實作中（2026-11-17，Claude 對話）**。
- 需求追溯：使用者在 2026-11-17 提出，原話依序如下：
  1. 「借鑒 https://github.com/storytold/cadcraft 優化專案系統的工程圖功能，希望能夠自動化任意3D模型的工程圖構建。」
  2. 「或是與 ai agent 協作，指定3D模型後，透過簡單的人機交互便能夠自動完成工程圖的繪製。」
  3. 「其中的公差與標註可以任意追加」
  4. 「繪製工程圖的原則，在於 fully determine 3D模型所有的特徵尺寸，與滿足用戶標註的需求，並且自主建立剖面、視圖及必要的標註。」
- 與 [ADR 0134](0134-drawing-main-view-first.md) 的關係：App 的「新工程圖」仍是空白圖頁，尺寸也仍按需標註。本 ADR 不改變 App 的預設流程，只新增一條路徑：由 agent 一次建好整張圖，再依使用者的口語逐項追加。使用者在 App 打開 agent 存的 `.3dbd`，可以照常手動修改。

## 事實核對（第一性原理）

- **CADCraft 是什麼**：以 Rust 撰寫的 2D 製圖軟體（AutoCAD 類），沒有 3D 模型，也沒有「3D 轉工程圖」功能（其 `docs/gaps.md` F24 自述「No 3D」）。所以它沒有「自動視圖」或「自動標註」可以照抄。本 ADR 借用以下三項做法：
  1. **QDIM**（`crates/engine/src/cmd/annotate_qdim.rs`）：選取幾何後一次產生連續、基線或座標尺寸。本 ADR 的位置尺寸採基線排列，同一列的位置超過門檻（預設 6）時改為一列座標尺寸。
  2. **MCP 自檢**（`docs/mcp.md` 的 `shapes`／`selfCheck`）：每個工具都回報做了什麼、略過什麼和原因，數值不合理時直接指出。本 ADR 每次變更都附 `checks`，內容包括重疊、出界、無法繪製的尺寸，以及尺寸完整性。
  3. **`render` 算圖**：agent 能看到自己畫的東西。本 ADR 的 `rasterizeSheet` 不依賴瀏覽器，把整張圖紙轉成 PNG，文字以系統 TrueType 字型的輪廓繪製。
- **現有能力**：單一視圖的「依模型自動標註」（總長、孔、孔位，`autoDimension.ts`）、尺寸排列（`arrange.ts`）、最適比例（`fit.ts`），以及 PDF、DXF、SVG 匯出。缺少的部分：主視圖選擇、視圖與剖面的自主建立、跨視圖去重、**完整性**判斷，以及 agent 端的工程圖工具。
- **「完全定義」怎麼判斷**：零件沿模型的每個方向都有若干「位置」：邊視的平面、真形圓的圓心、側視圓柱的軸線。每個位置都要以尺寸串接到該方向的基準；每個「大小」（孔徑、弧與圓角半徑、倒角）都要寫出一次。對每個方向建一張圖：位置是節點，線性尺寸與座標尺寸是邊。各方向的圖都連通、所有大小都有標示，才算完全定義。規劃器用這張圖補尺寸，自檢也用同一張圖找缺漏。因此 agent 宣稱「完整」時，判斷標準就是這張圖。

## 決定

1. **規劃器**（`packages/drawing/src/autoDrawing.ts`，純函式，App 與 agent 共用）
   - `rankMainViews`：六個方向逐一評分（ISO 128-30、ISO 5456-2）。權重為可見細節 0.35、真形圓 0.25、邊視平面 0.15、隱藏線少 0.2、長邊水平 0.05。每個方向都附評分所依據的數字，供 agent 向使用者說明。
   - `chooseProjections`：一定加一個投影視圖，以補足第三向尺寸。另一個方向只有在出現前面視圖都看不到的真形圓或斜面時才加。上下、左右兩組各取隱藏線較少的一側。
   - `adviseSection`：主視圖隱藏線占比 ≥ 0.2 時建議剖視。切線**沿著**被隱藏的孔或內孔軸線，並盡量穿過最多條；剖視取代同一側的投影視圖。
   - `planDrawingDimensions`／`dimensionCoverage`：依「完全定義」的圖補尺寸並自檢。位置尺寸放在最能看清它的視圖：孔放在呈圓形的視圖，內部軸線放在剖視，階梯放在主視圖的邊視線上。基準取該方向低端面積最大的平面；迴轉件取最大圓柱的軸線。
2. **圖紙算圖**（`packages/drawing/src/sheetRaster.ts`）：繪製線條、填滿箭頭，文字用 `glyf` 輪廓（含複合字形）以掃描線填滿。字型依序找 `DRAWING_FONT`、Windows 的微軟正黑體或 Arial、macOS 的 Arial、Linux 的 DejaVu；都找不到時，文字畫成外框。
3. **MCP 工程圖工具**（`apps/mcp/src/drawingTools.ts`、`drawingSession.ts`）
   - `drawing_plan`：主視圖排名與理由、建議的視圖與剖面、三張縮圖，以及要問使用者的一句話。
   - `drawing_create`：一次完成主視圖、投影視圖、剖視、等角視圖（帶邊線塗彩，放在空角），以及「完全定義」所需的全部尺寸。接著選圖紙與比例：A4→A3→A2 中第一個能以 1:1 以上放下的；都不行時用 A3 並取能放下的比例。最後去除無法繪製的尺寸並重新排列，存成 `.3dbd`。
   - `drawing_tolerance`：「±0.05」「+0.1/-0.05」「H7」「max」等，可用尺寸 id 或尺寸文字（「Ø10」）指定。
   - `drawing_annotate`：註記、表面粗糙度、基準、幾何公差。可用元素名稱或尺寸指定位置，程式自動擺在元素旁並把引線接到元素上。
   - `drawing_inspect`、`drawing_complete`（補回缺漏尺寸）、`drawing_apply`（任意 `DrawingCommand`）、`drawing_undo`、`drawing_picture`、`drawing_save`、`drawing_export`（PDF／DXF／SVG）、`drawing_open`。
   - 每次變更立即存檔，回傳自檢結果與整張圖紙的 PNG。
4. **協作流程**（寫入 MCP `INSTRUCTIONS`）：先存零件，再 `drawing_plan`，把主視圖選項與理由交給使用者（「照建議」或換一個）。接著 `drawing_create`，看圖並讀 `checks.coverage`。使用者以口語追加公差和註記時，用 `drawing_tolerance`／`drawing_annotate` 處理，最後匯出。

## 不在本次範圍（已知限制）

- 斜面與倒角的大小目前只在自檢中列為缺漏，還不會自動標註。agent 可用 `drawing_apply` 加入倒角或角度尺寸。
- 非軸向的視圖（輔助視圖）不參與完整性圖，自由曲面也一樣；這些項目在報告中列為未定義。
- 局部放大圖不會自動建立。（已由下方「補記」取代：2026-11-18 起會自動建立。）
- 工具只處理單一零件的工程圖；組合件工程圖仍在 App 中製作。
- App 端的一鍵按鈕尚未加入。App 打開 agent 存的 `.3dbd` 即可看到並修改。

## 補記（2026-11-19）：多頁與局部放大圖

`71290bc0`、`56a97b3b`（2026-11-18）在本 ADR 之上加入下列行為，當時沒有寫進 ADR，也沒有測試；本次審查後補記並補測試（`apps/mcp/test/drawing-pages.test.ts`）。

- **何時有第 2 頁**：第 1 頁上半徑 < 0.8 mm 的圓角／圓弧尺寸有 4 個以上，或產生了 B-B 剖面。這是**計數**，不是密集度：四個角各一個小圓角也會觸發。
- **B-B 剖面**：A-A 取代一個投影視圖後，另一個投影視圖的隱藏線比例 ≥ 25% 時，以正交方向再剖一次。規劃找不到剖切位置時不建（原本會切在座標 0）。B-B 一律移到第 2 頁。
- **局部放大圖**：每個父視圖（第 2 頁的 A-A 參考副本、B-B、主視圖副本）把微圓角以 3.5 mm 貪婪分群，取最多 3（A-A）或 2 個群，優先取有 2 個以上尺寸的群；同一參照名稱前綴（`featKey`）且在圓內的尺寸一併移入。比例取 20:1、15:1、10:1、8:1、5:1… 中最大、使圖紙上直徑 ≤ 52 mm 者；第 2 頁排版後若頁比例不小於所有放大圖，頁改用比最小放大比例小的標準比例（`enlargeDetails`）。頁名與視圖名經 `t()`。
- **隱藏線**：有剖面時，主視圖或投影視圖的隱藏線比例 ≥ 35% 即改為「隱藏線移除」。只看比例，不判斷剖面是否真的揭露了該視圖的隱藏特徵。
- **標尺尺寸的延伸線**：從參照輪廓（`contourAttach`，離輪廓 `GAP` = 1 mm）起，不從視圖外框起；線性尺寸自 2026-10-26（`c1807eb9`）即如此，`56a97b3b` 延伸到標尺。此函式在 `@3db/drawing`，App 的工程圖也受影響。
- **其他工具看得到每一頁**（2026-11-19 修正）：`drawing_complete` 以全部頁規劃、`drawing_inspect` 每項帶 `page`、公差／註記／字高寫到該尺寸所在頁、`drawing_apply` 可指定 `pageIndex`。DXF／SVG 一個檔一張圖紙：MCP 每頁一個檔（`名稱-n.ext`）；App 輸出目前顯示的頁，多頁時檔名帶頁碼並提示。

已知限制：放大圖直徑 ≤ 52 mm 的斷言在測試零件上成立，但該零件的群很小，沒有走到舊程式會超出的分支，故此項沒有突變證據。
