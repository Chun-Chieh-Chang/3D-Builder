# ADR 0114：折過的基材上的凸緣，平板型式（Schema 不變）

- 狀態：**已實作並驗證（2026-10-07）**。來源：你在選擇題選了「折過的基材上的凸緣的平板型式」。ADR 0088 與 0091 的限制「折過的基材凸緣上再長凸緣，平板型式還沒有做」在這裡解掉。

## 做法

1. **基材記下路徑**：折過的基材（開放折線）記 `side`（厚度在路徑的左或右）、`dir`（板寬的方向）、`straights`（路徑的每一段直線，在草圖座標裡，加上它在平板條裡從哪裡開始）。
2. **凸緣記下長在哪一段**：`SheetFlange.host` 是基材的第幾段直線（長在別的凸緣上的是 -1，平板為基材也是 -1）。用凸緣的邊的中點判斷：在某一段直線的範圍內、離路徑 0 到板厚、在板寬之內。
3. **每一段直線有自己的運動（折疊 → 平板條）**：路徑方向 → 條的長度方向，板寬方向 → 條的寬度方向，板厚方向 → 條的厚度方向；三個方向不是右手系時，把板翻過來（路徑那一面在上），平移到這一段在條裡的位置。凸緣原來的運算（先切掉、再接折彎展開與平直段）完全沿用：只是父節點的運動從「平板：不動」換成這一段的運動。
4. 平板的流程與折過的基材共用同一個「長凸緣」程序；平板型式視窗與 DXF 不用改。

## 驗證

`tests/phase7/bent-flange-flat.test.ts`（6 項）。基材是 L 形路徑 (0,0) → (60,0) → (60,40)、板寬 40、板厚 1.5、半徑 2、K 0.5；凸緣在第二段末端（跨板寬的邊）、90°、長度 20（平直段 20 − 3.5 = 16.5，基材被切掉 3.5）：
- 平板條長度 = 基材的展開長度 − 3.5 + 折彎展開長 4.3197 + 16.5，寬 40，面積 = 長 × 40，兩條折彎線，展開體積 = 折疊體積（K 0.5），一個有效實體；
- 同樣的數字用在四種擺法：板在路徑左邊、右邊、板寬反向、路徑反方向走；
- 凸緣的折彎線在條的 flatLength − 3.5 + BA/2 處，跨整個板寬 40；
- 長在第一段的長邊（沿路徑、在板寬末端）的凸緣：條在板寬方向變成 40 − 3.5 + BA + 16.5，長度仍是 flatLength。

## 限制

- 只對直線段上的邊；折彎本身的弧邊不能長凸緣（原來就是）。
- 折過的基材之後才切的孔（ADR 0113）仍然不進平板型式，列為「基材是折過的板」；斜接與閉合角落在折過的基材上沒有單獨驗證。
- 路徑自己交疊、板寬很小等極端情形沒有另外測。
