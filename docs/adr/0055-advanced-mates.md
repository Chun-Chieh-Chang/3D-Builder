# ADR 0055：進階結合——限制、寬度、相互對稱（Phase 4a-2，C15.9，組合件 Schema 6）

- 狀態：已實作並驗證（2026-10-03）。限制見最後一節。
- 相關：[phase4a-plan](../phase4a-plan.md)、[ADR 0012](0012-mate-solver.md)（結合求解器）、[ADR 0013](0013-mate-ui.md)（結合的介面）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **資料**（組合件 Schema 6，v5 → v6 不轉換）：`MateType` 多 `width`、`symmetric`；`Mate.more?: MateRef[]` 放額外的元素（寬度：[第二個寬度面（與 a 同一零組件）, 第二個薄片面（與 b 同一零組件）]；對稱：[對稱面]）；`Mate.min?`、`Mate.max?`（運算式）只給距離與角度結合，`value` 仍是起始值。指令檢查：元素個數、同一零組件的規則、`more`／限制只出現在該有的類型、限制是同類的數、最小 ≤ 最大、角度限制 ≤ 180°、起始值在限制內。`mateEnds(m)` 是「一個結合用到的所有元素」，刪除零組件與刪除確認都改用它 | 結合還是一個結合：額外的元素放在它自己身上，沒有第二種文件物件 |
| 2 | **求解器的結合改成 N 個端點**：`MateSpec.more`、`Live.ends`、`compileMate(spec, starts[])`、殘差 `(g[], p[], L)`；成對的舊結合包成兩個端點的形式，**程式碼不動**。分組把一個結合涉及的所有浮動零組件併成一組，導數區塊每個涉及的零組件一塊（同一零組件在寬度結合裡有兩個端點，只算一塊）。既有的求解器測試（52 項）全部照舊通過 | 最小的改動讓三、四個元素的結合進來，第三個零組件（對稱面屬於另一個零組件）也自然成立 |
| 3 | **相互對稱**：a、b 是同類的元素，b 是 a 在對稱面（`more[0]`，放置後的位置）的鏡像：兩個平面（法向照鏡像）、兩個點（含球心、圓心）、兩條線或軸；平面與點、對稱面不是平面都報原因 | SolidWorks 的相互對稱 |
| 4 | **寬度**：四個元素都是平面：薄片面與寬度面平行（兩條殘差，轉向不論正反）、兩個薄片面的中面與兩個寬度面的中面重合（沿第一個寬度面的法向一條）。留下三個自由度（沿面兩個方向平移、繞法向轉） | SolidWorks 的寬度結合；用中點而不是長度，薄片不需要和寬度一樣寬 |
| 5 | **限制**：距離與角度的殘差改成「超出範圍的量」（`v − clamp(v, 最小, 最大)`），範圍內是 0；角度用餘弦（與平面對線用正弦）比較，避免 `acos` 在 0 與 π 附近的奇異。**距離是線性的，所以剛好落在界線上；角度可能落在界線內側一點**（範圍內殘差是平的，求解器一進範圍就停）。自由度照「有效的方程式」算：範圍內距離結合不拘束距離（平面對平面 4 個自由度），在界線上拘束（3 個） | 限制不必是另一種求解：同樣的最小平方法，殘差換形 |
| 6 | **拖曳到限制外會停在限制上**：拖曳每一步都重解結合，超出的量被拉回（測試：目標高度 30、限制 5–15 → 停在 15） | 沿用 A3.5 的移動機制，沒有新程式 |
| 7 | **介面**：結合的屬性管理員多「進階結合」（寬度、相互對稱）：選了類型，面板列出各位置（寬度面 1／2、薄片面 1／2；元素 1／2、對稱面）並依序填，已選的再點一次就移除；寬度的第二個寬度面／薄片面必須在與第一個相同的零組件上、寬度面與薄片面在不同零組件上；齊了才有預覽，✓ 加入。距離與角度多「最小值」「最大值」欄位（空白是沒有限制）。浮出的樹與標籤沿用。所有新字串走 i18n（`packages/i18n/src/*/mates.ts`），`@3db/assembly` 因此依賴 `@3db/i18n`（分層表本來就允許） | 沿用既有的選取與預覽流程 |

## 驗證（證據）

- **求解器**（`packages/assembly/test/advanced.test.ts`，15 項，金樣的答案手算）：對稱——兩個平面（x = 30 的面 → x = −30、朝 −x，剩 3 個自由度）、對稱面在另一個零組件上（x = 5 → 2×5−30 = −20）、兩個點、兩條軸（剩 2 個自由度）、不成對時的 `unsupported`；寬度——薄片中面落在 x = 10、面平行、3 個自由度、隨槽零組件移動（+6 → 16）、只改中心不動面內的位置、不是平面時 `unsupported`；限制——5 到 15 之間：8 留著（4 個自由度）、20 拉到 15、1 推到 5（線性，剛好在界線上）、只有最大／只有最小、無限制時行為不變、拖曳停在 15、角度 45°–135°：100° 不動、30° 與 170° 回到範圍內、40° 與 140° 只進到範圍邊緣。
- **組合件層**（`tests/phase4/advanced-mates.test.ts`，13 項，金樣零件的真實面）：定位板的兩支削邊銷（銷 B 的軸是銷 A 的軸對定位板右基準面的鏡像，落在 x = +40、凸緣在同一個頂面）、V 型塊置中於定位板的兩側面（從 17、−23、40 mm 偏離，結果 x = 0、3 個自由度，隨板移動）、限制（V 型塊高度 0–10：4 留著、30 降到 10、−5 升到 0；值在限制外或最小大於最大時指令拒絕）、各項檢查的訊息、刪除零組件帶走用它當額外元素的結合、Schema 6 存檔往返相等。
- **舊檔**：組合件 v5 樣本（`v5-assembly.3dba`，由 Schema 6 程式寫出再改版本號，README 如實寫了）在 Schema 6 開啟，結合與爆炸步驟保留，沒有結合帶 `more`／`min`／`max`。
- **瀏覽器**（`tests/e2e/phase4-mates.js`，0 Console 錯誤）：用面板的按鈕與欄位建寬度結合（四個元素依序選，第四個之前沒有預覽，「結合成立」，V 型塊由 17 mm 偏離置中到 x = 0，結合以「寬度1」存入）、對稱結合選到同一零組件的兩個面時預覽說明不能解、距離結合加上最小 0、最大 10，V 型塊由 y = 45 降到 y = 25。
- `npm run check`：990 項通過。

## 限制與未做

- **寬度結合只接受四個平面**（SolidWorks 也接受其他形狀）；置中沿第一個寬度面的法向，兩個寬度面不平行時以第一個為準。
- **相互對稱只接受同類的兩個元素**，a 與 b 要在不同的零組件上（與其他結合相同）；對稱面可以是組合件的基準面、任一零組件的基準面或平面。
- **角度限制可能停在範圍邊緣的內側一點**（見決定 5），不保證是最近的界線；距離保證剛好在界線上。
- **限制只用於距離與角度**，沒有「限制鉸鍊」「限制滑軌」等機構結合（P2）。
- **沒有「結合建議」**：選兩個元素時面板仍只建議標準結合（`suggest.ts` 不變）；進階結合要自己按。
- 寬度與對稱的「對正」（反向）沒有介面：寬度不論正反、對稱用起始時較近的那一種。
