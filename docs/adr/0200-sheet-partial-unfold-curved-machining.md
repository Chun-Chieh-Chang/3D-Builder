# ADR 0200：部分展開、跨彎曲帶加工與角落映射

2026-10-25。依使用者「先補1、2的延伸缺口」續作 ADR 0199。零件 Schema84，組合件7、圖紙30不變。

## 行為與資料

新增「鈑金 → 部分展開」。屬性面板列出先前未抑制的中間折彎、凸折、凸緣與摺邊，可勾選要展開的特徵；凸折兩道彎作為一組。「全部折彎」與原「展開加工」保留完整展開。未選的彎保持折疊；確認後以原有除料工具加工，再按「摺回」。展開後重疊、失去連接或加工未展開的彎曲區會明確出錯。

`sheetUnfold.bends?: Id[]` 缺省代表全部，非缺省必須非空、不重複且指向先前合法折彎。`setSheetUnfold` 驗證與復原原子化。Schema83→84無損遷移；資料內只存選擇，原生材料映射依模型重建。DAG沿用全部先前本體操作依賴，已涵蓋選定來源；refs無新增幾何參照欄位。抑制或刪除來源後不能靜默改選其他折彎。

每塊平直材料保存各折彎的逆剛體運動；後續折彎移動它時以共軛更新。每塊圓柱彎曲材料另保存製造座標中的原始平片、目前原生曲面、圓柱框架及先前折彎運動。按反建構順序只撤銷所選折彎；未選圓柱區維持原生實體。部分展開中的平板型式仍是完整製造輪廓，包含當前待摺回的可映射加工。

## 非線性材料映射

`Kernel.bendSheetMaterial` 接受沿板厚方向等截面的材料片段。製造座標的跨彎距離 u 映射為角度 u/Rn；厚度位置 d 映射為 r0±d。原始平面邊線經原生2D曲線轉換建立兩層解析圓柱面，再用原生直紋側壁、縫合與修復建立B-rep實體；沒有用顯示網格代替製造幾何。3D邊線依既有原生容差建立，不宣稱任意曲線的無誤差表示。

角域以實際修剪UV曲線的原生極限檢查，不能只看圓上一個頂點。驗證有限數值、正交單位框架、半徑、角度、厚度、等截面、封閉縫合、實體有效性及體積。斜向、變截面或超域材料拒絕。K不等於0.5時，平板體積與彎曲體積的比值為平均半徑/Rn；以此解析Jacobian驗收，不能強迫兩者體積相同。

摺回先以每個加工前片段與移除材料求交。平片逆剛體映射，選定彎曲帶非線性映射，未選彎曲帶除料拒絕。原折疊本體扣除映射工具，核對全部平板除料都被分配，以及實際折疊除料體積等於映射工具體積和。平片與彎曲帶的剩餘材料都更新，故再次展開保留孔槽；原生展平工程圖可取得跨彎孔的圓與尺寸事實。

## 角落與邊界

封閉基材的斜接／封閉角落現在保留映射，不再整體拒絕。保存修剪後的真實平片及彎曲材料，更新既有鄰接凸緣的斜接邊界；後續整體剛體搬移也更新角落世界框架。驗證完整、分別展開任一凸緣、角落後平片加工，以及先中間折彎再於平直區建立角落接合。

斜接彎曲帶的展平邊界仍沿用既有24段中性層近似，未升級為任意斜接端面的精確反參數化。平直片段則保留原生45°斜切邊，與舊路徑「中性輪廓等厚拉伸」不同：本驗收的兩直壁長36.5及26.5，板厚1.5，展平上表面比舊中性輪廓少 `(36.5+26.5)×1.5/2=47.25 mm²`，材料體積一致。測試分別核對解析上表面差與體積，未放寬門檻。不能因此宣稱斜接展平外形適用所有工廠補償規則。

仍限封閉基材、單一鈑金本體；開放折線基材保留原唯讀平板功能。每道新中間折彎需無孔槽完整矩形帶，不能穿越既有曲面或垂直凸緣。跨彎加工須在展開後以沿板厚等截面除料進行；任意在折疊曲面直接鑽孔的逆展開、斜孔、加料、成形、任意STEP轉鈑金與工廠補償表不在本次範圍。

## 驗證與失敗證據

新增 `sheet-curved-material` 7項與 `sheet-extended-unfold` 10項，各有通過紀錄；含200組種子參數配置、解析體積與原生分類探針、內環、非法／超域／斜向輸入、跨兩側彎曲邊界圓孔、矩形槽、K因子、凸折正反方向、180°摺邊、選前／後折彎、來源角度修改、完整製造預覽、存讀／復原／原子性、角落混用及原生圖紙事實。相關舊角落21項、其餘受影響路徑與help40分項通過；型別、三項lint與build通過。未跑完整套件。

兩個實際瀏覽器案例各有通過結果：選單／勾選面板／加工摺回與存讀；跨彎曲帶圓孔／重複展開摺回與存讀。截圖已檢視。第二項首輪誤把一般儲存當另存新檔，改正測試重開路徑後只重跑該失敗案例。原生角落面積比較首輪以舊中性層外形當真值失敗，按上述解析斜切關係及原生體積區分；無數值門檻或期限變更。證據在 `out/sheet-extensions/`、`out/sheet-extensions-retry/`，包含原失敗報告。

200組測試由唯一真實路徑 `wasmMemory.buffer.byteLength` 讀取Heap並斷言存在>0，另外確認再生資源的shape釋放責任；不把handles或Heap餘裕當作零洩漏證據。沿用 AGENTS §3.5 的原生布林限制與Worker 512MiB成長高水位回收。
