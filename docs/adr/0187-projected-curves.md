# ADR 0187：投影曲線 C8.2

2026-10-24，零件 Schema 77，76→77 無損升級。

草圖到草圖取兩個草圖沿各自法向延伸曲面的真正空間交線。延伸範圍由兩個線框的實際包圍盒與法向夾角推得；平行或不可合理計算的範圍拒絕。草圖到面使用 BRepProj_Projection，保留選定修剪面上全部分支，含圓柱前後兩支，沿方向直線雙向投影。

開閉路徑皆可；輸出 curve=true 的線本體，不作曲面縫織、厚面等操作的輸入。目前未接為掃出路徑，說明已明記。面選取可在面板編輯時點選／取消，直邊或既有基準可作方向。名稱與真正拓樸逐一對齊，依幾何位置排名，失效參照明確報錯。

5 個新實體測試皆有通過結果，其中 100 組解析空間直線交集與 100 組面投影；另測圓柱雙分支、模型深度變動、DAG、序列化與非法參照／平行／空交集。讀取真正 wasmMemory 並報告成長，不宣稱無洩漏。新增 UI 1/1 通過，help 40/40、型別／lint／build 通過。初輪測試誤讀 BodyInfo 的 topology 與 surface 欄位，修正取值後只重跑失敗項。
