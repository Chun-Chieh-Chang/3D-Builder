# ADR 0022：多本體（Phase 3a-3：本體、合併結果、組合、參考本體、隱藏）

- 狀態：已採用（2026-10-01）。使用者決定四個行為（見決策 3–6），都採建議值。
- 依據：藍圖 C7.1（本體資料夾、合併結果開關、參考本體）、C7.2（加入、減除、共同）、D4.6（隱藏/顯示本體）；[phase3-plan](../phase3-plan.md) 的 3a-3；[ADR 0002](0002-phase0-kernel-and-solvers.md)（命名文法）、[ADR 0005](0005-features-and-booleans.md)（布林後的命名）、[ADR 0018](0018-visibility-and-reference-repair.md)（顯示/隱藏）。
- **Schema 升為 10**：`PartDoc.bodies`（本體的名稱與參考旗標）、伸長／旋轉／輸入本體的 `merge`、新特徵 `combine`。v9 → v10 只補一個空的 `bodies`。

## 決策

| # | 決策 | 理由 |
|---|---|---|
| 1 | **本體是重算的衍生資料，身分是建立它的特徵的 id。** 重算的狀態從一個本體變成一串本體（`Bodies`，`packages/regen/src/bodies.ts`）；本體 `extrude1` 被後來的填料併進去時仍叫 `extrude1`（保留較早的 id）；除料切出來的碎塊叫 `<除料id>#2`、`#3`。文件只存使用者說過的話：`bodies: { [id]: { name?, reference? } }`，沒有選擇就沒有項目；刪除特徵時它的本體（id 為該特徵或 `<id>#k`）的項目與隱藏記錄一起刪 | 一值一處：本體從特徵推導，不另存一份；id 不依位置，所以重算後不變 |
| 2 | **面、邊、頂點的名稱不變，不加本體前綴。** 單本體零件的名稱、金樣、TNP 測試、舊檔的參考一律照舊；多本體時名稱仍全零件唯一（每個名稱含建立它的特徵 id），撞名由既有的 `#k` 與指紋處理。藍圖寫的「命名文法加本體限定」改為「不需要」：改了會讓所有舊檔的參考失效，換不到任何東西 | 向下相容；計畫的完成條件是金樣與 TNP 全綠 |
| 3 | **填料的「合併結果」**（`merge`，預設 true，只存 `false`）：與它接觸的本體都併進來（逐一融合；結果仍是一個實體才算接觸，面接觸也算），沒接觸任何本體就成為新本體（不報錯）；取消勾選一律是新本體。碰到兩個本體的橋會把兩者併成較早的那個 | 使用者決定：沒接觸時成為新本體。流程最順，也最容易做出多本體 |
| 4 | **除料作用在它碰到的所有本體**；本體沒變就原樣保留，整個被拿走就消失（警告列出名稱），一個都沒碰到是「沒有移除任何材料」，全部拿走是「移除了整個本體」（與單本體相同的訊息）。**切成分離的幾塊就每一塊各成一個本體**：最大的保留原 id，其餘依體積由大到小 `<除料>#2`、`#3`（體積相同依位置），規則固定、重算結果相同。碎塊的面名依「切完的整體」命名，所以被切開的面仍帶它的 `#k`（`nameFromFaces`），名稱與以前相同 | 使用者決定。名稱不變所以舊檔中參考 `…#1` 的圓角照常成立（測試 `tnp.test.ts` 不改） |
| 5 | **輸入的 STEP 有多個實體時，每個實體各成一個本體**（`<輸入id>`、`<輸入id>#2` …，依體積）；面仍以檔案順序命名 `imp1:f<k>`，所以名稱照舊。單一實體的檔案行為完全不變。輸入也有 `merge`。同一個檔案被兩個特徵輸入時，第二個用 `clone`（不共用形狀），否則兩個本體的面在合併視圖裡只算一次 | 使用者決定。以前多實體合成一個本體，無法分別隱藏或組合 |
| 6 | **參考本體**（`reference`）：不計入物質特性（質量、體積）、不輸出到零件的 STEP、之後不進零件表（3b）；圖面照常顯示，組合件中的零件仍含它（零組件看到的是全部本體）。使用者決定排除 | 夾治具的工件只是設計依據 |
| 7 | **「合併視圖」讓其餘程式碼不必知道有幾個本體。** `RebuildResult.body` 是所有本體接起來的視圖：面、邊、頂點依本體順序連續編號，名稱接在一起，形狀是複合體；只有一個本體時就是那個本體。圖面拾取、組合件的結合、持久名稱解析、指紋、STEP、物質特性的既有程式碼都不動。另有 `RebuildResult.bodies`（每個本體的 id、名稱、參考旗標、形狀與在視圖中的編號範圍）。需要「是哪個本體」的地方（草圖伸長到某個面、圓角、導角、刪除面、移動面）用 `Bodies.locate` 找出面或邊屬於哪個本體，再對那個本體做 | 改動範圍小：重算引擎與 Worker 改了，介面只加了本體資料夾與兩個面板 |
| 8 | **圓角、導角、刪除面、移動面可以跨本體選，每個本體各做各的。** 參考先在視圖中解析（遺失時列出整個模型最接近的候選），再依所屬本體分派；沒有被指到的本體原樣保留在原位。同名參考靠指紋分辨時仍發出「依幾何指紋找到」的警告（在視圖中判斷，不在單一本體裡） | 與單本體的錯誤訊息和警告一致 |
| 9 | **「組合」特徵**（`combine { op: 'add'｜'subtract'｜'common', main, tools }`，參考是 `kind: 'body'`、名稱是本體 id）：加入（融合，必須接成一個實體，否則報錯說哪個本體沒接上）、減除（主要本體減掉各工具，可能切成幾塊）、共同（只留共有的部分，沒有共同的部分報錯）；結果取代主要本體的位置、保留它的 id，工具被用掉；名稱依 ADR 0005「目標在前、工具在後」。父特徵由本體 id 推導（`extrude1` → 特徵 `extrude1`） | C7.2 |
| 10 | **顯示/隱藏**：沿用 `visibility`，鍵是 `body:<id>`。隱藏的本體由 Worker 分別做網格再接起來（`mergeMeshes`，面與邊的編號保持視圖中的編號），所以沒有三角形、點不到；全部顯示時仍直接做複合體的網格。隱藏本體要重算（草圖與基準面的顯示不用），所以 `onlyVisibilityChanged` 把本體的鍵除外 | D4.6 的本體部分 |
| 11 | **介面**：設計樹多「實體(n)」資料夾，每個本體一列（眼睛、雙擊重新命名、右鍵：隱藏/顯示、重新命名、設為/取消參考本體；參考本體標「（參考）」）；選取本體列時圖面高亮它的面。「特徵」分頁多「組合」（有兩個以上本體才可用）：屬性管理員選類型、主要本體（清單）與要組合的本體（核取方塊），也可以在圖面點選本體的面（第一個是主要本體，之後切換工具）。伸長、旋轉填料與輸入本體的屬性管理員有「合併結果」核取方塊 | 沿用選取方塊與遺失參考的機制 |

## 驗證

- **向下相容**：既有的全部測試除兩個寫死的 Schema 版本號外都沒改期望值（381 + 57 項，含金樣、TNP、舊檔、組合件）。v1–v9 的舊檔都能開（新增 v9 樣本 `v9-direct-edit.3dbx`，由 `4a9b09e` 的程式寫出）。
- **核心**（`packages/kernel/test/bodies.test.ts` 6 項）：本體計數（相接 1、分開 2）、切成幾塊（由大到小、各自的面來源、面數相加等於整體、順序固定）、共同、`join`／`clone`、不洩漏形狀。
- **零件層**（`tests/phase3/bodies.test.ts` 25 項）：分開的兩塊是兩個本體（體積、面編號、名稱唯一、複合體有效）；合併（重疊、面相接）、`merge` 關閉、橋併兩個本體；除料作用於碰到的本體、切成幾塊（`['e1','c1#2','e2']`、體積 1200／500／2000、重算順序相同）、全部拿走的警告；第二個本體上的圓角、草圖加填料、伸長到它的面、刪除面；上游尺寸改變後 0 遺失參考、0 警告；組合的加入、減除（含切成兩塊）、共同、多個工具、遺失的本體、沒接上的加入、父子關係與驗證；本體的名稱與參考、隱藏鍵、存檔重開、刪除特徵時一併清掉；多實體的 STEP；重算不洩漏形狀（含失敗的組合）。
- **Worker**（`apps/web/test/mergeMesh.test.ts`）：網格接起來後的三角形、面與邊的編號。
- **瀏覽器**（`tests/e2e/phase3-bodies.js`，4 項流程全過，0 Console 錯誤）：只用草圖工具與屬性管理員畫兩個分開的塊（8000、4000 mm³，實體(2)）；第三個與第一個重疊、取消「合併結果」成為第三個本體；「組合」加入（10000 = 8000 + 4000 − 2000，質量 14000）；隱藏第二個本體時它的面不在網格中、再顯示回來；重新命名與設為參考本體（質量扣掉它）。

## 已知限制與未做

- **隱藏本體的頂點仍可點選**（頂點點選只在三點基準面時開啟）。
- **特徵範圍（C7.4）、分割零件、本體相交、刪除本體、移動/複製本體（C7.3）是 P2**，沒有做；除料一律作用在所有碰到的本體。
- **參考本體不進零件表**要等 3b 的零件表；目前只影響質量與零件的 STEP。
- 沒有「保留要移除的本體」（減除後工具一律用掉）。
- 組合的「加入」要求本體相接成一個實體；分開的本體不能「加入」（SW 在這裡也是警告）。
- 本體的 id 以特徵 id 為準，特徵改名不影響；但**刪除建立本體的特徵後，組合中對它的參考會遺失**（報「找不到本體」）。
