# ADR 0178：草圖的移動／複製／旋轉／縮放圖元與線性、環狀草圖陣列

## 1. 背景

審查報告 `docs/ui-interaction-audit.md` §8 第 2 批（差距 #4，H）：草圖沒有 SolidWorks 的 Move／Copy／Rotate／Scale Entities（含「保持關係」）與草圖陣列，FreeCAD Sketcher 的 Translate／Rotate／Scale 也是基本編輯。使用者在裁決頁選「第 2 批先做」，並於 2026-10-20 確認計畫、關係規則與三個假設：副本數不含原圖元（最小 1，同 FreeCAD）；線性陣列只有一個方向；旋轉與縮放另有「複製」勾選。

本分支建在第 1 批（ADR 0176，`claude/zealous-elion-0bae8c`）之上，因為右鍵選單（`contextMenus.ts`）在那裡。

## 2. 決策

### 2.1 工具與操作

六個草圖工具（`ToolId`），與鏡射相同：**先選取圖元再啟動**（沒有選取時不啟動並說明）。從工具列或圖元右鍵「移動／複製 ▸」（另含鏡射圖元）啟動。

| 工具 | 點選（抓取照常） | 面板（輸入值＋「套用」） |
|---|---|---|
| 移動圖元、複製圖元 | 基準點 → 目標點 | ΔX、ΔY；保持關係 |
| 旋轉圖元 | 中心 → 起始方向一點 → 目標方向一點（逆時針為正） | 角度（先點中心）；保持關係；複製 |
| 縮放圖元 | 基準點 → 參考點 → 參考點的新位置（比例＝距離比） | 比例（先點基準點）；保持關係；複製 |
| 線性草圖陣列 | 基準點 → 第一個副本的位置（間距向量） | 間距 ΔX、ΔY、副本數；保持關係 |
| 環狀草圖陣列 | 點一下中心即套用 | 副本數、總角度（360＝整圈平均：副本數＋1 等分；其他＝副本數等分）；保持關係 |

游標移動時預覽變換後的圖元（每個副本都畫）。每次操作是一個復原步驟。

### 2.2 關係與尺寸的規則（`packages/sketch/src/ops.ts`）

「選取的閉包」＝選取的圖元＋其點。一個關係或尺寸：參考全在閉包內＝**內部**；同時參考閉包與閉包外＝**跨界**。

- **內部**一律保留，只有兩種改變（`carried`）：
  - 縮放：驅動的長度、X/Y 距離、半徑、直徑、弧長尺寸乘上比例（以完整精度寫入，不四捨五入，求解器才會把點放在矩陣給的位置）；尺寸是運算式時拒絕並說出是哪一個。角度不變；從動尺寸不改。
  - 旋轉：水平↔垂直、distanceX↔distanceY 在 90°／270° 互換，180° 保留，其他角度刪除（並告知刪了幾個）。
  - 尺寸文字位置跟著變換。
- **移動（就地）、保持關係開**：跨界的保留。被移動的點以拖曳目標（PlaneGCS 的暫時約束）拉到變換後的位置，其餘從畫面上的位置出發；跨界關係擋住時以關係為準（例：到原點的距離尺寸會把點留在尺寸允許處）。拖曳本身無解時（例：兩條選取的線各夾住一條被保持垂直的線的兩端，再轉 120°），改以不拉拖曳、從目標位置出發再解一次，仍由關係決定位置；兩次都無解才拒絕並說明（`sketch.xformBlocked`）。
- **移動（就地）、保持關係關**：跨界的刪除；與未選取圖元共用的點**拆開**——選取方取得新點（放在變換後），未選取方保留原點；只碰到被拆開的點的關係歸未選取方。明確選取的點屬於選取方，不拆（用它的曲線跟著動）。
- **複製與陣列**：每個副本有自己的點與曲線（原圖元跟隨模型時，副本是一般圖元）。保持關係開：內部關係與尺寸以新 id 複製到每個副本（依上面的規則）；關：只有幾何。跨界的與「固定」一律不複製。副本之間、副本與原圖元之間不連動（不同於鏡射的對稱關係）。
- **拒絕**（不默默修正，AGENTS.md §2.1）：選取含原點或草圖的軸；就地移動有「固定」關係的點、或跟隨模型的圖元（轉換實體引用、貫穿點；可改用複製）；ΔX/ΔY/中心不是有限數；移動距離 0；角度非有限或為 360° 整數倍；比例 ≤ 0、非有限或剛好 1；副本數不是 1–200 的整數；陣列間距 0；總角度 0、|角度| > 360 或非有限；旋轉、縮放用「套用」卻沒先點中心。面板欄位保留使用者打的原值（空白＝NaN），由運算說明為何不能用。

### 2.3 命令

`editSketch` 的 `SketchEdit` 新增 `place`（點座標、圓半徑、橢圓短半徑、文字大小與角度；欄位只能給有它的圖元，數值由既有 `sketchError` 檢查），`EntityRefs` 新增 `major` 與雲形線的 `points`（拆開共用點用），`constraints[].set` 可帶 `labelPosition`。這是命令，不是檔案格式：Schema 版本不變。控制器先試解（`SketchHost.trial` 新增可選的拖曳參數），再把求解結果（所有點與圓）寫入同一個命令，與拖曳放開時相同。

## 4. 已知限制

- 陣列副本與原圖元不連動（改原圖元不會更新副本）；SolidWorks 的草圖陣列會加尺寸維持間距。
- 線性陣列只有一個方向（使用者確認）。
- 沒有 SolidWorks 的「延展圖元」（Stretch Entities）。
- 預覽不畫點與文字，橢圓與雲形線以折線近似。
- 拖曳無解時的第二次求解是從目標位置出發的最近解，不保證是「最少移動」的解。
