# ADR 0120：離隙的形狀——長圓與撕裂（零件 Schema 49 → 50）

- 狀態：**已實作並驗證（2026-10-09）**。來源：handoff §8「Phase 7 鈑金的待辦 C」的「長圓與撕裂離隙」。

## 做法

1. `relief.shape?: 'rect' | 'obround' | 'tear'`（邊線凸緣與摺邊都有）。沒寫就是矩形，舊檔照舊；49 → 50 沒有要轉換的東西。
2. **長圓**：缺口俯視是一條槽，閉口端是半圓。`width` 是槽寬（半圓直徑），`depth` 照舊是「比折彎起點再深」多少（槽底到邊的距離 = 修剪量 + depth），所以 **depth 必須不小於 width 的一半**，否則特徵出錯並說明（`flange.reliefObround`）。刀具是在板平面上畫的輪廓（兩條直線加一段半圓弧）沿板厚擠出；面積 = 寬 × (深 − 半徑) + π·半徑² / 2，體積檢查用這個值。
3. **撕裂**：板上做一條很窄的細縫，位置在凸緣邊界上，深度同上。實體不能零寬，所以寬度固定 `TEAR_RELIEF_WIDTH` = 0.05 mm，`width` 欄不用（面板也不顯示）。這是對「撕裂」的近似：真正的撕裂是零寬切開，這裡是 0.05 mm 的切縫，體積少 0.05 × 深度 × 板厚。
4. 平板型式用同一個輪廓（`packages/regen/src/relief.ts` 的 `obroundRegion` 兩邊共用），輪廓裡有半圓弧，DXF 照 ARC 寫。可製造性檢查「缺離隙」只看有沒有離隙，與形狀無關。
5. 介面：凸緣與摺邊的屬性管理員多一個「離隙形狀」選單。

## 驗證

`tests/phase7/relief.test.ts`（長圓：體積差、單一有效實體、平板型式面積差與半圓弧；撕裂：0.05 mm 細縫；放不下的長圓；矩形指名與不指名一樣）；`phase7-relief-ui.js` 在介面選三種形狀、核對體積。

## 沒做

零寬的真撕裂（要改成「切開不去除材料」的核心操作）；離隙的長度與位置獨立於凸緣（現在固定在縮短處）；斷開角落。
