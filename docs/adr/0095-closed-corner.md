# ADR 0095：封閉角落（鞏固 H-6，C11.4，零件 Schema 42）

- 狀態：已實作並驗證（2026-10-04）。**只做垂直於邊的相鄰凸緣**（如兩條相鄰邊上的 90° 凸緣），見限制。
- 相關：[ADR 0087](0087-insets-reliefs.md)（縮短與離隙：之前相鄰邊的凸緣在角落要手動縮短）、[ADR 0091](0091-acceptance-7.md)（驗收找到的「相鄰邊的凸緣要手動縮短」）。

## 問題

兩條相鄰邊上的凸緣，折彎區會在角落重疊，所以第二個要縮短（`inset`）讓折彎躲開；但縮短之後角落還有一個縫：第二個凸緣的平直段停在折彎的末端，離第一個凸緣的內側還有「半徑 + 縮短」那麼遠。真實的鈑金件角落由兩個凸緣的**平直段**合起來（折彎處留離隙），平直段在折彎之後繼續長到離鄰接凸緣只剩一個很小的間隙。

## 決定

`EdgeFlangeFeature.corner?: { start?, end? }`（零件 Schema 42，運算式，≥ 0）：在凸緣的起端／末端（同 `inset` 的稱呼）**把折彎之後的平直段繼續往鄰接凸緣長，停在離它的內側剛好這個間隙的地方**；**折彎本身不變**（仍躲開鄰接凸緣的折彎，由 `inset` 決定）。空白＝不閉合，和以前一樣，既有的檔案不變。

- **鄰接凸緣怎麼找**：在已經做好的凸緣裡，找面（平直段的兩個面之一）的法向平行於這條邊（|u·n| ≥ 0.99，u 是這一端往外的方向）、而且蓋住這個凸緣平直段**中間**一點的那個；取這一端往外離這個面最近的距離 d，延伸量 = d − 間隙。**找不到面向這一端的凸緣**說「旁邊沒有可以接上的凸緣」；**有面向這一端的，但沒蓋住中間**（比它矮、或錯開）說「沒有蓋住這個凸緣平直段的中間」；**間隙比 d 大**說「離鄰接凸緣的內側只有 …，比要留的間隙小」。
- **幾何**：折彎還是原來寬度的折彎（`bendTool` 的範圍是 `[xa, xb]`），平直段（`flangeTool`）的範圍是 `[xa − 延伸, xb + 延伸]`；體積檢查的預期加上延伸的那一塊（T × 延伸 × 平直段）。
- **登記與平板型式**：`SheetFlange.corner = [起端的延伸, 末端的延伸]`、`fold.pa/pb`（平直段的範圍）；之後在這片平直段上長的凸緣用 `pa/pb` 找父片；平板型式把「折彎」與「平直段」分兩段接上（折彎的寬度是凸緣的寬度，平直段較寬），所以平板型式在角落有階梯狀的形狀（折彎區窄、平直段寬），和真實的下料一樣。
- **介面**：邊線凸緣的 PropertyManager 多「起端／末端閉合角落：與鄰接凸緣的間隙（空白＝不閉合）」兩欄與說明。

## 驗證（證據）

- `tests/phase7/closed-corner.test.ts`（6 項；板 100 × 60 × 1.5、半徑 2；第一個凸緣在 x = 100，全寬，內側在 x = 98.5；第二個在 y = 60，邊剩 96.5 長，縮短 0.5 讓折彎停在 x = 96）：間隙 0.5：d = 98.5 − 96 = 2.5，**延伸 2.0，平直段到 x = 98**，比不閉合多 **2.0 × (30 − 3.5) × 1.5 = 79.5 mm³**；總體積對手算；一個有效的實體；x = 98 處有一個法向 +x、面積 1.5 × 26.5 的面（平直段的端）；登記延伸 [2, 0]、折彎寬度仍是 96。間隙 0.2：延伸 2.3。平板型式：面積多 2.0 × 26.5 = 53 mm²，大小不變（寬 = 100 − 3.5 + BA + 36.5、高 = 60 − 3.5 + BA + 26.5），K 0.5 平板的體積 = 摺疊的體積。錯誤：末端沒有鄰接凸緣、間隙 3（說「2.500」）、第一個凸緣做閉合角落（旁邊還沒有凸緣）；板長改 140 全部跟著。
- `tests/phase8/fuzz-sheet.test.ts`（24 個隨機的角落）：任意板厚、半徑、凸緣高度、縮短、間隙：延伸 = 半徑 + 縮短 − 間隙（手算）、體積對手算公式、平板型式的體積守恆與大小；第二個凸緣的平直段比第一個凸緣高時，說「沒有蓋住中間」（隨機測試找到：原本訊息說「旁邊沒有凸緣」是錯的）；間隙超過距離時被拒。
- `tests/e2e/phase7-corner-ui.js`：在介面點邊、長度 30、起端縮短 0.5、起端閉合角落 0.5：✔ 後做成；清空這一欄體積少 79.5；間隙 3 被說「2.500」。
- `npm run check`：1766 項通過、21 項略過。

## 限制與未做

- **只做垂直於邊的鄰接凸緣**（|u·n| ≥ 0.99）：斜的鄰接凸緣（45°、135°）、斜接（兩個凸緣在角落以 45° 斜面對接）、重疊（一個蓋過另一個）沒有做。
- **一個凸緣要等鄰接凸緣先做**；兩個都要閉合角落時，只有後做的那個能閉合（先做的找不到鄰接凸緣）。
- **只延伸平直段**：折彎區的離隙（缺口的形狀與大小）仍由 `inset` 與 `relief` 手填，沒有自動算。SW 的「封閉角落」還會自動調整離隙；這裡不會。
- **沒有斷開角落**（把凸緣的角倒圓／倒角）、沒有 SW 的對接、重疊、底下重疊三種型式的選項。
