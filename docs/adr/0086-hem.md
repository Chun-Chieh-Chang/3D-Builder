# ADR 0086：摺邊（Phase 7-3，C11.2，零件 Schema 38）

- 狀態：已實作並驗證（2026-10-04）。**凸折（jog）沒有做**，原因與替代見下。
- 相關：[phase7-plan](../phase7-plan.md)、[ADR 0085](0085-edge-flange.md)（邊線凸緣；摺邊用同一套折彎與凸緣的做法）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **特徵 `hem`**（零件 Schema 38）：`edge`、`length`（折彎之後回折的平直段）、`gap`（兩層內側面之間的距離，折彎的內側半徑是它的一半）、`position`（`materialInside` 預設、`bendOutside`）、`flip`。指令 `setHem`。**沒有「閉合／開口」的種類：閉合摺邊就是很小的間隙**（半徑為零的折彎沒有形狀可做，真的零間隙的兩層會在面上相貼）；`gap`、`length` 要大於 0 | 一個參數涵蓋兩種；老實說閉合是近似 |
| 2 | **與邊線凸緣共用 `foldEdge`**：認邊（板的面後面隔一個板厚有平行的面）、折彎（端面斷面的旋轉）、平直段（沿切線拉伸）、切掉板的一段、每一步的體積檢查、登記折彎資料；邊線凸緣與摺邊各自只決定「轉多少、內側半徑、平直段多長、切掉多少、訊息怎麼說」（`plan`）。摺邊是 θ = 180°、內側半徑 = gap/2、平直段 = length、材料在內時切掉 r + T（折彎的外側半徑） | 兩個特徵 95% 相同；7-2 的測試不改全過 |
| 3 | **180° 的幾何**：折彎旋轉 π，轉完的斷面在原來的斷面上方 `gap + 2·…`；平直段沿 −o 拉伸，蓋在板上，與板的距離正好是 `gap`（兩層內側面）；材料在內時，折彎的最外點正好在邊上 | 體積 π·T·w·(r + T/2)，位置對手算 |
| 4 | **登記**：折彎角度 π、內側半徑 gap/2、裕度 π(r + K·T)；`sheet.flanges` 一筆（trim = r + T、平直段 = length） | 平板型式（7-5）用 |
| 5 | **介面**：「鈑金」頁的「摺邊」；PropertyManager：邊線（在圖面點，編輯時顯示摺邊之前的模型）、回折的長度、兩層的間隙、凸緣的位置、往另一面折 | 同邊線凸緣 |

## 凸折（jog）沒有做

凸折是在**板的中間**一條線上，把一邊的板移開一段高度、用兩個相反的折彎接起來。特徵原生要做到這個，得把已經存在的實體沿那條線切開、把一半平移（旋轉）、再補上兩個折彎——需要一個新的核心操作（切開並移動一半的實體，同時維持折彎資料），不是 7-3 這個大小的事。**替代**：在板的**邊**上做的凸折（階梯）可以用兩個邊線凸緣組成——第一個往上折一段，第二個做在它的末端、往反方向折（測試 `the joggle`：一個實體、體積對手算、兩個折彎）。列為使用者的決定項（要不要為板中間的凸折加上切開並移動的核心操作）。

## 驗證（證據）

- **特徵**（`tests/phase7/hem.test.ts`，8 項；板 100 × 50 × 1.5）：
  - 間隙 1（內側半徑 0.5）、折回 10、材料在內：**板切掉 r + T = 2、折彎 π·T·w·(r + T/2) = 294.52、平直段 1.5·50·10 → 8394.52 mm³**、一個有效的實體；x 最大 100（外側切齊）、z 最大 1.5 + 1 + 1.5 = 4；平直段末端面的中心在 x = 98 − 10 = 88、面積 1.5·50；平直段內面在 z = 1.5 + 1（與板隔 1）、面積 50·10；名字不重複。
  - 登記：折彎 180°、半徑 0.5、裕度 π(0.5 + 0.75) = 3.927；凸緣 trim 2、平直段 10。
  - 折彎在外：8544.52，折彎最外到 x = 102；往下折（flip）：體積相同、z 最小 −2.5；間隙 4（半徑 2）：切掉 3.5、折彎 π·T·w·(2 + T/2)、z 最大 1.5 + 4 + 1.5。
  - **凸緣末端的摺邊**（回折的唇）：9548.98 − 150 + 294.52 + 600 = 10293.5，一個有效的實體，兩個折彎（90° 與 180°）。
  - 摺邊的平直段穿進對面的凸緣：說「撞到板的其他部分」，不會做出錯的實體。
  - **凸折組合**（兩個邊線凸緣，往上 10 再在末端往外 20）：一個有效的實體，體積 = 第一個 − 切掉 + 折彎 + 平直段，兩個折彎。
  - `setHem` 改間隙與長度、體積對手算；間隙或長度為 0 在輸入時被拒；`setHem` 拒絕面、拒絕別種特徵；沒有基材凸緣報錯。
  - 7-2 的 13 項邊線凸緣測試在重構（`foldEdge`）後不改全過。
- **瀏覽器**（`tests/e2e/phase7-hem-ui.js`，全部通過）：開啟一片板、「鈑金」→「摺邊」、點邊、間隙 1、長度 10、✔ 後體積 8394.52、設計樹有摺邊、訊息說折彎裕度 3.927；重新開啟、位置改折彎在外：8544.52。
- `npm run check`：1448 項通過、21 項略過。

## 限制與未做

- **沒有凸折（jog）**（上）、沒有淚滴形與捲邊（rolled）摺邊、沒有開口摺邊的角度（折回的平直段與板平行）。
- **閉合摺邊是很小的間隙**，不是零；平板型式的折彎裕度用 π(gap/2 + K·T)，SW 的閉合摺邊用的是自己的規則（不知道），與 SW 的平板長度可能差一點。
- **摺邊的長度是折彎之後的平直段**（不是 SW 的從某個虛擬交點量）；摺邊整條邊的寬度（沒有偏移起訖）；只限直邊。
- 與邊線凸緣相同：併面改名使重排特徵後邊線參考可能遺失；編輯時看不到結果與錯誤。
