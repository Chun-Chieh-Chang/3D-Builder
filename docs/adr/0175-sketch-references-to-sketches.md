# ADR 0175：草圖參照較前面的草圖（G6）

## 1. 背景
2026-10-19 草圖參照盤點的 G6，第二批的第一項，2026-10-20 由使用者選定。

**現況**：草圖的圖元只能跟著模型元素走：邊、頂點（ADR 0171）、基準（ADR 0172）、貫穿點（ADR 0173）。**另一張草圖的點與線完全參照不到**。

**別的軟體**：
- SolidWorks 可以直接對另一張草圖的圖元加關係（例如重合、貫穿），轉換實體引用也能選其他草圖的線；
- FreeCAD 的外部幾何可以選同一個 Body 內其他草圖的邊，Carbon Copy 可以整張複製。

**用途**：
- 夾治具常見「前一張草圖的輪廓決定後一張」，例如定位孔位置沿用底板草圖；
- 掃出的輪廓要貫穿另一張草圖畫的路徑。

## 2. 決策（使用者已定：FreeCAD 式看得見的參照圖元；只能參照較前面的草圖）
1. **`Ref.kind` 新增 `'sketch'`**，`name` 寫成 `<草圖 id>:<圖元 id>`，Schema 72。
   - 草圖的點：`ref` 可以是 sketch 種類（另一張草圖的點），位置是它沿本草圖法向投影的位置。
   - 草圖的直線、圓、圓弧：`ref` 可以是 sketch 種類（另一張草圖的同類圖元），以投影跟著走，一律為建構線。
   - 點的 `pierce` 也可以是 sketch 種類：另一張草圖的直線、圓、圓弧穿過本草圖平面的位置，有多個時取最接近儲存位置的那個（沿用 ADR 0173 的規則）。
2. **能投影的範圍**：
   - 點、直線：任何方向都可以；
   - 圓、圓弧：只有在兩個平面平行時；
   - 傾斜的圓、橢圓、雲形線、文字：**明確拒絕**，不做近似投影，與 ADR 0136 對傾斜圓的處理一致。
3. **只能參照較前面的草圖**：
   - 指令層檢查被參照的草圖在本草圖之前、圖元存在、種類相符；
   - 重建依序進行，所以 engine 只看得到前面的草圖；
   - 調整特徵順序後若被參照的草圖變成在後面，重建時回報遺失參考，不會形成循環。
4. **DAG**：草圖的父項含被參照的草圖 id。
5. **介面**：
   - 開著轉換實體引用工具時，在設計樹點一張較前面的草圖，就把它能投影的點、直線、圓、圓弧整批轉進來，類似 SolidWorks 對整張草圖做轉換實體引用。
   - 畫圖與選取時的吸附，加入**顯示中的**較前面草圖的圖元（被特徵用掉的草圖預設是隱藏的，與 SolidWorks 相同）。點下去就產生跟著該圖元走的建構圖元，或點。

## 3. 設計
- `references.ts`：`ReferenceScope` 新增 `sketches(id) → { frame, geometry }`；新增 `sketchItem(scope, ref)`，把另一張草圖的解在 3D 中投影到本平面，算出點、`Projected` 或貫穿點；`followReferences`、`convertEdges` 和吸附都走同一個函式。
- engine 提供前面已重建的草圖；worker 由 `lastResult.sketches` 提供。
- 指令：`sketchDatums` 擴充為 `sketchRefs`，同時檢查基準與草圖參照。

**反向對照**（皆已還原）：
- 拿掉跟隨 → 1 項轉紅；
- 不互換圓弧起訖 → 1 項轉紅；
- 拿掉指令檢查 → 1 項轉紅。

**拿掉 DAG 的 sketch 分支時測試仍然是綠的**：`ownerFeatures` 把 `s1:ap1` 當面名解析，剛好取到 `s1`。結果正確，但正確只是巧合，所以保留明確的分支，不依賴面名格式。

**測試第一版的錯，都在測試這邊**：
- s1 的圓弧把三點全部固定，草圖過多定義；
- 誤以為偏移平面的「反轉方向」會翻轉法向（它只改變偏移的方向）；
- 用 `toEqual` 比較時，−0 與 +0 被視為不同。

## 5. 已知限制
- 傾斜的圓與圓弧、橢圓、雲形線、文字不能參照（§2.2）。
- 只參照同一個零件中的草圖，不能跨零件或跨組合件。
