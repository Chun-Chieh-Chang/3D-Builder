# ADR 0177：工程圖尺寸類型與右鍵選單

## 1. 背景

2026-10-20 使用者回報：「在工程圖上標註尺寸的功能不完整，只能標註直徑。而且每次都要到『註記』點選標註功能太麻煩，應該在滑鼠右鍵選單中點選。」

**實測（定位板，於真實 App 以 pointer 事件重現）**：

- 模型與繪製層早已支援線性（水平／垂直／對齊）、半徑、直徑、角度、座標尺寸（`packages/drawing/src/dimension.ts`）；兩條線、兩個頂點都能標出 120。
- **單選一條直線後點空白處，只得到「再點選第二個元素」**：`featureAt` 以面積優先，把線判為「側視的平面」（`plane`），而 `planDimension` 對單一 `plane`／`slant` 回傳 `need: 'second'`；只有 `edge` 單選才給線長，但模型邊幾乎總被平面蓋過。結果是**只有圓一點就能成立**——這就是「只能標直徑」的原因。
- 右鍵選單（ADR 0140／0141）已存在，但沒有任何尺寸或註記指令，也不區分點到的是邊、頂點還是圓弧。

## 2. 決策

1. **單選直線＝線長**（SolidWorks 智慧型尺寸的行為）。`featureAt` 選到側視平面或斜面時，把指標下、落在同一條線上的模型直線邊一併帶上（`LinePick.along`）；`planDimension` 單選時以該邊的兩端頂點標線長。邊看成一個點（沿視線方向）時不帶。
2. **尺寸類型可指定**：`DimensionMode = smart | horizontal | vertical | aligned | radius | diameter | angle`。`planDimension(picks, p, placed, axes, mode)`：
   - 指定的類型做不出來時**明確拒絕並說明原因**，不偷偷改成別的類型（AGENTS §2.1-1）：圓配水平→「請用直徑或半徑」；線配半徑→「只能標在圓、圓弧或圓柱」；圓角配直徑→「只能標半徑」；平行線配角度→「要兩條不平行的直線」；方向不符→「無法標成〇〇尺寸」；不存在的類型、非有限的指標位置→拒絕。
   - 對齊尺寸遇到「兩條平行於 x 或 y 的線」時，與跨越它們的距離是同一個量，接受。
   - 半徑／直徑模式不收第二個元素，下一下即放置。
3. **一份命令定義**：`actions.ts` 新增 `drw-dim-horizontal`、`drw-dim-vertical`、`drw-dim-aligned`、`drw-dim-angle`、`drw-dim-radius`、`drw-dim-diameter`，以 `parent: 'drw-dimension'` 掛在「智慧型尺寸」下；`DIMENSION_ACTION` 對照類型與命令、`startDimension(mode, seed)` 啟動工具。工具列、下拉、右鍵選單都讀這一份（名稱、可否執行、動作）。
4. **工具列下拉**：`CommandBar` 對有子命令的按鈕畫成「主按鈕＋▾」；下拉內容展開在面板裡（面板會捲動，浮出式選單會被裁掉）。
5. **右鍵選單依點到的對象**（`DrawingMenuAt.view.element`）：
   - 線：智慧型、水平、垂直、對齊、角度；頂點：智慧型、水平、垂直、對齊；圓：直徑、半徑、智慧型、水平、垂直、對齊＋中心記號；圓弧：半徑、直徑…＋中心記號；圓角：半徑；側視圓柱輪廓：直徑、智慧型、水平、垂直（`dimensionModesFor`，純函式，單元測試逐一驗證每個提供的類型都做得出來）。選了之後工具以該元素為第一個選取啟動。
   - 視圖：原有項目＋剖面、細部、「尺寸」與「註記」子選單、屬性…、刪除。
   - 圖紙空白處：原有項目＋「尺寸」與「註記」子選單。
   - 有工具開著時，最上方為「結束目前的工具」。
   - 指在視圖外框線上（剛好在視圖方框邊界外一點點）也算該視圖（先前會落到圖紙選單）。
6. **工具保持類型**：放置一個尺寸後，工具維持同一類型（與 SolidWorks 相同），Esc 結束。

## 3. 一併修正的既有缺陷（由 Fuzz 測試發現）

`packages/regen/src/drawingEdges.ts`：邊的兩端頂點（`ends`）依拓樸順序列出，但點列依網格走向；兩者相反、且遠端頂點在圖上不是可點的角點時，`visibleElements` 以拓樸順序補上，**兩端成了同一個頂點**，線長標出 0。改為依點列首尾的投影位置排定兩端。測試：視圖中每一條直線邊，第一端的頂點在第一個點、第二端在最後一點（< 1e-6）。

## 5. 已知限制

- 等角視圖中不在圖紙平面上的邊，單選時量到的是投影長度（與既有規則相同，`drawing.dimNotEdgeOn` 只擋角度）。
- 半徑／直徑模式不支援「側視圓柱的半徑」（拒絕並說明）。
- 右鍵選單的「屬性…」只選取視圖並捲到屬性頁頂端，沒有另開對話框。
