# ADR 0230: 草圖樣條 G2/節點權重探針 (G17, D4)

- 日期：2026-11-02
- 狀態：探針報告（未進入正式實作）
- 相關：G17（plan.md）、D08（acceptance.md）、ADR 0195（草圖拘束擴充）

## 1. 探針目的

G17：Bézier G1 已有；一般樣條 G2／完整節點權重編輯沒有。先核實 PlaneGCS 與 OCCT 對同一曲線的表示，再定義控制柄、曲率梳與 G2。本探針評估可行性（plan.md P5：每項探針 2–4 日）。

## 2. 現有基礎

- 本專案 spline 實體為 B-spline（`SketchEntity` type 'spline'，含 points 陣列與 bezier 旗標）。
- PlaneGCS 求解器以點列表示樣條（控制點），並支援 G1 拘束（相切）。
- OCCT 提供 `Geom_BSplineCurve`，支援權重（NURBS）與節點向量。

## 3. 可行性分析

### 3.1 表示一致性

- PlaneGCS 與 OCCT 都以控制點 + 節點向量表示 B-spline，但：
  - PlaneGCS 的求解器只處理控制點位置，不處理權重（NURBS 權重需額外拘束）。
  - OCCT 支援 NURBS，但本專案 spline 實體無權重欄位（schema 未定義）。
- 結論：G2（曲率連續）需要曲率計算，OCCT 可提供（`GeomLProp_CLProps`），但 PlaneGCS 求解器不直接支援曲率拘束——需自行定義曲率相等拘束（複雜）。

### 3.2 G2 拘束

- G2 = 曲率連續（曲率大小與方向在接點相等）。
- 本專案已有 G1（相切，方向連續）。G2 需額外曲率大小相等。
- 實作需：在接點計算兩側曲率（OCCT），並加入拘束（曲率相等）。PlaneGCS 無內建曲率拘束，需自訂方程（solver 擴充）。

### 3.3 節點權重編輯

- 權重編輯需 NURBS 表示（控制點 + 權重 + 節點）。
- 本專案 spline 無權重欄位 → 需 schema 擴充（新增 `weights` 陣列）。
- OCCT 可渲染 NURBS，但 PlaneGCS 不求解權重 → 權重只能作為直接輸入（非驅動拘束）。

## 4. 建議方案

1. **短期（本輪不做）**：G1 已有；G2/權重列為候選。
2. **中期**：
   - G2：自訂曲率拘束（OCCT 計算曲率 + PlaneGCS 擴充），估計 10–15 工作日。
   - 權重：schema 擴充 + 直接輸入（非驅動），估計 4–6 工作日。
3. **長期**：完整 NURBS 編輯器（控制柄、曲率梳），估計 15–20 工作日。

## 5. 風險

- PlaneGCS 求解器擴充複雜度高（曲率方程非線性）。
- G2 拘束可能與 G1 冗餘或衝突，需 redundant 偵測。
- 曲率梳視覺化需 OCCT 曲率計算，效能考量。

## 6. 探針結論

- **G2 可行但複雜**：需 PlaneGCS 擴充 + OCCT 曲率計算，估計 10–15 工作日。
- **權重可行（直接輸入）**：schema 擴充 + 直接輸入，估計 4–6 工作日；驅動拘束需 solver 擴充。
- **建議**：先做權重直接輸入（低風險），G2 延後。

## 7. 驗收對應

- D08（acceptance.md）：探針報告已交付；G2 驗曲率連續（不只外觀相切）。
- G17：探針完成；建議先做權重直接輸入。
