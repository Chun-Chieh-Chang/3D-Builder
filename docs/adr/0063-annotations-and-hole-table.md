# ADR 0063：中心記號與中心線、孔標註、孔表（Phase 5-4a，C16.5、C16.6，工程圖 Schema 4）

- 狀態：已實作並驗證（2026-10-03）。限制見最後一節。5-4b（組合件當來源、零件表、號球）接著做。
- 相關：[phase5-plan](../phase5-plan.md)、[ADR 0062](0062-dimensions.md)（可標註的元素、元素資料）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | **註記由零件算出，不存**：中心記號、中心線、孔的標註文字、孔表的列都是從 Worker 找到的「視圖可標註的元素」（`ViewFeature`）算出，零件改了就跟著改。文件只存意圖：視圖的 `centreMarks`（開關，沒有就是開，剖面視圖除外）、直徑尺寸的 `callout`、孔表 `HoleTable`（所在視圖、可選的位置 `at`、各直徑的公差等級 `fits`） | 一值一處 |
| 2 | **孔的資訊**（`holeInfo`，`@3db/regen`，純函式，只看拓樸）：整圈的凹圓柱面才是孔；兩端各是一個同軸的整圓邊；**一端被圓盤（面積＝πr²）或圓錐封住是盲孔**，兩端都開是貫穿，兩端都封住不是孔；深度是圓柱的長度；**沉頭**＝開口端的平面是個環，環的另一個圓邊與孔同軸且較大，外側是同半徑的凹圓柱（它的深度）；**沉頭的壁本身不算孔**（它屬於下面那個孔）。`elementFacts` 的圓柱面帶 `hole` | 夾具與零件的孔不外乎貫穿、盲孔、沉頭 |
| 3 | **孔標註**：直徑尺寸的 `callout` 把模型說的接在直徑後面——`貫穿`、`深 12`、`沉頭 Ø15 深 8`（英文 `THRU`、`DEEP 12`、`C'BORE Ø15 DEEP 8`），在公差之後、括號之內：`4×Ø9 H11 (+0.09/0) 貫穿`。不用 ↧ ⌴ 符號（PDF 的標準字型沒有）。自動尺寸有「孔標註」選項（面板預設開，函式預設關，所以 5-3 的結果不變） | 文字用語言檔，五之五輸出時也不會缺字 |
| 4 | **中心記號與中心線**（`centreItems`）：整圈的圓畫十字，整個圓柱側看畫軸線（從端到端），都**超出 2 mm**（圖紙上）；每條線**從中間往外各畫一半**，讓鏈線的長線段剛好跨過中心；同一條軸線只畫一次；細部放大圖只留圓內的部分（`clipToCircle`）；剖面視圖預設沒有 | ISO 128 的中心線 |
| 5 | **孔表**（`holeRows`、`holeTableItems`）：視圖看成整圓的孔，**同樣的（直徑、貫穿或深度、沉頭）一組，由大到小給字母 A、B…**，同組由左上起編號 A1、A2…；X、Y 從視圖的**左側與下側的平面**量起（沒有就從模型原點，與自動尺寸相同）；尺寸欄是 `Ø9 H11 (+0.09/0) 貫穿`（等級由 `fits` 依直徑給）；標籤寫在孔的右上方；表在圖頁繪圖區的右上角，或使用者給的 `at`（左上角）。指令 `insertTables`、`setTable`（`at: null` 放回角落、`fits` 取代整個設定）、`deleteTables`；刪除視圖時表一起刪；ID 前綴 `tbl` | C16.6 |
| 6 | **Schema 4**：`tables`（3→4 的轉換是空清單）；`buildScene` 多一個 `features` 參數，回傳每個表的列（`tables`） | 前面的 Schema 向下相容 |
| 7 | **面板**：「註記與表格」（選到視圖時）：中心記號開關、加入孔表、每個表的「放回右上角」與刪除、每種孔徑的公差等級；「尺寸」的自動選項多一個孔標註，直徑尺寸多一個孔標註開關 | |

## 驗證（證據）

- **孔的資訊**（`tests/phase5/drawing-annotations.test.ts`）：40×30×20 的板上做三種孔——盲孔 Ø8 深 10、貫穿 Ø6、貫穿 Ø6 加沉頭 Ø12 深 4：四個凹圓柱面中三個是孔（`深 10`、貫穿深 20、貫穿深 16 加沉頭 Ø12 深 4），沉頭的壁（Ø12）不是孔；文字 `貫穿`、`深 10`、`貫穿 沉頭 Ø12 深 4`、`深 7.25`；三個孔的直徑標註 `Ø8 深 10`、`Ø6 貫穿`、`Ø6 貫穿 沉頭 Ø12 深 4`。
- **文件**：視圖的開關、callout 只屬於直徑（半徑與線性被拒）、孔表的插入與拒絕（不存在的視圖、不明種類、不支援的等級、位置無效）、移動與給等級與放回角落、刪除、刪視圖連動、ID 不重發、存檔重讀相同、版本 3 讀成沒有表。
- **金樣定位板**：上視圖六個整圈孔都是貫穿、深 15；四個 R10 圓弧不是孔；自動尺寸加孔標註為 `4×Ø9 貫穿`、`2×Ø8 貫穿`、`4×R10`；中心記號 24 條（六個孔各四個半線），Ø9 孔 (−50, 30) 的一條從 (150, 180) 到 (156.5, 180)，Ø8 孔的 6 mm；前視圖看到六個圓柱的軸，兩個 Ø9 孔在同一個 x 是一條線，共四條、八條半線；剖面視圖沒有中心記號、可以自己開、可以關；細部圖只有圓內的十字，長度是 r＋2 mm；孔表 A1–A4（Ø9）與 B1–B2（Ø8）、位置 (10, 70)、(110, 70)、(10, 10)、(110, 10) 與 (20, 40)、(100, 40)（從 x = −60、y = −40 量起）、尺寸 `Ø9 貫穿`、給 H11 後 `Ø9 H11 (+0.09/0) 貫穿`；表在右上角（右邊 402、上邊 279、7 列高 42）、標籤在孔的右上方、`at` 指定的左上角；表跟著模型（改成 150×100、孔 ±60 後 15、135 與 20、80）。
- **瀏覽器**（`tests/e2e/phase5-annotations.js`，0 Console 錯誤）：中心線 38 條（上視 24、前視 8、右視 6），關掉上視的再開；自動尺寸三個帶孔標註、關掉一個的標註再開；加入孔表（標籤 A1–A4、B1–B2、位置）、表與標籤畫在圖上；給 Ø9 公差等級 H11、不支援的等級被拒；復原重做；存檔重開後表與中心線都在；刪除表。
- `npm run check`：1162 項通過。

## 限制與未做

- **孔的螺紋、錐形沉孔（countersink）、鑽尖角度不看**：錐面的孔口被當作開口；螺紋孔要靠之後把孔特徵的資料帶進來（現在只看幾何，所以標準孔表的「M6 螺紋」還沒有）。
- **孔表的 X、Y 只有一種基準**（視圖左側與下側的平面）；沒有選別的原點、也沒有分組的合併列（每個孔一列）。
- **中心記號對隱藏的孔也畫**（例如從底面開的盲孔，從上方看孔是隱藏的）；沒有「只畫看得到的孔」的判斷。
- **圓弧（R10）沒有中心記號**；圓柱要整圈才有軸線；斜著的圓柱不畫。
- 孔表用等寬估計欄寬，中文字寬以全形計；文字很長時可能超出（欄寬是估的，不是量出來的）。
- 表只有孔表；零件表（BOM）與號球在 5-4b。
