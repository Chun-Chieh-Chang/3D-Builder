# ADR 0181：草圖附著，原點與 X 方向取自模型（G7）

## 1. 背景
2026-10-19 草圖參照盤點的 G7，第二批。2026-10-21 使用者選「做」，並裁決下面四點。

**現況**：草圖的座標系完全由平面決定（`planeFrame`）：原點是零件原點在平面上的垂足，X、Y 跟著預設基準面走。要讓草圖的原點在某個角、X 沿某條邊，只能另外建座標系特徵，再把草圖畫在座標系上；而座標系用兩個方向定義平面，不能直接說「平面就是這個面」。

**別的軟體**：
- SolidWorks 只能事後用「編輯草圖基準面」調整，沒有原點與方向的選擇；
- FreeCAD 的 Attachment 有完整的附著模式、偏移與角度。

**用途**：夾治具的定位草圖常要「以這個角為原點、沿這條邊為 X」，圖元的尺寸才跟著零件的基準走。

## 2. 決策（使用者已定）
1. **`SketchFeature` 新增選填的 `attach`**，Schema 73；沒有 `attach` 的舊檔行為完全不變：
   - `origin`：模型頂點或參考點，沿平面法向落到平面上，成為草圖的原點；
   - `x`：直線邊或參考軸，投影到平面上，成為 X 方向；
   - `flipX`：X 與 Y 一起繞法向轉 180°。
2. **平面不變**：`plane` 仍決定草圖所在的平面，`attach` 只改平面內的原點與方向。圖元的 2D 座標不變，整張草圖跟著新的座標系移動；跟著模型元素走的圖元（G2–G6）在新座標系中重新計算位置。
3. **翻轉只做 X 反向**（使用者選項）：X 與 Y 一起轉，法向不變。不做「法向反向」，因為伸長已有自己的「反向」，兩處都能翻會混淆。
4. **不做沿法向偏移與旋轉角度**（使用者選項）：偏移可以用「基準面」的偏移距離做到，角度可以用「X 方向取一條邊」達成；一件事只有一種做法。
5. **原點只取頂點與參考點**（使用者選項），不含前面草圖的點。
6. **介面放在草圖的屬性管理員**（使用者選項）：設計樹對草圖按右鍵「編輯草圖基準面」，面板多一區「草圖附著」。圖形區點頂點或參考點進原點欄，點直線邊或參考軸進 X 欄；設計樹點參考點或參考軸也一樣；每欄有 × 可以清除，核取方塊「X 反向」。
7. **明確拒絕，不做近似**：
   - X 方向垂直於平面（投影成一點）：回報原因；
   - 附著的頂點或邊遺失：草圖報錯，不退回預設座標；
   - 參照比草圖後面的參考點或參考軸：指令層拒絕。
8. **空的附著不存**：`{}` 被拒絕，要取消請傳 `null`；`flipX: false` 不寫入。

## 3. 設計
| 層級 | 檔案 | 改動 |
|---|---|---|
| 模型 | `schema.ts`、`serialize.ts`、`refs.ts`、`commands.ts` | `SketchAttach`、`SketchFeature.attach`；v73；`mapRefs` 處理附著的參照（遺失參考修復）；新命令 `setSketchAttach`；新增草圖時也檢查 |
| 再生 | `engine.ts`、`dag.ts` | `frame()` 套用 `attachedFrame`（唯一算出草圖座標系的地方，所有用到的人自動跟著改）；草圖的父項含附著的頂點、邊與基準 |
| 介面 | `datumSlots.ts`、`store.ts`、`Viewport.tsx`、`PropertyManager.tsx` | 草圖有兩個選取欄（原點：點，X：軸，都可空）；編輯基準面時畫面上點選與設計樹點選分流給附著；面板新增區塊 |
| 雙語／說明 | `model.ts`、`features.ts`、`pmpanels.ts`、`help.ts` | 訊息與面板文字；「草圖」說明補一段 |

`attachedFrame`：原點 `p − n·((p − o)·n)`；X 方向 `d − n(d·n)` 取單位向量（長度小於 `1e-9·|d|` 即拒絕）；`y = n × x`；`flipX` 時 x、y 同時取負。純向量運算，沒有布林運算，不涉及 OCCT 的 Heap。

**反向對照**（皆已還原）：
- 單元：引擎不套用附著，8 項轉紅；原點不投影，3 項轉紅；不拒絕垂直邊，2 項轉紅；DAG 忽略附著，2 項轉紅；`mapRefs` 忽略附著，1 項轉紅。
- 瀏覽器：引擎不套用附著，e2e 轉紅；編輯基準面時點選不分流給附著，e2e 轉紅。

**測試第一版的錯，都在測試這邊**：
- 在 `describe` 內直接呼叫 `model()`，核心還沒載入；
- 參考點的模式名稱寫成 `coordinates`（實際是 `coords`）。其中「參考點必須在草圖之前」那一項原本只寫 `toThrow()`，可能因為別的原因丟錯而假通過，已收緊成指定的訊息；
- e2e 在編輯基準面期間要求 `S.failed()` 為空，但被編輯的草圖當下是 `rolledBack`（設計如此，座標系仍會算出），改成只要求沒有 `error`。

## 5. 已知限制
- 只取一個原點與一個 X 方向，不做偏移與角度（§2.4）；
- 原點不取前面草圖的點、不取模型的邊與面；
- 改變草圖的平面（`redefineSketchPlane`）時附著保留：若 X 的邊在新平面上垂直，草圖報錯並說明原因，不會自動清除；
- 設計樹點參考點、參考軸（`store.treeClick` 分流）有接線，但瀏覽器腳本只走了圖形區的點選，這一條沒有自動驗證；
- 新增草圖時沒有介面一次選好附著，要在「編輯草圖基準面」中設定（與 SolidWorks 的流程相同）。
