# ADR 0083：鈑金的技術驗證（Phase 7-0，C11）

- 狀態：已驗證（2026-10-04）。**沒有改任何產品程式**；只有計畫與一個驗證測試。
- 相關：[phase7-plan](../phase7-plan.md)、藍圖風險表第 8 列（鈑金展開沒有現成演算法）、[ADR 0074](0074-plastic-validation.md)（Phase 6 的驗證，同一種做法）。

## 問題

藍圖說：沒有現成的演算法能展開任意鈑金實體，所以**特徵原生**：建立折彎時就記錄折彎資料，平板型式從資料算。這條路能不能走得通，取決於三件事：折彎與凸緣能不能用核心現有的工具做成**一個有效的實體**、體積是不是和手算一致、折彎資料算出來的平板長度和實體有沒有一個**獨立的**對照。

## 驗證（`tests/phase7/spike.test.ts`，10 項；T = 1.5、內側半徑 r = 2、K = 0.4；板 x 0..100、y 0..50）

| 項 | 做法 | 結果 |
|---|---|---|
| 折彎 | 旋轉一個矩形（在垂直於板的平面上、y 0..50、z 0..T），軸平行 y、在板上面 r 處 | **45°、90°、135°、180° 的體積都是 θ·T·w·(r + T/2)**（對手算到 1e-6）、有效；軸的正負方向**由外包盒找出來，不假設**（繞 +y 轉是往 −x 折回板上面、繞 −y 往 +x 長出去；兩個方向的 z 都升起來，所以不能用 z 判斷，要用 x） |
| 板 + 折彎 + 凸緣 | 板（拉伸）、90° 折彎、凸緣（拉伸，長 30）合併 | **一個有效的實體，體積 10073.98 mm³（手算 100·50·T + ½(π/2)((r+T)² − r²)·50 + T·50·30，差 < 1e-5）**；外包盒 x 到 103.5、z 到 33.5；兩個圓柱面，面積 50·(π/2)·r 與 50·(π/2)·(r + T) |
| 平板長度的獨立檢查 | 折彎資料給的平板長度 x0 + θ(r + K·T) + L | **K = 0.5 時折起來的體積 ÷ (T·w) = 134.3197 = 平板長度**（鈑金體積守恆）；K = 0.4 的平板長 134.0841，比 K = 0.5 短 (π/2)·0.1·T。**K 因子是材料與製程的經驗值，實體證明不了**：0.5 以外的 K 沒有獨立的檢查 |
| 折過的輪廓 | 一條 U 形槽（外寬 60、外高 20、長 40、下面兩個轉角內側半徑 2）的輪廓含 4 段弧，一次拉伸 | **一個有效的實體、4 個圓柱面，體積 5678.3 mm³ = T × 中心線長度（94.639）× 40**（中心線 2(20 − R) + (60 − 2R) + 2·(π/2)(r + T/2)，R = r + T） |
| 兩個凸緣在角落 | 方板 100 × 100，邊 x = 100 與 y = 100 各一個凸緣，長度等於邊長 | **一個有效的實體，體積是三者之和**（兩個凸緣只在一條線上接觸，沒有重疊）；縮短其中一個 0.5 留下缺口也是一個有效的實體，縮短的體積 = 缺口 × T·(θ(r + T/2) + 30) |

## 決定

1. **特徵原生**（計畫的「最重要的決定」）：折彎資料在建立時記錄；平板型式從資料算，不展開實體；不能展開匯入的 STEP。
2. **折彎 = 旋轉的矩形、凸緣 = 拉伸、平板 = 拉伸、折過的輪廓 = 一次拉伸**，以填料（`apply('boss')`）合併，面以「特徵:side:輪廓邊」命名，沿用 Phase 6 的做法；**折彎方向的正負由結果的外包盒決定**，不寫死。
3. **平板長度的獨立檢查是 K = 0.5 的體積守恆**，每個里程碑都放進測試；其他 K 的平板長度與公式一致，而不是與實體一致（計畫的風險 4）。
4. **角落**：兩個凸緣只在一條線上接觸的實體 OCCT 認為有效，但這不是一個能折出來的件；**預設在角落留缺口**（離隙，7-4），平板型式才有意義。

## 限制與沒驗證的

- **沒有驗證邊線凸緣在彎過的板、曲面或斜邊上**（7-2 要做，計畫風險 2）；**沒有驗證持久命名**（折彎與凸緣的面在改半徑、K 因子後名字穩不穩，7-1、7-2 的測試）。
- **沒有驗證 DXF 輸出**（7-6，預期沿用 Phase 5 的寫法）、**沒有驗證平板上各個面的二維位置追蹤**（7-5，這是最複雜的部分）。
- **凸緣長度與折彎位置的定義與 SW 是否相同不知道**（外側虛擬交點是 SW 的預設，我沒有 SW 可以確認）。
- 驗證用的是核心的 `extrude`／`revolve`／`boolean`，沒有用到文件與重算；產品程式的效能與失敗模式要到 7-1 才知道。
