## 升版與重建 SOP（之後增修時照做）

1. **何時升版**：建置來源提交與上一次建置不同（內容有變）就升版；只有重新打包同一個提交才可沿用版號。
   - 修補（修缺陷、小改）升第三碼，例如 0.2.3 → 0.2.4；新增功能群或檔案格式（Schema）不相容時升第二碼。
2. **改版號（三處，缺一不可）**：
   - `apps/desktop/src-tauri/tauri.conf.json` 的 `"version"`
   - `apps/desktop/src-tauri/Cargo.toml` 的 `version`
   - `apps/desktop/src-tauri/Cargo.lock` 中 `name = "desktop"` 那一項的 `version`（同檔其他 `0.2.x` 是無關的套件，例如 `num-conv`，不要改）
3. **建置**：`npm run build -w @3db/desktop`（會先 `npm run build -w @3db/web`）。
