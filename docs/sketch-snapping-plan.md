# 草圖吸附與推斷計畫（參照 SolidWorks；已規劃、尚未排入開發）

- 日期：2026-10-06。來源：使用者做手動驗證 C3（在板子頂面畫圓）時提出：「沒有像 SW 自動出現磁吸式座標的功能，沒有虛線連接附近的特徵點和游標」，並要求把它規劃進 handoff 或藍圖。
- **狀態**：使用者決定 C 章驗證走完再排優先序，現在不做。本文件是排進去時的依據。
- 對應藍圖目錄：C1.25（自動給定限制條件，P0，已做推斷水平／垂直／相切）、D5.3（草圖推斷與抓取，P0，已做吸附點／中點／線上）；新增 D5.3a、D5.3b、D5.3c（見 [藍圖](blueprint.md) 附錄 C）。既有規則見 [ADR 0004](adr/0004-sketch-editing.md) 的「推斷與吸附規則」。

## 1. 現況與缺口

現況是我在瀏覽器裡實際試出來的（游標靠近草圖點、線的中點、線上）：

| | 有 | 沒有 |
|---|---|---|
| 吸附目標 | 草圖自己的點（含原點）、線的中點、線／圓／圓弧上 | 圓心、象限點、交叉點、圓弧的相切／垂直點 |
| 畫面回饋 | 吸附的點上一個小圓點，游標旁一個提示字（重合、中點、在圖元上） | **虛線對齊線**（游標與附近特徵點水平或垂直對齊時，畫一條虛線連過去） |
| 推斷的關係 | 畫直線時 3° 內自動加水平／垂直；從圓弧端點出發 6° 內推斷相切 | 與**別的點**對齊的水平／垂直（只和自己的起點比） |
| 模型幾何 | 只有「轉換實體引用」（C7）能把模型的邊轉進草圖 | **游標靠近草圖面上模型的邊、角、孔圓心時不會吸附** |

程式的位置：吸附與推斷在 `packages/sketch/src/interact.ts`（`snap`、`inferDirection`），由 `apps/web/src/sketcher/controller.ts` 呼叫，畫面是 `apps/web/src/sketcher/overlay.ts`（小圓點與提示字）。模型邊與頂點進草圖靠「轉換實體引用」與圖元的 `ref`／`pierce` 欄位（零件 Schema 13 起）。

## 2. SolidWorks 的行為（要複製的目標；出處是 SW 2010 繁體中文說明，2026-10-06 讀過）

出處（說明站的內容要用瀏覽器才讀得到，連結網址是頁面本身）：[推斷](https://help.solidworks.com/2010/chinese/SolidWorks/sldworks/LegacyHelp/Sldworks/SW_Sketch/Inferencing.htm?id=25.4)、[草圖抓取](https://help.solidworks.com/2010/chinese/SolidWorks/sldworks/LegacyHelp/Sldworks/SW_Sketch/Sketch_Snaps.htm?id=25.8.0)、[快速抓取](https://help.solidworks.com/2010/chinese/SolidWorks/sldworks/LegacyHelp/Sldworks/SW_Sketch/Quick_Snaps.htm?id=25.8.1)。

**推斷（說明原文的重點）**
- 「推斷提示線是當您繪製草圖時出現的**點狀虛線**。當游標接近強調的提示（例如中點）時，推斷提示線會相對於現有的草圖圖元給您引導。」
- 「游標顯示」會指出游標在哪種幾何限制條件上（例如相交點）、啟用中的工具是直線或圓、以及尺寸（弧的角度與半徑）；「如果游標顯示一個例如水平放置的限制條件，則限制條件會自動加入圖元中。」
- 草圖抓取預設開啟（工具 → 選項 → 系統選項 → 限制條件／抓取 →「啟用抓取」）；清除它同時清除「自動給定限制條件」。
- 一次畫完圖元（按一下表示完成）之後才顯示限制條件的圖示；「檢視 → 草圖限制條件」可以顯示。

**草圖抓取（共 14 種，說明原文的表）**：終點及草圖點、中心點（圓、弧、圓角…）、中間點、四分之一點（圓、弧、橢圓…）、交點、最近點、相切（圓、弧、橢圓、不規則曲線）、垂直（直線抓到另一條直線）、平行（產生與直線平行的圖元）、**水平／垂直線**（抓到與現有水平線垂直、或與現有垂直線水平的直線）、**水平／垂直點**（直線垂直或水平抓到現有草圖點，**這就是使用者在 C3 說的「虛線連到附近特徵點」**）、長度（按住 Shift，抓到格網增量）、網格（預設唯一不啟用的）、角度（在選項裡設角度值）。

**快速抓取**：在任何草圖工具啟用時，用功能表（工具 → 限制條件 → 快速抓取）、右鍵選單或工具列，選一種抓取，其他抓取被過濾，只剩這一種；雙擊工具列的快速抓取可以保留到換另一種為止；不管「啟用抓取」有沒有勾都可以用。

**說明沒有寫、要用 SW 確認的**（S-0）：虛線的顏色；在面上畫草圖時游標經過**模型本身**的邊、頂點、孔，是否高亮與怎麼建立關係（說明的抓取表只寫「草圖圖元」，但實際使用上 SW 會抓到模型的邊與頂點；本文件把它當作要做的，D5.3b）；同時對齊兩個點時的畫面。
## 3. 做法（對應現有架構）

- **水平／垂直點、水平／垂直線（推斷虛線）**：在 `@3db/sketch/interact` 新增 `alignments(geometry, p, tol, exclude)`：回傳所有與游標水平或垂直對齊（螢幕距離在 5 像素內）的草圖點（端點、圓心、中點、原點、模型頂點）與對齊方向，以及與現有水平線垂直、與現有垂直線水平的候選；`ControllerView` 多一個 `guides`（虛線的兩端與方向）；`overlay.ts` 畫點狀虛線；點下去時，`commit` 在新點與目標點之間加 `horizontal`／`vertical` 關係（結構已有，`horizontal` 的 `a`、`b` 可以是兩個點）。
- **吸附到模型幾何**：store 提供「草圖面上看得到的模型幾何」：該面的外輪廓與孔的頂點、邊、圓心（由已有的 `faceFingerprints`、`vertexPoints`、`edgeFingerprints` 投影到草圖面）。游標靠近就高亮；按下去走現有「轉換實體引用」的機制，產生帶 `ref` 的點（或圓心）圖元並加重合，所以遺失參考的報告、重算後跟著走都沿用 4d 的做法，不另寫一套。
- **其餘草圖抓取**：`snap` 的優先序擴充成 SW 的 14 種（見第 2 節）：終點、中心點、中間點、四分之一點、交點、最近點、相切、垂直、平行、長度（Shift）；網格與角度最後。
- **快速抓取與開關**：草圖工具啟用時，右鍵選單與功能區可選一種快速抓取（只留那一種）；「系統選項」加「啟用抓取」（清除時一併關掉自動給定限制條件，與 SW 一致）與逐項勾選。

## 5. 風險與預設假設（沒有問過使用者，先這樣假設）

- 行為以 SW 2010 繁中說明為準（第 2 節）；說明沒寫的細節（顏色、模型幾何）以 S-0 使用者在 SW 的觀察為準。虛線顏色在那之前先用「細虛線、與草圖線不同的顏色」。
- 模型幾何吸附會讓候選點變多，要避免干擾已有的吸附優先序：草圖自己的點優先於模型的點（與 ADR 0004「草圖點優先」一致）。
- 工作量粗估：S-0 約 1 天、S-1 約 1 個階段、S-2 約 1 個階段、S-3 約 1 個階段、S-4 約 0.5 個階段。順序可以調；使用者的感受是 **S-2（板子上畫圓對得準）最有感**，其次 S-1（C3 提到的虛線）。
- 說明站的內容是動態載入的，用一般的下載讀不到，要用有瀏覽器的工具開頁面才讀得到；日後要再查，用第 2 節的網址。
