## 你在 SolidWorks 的人工核對（驗收 ②）

1. 在專案目錄執行 `npm install`（第一次），再執行 `npm run dev`，用 Edge 或 Chrome 開啟 http://localhost:5173 。
2. 上方切到「檔案」→「輸出 STEP」，會下載 `行走骨架示範件.step`。
3. 在 SolidWorks 開啟這個 STEP 檔。
4. 用「評估 → 物質特性」核對：
   - 體積應為 **991.416 mm³**（20×10×5 的方塊，一條長 10 的邊做 R2 圓角：1000 − (1 − π/4)·2²·10）。
   - 實體數量為 1，特徵樹中的名稱為「行走骨架示範件」。
5. 回到 3D-Builder，在設計樹雙擊「草圖1」，把寬度改成 30，按 ✔ 確定，再輸出一次 STEP。SW 中的體積應為 **1491.416 mm³**。
6. 把結果回報給我；若有差異，請附上 SW 顯示的數值。

## 操作說明（Phase 0 介面）

- 圖面操作：中鍵拖曳旋轉、Ctrl+中鍵拖曳平移、滾輪縮放（以游標為中心）、Alt+左鍵拖曳旋轉（觸控板用）。
- 快速鍵：F 全部顯示、Ctrl+1/4/5/7 前/右/上/等角視、Ctrl+Z 復原、Ctrl+Y 重做、Ctrl+B 重新計算。
- 設計樹：
  - 雙擊特徵：開啟 PropertyManager 編輯，✔（Enter）確定、✖（Esc）取消，整個編輯算一個復原步驟。
  - 右鍵：編輯特徵、抑制/恢復抑制、父子關係。
  - 拖曳藍色的回溯控制棒，可以回到歷史中的某一點。
- 圓角：編輯時會顯示圓角之前的模型。在圖面點選邊線可加入或移除，下方會顯示邊線的持久名稱。
