# 自動出圖改善計畫（依《工程圖標註與配置通則》）

- **依據**：`docs/design/drawing-rules-cns.md`（規則編號 P／V／D／C／L／Q 沿用該文件）
- **決定**：預設 CNS 3，ISO 為可切換的設定檔（2026-11-19）
- **基準**：`main` @ `db051b9a`，工作樹乾淨
- **方式**：分四期，每期各自一份 ADR、各自提交；每期的驗收標準全部達成才進下一期

## 第一期　標準設定檔與線型（CNS 預設）

**範圍**：P5、P6（字高預設）、P8（欄位檢查）、L3、L4、L5、Q3

**改什麼**

1. 圖紙加一個「標準」欄位：CNS 或 ISO。圖面結構版本 38 → 39。
2. 新建的工程圖（MCP 的 `drawing_create` 與網頁的新增工程圖）一律寫入 CNS。
3. **既有的工程圖沒有這個欄位時，視為 ISO**，因此打開舊檔，外觀與目前完全一樣。（假設，見下方「待確認」）
4. 線寬依標準與圖紙大小查表：
   - CNS：粗／中／細三級，例如 A0–A1 0.7／0.5／0.25、A2–A3 0.5／0.35／0.18、A4 0.5／0.35／0.18（以教材例子為準，CNS 3 原文到手後核對）。
   - ISO：維持現在的 0.5／0.25。
5. 隱藏線在 CNS 用中線；中心線線段改為 CNS 的長約 20、空約 1、一點。
6. 圖框邊距依標準：CNS 為 A0–A2 15 mm、A3–A4 10 mm、左邊 25 mm（裝訂）；ISO 照舊。
7. PDF、SVG、DXF（含圖層的線寬）、PNG 預覽都讀同一份設定。
8. 網頁的圖紙設定加入「標準」選項；說明文件（中英）與 `docs/help-links.json` 同步。

**驗收標準**

## 第二期　視圖配置（已量基準，驗收標準已依實測修訂）

**範圍**：P1–P4、V1–V8（見通則）。ADR 另取號（目前最後是 0260，開工時再確認）。

### 現況基準（2026-11-19 量測）

以 `drawing_create` 預設選項出圖，再用新的 `layoutMetrics`（`packages/drawing/src/layoutMetrics.ts`，已寫、已測）逐頁量。零件：`tests/golden` 4 件＋R1-8032 Rev. 08。表中「淨空」是相鄰視圖連同各自尺寸、標題的外框之間的距離（負值＝重疊）；「受限方向填滿」是 max(寬向佔比, 高向佔比)。

| 零件／頁 | 圖紙與比例 | 受限方向填滿 | 視圖外框面積佔可繪區 | 最小淨空 mm |
|---|---|---|---|---|
| diamond-pin p1 | A4 1:1 | 0.774 | 0.040 | **−0.06** |
| locating-plate p1 | A3 1:1 | 0.798 | 0.195 | 9.66 |
| sds-plus-bit p1 | A2 1:1 | 0.831 | 0.058 | 9.03 |
| sds-plus-bit p2 | A2 1:1 | 0.911 | 0.025 | **−19.05** |
| v-block p1 | A4 1:1 | 0.785 | 0.150 | 9.66 |
| R1-8032 p1 | A3 5:1 | 0.819 | 0.123 | **−0.72** |
| R1-8032 p2 | A3 5:1 | **1.161（超出可繪區）** | 0.316 | **−42.00** |

R1-8032 p2 的詳圖共 6 個：5 個被別的視圖擋在母視圖與它之間；與母視圖的距離 95–158 mm（母視圖對角線 77–117 mm）；2 個詳圖的線長只有圓周的 0 與 0.8 倍（詳圖 G 空白、F 只有一個直角）；4 個比例不是標準比例（8:1、15:1）。

注意：這次出圖的結果與你審查的 `.3dbd`（A1 20:1）不同（現在是 A3 5:1），所以「現況」以這次量到的為準。

### 原標準中不可能達成、改掉的

| 原標準 | 實測 | 改為 |
|---|---|---|
| 視圖連同尺寸在寬、高兩向都佔 60–85% | 細長件兩向不可能同時達到（受限方向 0.77–0.91，另一方向由形狀決定） | **只看受限方向**：max(寬, 高) 佔比在 0.60–0.95，且不超出可繪區（≤ 1.00） |
| 視圖外框面積 ≥ 35% | 最高 0.195（locating-plate）；三視圖加尺寸本來就用不到 35% | **取消**。填滿由受限方向衡量 |

| # | 項目 | 標準 | 基準（不合格者） |

| 2-1 | 視圖淨空 | 最小淨空 ≥ 7 mm（= 2 × 字高 3.5 mm） | 4 頁不合格（−0.06、−19.05、−0.72、−42） |
| 2-2 | 填滿 | max(寬, 高) 佔比 0.60–0.95，且不超出可繪區 | 1 頁不合格（R1-8032 p2：1.161） |
| 2-3 | 詳圖位置 | 每個詳圖：不被別的視圖擋在母視圖之間；到母視圖距離 ≤ 母視圖對角線 | 5／6 被擋；2 個超過對角線以外或接近 |
| 2-4 | 詳圖內容 | 線長／圓周 ≥ 1.0；不足就不產生該詳圖（其尺寸留在母視圖） | 2 個不合格（0、0.8） |
| 2-5 | 比例 | 所有視圖用標準比例（ISO 5455：…20、10、5、2、1、1:2…） | 4 個詳圖不合格（8:1、15:1） |
| 2-6 | 多頁 | 各頁圖紙相同；同一個剖面或詳圖代號在整份圖中只出現一次；同一個視圖不在兩頁重畫 | R1-8032：代號 A 出現兩次，下視圖兩頁重畫 |

### 實作順序（每步各自跑測試）

1. `layoutMetrics`（已完成，11 項單元測試、7 種突變，其中 1 種為等價突變）。
2. 視圖間距：量測淨空，不足時沿 `DrawingView.slide`（已入檔、可再調）拉開；取代只看雜亂分數的 `spreadViews`。
3. 詳圖：靠近母視圖、不被擋、空詳圖不產生、比例用標準值。
4. 多頁：代號唯一、不重畫視圖。
5. 主視圖（先量回轉面比例再定 X）。
6. 自檢接上。

## 第三期　標註的佈置與內容

**範圍**：D1、D3、D5、D6、D7、D9、D10、C1、C2、C4、L1、L2

**改什麼**

1. 尺寸優先標在特徵落在外形上的視圖；尺寸界線不穿過剖面線區。
2. 座標尺寸：相鄰數字中心距 ≥ 1.5 × 字高，相同值合併；不足時改用一般尺寸或詳圖。
3. 引線文字放在外形外；箭頭落在幾何上；半徑引線通過圓心。
4. 「n×」依建模特徵計數，不依被切開的面片數。
5. 回轉件的直徑在縱向視圖標 Ø，不在端視圖標 R。
6. 「貫穿」只用於真的貫穿的孔。
7. 縱向視圖與剖面畫回轉軸線；同一圓心只畫一組中心十字；中心線超出外形 2–5 mm。
8. 不對碎面（面積 < 0.01 mm²）標註。

**驗收標準**

| # | 項目 | R1-8032 現況 | 目標（R1-8032 與第二期的另外 3 件） |
|---|---|---|---|
| 3-1 | 穿過剖面線區的尺寸界線 | 15 | 0 |
| 3-2 | 間距 < 1.5 × 字高的座標數字 | 5 組 | 0 |
| 3-3 | 雜亂、交叉 | 41、2 | 0、0 |
| 3-4 | 箭頭未落在幾何上 | ≥ 3 | 0（以向量量測：端點到幾何 ≤ 0.2 mm） |
| 3-5 | 離開所屬視圖的尺寸 | 2 | 0 |
| 3-6 | n× 與特徵數不符 | ≥ 4 | 0 |
| 3-7 | 整圈圓柱標成 R | 13 | 0 |
| 3-8 | 錯誤的「貫穿」 | 1 | 0 |
| 3-9 | 縱向視圖缺軸線 | 2 | 0；重複中心十字 0 |
| 3-10 | 指向碎面或讀不到的尺寸 | 1 | 0 |
| 3-11 | 完整度 | 自檢 `complete` | 不低於改版前（每個位置仍有尺寸） |
| 3-12 | 全量 | — | 同 1-8、1-9 |

## 第四期　品質閘門

**範圍**：Q1、Q2、C5、C7

**改什麼**

1. `drawing_inspect` 依本通則列出每一項的通過與否。
2. 有任何一項不通過時，`drawing_create`、`drawing_export` 回報「草稿」並列出未通過的項目；匯出的圖面標示 PRELIMINARY。只有全部通過才是正式。
3. 一般公差欄空白、沒有「依 3D 模型」註記時，不得以正式狀態匯出（公差數值仍由使用者決定，工具不自行填）。

**驗收標準**

| # | 項目 | 標準 |
|---|---|---|
| 4-1 | 閘門 | 測試：每一項規則各造一個違反的圖，正式匯出都被擋下並指出該項；全部通過的圖可以正式匯出 |
| 4-2 | 突變 | 把閘門的判斷改壞（例如永遠通過），對應測試必須轉紅 |
| 4-3 | 全量 | 同 1-8、1-9 |

## 待確認

1. **舊檔的預設**：沒有「標準」欄位的既有工程圖視為 ISO（外觀不變），只有新建的圖用 CNS。另一種做法是舊檔也改用 CNS，打開時外觀會變。建議前者。
2. **CNS 數值來源**：先用教材的數值，程式中註明出處；取得 CNS 3 原文後逐項核對。
3. **順序**：建議照第一到第四期進行。第一期範圍最小、風險最低，也是其他各期的基礎。
