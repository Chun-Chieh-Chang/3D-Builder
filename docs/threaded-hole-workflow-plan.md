# 牙孔流程整合與驗證計畫

日期：2026-11-03。基準：0e78483。使用者已授權先訂方案再實作。狀態：實作中，未驗收。ADR 與 Schema 編號於實作時決定，不預占。

## 目標操作

選平面 → 異型孔 → 放置並拘束孔位（或選既有草圖）→ 選螺紋規格、底孔終止條件、有效牙深及裝飾線 → 確認。一次設定套用同一草圖的全部孔位。既有孔仍可使用獨立裝飾螺紋功能。

## 實作順序

1. 深度真值防禦：現行獨立裝飾螺紋會將超長的給定深度偷偷截短。改成明確報錯；全長模式才取實際圓柱長度。整合模式同樣不得截短。
2. 統一資料：在 HoleFeature 儲存可選螺紋表示設定與有效深度，規格與公差沿用孔本身。不要為每個孔複製可獨立失同步的規格。缺欄位的舊檔維持原行為。新增表達式需接 params、命令驗證、依賴與序列化。
3. 重建：對每個孔位的實際圓柱壁產生 CosmeticThreadInfo，沿用既有 3D 與工程圖通路。孔名、孔軸、入口及長度須從實際拓樸驗證；不使用固定假長度。多本體及拆分孔壁不得任意挑第一面。失敗不得留下部分裝飾結果。
4. 面板：螺紋孔提供裝飾線勾選、全長／給定牙深，明確區分底孔與牙深；規格變更同步更新底孔與標註。自訂底孔不能冒充標準螺紋。保留獨立裝飾功能處理既有孔及外螺紋，重複標註須提示。
5. 定位：異型孔可由選定平面進入孔位草圖，使用既有點工具、尺寸與拘束；返回孔設定後保留位置。取消整個操作不殘留草圖／孔；復原重做有明確交易邊界。既有草圖入口維持相容。
6. 真實牙形：設計為明確的進階選項，先確認既有 thread 牙型與標準表映射、內螺紋方向、入口及深度。未完成真實幾何驗證前不可提供只有裝飾線的「實體牙」選項。此項須獨立性能與 Heap 驗收，不與輕量表示混稱完成。

## 驗收條件

| 項目 | 必須通過的證據 |
|---|---|
| 輸入 | 命令／引擎拒絕零、負、NaN、無限大及超過可用孔壁的牙深；不得 round、abs 或靜默截短；表達式引用更新正確 |
| 單孔／多孔 | 同軸端面孔、偏心孔、至少三個孔位；每孔的目標面可解析，原生圓柱半徑、軸、入口與有效長度吻合 |
| 深度 | 盲底孔短牙、全長牙、貫穿底孔短牙；反向及端面／基準面各測。有效牙深不得越過實際材料，亦不得與鑽深混寫 |
| 變更 | M6 改 M8、移動孔位、改底孔深度、抑制／刪除、復原／重做、保存重開；規格、幾何與標註同步 |
| 相交 | 重疊孔位／合併孔壁須在危險運算前處理或明確拒絕，不產生重複或錯誤標註 |
| 工程圖 | 以 elementFacts／viewFeatures 驗證實際面與圓邊標註；牙深、底孔深度、公差、單位、孔數正確；檢視 SVG／PDF／DXF 結果 |
| 幾何 | 裝飾開關前後體積、面數不變；不新增螺旋布林。真實牙形另以原生剖面及體積探針驗證 |
| 壓力 | 至少 100 組可重現隨機參數；各方向／深度變體都至少成功驗證一次。Heap 取 wasmMemory.buffer.byteLength 且基準 > 0，附可觀察成長的對照，不宣稱底孔布林零洩漏 |
| UI | 實際放孔、取消、修改、重新開檔與多孔畫面截圖；完整 verify:ui，執行期間不編輯原始碼 |
| 守門 | typecheck、lint:rules、lint:deps、lint:i18n、lint:repo、相關模型／重建／工程圖測試；同步中英文說明及 DEV_LOG 紅隊四問 |
