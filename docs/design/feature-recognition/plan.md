# STEP 特徵辨識與重建（藍圖 F2.4）

狀態：第一版已實作，見 [ADR 0239](../../adr/0239-feature-recognition.md)（2026-11-06）。使用者決定把 F2.4 由 X（不做）改為要做，第一版範圍：伸長（凸台／除料）、孔（簡單、沉頭、錐坑）、圓角與倒角、旋轉。ADR 與 Schema 編號在交付時才取（AGENTS §4 2026-10-19 第 5 條）。

## 1. 目標與不做的事

**目標**：對一個 `importedBody`（STEP／IGES 讀入的單一實體），產生一串本系統的原生特徵（草圖、伸長、旋轉、孔、圓角、倒角），重算結果與原匯入件**幾何相同**，之後每個特徵都能照常修改。

**一律全有或全無**：只要有一個面沒被解釋，或重建結果與原件不同，就拒絕並說明哪些面、差多少；不交出「部分辨識」的模型，原匯入件不動。

**不做（第一版）**：自由曲面（B 樣條）、拔模面、變半徑圓角、薄殼、掃出／疊層、多實體、陣列與鏡射的意圖辨識、草圖完全定義（尺寸只加半徑／直徑，其餘依存放位置）。

## 2. 分解順序（由外而內移除，反向重建）

辨識是「把特徵一個個從模型拿掉」，重建是倒過來加回去：

1. **圓角與倒角**（最後加的，先拿掉）
   - 圓角面：圓柱面（或圓環面、球面），與兩側鄰面在共用邊上**相切**（法向點積 ≥ 1−1e-9，於邊的三個點取樣），半徑為曲面半徑，且為凸／凹皆可。
   - 倒角面：平面，兩條長邊都是直線且互相平行，兩側鄰面與它不相切、彼此不共面；量出兩側的距離（距離-距離）。
   - 以 `Kernel.deleteFaces`（`BRepAlgoAPI_Defeaturing`）移除；成功的條件同 ADR 0021：面真的被刪除、結果有效。移除後記下**還原出來的尖角邊**（在移除後模型上，兩支撐面的交線）的中點與方向，供重建時找邊。
2. **孔**：一組同軸的凹圓柱（與錐面、與軸垂直的環形平面），入口在一個與軸垂直的平面上：
   - 簡單孔：一個凹圓柱；盲孔底為與軸垂直的平面。
   - 沉頭孔：兩個凹圓柱＋一個環形平面（大徑在入口側）。
   - 錐坑孔：凹錐面（入口側大）＋凹圓柱。
   - 對應 `HoleFeature`；不合孔精靈的形狀（例如鑽尖錐底）改由**旋轉除料**表達（同軸凹回轉面組）。以 `deleteFaces` 移除整組。
3. **基體**：剩下的實體只能是下列之一，否則拒絕：
   - **旋轉體**：所有面都是與同一軸共軸的回轉面（平面須垂直於軸，圓柱、圓錐、圓環、球心在軸上）。截面＝實體與含軸半平面的交集 → 草圖（直線、圓弧）＋中心線 → `revolve` 360°。
   - **分層伸長體**：存在方向 d，使每個面不是法向 ∥ d 的平面（端面），就是平行於 d 的柱面（法向 ⟂ d 的平面、軸 ∥ d 的圓柱）。把端面高度排序成層，每層中間取截面 → 該層輪廓。第一層 `extrude` 盲孔深度＝層高；其餘各層在該層底面高度的基準面上 `extrude` 凸台。
4. **截面轉草圖**：截面邊只接受直線、圓、圓弧（其餘拒絕）；端點在 1e-7 mm 內共用一個點 id；圓與圓弧加半徑尺寸。

## 3. 草圖平面

- 方向與預設平面法向一致（±X/±Y/±Z）→ 預設平面或其 `offset` 基準面。
- 其他方向 → 兩個 `refPoint`（座標）→ `refAxis`（兩點）→ `refPlane`（垂直於軸、通過點）。草圖座標以 `planeFrame` 換算（與重算引擎相同）。

## 4. 重建與驗證

1. 在零件中，於原 `importedBody` 位置插入特徵，刪除該 `importedBody`；全部是同一次可復原的整批（`History.applyBatch`）。
2. 基體與孔先加，重算一次，再以「還原尖角邊」的中點與方向在重算後的模型上找邊（距離 ≤ 1e-6 mm、方向平行），取其**持久名稱**建圓角／倒角特徵（同半徑或同距離的邊合為一個特徵）。
3. 最終驗證（任何一項不過即整批拒絕）：
   - 所有新特徵狀態為 ok；
   - 面數只回報（他牌 STEP 的分面可能不同，不當條件）；
   - 體積相對差 ≤ 1e-6；
   - 對稱差體積（原件−重建、重建−原件）各 ≤ 1e-6 × 原體積。

## 5. 拒絕訊息（可讀、可行動）

- 「有 n 個面無法辨識（類型：bspline…）」並列出面編號；
- 「圓角面 n 無法移除」（Defeaturing 失敗）；
- 「找不到伸長方向或旋轉軸」；
- 「截面含不支援的曲線（橢圓／樣條）」；
- 「重建結果與原件不同：體積差 x、對稱差 y」。

## 6. 驗證計畫

- 金樣：以本系統原生特徵建模 → 匯出 STEP → 匯入 → 辨識 → 重建，與原件比體積、對稱差、面數，並檢查特徵種類與參數（半徑、孔徑、深度）等於建模時的值。
- 涵蓋：方塊＋貫穿孔、盲孔、沉頭、錐坑；L 形分層；凸台＋除料袋；圓角（凸、凹）、倒角；旋轉軸件（階梯軸、錐、圓環槽）；非預設方向（整件旋轉 30°）。
- 拒絕：B 樣條面、拔模、無法移除的圓角、多實體。
- Fuzz：≥ 100 組隨機尺寸的方塊＋孔＋圓角，0 崩潰、0 錯誤接受；Heap 以 `wasmMemory.buffer.byteLength` 量測並先斷言 > 0。
