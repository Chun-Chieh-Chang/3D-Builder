# 樣條間隙：偏移結果的逐邊間隙證明

日期：2026-11-05；基準 `41a0259`。研究階段，未接入產品命令或 UI，未新增 Schema、未占用 ADR。接續[圓弧候選及推導](bounded-offset.md)留下的「最終偏移的全域間隙上限尚未取得證書」。

## 結論

- 偏移結果的**每一條邊**都改由「產生它的來源元素」證明上限，不再靠一齒角域抽樣。下限沿用完整線框的全域最短距離。兩者合起來，才是對所有齒的雙側間隙界。
- 四個齒輪案例（模數 0.5／1／3、間隙 0.01–0.2 mm）全部邊都有證明。對平滑截面的間隙區間落在 [間隙 − 1.7e-6, 間隙 + 1.2e-5] mm 以內。
- **找到兩個 `BRepOffsetAPI_MakeOffset` 的真實缺陷**：模數 3／40 齒／0.3 mm，以及模數 1／24 齒／0.8 mm。原生演算法回傳單一、封閉、看起來有效的線框，伸長後也是有效實體，但有段落只離來源 0.147 mm 與 0.349 mm。一齒抽樣、有效實體、體積一致這些既有檢查都不會發現，只有全域最短距離抓得到。產品化時，這兩種情況必須被偵測並拒絕，不能交出去。

## 方法

輸入是 [bounded-offset.md](bounded-offset.md) 的明示圓弧／直線近似線框（記作 A）與 `MakeOffset` 的輸出線框（記作 O）。O 的每條邊都必須是平面直線或圓弧，否則明確拒絕。

**上限（逐邊、無抽樣）**：對 O 的每條邊，找一個來源元素證明「這條邊上每一點到 A 的距離 ≤ 間隙 + slack」。slack 取 1e-5 mm，與既有取樣門檻同值。

1. **直線 ↔ 來源直線**：到線段的距離沿直線是凸函數，所以兩端點距離的較大者即為整條邊的上限。
2. **圓弧 ↔ 同心來源圓弧**：P 沿輸出圓轉，它在來源圓上的徑向投影若落在來源圓弧角度範圍內，距離 ≤ |R − r| + 圓心誤差。
   - 範圍外的**小幅超出**（≤ 0.2 rad）以該端的接點為最近點；距離隨離開接點的角度單調增加，所以由超出那一端的端點距離界住。
   - 這種超出確實存在：近似圓弧接點有極小凹折，兩條偏移圓的交點落在範圍外。0.05 mm 案例約 0.045°。
   - 兩端都在範圍內、但從圓的另一側繞過去的圓弧，以中點角度檢查排除。
3. **接角圓弧 ↔ 來源頂點**：上限為 R + 圓心到頂點的距離。
4. **補救（Lipschitz）**：以上規則都證不了的邊才進入這一步。
   - 到 A 的距離是 1-Lipschitz，所以一段弧長 L 的上限是「中點的精確距離 + L/2」。
   - 中點距離對每個直線／圓弧元素都是精確公式，用格點索引只看鄰近元素。不合格就二分。
   - 每條邊 40 萬步、整份 1,200 萬步的預算，超出即明確判失敗。
   - 每條補救邊另取 65 個精確點距離，記為 `fallbackSampledMax`。它只是參考值，不作為證明。

**下限**：用 OCCT 全域最短距離（`BRepExtrema`）量 O 到 A 與 O 到平滑截面兩者。這個值仍依賴原生極值計算，沒有獨立的形式化證明。

**對平滑截面的雙側界**：
- 下限：O 到截面的全域最短距離。
- 上限：逐邊證明的最大值，加上 A 的表示誤差上限（三角不等式）。
- 截面自身相對 STEP 真實交線的平滑誤差不在這個界內，與前一份報告相同。

- **上限偏保守**：補救邊的 65 點精確取樣最大值只比間隙多 1.6e-14 mm。證明上限偏大約 1e-5，來自超出段改用接點距離，以及 Lipschitz 停在「≤ 間隙 + slack」。
- **違反位置**：
  - 模數 3 的違反點在齒根圓（r = 56.25）與徑向齒腹的凹角：來源 (55.982, 5.481)，偏移 (56.128, 5.495)。
  - 模數 1、0.8 mm 的違反點在 (−7.082, −8.857)。
  - 這兩個案例的逐邊上限全部通過：缺陷是「點離來源太近」，只有下限抓得到。所以上下限都不能省。
- **有孔截面**：0.5 mm 孔的齒輪截面得到 2 個環。現在明確以「single-loop section required, got 2 loops」拒絕，不只認證外圈。
- **其他**：12 齒、模數 0.5 會根切，由齒輪產生器在建模前拒絕；案例改用 18 齒。
- **耗時與 Heap**：整檔 14 項 85.4 秒（2 核 Linux VM）。同一 Kernel 從 128 MiB 長到 458.9 MiB。案例共用 Heap，不能歸因到單一案例，也不宣稱任何洩漏結論。

## 對抗驗證

- 純函式：
  - 方形偏移（4 直線＋4 接角）精確證明。
  - 同心弧只在範圍內成立；圓心偏 0.01 mm 的圓弧沒有任何規則救得了。
  - 間隙、slack、空輸入、非有限座標皆明確拒絕。
- 應被拒絕的輸入：
  - 間隙畫成兩倍：8 條邊全部失敗。
  - 一個接角圓心移 1e-3 mm：只有那一條邊失敗。
  - 一條邊延伸超出來源線段：只有那一條邊失敗。
  - 超出來源範圍 0.6 rad 的同心弧：被拒絕。
  - 兩端都在範圍內、但繞遠路的同心弧：被拒絕。
  - 只有中點剛好在間隙上的斜線：被拒絕。
  - 每個齒輪案例另以一半的間隙重驗，全部邊都必須失敗。
- 程式突變（各自還原後重跑）：
  1. 拿掉圓弧角度範圍檢查：「繞遠路」轉紅。原本只有超出量檢查的測試抓不到這個突變，因此補了這一項。
  2. Lipschitz 去掉 L/2：三項轉紅。
  3. 直線規則只看垂直距離、不夾在線段內：「延伸超出」轉紅。
