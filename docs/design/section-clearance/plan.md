# 輪廓／截面＋間隙：可行性探針

日期：2026-11-05。狀態：探針已執行；直線／圓弧單外圈可行，樣條及一般多區域尚未通過，未開發產品介面。

## 範圍與結論

使用者指定依 handoff §1b 先做探針，並於本輪同意以合成檔案驗證，不要求特定私有 STEP。建立真實 OCCT 實體，輸出 STEP 後重新匯入，再取指定高度的截面、檢查封閉線框、偏移間隙與伸長。不是以預先寫好的輪廓或網格冒充截面。

**目前只足以支持直線／圓弧單外圈的技術路徑，不能據此交付任意齒形的一鍵工具。** 24 齒漸開線樣條樣本在面積／體積一致性與偏移兩關被攔下；環形樣本還需要孔洞及區域語意。原使用者 340 面 STEP 未測，也未宣稱使用者端驗收。

## 可重現方式

執行 `npm test -- tests/phase6/section-clearance-probe.test.ts`。

腳本將原生量測寫到 `out/section-clearance/probe.json`，並產生 `rack.step` 與 `involute-gear.step`。這些是可重新產生的本機輸出，不提交樣本副本。樣條測試的成功條件是**確實重現並記錄拒絕**，不表示樣條功能通過。

本輪最終探針 7/7 通過（含三項預期拒絕），約 44 秒；typecheck、規則／依賴／翻譯／儲存庫檢查通過，文件盤點已同步。產品程式未修改，未重跑全套單元測試或 UI。

## 實作路徑與驗收

1. `Kernel.extrude` 建合成來源，再由 `exportStep`／`importStep` 往返。
2. `BRepAlgoAPI_Section` 與水平平面取交線；`ShapeAnalysis_FreeBounds.ConnectEdgesToWires` 以 1e-7 mm 接線。
3. 每圈須原生 `BRep_Tool.IsClosed`；所有圈的邊數合計須等於原截面邊數，不得漏邊。
4. 以明確平面建立支撐面，`BRepOffsetAPI_MakeOffset` 採圓弧接角。兩個符號皆實測，以面積增加選擇外擴；不假設線框方向固定。只接受單一封閉結果，不能把分裂結果默默挑一圈。
5. `MakePrism` 的結果須有效且為一個實體。截面面積與體積／高度差須小於 1e-6 mm²。
6. 原生最短距離與要求間隙差小於 1e-6 mm；每條輸出原生邊取五個參數點，再量點到來源線框的距離，最大間隙誤差小於 1e-5 mm。這是離散探針，不是曲線全域誤差的數學證明。
7. 圓柱另以 π(r+d)² 獨立對照偏移面積，誤差小於 1e-6 mm²。非法 gap（負值、NaN、Infinity）在呼叫 OCCT 前拒絕；無交線明確回報空截面。

樣條的一致性差異目前不能歸因為「形狀錯」或「積分錯」。面積即使改用 1e-10 的自適應積分仍不一致；來源齒輪的獨立解析面積為 443.8508235137 mm²，接近截面面積，但不能單獨證明伸長後的幾何。明確指定體積積分 `eps: 1e-9` 時，體積變成 1318.3581168619 mm³，仍不一致。原生面種類包含 Plane、SurfaceOfExtrusion 與 Cylinder；既有 `hasComplexSurfaces` 未將 SurfaceOfExtrusion 列入自動積分判斷，但本次強制自適應亦未解決，不能僅補旗標就宣稱根治。下一步需分離 STEP 表示、建面與體積積分誤差，不放寬門檻。

## 資源與紅隊

- 所有暫存 OCCT 物件進 Arena，`finally` 釋放。各案例後 `liveShapes === 0` 僅驗本專案持有的形狀已釋放。
- `(oc as any).wasmMemory?.buffer?.byteLength` 是 Heap 真值；先斷言基準大於 0，再記錄起訖。一次完整探針由 128 MiB 成長至 265.5 MiB，不能宣稱零洩漏；其中 100 組圓柱段成長 44.25 MiB。數值隨配置餘裕改變，重跑以 JSON 為準。不同路徑共用 Heap，這不是洩漏來源的隔離歸因。
- 輸入破壞：負值／非有限 gap 與空截面已覆蓋；尚無任意尺度、任意平面與一般自相交防禦。
- 相交破壞：本探針只接受一圈偏移結果並量測間隙；尚未處理多個外圈膨脹後相撞、孔縮至消失或窄縫合併，不得直接接產品命令。
- 依賴鏈：僅新增獨立測試／報告，未新增特徵、Schema、命令或 UI。來源面的持久參照、DAG 與求解器尚未設計，不宣稱參數式連動已可用。
- 真實性：資料來自原生截面、拓樸、曲線距離、體積與解析控制組；未 mock 幾何，未以畫面或 handle 數代替幾何／Heap。
- 突變驗證：暫把 `offset.Perform(sign * gap)` 改成兩倍，解析圓柱案例在最短距離斷言轉紅（0.05 mm 誤差大於 1e-6 mm）；還原後完整重跑。六項未選案例在這次針對性呼叫中未執行，不是新增 `skip`。

## 後續實作前的出口

先隔離樣條 STEP 的建面與積分差異，再比較可靠的原生偏移或有明確誤差界的近似。近似必須向使用者顯示語意與誤差，不能偷偷把自由曲線改成折線。一般區域需建立包含關係：外圈外擴、孔洞內縮，並明確處理分裂、相撞及孔消失。通過這些探針後，才核定產品範圍、持久參照與介面；不先占 ADR 或 Schema 編號。
