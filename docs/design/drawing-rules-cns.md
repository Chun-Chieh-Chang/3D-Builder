# 工程圖標註與配置通則

- **用途**：3D-Builder 自動出圖的通用規則，不針對任何單一品項。以 R1-8032 Rev. 08 這張自動出圖（`R1-8032_Rev08_2D_完整修訂.3dbd`）作為案例，每條規則都用它實際量到的數字說明違反在哪裡。
- **量測方式**：視圖外框取自 `drawing_inspect` 的 `sheetBox`（圖紙 mm）；文字、引線與中心線位置取自匯出的 PDF 向量（PyMuPDF 讀取），以及 4 px/mm 的 PNG；工具的行為讀自 `packages/drawing/src`。
- **日期**：2026-11-19

### 依據與用語

台灣的製圖以 **CNS 3（工程製圖，CNS3-B1001 系列）** 為準；CNS 3 大致與 ISO 一致，但圖框邊距、線寬組合等細節不同。下表的 ISO／ASME 條文仍然適用；兩者不同時，§2 會註明。**預設採 CNS 3，ISO 為可切換的替代設定檔**（2026-11-19 決定，見 §5）。

| 代號 | 標準 | 管的範圍 |
|---|---|---|
| CNS 3 | 中華民國國家標準：工程製圖 | 圖紙、圖框、標題欄、工程字、線型與線寬、視圖、尺度標註 |
| ISO 5457 | 圖紙尺寸、圖框 | 圖框邊距 |
| ISO 7200 | 標題欄 | 標題欄欄位 |
| ISO 5455 | 比例 | 只用 1、2、5 × 10ⁿ |
| ISO 128-20／-24 | 線型與線寬、中心線 | 粗細線 2:1、軸線畫法 |
| ISO 128-22 | 引線 | 引線端點、走向 |
| ISO 128-30／-40／-44／-50 | 視圖、剖面、剖面線 | 主視圖選擇、投影對齊、剖面標示、剖面線遇文字中斷 |
| ISO 5456-2 | 正投影 | 第一角、第三角配置 |
| ISO 129-1 | 尺寸標註 | 尺寸位置、重複特徵、直徑與半徑、座標尺寸 |
| ISO 3098 | 字體 | 字高系列 2.5／3.5／5／7 mm |
| ASME Y14.5、Y14.3 | 尺寸公差、視圖 | 尺寸線間距 10／6 mm、剖面代號不用 I、O、Q |

規則的數值分三種，表中會註明：

- **〔標準〕**：標準條文本身的要求或建議值。
- **〔CNS 教材〕**：取自參考資料中依 CNS 3 編寫的教材；教材轉述的數值，正式採用前應以 CNS 3 原文核對。
- **〔慣例〕**：業界常用的做法。標準只要求「清楚、不擁擠」而沒有給數字時，用這些值當作可以量測的門檻。

| 現象 | 量測 | 違反 |

## 2. 通則

每條規則包含：要求、可量測的門檻、出處，以及能否自動檢查。

### P　圖紙與比例

| 編號 | 要求 | 門檻 | 出處 | 自動檢查 |
|---|---|---|---|---|
| P1 | 圖紙大小與比例一起決定，並比較不同的視圖排法（橫排、上下排、L 形），選出最平衡的組合 | 視圖連同尺寸的外框，在可繪區的寬向與高向都佔 **60–85%**；視圖外框面積佔可繪區 **≥ 35%**。達不到就換小一號的圖紙或改變排法 | 〔慣例〕 | 可 |
| P2 | 可繪區包括標題欄左側的空間；視圖群依整體外框置中，不偏向任何一側 | 視圖群中心與可繪區中心的偏差 ≤ 可繪區尺寸的 10% | 〔慣例〕 | 可 |
| P3 | 同一份圖的每一頁使用相同的圖紙大小 | 頁與頁不同的數量 = 0 | 〔慣例〕 | 可 |
| P4 | 比例只用 1、2、5 × 10ⁿ（放大比例 2:1、5:1、10:1、20:1、50:1） | 非標準比例的數量 = 0 | ISO 5455〔標準〕 | 可 |
| P5 | 圖框依所選標準；所有內容在圖框內，並與圖框、標題欄保持距離 | **CNS**：圖框離紙邊 A0–A2 為 15 mm、A3–A4 為 10 mm、A5 為 5 mm；需裝訂時左邊 25 mm。**ISO 5457**：左 20 mm，其餘 A3–A4 為 10 mm、更大為 20 mm（工具目前用這組）。文字與線條離圖框、標題欄 ≥ 10 mm | CNS 教材、ISO 5457〔標準〕；內容距離〔慣例〕 | 可 |
| P6 | 字高依圖紙選用，並考慮縮印 | A0–A2 的尺寸字高 ≥ 3.5 mm、A3–A4 ≥ 2.5 mm；預定縮印時，縮印後仍 ≥ 2.5 mm（例如 A1 縮印成 A3，字高要 ≥ 5 mm）。CNS 另有「建議最小字高」表，教材中是圖片，本次未讀到數值，需以 CNS 3 原文確認 | ISO 3098 字高系列〔標準〕；依圖紙與縮印選值〔慣例〕 | 可 |
| P7 | 工程字的比例與排列：中文字的字寬等於字高（方形字），字距約字高的 1/8，行距約字高的 1/3；拉丁字母與數字行距約字高的 2/3；一律由左向右橫書；同一張圖的字體大小一致 | 多行註記的行距與字距落在上述比例 ±20% 內；同一類文字字高只有一種 | CNS 教材 | 可 |
| P8 | 標題欄放在圖紙右下角，右邊與下邊就是圖框線；每張都有，欄位至少包括圖名、圖號、機構名稱、設計／繪圖／校核／審定的姓名與日期、投影法、比例 | 缺漏欄位 = 0；標題欄右、下邊與圖框重合 | CNS 教材、ISO 7200〔標準〕 | 可 |

### V　視圖配置

| 編號 | 要求 | 門檻 | 出處 | 自動檢查 |
|---|---|---|---|---|
| V1 | 視圖之間的間距由兩側的尺寸區推算，不用固定值 | **淨空** = 外框間距 − 左（下）視圖的尺寸區深度 − 右（上）視圖的尺寸區深度，須 **≥ 2 × 字高**（3.5 mm 字高即 ≥ 7 mm）；同一排各間距的差 ≤ 30% | 間距須足以標註〔ISO 128-30 的原則〕；數值〔慣例〕 | 可 |
| V2 | 主視圖選最能表達形狀、並依功能、加工或安裝位置擺放的方向；回轉件以軸線水平的縱向視圖或縱剖面為主視圖 | 回轉件以端視圖作主視圖的數量 = 0 | ISO 128-30〔標準〕 | 可（判斷主軸是否為回轉軸） |
| V3 | 投影視圖對齊投影線；剖面放在投影位置，否則必須標代號。每個視圖都有標題，標題緊靠視圖，並與尺寸文字分開 | 對齊偏差 ≤ 0.5 mm；標題到視圖外框 ≤ 10 mm，與其他文字及詳圖邊框的距離 ≥ 1 × 字高 | ISO 5456-2、ISO 128-40〔標準〕；距離〔慣例〕 | 可 |
| V4 | 詳圖放在母視圖附近，同一側，中間不隔著其他視圖 | 詳圖外框到母視圖外框 ≤ 母視圖對角線長，而且兩者連線不穿過第三個視圖 | ISO 128-30 的建議〔標準〕；距離〔慣例〕 | 可 |

| V7 | 同一個視圖不重複畫；剖面與詳圖代號在整份圖中只用一次，不用 I、O、Q | 重複的視圖或代號 = 0 | ASME Y14.3〔標準〕 | 可 |
| V8 | 視圖數量以「能完整表達」為限，不多畫。內部形狀用剖視圖而不是一堆虛線；傾斜面用輔助視圖表示實形；底部或背面才看得到的特徵，加畫該方向的視圖或取代原本的視圖 | 單一視圖的隱藏線長度超過可見線的 30% 時，改為剖視（門檻為經驗值，需實測校準）；傾斜面沒有實形視圖又需要標註時，產生輔助視圖 | 機工類乙級學科題庫、HackMD；ISO 128-30〔標準〕 | 可 |

### D　標註的佈置

## 3. 3D-Builder 目前的做法與缺口

| 規則 | 目前的做法 | 缺口 |
