## 現況與方向

目前 `CommandBar.tsx` 直接按 `UiAction.group` 把指令平鋪在下拉選單。完整盤點是205個action ID（含33個生成式草圖工具、子選單與右鍵專用動作），不是205個永遠同時顯示的按鈕。其中54個指令共用「特徵」，曲面、塑膠、機械及參考幾何混在一起；組合件缺獨立檢查／管理頁籤，檢視亦有重複入口。

採用SolidCraft的任務分組，保留3D-Builder既有文件種類與左側FeatureManager／PropertyManager。首版使用固定靠邊的緊湊配置；浮動面板、多文件分頁與底部時間軸另列後續，不隨選單改版改動文件或回復歷史。

工具使用**圖示＋完整文字**。不恢復使用者先前拒絕的純圖示工具列。以立體體積表達建模、綠色平面幾何表達草圖、橘色表達曲面；顏色只輔助分類，同時保留形狀、文字、狀態與說明。一般／除料、完整／部分展開、實體／裝飾螺紋及不同尺寸工具必須可區分。

## 建議版面

上方應用列：`3D-Builder｜檔案｜編輯｜儲存｜復原｜重做｜文件名稱｜說明`。

下方工作列：`工作頁籤｜指令搜尋`，再下一列顯示當前頁籤的分組；每組顯示1–3個常用指令，組名帶下拉開完整清單。可收合工作列，保留頁籤；「完成草圖」固定在草圖列右側、始終可找到。狹窄寬度先收合次要分組，再放入有文字的「更多工具」，不能只裁掉右側內容。

| 文件／狀態 | 工作頁籤（由左至右） |
|---|---|
| 零件 | 建模、曲面、鈑金、插入、檢查、管理、檢視 |
| 編輯草圖 | 草圖自動啟用；其餘零件頁籤保留，依既有enabled規則限制操作 |
| 組合件 | 組合件、插入、檢查、管理、檢視 |
| 工程圖 | 視圖配置、註記、表格、管理、檢視 |

鈑金固定可找到，不等有鈑金本體才顯示；選到鈑金本體可自動選該頁一次，但純移動滑鼠／預覽回覆不能切走使用者目前的頁籤。文件切換記住各文件最後頁籤；進／離開草圖恢復原頁。這些均為新版選單的實作要求，本批圖示接入不改目前切換邏輯。

## 指令分組

| 頁籤 | 分組與代表工具 |
|---|---|
| 建模 | 草圖；建立（伸長、旋轉、掃出、疊層、肋材）；除料；修飾（圓角、導角、薄殼、拔模）；排列；參考幾何；實體操作；孔與機械（異型孔、螺紋、滾花、齒輪／齒條）；塑膠結構 |
| 曲面 | 建立（平坦、填補、偏移、直紋、放射）；修剪與延伸；縫合與替換；實體化（加厚、曲面切除） |
| 鈑金 | 基材與折彎（基材、邊線凸緣、中間折彎、凸折、摺邊）；角落；展開加工（全部、部分、摺回）；平板型式 |
| 草圖 | 繪製；修剪與修飾；變換與陣列；尺寸與拘束；參考；完成 |
| 組合件 | 插入與結構；配合；位置；排列；呈現與清單 |
| 插入 | 依文件種類呈現STEP／組合件來源；不能把僅供零件的命令變成組合件可執行 |
| 檢查 | 量測／物質特性；幾何品質／拔模／底切／厚度；裝配干涉與間隙 |
| 管理 | 方程式與屬性；外觀；系統選項與快捷鍵 |
| 檢視 | 方向／全部顯示；顯示方式（含透明）；剖面；選取濾器 |
| 視圖配置 | 標準、投影、剖面、細部、比例；來源 |
| 註記 | 尺寸種類；基線／座標／自動排列；文字與GD&T／表面符號；中心標記／中心線 |
| 表格 | 孔表、BOM；折彎表保持展平視圖屬性中的既有設定，後續可新增同源入口 |

精確205個現有ID的目標分類見 [command-map.json](command-map.json)。14個右鍵專用動作保留右鍵範圍，不為了填滿工具列改成一般按鈕。方程式、外觀等也須沿用目前文件／選取的可用條件；組合件／工程圖沒有的能力不捏造為可用。

草圖「相切、平行、垂直、等距、對稱」目前從選取關係面板產生，不全是ACTIONS中的獨立命令。新版尺寸與拘束分組要接既有 `addRelation`／候選驗證，以Adapter提供同源入口；不能僅為了與SolidCraft相似就顯示能按但不工作的按鈕。顯示樣式與剖面等現有Viewport控制也採同源Adapter，沒有捏造其action ID。

## 互動與易用性

- 完整選單保留所有現有指令；子類型仍用清楚的文字下拉。常用按鈕只是額外入口。
- 搜尋按名稱、別名及指令路徑找工具；規劃用Ctrl+K，先查使用者自訂快捷鍵與瀏覽器衝突，不硬搶SolidCraft的S鍵。停用結果仍能看到原因。
- 懸停／鍵盤聚焦顯示工具名稱、適用選取、使用步驟、快捷鍵。既有 `actionTooltip`／help字典仍為唯一說明來源。
- 停用指令同時淡化圖示和文字；選中狀態有邊框，不僅改顏色。圖示是裝飾，無障礙名稱由可見文字提供。
- Esc先關最上層選單，不穿透成取消CAD操作；方向鍵／Enter可走訪頁籤與選單。點完回到原CAD指令流程，不新增確認層。
- 顯示32px工具圖示、20px快速列，完整檢查16／24／32／48px；文字長度用英文檢驗，繁中不能被分成一字一行。
- 釘選／排序／還原預設後續做，偏好存在UI設定，不寫模型Schema，不包含新的幾何能力。

## 實作順序與目前狀態

1. **本批實作：工具圖示。** 205個ID對應、125份保留原始檔；補充3D-Builder專屬語意變體。現有選單實際使用圖示＋文字，保留點選、enabled與既有說明。來源、校驗碼、MIT聲明皆進專案與網頁成品。
2. **本批設計稿：任務頁籤／分組與搜尋。** [preview.html](preview.html)可切換零件／草圖／組合件／工程圖、開分組選單、搜尋及查看圖示總覽。它是獨立介面提案，不執行CAD，也不代表分組已接入正式程式。
3. 下一個實作里程碑：純選單配置資料層→常駐工作列／收合／寬度處理→情境切換→檢查／管理入口及Adapter→鍵盤操作／失效原因。
4. 最後增加釘選與自訂，並在新、空白、有本體及編輯中等狀態逐一驗收。

驗收時核對所有205個ID有去處，右鍵範圍不外洩、快捷鍵不變；實際草圖→伸長／圓角、鈑金、組合件／工程圖、尺寸子類型皆仍可操作。檢查1024／1280／1920寬度、英文長名稱、圖示載入、停用與選中、懸停說明及無水平溢出。只跑新／受影響與失敗重試，按使用者要求不重跑全套CAD測試。
