# 草圖拘束六項擴充

使用者指示依建議順序做，2026-10-24 開始。已依序實作與分項驗證，詳 [ADR 0195](adr/0195-sketch-constraint-expansion.md)。沿用只重試失敗或變更影響案例的限制，不跑全套。

| 順序 | 工作 | 狀態 |
|---|---|---|
| 1 | 多圖元批次拘束：平行、水平／垂直、等長／等徑、同心／同心同徑，避免重複與傳遞冗餘 | 已通過原生求解與兩項瀏覽器驗證 |
| 2 | 等距與比例拘束 | 原生測試與兩項瀏覽器驗證通過 |
| 3 | 整個圖元的對稱 | 原生幾何及兩項瀏覽器驗證通過 |
| 4 | 端點重合＋相切操作與內／外相切方向 | 原生與瀏覽器驗證通過（只重試失敗案例） |
| 5 | 橢圓與樣條拘束，先驗證原生求解器能力 | 原生、三項 UI 及真實 OCCT 探針通過；Bézier G1，G2 不支援 |
| 6 | 自由度與衝突診斷強化 | 可行位移、逐項 DOF 貢獻、有界單／雙拘束修復，原生及兩項 UI 通過 |

目前基本拘束及單項衝突修復已存在；擴充其範圍與操作，不把原功能重新宣稱為新增。每項採真實 PlaneGCS 求解與幾何比對，原子提交／復原及顯式非法輸入拒絕；新核心參數化分支含 100–200 組壓力驗證。ADR／Schema 在各項開工時才取號。

2026-10-25：33 個新核心案例與 13 個新 UI 案例各有通過紀錄（不是全套同輪結果），含 800 組原生參數組態、真實 OCCT 曲線與實體量測。尚不支援 G2、任意擬合樣條相切，以及一般最小不可滿足衝突集的完整搜尋。
