- 日期：2026-10-03。依據：[藍圖](blueprint.md) §2.9 夾治具工作流第 3 步、§3 的 Phase 4b 列、風險 6、附錄 C 的 C8.1、C9.2–C9.4；做法與格式沿用 [phase4a-plan](phase4a-plan.md) 與 [phase5-plan](phase5-plan.md)。技術驗證見 [ADR 0067](adr/0067-surface-validation.md)（**4b-0 已做**）。
- **使用者的決定（2026-10-03，延續 4a、5）**：沒有 SW、沒有真實工件；先走完開發，對接時有問題再修正。因此每個里程碑用**金樣**（形狀可以手算或用獨立方法量測的件）驗收，閘門是「有條件通過」；真實的沖壓件或塑膠件 STEP 是使用者的待辦。
- 使用者說「接著做 4b 檢具」（Phase 5 完成後）。

## 什麼是檢具，要做什麼

檢具（gauge）的型面塊：**照工件的型面，往外（或內）退一個間隙（例如 3 mm），再加厚成一塊可以加工的實心**。藍圖的步驟：選工件型面 → 分割線選出區域 → 偏移曲面（間隙）→ 填補／修剪／縫織 → 厚面，或以曲面除料。驗收（藍圖）：**以一個沖壓件或塑膠件 STEP 為工件，做出間隙 3 mm 的型面塊；型面與工件的間隙量測誤差 < 0.05 mm。**

## 預設假設（使用者沒說，我先定；有異議再改）

| 項目 | 假設 | 為什麼 |
|---|---|---|
| 間隙的檢查 | **每個產生曲面的特徵都量測結果**：取結果曲面網格上的點，量到來源曲面的距離，與要求的間隙差超過 **0.05 mm** 就失敗並說出量到的最大誤差 | ADR 0067：偏移失敗時 OCCT 會給一個「有效但錯」的形狀（量到 1.99 mm 的誤差），不量測就不知道 |
| 曲面本體 | 沒有實體的本體（只有面或殼）是「曲面本體」：**不是零件**——不進零件表、質量特性、干涉檢查、工程圖的視圖；顯示為雙面的面；輸出 STEP 時當殼輸出 | 與參考本體（工件）的處理一致；厚面之後才成為零件 |
| 偏移 | 沿面的外法向，正值向外、負值向內；接合型式預設圓弧（與交會式的結果相同，ADR 0067）；偏移的結果以 B 樣條輸出（STEP 與其他 CAD 讀得到） | 實測 OCCT 的偏移曲面是「偏移曲面」型別，轉成 B 樣條誤差 4e-5 mm |
| 分割線 | 草圖的曲線沿草圖法向（或給定方向）投影到選定的面；**預設只投影到最近的一層**（OCCT 會同時投影到穿過的每一層），可選「穿透全部」；穿過週期面接縫的區域合併成一個面 | ADR 0067 |
| 填補 | 邊界的連續性預設**相切（G1）**，貼著相鄰的面；回報 G0、G1 誤差 | 實測有支撐面時誤差 0.02 mm，只給邊線是 1.08 mm |
| 厚面 | 方向：向外、向內、兩側；結果是實體本體；體積為正、結果有效且厚度量測符合 | 實測 `MakeThickSolidBySimple` 的結果可能整個反向（負體積） |
| 以曲面除料 | 曲面沿一個方向掃成刀具實體，從目標本體減去（選保留哪一側） | 實測誤差 2e-6 mm，比分割更穩 |
| 工件 | 輸入的 STEP 本體（4a 的參考本體）；曲面由工件的面產生，工件本身不改 | 4a |

## 設計

**曲面本體**：本體的形狀現在都是實體。曲面特徵的結果是 `shape` 為殼或面的本體，`solidCount = 0`。`@3db/regen` 的本體狀態多一個「曲面」標記（由形狀導出，不存進檔案）；顯示、質量特性、零件表、干涉、工程圖、衍生零件各處對它的處理在 4b-1 一次定下來並測試。

**特徵**（零件檔 Schema 升版，向下相容）：

| 特徵 | 做什麼 | OCCT（ADR 0067 已驗證） |
|---|---|---|
| `splitLine`（C8.1） | 草圖曲線投影到面上，把面分成區域；區域面有持久名稱，可以被選取 | `BRepProj_Projection`、`BRepFeat_SplitShape`、`UnifySameDomain` 保留分割線的邊 |
| `offsetSurface`（C9.2） | 選一些面（一個區域），偏移一個距離，得到曲面本體 | `BRepBuilderAPI_Sewing` 縫成殼、`BRepOffsetAPI_MakeOffsetShape` |
| `fillSurface`（C9.2）、`flatSurface` | 補上洞或做平面片 | `BRepFill_Filling`（G0／G1，支撐面） |
| `trimSurface`、`extendSurface`（C9.3） | 修剪（草圖或曲面為界）、延伸邊 | `BRepAlgoAPI_Splitter`／布林；延伸**尚未驗證** |
| `knit`（C9.3） | 把曲面本體縫成一個本體（封閉就成實體） | `BRepBuilderAPI_Sewing`，自由邊數檢查 |
| `thicken`（C9.4） | 曲面本體加厚成實體 | `BRepOffsetAPI_MakeThickSolid.MakeThickSolidBySimple`，反向時翻面 |
| `cutWithSurface`（C9.4） | 以曲面除料 | 曲面掃成實體做布林 |

**量測間隙**（核心的 `gapReport`）：取一個形狀網格上的點，量到另一個形狀的距離，回報最大、最小、平均與誤差；特徵用它檢查自己的結果，驗收也用它（獨立於偏移的演算法本身）。

## 風險

| # | 風險 | 影響 | 對策 |
|---|---|---|---|
| 1 | 偏移在曲率半徑小於偏移距離處**給出有效但錯的形狀** | 型面塊的間隙不對卻沒有人發現 | 每個特徵都量測結果（預設 0.05 mm），不合就失敗並說出誤差；ADR 0067 已量到這個失敗 |
| 2 | 真實工件的曲面是修剪過的 B 樣條，面很多、很小、有裂縫 | 偏移、縫織失敗 | 輸入時的修復（3a-3）；偏移失敗時改逐面偏移再縫織（已驗證可行）；縫織容差可調；說出哪一面 |
| 3 | 偏移曲面型別在其他 CAD 讀不到 | 型面塊輸出後打不開 | 輸出前轉成 B 樣條（誤差 4e-5 mm，已驗證 STEP 往返） |
| 4 | 曲面本體在零件表、質量、干涉、工程圖、衍生零件各處的處理遺漏 | 錯誤的數量與體積 | 4b-1 一次定規則並逐項測試 |
| 5 | 分割線穿過週期面的接縫、投影到多層 | 區域破成兩半或多出一個區域 | ADR 0067 已驗證做法（只取最近一層、合併接縫、保留分割線的邊）；多層的「穿透全部」列為選項 |
| 6 | 沒有真實的沖壓件、塑膠件 STEP | 金樣不足以代表真實的複雜度 | 金樣用放樣的自由曲面加圓角；真實檔案列為使用者的待辦 |
| 7 | 延伸曲面沒有驗證過 | 4b-4 做不出來 | 先驗證；不穩就只做修剪與填補，把延伸列為限制 |

## 反向提問與智囊團（精簡）

- **反駁者**：「OCCT 的偏移在自由曲面上會失敗，你怎麼知道？」→ 4b-0 實測：區域與整體都準（1e-6 到 3e-5 mm），**失敗時是有效但錯的形狀**，所以對策是量測，不是相信 `IsDone`。
- **本質追問者**：「型面塊為什麼不直接用 `布林減除` 掉工件的偏移實體？」→ 可以（4b-0 已驗證，誤差 3e-5 mm），但那要整個工件的偏移；檢具只要一個區域，所以走曲面本體加厚面。
- **機會發現者**：同一套曲面工具可以做塑膠件的分模面、鈑金展開的中間曲面（Phase 6、7）。
- **外行人**：「間隙 3 mm 是指什麼？」→ 型面塊的面上每一點，到工件最近的點是 3 mm。
- **無情執行者**：今天的第一步是 4b-0 的技術驗證（已做）；下一步是 4b-1 的核心方法與曲面本體的規則。
- **可信度**：4b-1 85%；4b-2 分割線 75%（週期面與多層）；4b-3 偏移 80%（有量測把關）；4b-4 填補與修剪 65%（延伸最不確定）；4b-5 厚面 80%；真實工件 50%（沒有樣本）。
