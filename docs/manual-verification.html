先看這裡：畫面怎麼認、共用做法、名詞（第一次用請先讀）

1. 畫面怎麼認

  • 最上方的選單列：特徵、鈑金、草圖、工具、檔案、檢視。點一個名稱，那一組的按鈕就在它下方展開（排成幾欄）；點了按鈕、按 Esc、或點別處就收起來；展開時滑到旁邊的名稱會換成那一個。灰色的按鈕表示「現在不能用」（通常是還沒選東西，或正在編輯草圖）。
  • 左邊：「設計樹」，記錄你做過的每一步，由上到下是做的順序。做特徵（例如伸長）時，左邊會換成這個特徵的「屬性面板」，面板最上方有綠色的 ✔（確定，也可按 Enter）和 ✕（取消，也可按 Esc）。
  • 中間：3D 視窗。左上角有「顯示類型」下拉和「選擇濾器」，右上角有一個小方塊（視角方塊）。
  • 最下方：狀態列，顯示「體積」「質量」、錯誤與警告（例如「1 個錯誤」）、重新計算花的時間。

2. 滑鼠與鍵盤

  • 選取：滑鼠左鍵點一下。設計樹裡被選的列會變藍；3D 視窗裡被選的面會變色。多選：按住 Ctrl 再點。
  • 3D 視窗：滾輪＝縮放；按住中鍵（滾輪）拖曳＝旋轉；按住 Ctrl 加中鍵拖曳＝平移。按「檢視」→「全部顯示」（F）讓模型填滿視窗；「等角」是立體的斜角視角；「前視」「上視」「右視」是正對的視角。
  • 右鍵：在設計樹的某一列、或 3D 視窗裡的面與邊上按右鍵，會出選單。
  • Esc：結束目前的工具，或取消。Ctrl+Z 復原，Ctrl+Y 重做。
  • 輸入數字：打完要按 Enter 才算數；欄位裡可以寫算式（例如 20*2）。單位預設是 mm。
  • 單擊與雙擊不一樣：在設計樹的某一列單擊，只是「選取」它（要拿它當草圖或當參考時用）；雙擊（或按右鍵 →「編輯特徵」／「編輯草圖」）才會打開它的設定面板，可以看或改它的數字。
  • 畫草圖時的吸附：游標靠近你已經畫好的草圖點、線的中點、或線上時，會出現一個小圓點和游標旁的提示字（「重合」「中點」「在圖元上」），這時按下去就會接上去。畫直線時接近水平或垂直（3° 內）會自動加水平或垂直的關係。目前沒有 SolidWorks 那種「虛線連到附近特徵點」的對齊線，模型本身的邊與頂點（例如板子的角）也不會自動吸附；要對齊模型的邊，用「轉換實體引用」（C7）把邊轉進草圖，或用「智慧型尺寸」標出位置。
  • 沒有「關閉檔案」按鈕：程式一次只開一個文件。要「關掉」目前的檔案，按「檔案」→「新零件」（或「開啟舊檔」開別的檔）；若目前的檔案有沒存的變更，會跳出「要儲存變更嗎？」，按「儲存」或「不儲存」。畫面最上方右邊的名字（例如 零件4.3dbx）前面有「*」就是有未存的變更。
  • 做錯了不用怕：按畫面最上方、分頁列右邊的「復原」按鈕（每個分頁都在，灰色代表沒有可以退的），或按 Ctrl+Z，就退一步；「重做」按鈕或 Ctrl+Y 再往前一步。

3. 共用做法（下面很多項目會說「照做法 A」）

做法 A：做一個長方體（寬 × 深 × 高）

  1. 按「檔案」分頁 →「新零件」。（若問要不要儲存，按「不儲存」。）設計樹只有「原點」和前、上、右三個基準面；3D 視窗是空的。
  2. 在左邊設計樹點一下「上基準面」。那一列變藍，表示選到了。
  3. 按「草圖」分頁 →「草圖」。進入草圖模式：左邊變成「編輯草圖」面板，3D 視窗右上角有綠色的 ✔（離開草圖）。
  4. 按「邊角矩形」。在 3D 視窗按一下設第一個角，移動滑鼠，再按一下設對角。畫出一個矩形（兩次按之間不用拖曳）。
  5. 按「智慧型尺寸」。點矩形的一條邊，再在旁邊的空白處按一下放置尺寸。跳出一個小數字框；輸入寬（例如 40），按 Enter。 再點另一條邊，放置，輸入深（例如 30），按 Enter。按 Esc 結束尺寸工具。左邊的「草圖狀態」寫「定義不足」也沒關係（矩形的位置沒釘死），只要寬和深是對的。
  6. 按「離開草圖」（在「草圖」分頁），或按 3D 視窗右上角的 ✔。設計樹多一列「草圖1」。
  7. 點設計樹的「草圖1」，按「特徵」分頁 →「伸長填料/基材」。左邊出現「伸長」面板，3D 視窗出現預覽。
  8. 在「深度」格輸入高（例如 10），按 Enter，再按面板上方綠色的 ✔。長方體出現；設計樹多「伸長1」；最下方顯示體積（寬 × 深 × 高，例如 12000 mm³）。

要「以原點為中心」時，第 4 步改按「中心矩形」：第一下點座標原點（座標軸交叉的那個點），第二下點角落。

做法 B：做一個示範件

按「檔案」→「新示範件」。出現 20 × 10 × 5 mm 的方塊，一邊有圓角；設計樹有「草圖1」「伸長1」「圓角1」；最下方的體積是 991.416 mm³。 這是程式內建的現成零件，不用自己畫。

做法 C：在方塊的頂面畫新草圖

  1. 按「檢視」→「等角」，讓你看得到方塊的頂面。
  2. 在 3D 視窗，用滑鼠左鍵點方塊的頂面。頂面變色（已選取）。
  3. 按「草圖」分頁 →「草圖」。進入草圖，頂面就是畫圖的平面。 之後和做法 A 的第 4 步以後一樣：選工具、點兩下畫、「離開草圖」。

做法 D：開啟檔案

  1. 按「檔案」→「開啟舊檔」。跳出瀏覽器自己的「開啟檔案」視窗。
  2. 在視窗裡找到「驗證資料夾」（P2 做出來的那個），選檔案，按「開啟」。若瀏覽器問能不能存取，按「允許」。若問目前的零件要不要儲存，按「不儲存」。

做法 E：開啟與新做組合件

  1. 開啟：按「檔案」→「開啟舊檔」，選一個 .3dba 檔。若問目前的零件要不要儲存，按「不儲存」。
  2. 第一次會跳出「選擇專案資料夾」視窗，按「選擇資料夾…」，在系統視窗選「這個 .3dba 檔案所在的資料夾」（例如開 夾具組\夾具 組合件.3dba 就選 夾具組），瀏覽器問時按「允許」。下一個視窗只顯示資料夾、看不到檔案是正常的。
  3. 等零件載入（最下方有進度）。3D 視窗出現零組件；設計樹每個零組件一列，名字後面有 <1> 這樣的編號，前面的 (f) 表示固定、(-) 表示可以動。
  4. 新做：按「檔案」→「新組合件」，選資料夾（之前選過的資料夾會被沿用，不會再問；選錯或要換，按面板上「專案資料夾」下面的「更換資料夾…」，放進第一個零組件之後就不能換了），左邊出現「開始組合件」面板，在「要插入的零件」清單點一個零件，等載入完，按 ✔ 放在原點（第一個零組件會自動固定）。之後按「組合件」→「插入零組件」，點清單裡的零件，再在 3D 視窗空白處按一下放置。

做法 F：用結合把兩個面貼在一起

  1. 按「組合件」→「結合」。左邊出現「結合」面板，提示「在圖面中點選兩個零組件上的面、邊線或頂點」。
  2. 在 3D 視窗依序點兩個不同零組件上的面（例如銷的圓柱面，再點板上孔的內壁）。「結合選擇」列出兩個元素；下面出現「標準結合」的一排按鈕（重合、平行、垂直、相切、同軸心、鎖住、距離、角度），程式建議的那個亮著，不能用的是灰色。
  3. 確認亮著的是你要的，不對就按別的。有「結合對正」（同向對齊／反向對齊）可以換；選「距離」或「角度」要填數值。面板寫「結合成立」；若寫「這個結合與之前的結合矛盾，組合件會過多定義」就不要加。
  4. 按 ✔ 加入這個結合；面板留著等下一對。全部做完，再按一次 ✔（什麼都沒選時）或 ✕ 關閉。設計樹多一個「結合」資料夾與一列；零組件移到定位。基準面與原點要選時，用圖面左上角那棵小樹。

做法 G：做一個外殼（60 × 40 × 30、壁 2、頂面開口）

  1. 按「檔案」→「新零件」。點設計樹的「前基準面」，按「草圖」→「草圖」。
  2. 按「中心矩形」：第一下點座標原點，第二下點角落；再用「智慧型尺寸」標出 60 和 40；按「離開草圖」。
  3. 點這張草圖，「特徵」→「伸長填料/基材」，「深度」輸入 30，按 ✔。一個 60 × 40 × 30 的方塊，體積 72000 mm³。
  4. 按「檢視」→「前視」，點方塊正對你的那個面（面變色），按「特徵」→「薄殼」，「壁厚」輸入 2，按 ✔。一個開口朝向你的盒子，壁厚 2；體積 15552 mm³。

做法 H：做一塊鈑金平板（100 × 50）

  1. 按「檔案」→「新零件」。點設計樹的「上基準面」，按「草圖」→「草圖」。
  2. 按「邊角矩形」：第一下點座標原點，第二下點右上方；再用「智慧型尺寸」標出 100 和 50；按「離開草圖」。
  3. 點這張草圖，按「鈑金」分頁 →「基材凸緣」。面板有板厚、折彎半徑（內側）、K 因子；預設是板厚 1.5、半徑 1.5、K 0.5，不用改。
  4. 按 ✔，再按「檢視」→「等角」。一片 100 × 50 × 1.5 的平板，體積 7500 mm³。

4. 名詞

名詞意思
草圖畫在一個平面上的 2D 輪廓（線、圓、矩形），用來「長出」3D 的形狀。
特徵建模的一步：伸長、旋轉、圓角、孔、薄殼…；每個特徵在設計樹裡是一列。
基準面前基準面、上基準面、右基準面：三個預設的平面，草圖可以畫在上面。你也可以自己做新的基準面。
本體一塊分開的實體。設計樹的「實體(2)」表示零件裡有兩塊分開的實體。
設計樹 / 屬性面板左邊的清單 / 做特徵時出現的設定面板（有 ✔ 和 ✕）。
終止型態伸長要長到哪裡停（給定深度、貫穿、到下一面…）。
定義完整 / 定義不足 / 過多定義草圖的尺寸夠不夠。「定義不足」＝有些東西還能被拖動（不影響使用）；「過多定義」＝尺寸互相矛盾。
從動尺寸只顯示量到的數字、不能用來改形狀的尺寸（數字在括號裡，例如 (30)）。
抑制暫時關掉一個特徵（它仍在樹上，但不計算）；右鍵「恢復抑制」可還原。
參考特徵指著模型上的某個面、邊、點；模型改了，參考跟著走；找不到時會寫「遺失參考」。
狀態列畫面最下面那一行（體積、質量、錯誤數）。
組合件 / 零組件 / 次組合件組合件（.3dba）是把好幾個零件「組」在一起的檔案；放進去的每一個零件叫零組件；組合件也可以整個放進另一個組合件，叫次組合件。
結合規定兩個零組件的面怎麼貼：重合、同軸心（圓柱對圓柱）、距離…；結合讓零件定位。
固定 / 浮動(f) 固定的零組件不會動（第一個放進去的自動固定）；(-) 浮動的可以被結合或拖動。
專案資料夾組合件與工程圖用相對路徑找零件，所以要告訴程式：零件放在哪個資料夾。
工程圖 / 視圖 / 母視圖工程圖（.3dbd）是出圖用的圖紙；一張圖有多個視圖（前視、上視…）；剖面、細部放大、投影視圖要從一個「母視圖」衍生出來。
曲面本體只有面、沒有厚度的本體（偏移曲面的結果）；設計樹的名字後面標「（曲面）」。
拔模 / 底切拔模：塑膠件側壁的脫模斜度；底切：模具打不開、要側向抽芯的面。
基材凸緣 / 邊線凸緣 / 摺邊鈑金的特徵：基材凸緣是第一片板；邊線凸緣是在板邊折起一片；摺邊是邊折 180° 回來。
K 因子 / 折彎裕度 / 平板型式K 因子決定折彎處要多長；折彎裕度是折彎展開後的長度；平板型式是鈑金件展平後的樣子（送去雷射切割）。

5. 遇到這些情況

  • 找不到按鈕：先確認點開了對的選單（特徵、鈑金、草圖、工具、檔案、檢視）；按鈕是灰色的，代表現在不能用，通常要先選取東西、或要先離開草圖。
  • 畫面上出現錯誤：設計樹那一列會變紅，最下方寫「N 個錯誤」；在那一列按右鍵 →「錯誤為何？」會說明原因。這些訊息請原文抄到備註。
  • 想重來：「檔案」→「新零件」，或按 Ctrl+Z 退一步。

為什麼要做：一個零件裡可以有好幾個分開的實體，這是做夾具主模型的基礎。

程式內的說明（按 F1，或功能列最右的「說明」搜尋）：組合。這一項驗出問題、修好時，這些說明也要一起改。

先準備

一個新零件（「檔案」→「新零件」）。下面三個方塊都畫在上基準面上，各自是一張草圖。大小隨意（約 40 × 20，伸長 10），重點是位置：第一個和第二個要離得遠，第三個要和第一個有一半重疊。方塊怎麼畫見 做法 A。

先準備

D9測量像 eDrawings：圖上畫出距離與 dX／dY／dZ、英制、弧圓量法必做

已自動重播驗過（2026-10-09）。腳本 manual-measure-view.js（18 步，零件、組合件的算法、點選位置、保留多筆、拖標籤與工程圖英制）與單元測試 measure-units.test.ts、drawing-units.test.ts 驗了數字與文字；這一項留給你「用真的滑鼠點，看圖面標示順不順眼」：標籤會不會互相蓋住、線粗細、顏色。

為什麼要做：量測要像 eDrawings：兩個元素選好後，直接在 3D 裡看到距離與沿三個軸的分量，並且能用英制。

先準備

開一個零件（例如 金樣\定位板.3dbx）或一個組合件，「工具」→「測量」。

怎麼做

  1. 點兩條邊線（或兩個頂點）。3D 裡出現黑色的最短距離線，上面貼「距離: …mm」；沿 X（紅）、Y（綠）、Z（藍）各一段階梯線，每段貼「dX: …」「dY: …」「dZ: …」（位移是 0 的那段不畫）。右邊面板的「結果」寫：「所選的兩個項次相互平行（或垂直，或夾角）」、距離、Delta X／Y／Z、總長度。
  2. 「長度」改「英寸」。結果與圖上的標籤都換成英寸（4 位小數）。勾「以分數顯示」。是分數（例如 3/4）的就寫分數，不是的維持小數。再勾「趨於最近的分數值」，「分母」選 16、4。一律寫成最接近的分數（例如 1 5/8in、1 3/4in）。「角度」可選度或弧度。選擇會記住，下次開啟還在。
  3. 「複製結果」。貼到別處是結果那幾行文字。
  4. 弧／圓測量：點兩個孔的圓周邊線（或孔壁面）。「弧／圓測量」變成可選：中心到中心（預設）、最小距離、最大距離；圖上的線與數字跟著換。最大距離 = 中心距離 + 兩個半徑；最小 = 中心距離 − 兩個半徑。兩個圓的軸不平行時沒有「最大距離」（面板會提示）。
  5. 在組合件裡跨零件量測，同樣畫在組合件座標上。
  6. 量任意位置的點：測量面板的「選取」改選「點」。游標移到模型上會吸附並出現橘色圓點與名稱：端點、圓心（圓或圓弧）、邊的中點、邊上的點、面上的點；優先順序是端點、圓心、中點，其次邊上，最後是面上。點兩個位置。畫出兩點的最短距離與 dX／dY／dZ，結果文字與一般量測相同。點的位置在模型被剖開時只吸附留下的部分。也可以先點一個位置，再選「元素」改點一個面：是點到面的最短距離。
