這份清單是什麼：自動化測試（共 1985 項）都通過了，但它們是用程式驅動畫面與手算的標準答案驗的。下面是還沒有人用滑鼠、鍵盤、別的軟體實際走過的項目，共 84 項。每一項都寫了「為什麼要做、怎麼做、應該看到什麼、有問題時回報什麼」。

怎麼用：點項目標題展開；做完在右邊的下拉選單選「通過」「有問題」「略過」，並在備註寫下觀察。進度會自動存在這個瀏覽器裡。全部做完（或做到一個段落）按上方的「複製結果」把整份貼給我。

建議順序：先做 0（準備）→ C（零件，每項十分鐘內）→ D、E（組合件與夾具）→ F（工程圖）→ H、I（塑膠與鈑金），標「必做」的優先；標「需樣本」「需你決定」的是等你提供資料或下決定，不用現在做。

產生日期 2026-10-04；對應的程式版本：提交 3149a54（H-10）之後，檔案格式 Schema 42。

0. 開始之前（只做一次）

這一節不是驗證項目，是把環境與測試用的檔案準備好。後面的項目都假設你做完了這一節。

P1啟動程式、選對瀏覽器準備

為什麼要做：程式用到瀏覽器的「檔案系統存取」功能，只有 Edge 與 Chrome 有，Firefox、Safari 不行。

怎麼做

  1. 在專案資料夾（放 3D-Builder 程式碼的那個資料夾）開終端機，輸入 npm run dev。
  2. 用 Edge 或 Chrome 開 http://127.0.0.1:5391 。第一次會下載約 43 MB 的幾何核心，畫面上會有載入進度。
  3. 看到上方有「特徵｜鈑金｜草圖｜工具｜檔案｜檢視」分頁就是好了。

應該看到

  • 畫面左邊有設計樹、中間是 3D 視窗、上方是分頁。
  • 按一下「檔案」分頁裡的「新示範件」，3D 視窗出現一個方塊（有圓角）。

有問題時請回報：若打不開：請貼終端機最後 20 行字。

P2建立測試用的專案資料夾與樣本檔準備

為什麼要做：之後要存檔、開檔、插入零件，都要有一個你可以隨便弄髒的資料夾。

怎麼做

  1. 在專案資料夾開終端機（PowerShell），輸入：$env:KIT_OUT = 'C:\3DB實機確認'; npm run make:kit（資料夾位置可自己換，不要用「下載」資料夾；沒設 KIT_OUT 時寫到 D:\3DB實機確認，這個磁碟不存在就會失敗）。這個指令會產生驗證用的所有檔案，檔案不在版本庫裡，每台電腦要自己產生一次。
  2. 資料夾的根目錄會有 4 個檔案：locating-plate.3dbx（定位板）、diamond-pin.3dbx（削邊銷）、v-block.3dbx（V 型塊）、plate-with-hole.step（40 × 30 × 10 的板、中間一個半徑 4 的孔）。
  3. 另有子資料夾：夾具組、組合件金樣、塑膠件、鈑金、STEP替身、輸出（含 看圖清單.md）。這些是程式自己做的替身，不是真實的 SolidWorks 檔案。弄壞了再執行一次 make:kit 就會覆蓋回來。

應該看到

  • 資料夾根目錄有 4 個檔案，另有 6 個子資料夾（夾具組、組合件金樣、塑膠件、鈑金、STEP替身、輸出）。
P3怎麼回報問題準備

為什麼要做：回報得越具體，我越容易重現。

怎麼做

  1. 每個項目下面都有一欄「備註」，邊做邊寫：做到哪一步、畫面上跳出的訊息原文、你預期看到什麼。
  2. 做完按頁面上方的「複製結果」，整份貼給我即可。
  3. 遇到畫面卡住或全白：按 F12 開開發者工具的 Console 分頁，把紅字複製下來。

應該看到

  • 頁面上的狀態與備註會自動存在這個瀏覽器裡，關掉頁面再開還在（換瀏覽器或清除網站資料就會消失，所以做完請複製一份）。

A. 桌面版安裝

3b-6 做了 Windows 安裝檔，自動化測試無法替你在乾淨的電腦上安裝，只有真人能驗。

A1在沒有裝過開發工具的 Windows 上安裝、斷網使用、解除安裝需另一個帳號或電腦

為什麼要做：要確認安裝檔不依賴這台電腦上的開發環境（Rust、Node 等），而且「原生」的開檔與存檔視窗能用。

怎麼做

  1. 安裝檔在這台電腦：apps\desktop\src-tauri\target\release\bundle\nsis\3D-Builder_0.1.0_x64-setup.exe（沒有的話在專案資料夾執行 npm run build -w @3db/desktop 重做，約要幾分鐘）。把它複製到另一個 Windows 帳號或另一台電腦。
  2. 雙擊安裝。Windows 會跳「不明發行者」的警告（因為沒有簽章，這是預期的），選「仍要執行」。
  3. 把網路線拔掉或關 Wi-Fi，從開始選單啟動 3D-Builder。
  4. 做一個新零件：畫矩形、標尺寸、伸長。按「儲存檔案」，應該跳出 Windows 原生的存檔視窗，存成 .3dbx。
  5. 關掉程式再開，按「開啟舊檔」選回剛存的檔，內容要一樣。
  6. 按「新組合件」→ 開始組合件，選一個真的資料夾（放有零件檔的），開一個 .3dba，零件都要讀到。存檔。
  7. 到「設定 → 應用程式」解除安裝，確認安裝資料夾與桌面／開始選單捷徑都不見了。

應該看到

  • 每一步都沒有錯誤訊息；原生視窗可用；斷網也能完整操作；解除安裝後沒有殘留的程式資料夾與捷徑。
  • 已知的限制（不算問題）：沒有自動更新、圖示是暫用的、解除安裝不會清掉自動存檔的還原副本。

有問題時請回報：請回報：哪一步失敗、Windows 版本、有沒有跳出任何錯誤視窗。

B. 基礎功能殘留

Phase 1、2 補做的小功能，還沒有人用滑鼠走過。

B1設計樹的「眼睛」與遺失參考的修復看畫面

為什麼要做：眼睛控制原點、基準面、草圖要不要顯示；預設值要和 SolidWorks 一樣；壞掉的參考要能一鍵修。

怎麼做

  1. 新示範件。看設計樹每一列右邊有一個眼睛圖示（原點、前／上／右基準面、草圖）。
  2. 預設應該：三個基準面是隱藏的、原點是顯示的（和 SolidWorks 一樣）；用過的草圖是隱藏的。逐一點眼睛，3D 視窗裡對應的東西要出現或消失。
  3. 把眼睛的狀態改成和預設不同（例如顯示一個基準面、隱藏原點），然後「檔案 → 儲存檔案」存成 .3dbx；再「檔案 → 新零件」換成空白零件；最後「檔案 → 開啟舊檔」選剛存的檔案。眼睛的狀態要保持。（重新整理頁面不算「關掉再開」。）
  4. 略過：遺失參考的修復（「改用最接近的」）。這一步沒有簡單的畫面操作能做出「找不到的邊、但還記得它原來在哪裡」：刪掉伸長只會讓圓角顯示「圓角之前沒有本體」，沒有可換的邊，所以不會有按鈕。這個功能已由測試（tests/phase1/repair.test.ts）和 2026-10-05 在瀏覽器裡用腳本驗過：「錯誤為何？」出現「改用最接近的」，按下後圓角恢復，體積 991.416 mm³。

應該看到

  • 預設：三個基準面隱藏、原點顯示；每個眼睛都能切換 3D 視窗裡對應的東西。
  • 存檔、開新零件、再開啟舊檔之後，眼睛的狀態和存檔前相同。

有問題時請回報：預設值與上面不同，或存檔重開後眼睛的狀態跑掉時，請寫出是哪一個項目（原點、哪個基準面、哪個草圖）以及存檔前後的狀態。

C. 零件建模（Phase 3a）

以下每一項，自動化測試都用程式驅動過，但沒有人用滑鼠與鍵盤實際走一遍。重點是「順不順」：按鈕找得到嗎、提示看得懂嗎、結果對不對。建議每個項目都用示範件或金樣零件做，不需要自己的檔案。

C1方程式、全域變數與檔案屬性（3a-1）必做

為什麼要做：尺寸可以寫成運算式，並且跟著變數走。

預跑（2026-10-05，瀏覽器腳本照 UI 操作）：已在頁面上走過：新增變數、尺寸寫成 w*2、改 w、壞運算式與循環被擋下（訊息在狀態列）、改名連動、伸長深度輸入 h/2 顯示「= 7.5 mm」並套用、檔案屬性加「板厚」。沒走到：寫成 property('板厚') 真的當深度用、草圖上的 Σ 顯示。

怎麼做

  1. 新示範件，進入方塊的草圖，記下一個尺寸（例如寬度）。按「工具」分頁→「方程式」，新增變數 w，值 30。
  2. 把草圖的那個尺寸改成 w*2，確認；3D 視窗中的方塊變成 60 寬。再把 w 改成 20，方塊要變成 40 寬。
  3. 輸入一個壞運算式（例如 w*）：應該被擋下並說出原因。把兩個變數互相引用（a = b、b = a）：應該被擋下並說出循環的路徑。被擋下的原因會出現在畫面最下方的狀態列（預期是「運算式不完整：「w*」」與「循環引用：a → b → a」），方程式視窗本身不顯示。
  4. 把變數 w 改名成 width：用到它的運算式要一起改。
  5. 在任一個數值欄位（例如伸長深度）輸入 h/2（先建一個變數 h = 15）：欄位旁邊要顯示「= 7.5 mm」。
  6. 「工具」→「檔案屬性」加一個自訂屬性「板厚 = 4mm」，把伸長深度寫成 property('板厚')，深度應變成 4。
  7. 草圖裡由運算式驅動的尺寸，畫面上應顯示成 Σ60 這種樣子。

應該看到

  • 每個改動都立即反映在模型上，沒有出現「重算失敗」。

有問題時請回報：請記下哪個運算式寫法不被接受、錯誤訊息是什麼。

C2刪除面與移動面（3a-2）必做

為什麼要做：直接編輯輸入進來的、或已建好的模型：不用回到草圖就能拿掉圓角或推拉一個面。

用這個檔案：新示範件，加上 locating-plate.3dbx

預跑（2026-10-05，瀏覽器腳本照 UI 操作）：刪除圓角（7 面 991.416 → 6 面 1000）、移動面、相切面被拒（訊息和這裡寫的一致）過。腳本沒涵蓋：刪除孔內壁、不能刪的面的錯誤。

怎麼做

  1. 新示範件（一個有圓角的方塊，體積 991.416 mm³、7 個面）。按「特徵」→「刪除面」，在 3D 視窗點圓角的面，按 ✔。圓角要消失，體積回到 1000 mm³、剩 6 個面（按「工具」→「物質特性…」可看體積）。
  2. 另外開 locating-plate.3dbx（定位板，有孔）。用「刪除面」點一個孔的內壁、勾「刪除鑽孔」：孔要消失（含盲孔的孔底、孔口的倒角）。
  3. 試著刪一個不能刪的面：特徵旁出現錯誤，按「錯誤為何？」要有原因。
  4. 「移動面」：點一個平面，輸入距離（正值往外、負值往材料裡）。斜的壁會維持原來的斜度。
  5. 點一個和圓角相切的面做移動：要被拒絕，訊息應說「請先移動連同的圓角，或先刪除圓角」。

應該看到

  • 每一步結果都和說明一致；錯誤訊息是中文且看得懂。
C3輸入 STEP 為本體與診斷報告（3a-2）看畫面

為什麼要做：真實檔案進來後的第一關。這裡用小的樣本先看流程，真實檔案放在 J 節。

怎麼做

  1. 新零件 → 「特徵」→「輸入 STEP」，選專案裡的 plate-with-hole.step。
  2. 成功後設計樹出現「輸入1」。點它，屬性管理員有「診斷報告」與「縫合容差」。
  3. 在這個輸入的本體上再加一個草圖與伸長（例如在板頂面畫一個圓，往上伸長），再改縫合容差，看是否影響結果。

應該看到

  • 板的體積 = 40 × 30 × 10 − π×4²×10 ≈ 11497 mm³。診斷報告不會報錯。你加上去的特徵能正常長在它上面。

有問題時請回報：若診斷報告有警告字樣，整段貼給我。

C4多本體（3a-3）必做

為什麼要做：一個零件裡可以有好幾個分開的實體，這是做夾具主模型的基礎。

預跑（2026-10-05，瀏覽器腳本照 UI 操作）：兩個分開的塊、取消「合併結果」、組合、本體的隱藏、重新命名、設為參考本體過。腳本沒涵蓋：存檔重開、用除料切成兩塊。

怎麼做

  1. 新零件，畫一個矩形伸長；再開一張新草圖，在離第一個方塊遠的地方畫另一個矩形伸長。設計樹應出現「實體(2)」。
  2. 畫第三個方塊，與第一個重疊；伸長時在屬性管理員取消「合併結果」，它應成為第三個本體，不與第一個融合。
  3. 「特徵」→「組合」，選類型（相加／相減／共同）、主要本體、要組合的本體；也可以直接在 3D 視窗點選。
  4. 本體那一列的眼睛關掉：3D 視窗看不到也點不到它。雙擊本體列可重新命名。
  5. 右鍵本體 →「設為參考本體」，「工具」→「物質特性…」的質量要扣掉它。
  6. 用除料把一個本體切成兩塊：應變成兩個本體。
  7. 存檔、重開，本體都還在。

應該看到

  • 每種操作的結果和上面一致；沒有「重算失敗」。
C5草圖工具：狹槽、多邊形、圓角／導角、修剪、延伸、偏移、鏡射（3a-4a）必做

為什麼要做：日常畫草圖最常用的一批工具。

預跑（2026-10-05，瀏覽器腳本照 UI 操作）：狹槽、多邊形、草圖圓角、修剪、偏移，擠出後的體積都和手算一致。腳本沒涵蓋：草圖導角、延伸、鏡射圖元。

怎麼做

  1. 新零件，進入草圖（「草圖」分頁）。依序用：狹槽、多邊形（邊數在屬性管理員改）、草圖圓角、草圖導角、修剪、延伸、偏移圖元、鏡射圖元。
  2. 偏移與鏡射要先選取圖元再按工具。
  3. 每畫完一個，按離開草圖、伸長，確認形狀跟畫的一樣。

應該看到

  • 工具按鈕都找得到，操作時有提示；修剪與延伸的結果符合直覺；鏡射後左右對稱。

有問題時請回報：請記下哪個工具的操作順序讓你困惑。

C6草圖限制條件、從動尺寸、診斷與輪廓選取（3a-4b、4c）看畫面

為什麼要做：草圖被過多定義或有縫隙時，程式要能說得清楚。

怎麼做

  1. 選兩個圓 →「同心同徑」；選一個點與兩條曲線 →「交錯」；選兩個點 →「合併」；選一條圓弧 →「標註弧長」。
  2. 故意把一個已定義的尺寸再標一次，造成過多定義：屬性管理員應出現「過多定義診斷」，列出可處理的方式；按按鈕處理。尺寸清單每一列有「設為從動／驅動」，被判成從動的尺寸應是灰色斜體、括號，顯示量到的值。
  3. 「檢查草圖用於特徵」：畫兩條幾乎接上但有 0.05 mm 縫隙的線，應列出間隙；按一下選取相關圖元；按「修復草圖」合併間隙。
  4. 一張草圖畫兩個分開的輪廓，伸長時的屬性管理員有「所選輪廓」清單，只勾其中一個。

應該看到

  • 診斷與修復都有效；伸長只伸長勾選的輪廓。
C7轉換實體引用與貫穿（3a-4d）看畫面

為什麼要做：草圖圖元可以「跟著模型的邊走」，模型改了草圖自己跟著動。

怎麼做

I. 鈑金（Phase 7）

前置：「鈑金」分頁。鈑金零件的第一個特徵必須是基材凸緣，板厚、折彎半徑、K 因子都放在它上面。這裡的平板型式是從特徵記錄的折彎資料算出來的（不是把實體展開）。公式備忘：90° 折彎的折彎裕度 = (π/2) × (內側半徑 + K × 板厚)。例如板厚 1、半徑 1、K 0.5 → 2.356 mm。
