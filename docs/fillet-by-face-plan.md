# 圓角與導角可選面的計畫（含面圓角、完整圓角）

- 日期：2026-10-06。來源：使用者做手動驗證 C7 時發現「做圓角只能選邊線，不能選一個面，SW 可以選邊線也可以選面」；決定範圍：① 圓角與導角都要能選面（選面＝倒那個面的所有邊）；② 也要 SW 的其他圓角種類：面圓角、完整圓角。
- **狀態：計畫，未動工。** 動手前請使用者回答第 7 節的問題；第 4 節的 F-0 是技術驗證，結果會改變後面的範圍。
- 對應藍圖：C5.1（圓角）、C5.3（導角）。現況：[`FilletFeature`／`ChamferFeature`](../packages/model/src/schema.ts) 只有 `edges: Ref[]`；核心 `Kernel.fillet(shape, edgeIndices, radius)`、`Kernel.chamfer(shape, [{edge, face}], mode, d1, d2)`（OCCT `BRepFilletAPI_MakeFillet` 與 `MakeChamfer`）；引擎的 `fillet`／`chamfer` 以持久名稱找邊（`edgeIndices`）；面板的邊選取清單與 `toggleEdge` 在 `PropertyManager.tsx`／`store.ts`。零件 Schema 目前是 42。

## 1. SW 的行為（要複製的目標；SW 2010 的圓角 PropertyManager）

- **圓角種類**：固定半徑、變數半徑、**面圓角**、**完整圓角**。要圓角的項目可以是**邊線、面、特徵、迴路**。
- **選面**：選一個面，就是這個面的**所有邊線**都倒圓角（外圈與內圈的孔邊）；SW 預設勾「相切延伸」，圓角沿著相切連續的邊一路延伸。
- **面圓角**：在兩組面之間做圓角，用來把相鄰的面倒圓、或補在不相鄰的面之間（需要滾球與偏移曲面求交的做法）。
- **完整圓角**：三組面（邊側面 1、中央面組、邊側面 2）：中央的面被一個與兩側都相切的圓弧面取代，半徑由中央面的寬度決定，不用輸入。
- **導角**：同樣可以選邊線或面；選面也是倒那個面的所有邊。

**這次不做**：變數半徑、選特徵與迴路、圓角的「保留特徵」「圓角角落」「設定尾端」選項。（使用者沒有要求；日後單獨列。）

## 2. 設計（第一性原理：資料只存使用者選的東西，邊在重算時由面展開）

- **為什麼存面不存邊**：使用者選的是「這個面」。如果在點下去的當下把面展開成邊存起來，面之後多出的邊（例如在那個面上又切出一個槽）不會被倒角，而 SW 會；而且重算時要靠邊的名稱找回來，邊一多、名稱一變就容易遺失。存面的持久名稱、重算時展開，行為與 SW 一致，遺失參考也只有「那個面不見了」這一種。
- **資料（零件 Schema 43，新增選用欄位，舊檔照讀、新檔舊程式讀不了會明確拒絕，與過去的升版一樣）**：
  - `FilletFeature`：`edges`（維持）、`faces?: Ref[]`、`kind?: 'constant' | 'face' | 'full'`（沒有＝固定半徑）、`faces2?: Ref[]`（面圓角的第二組面；完整圓角的邊側面 2）、`center?: Ref[]`（完整圓角的中央面組）。固定半徑：邊 ∪ 面的所有邊；面圓角：`faces` 與 `faces2` 的交界邊；完整圓角：`faces`（側 1）、`center`、`faces2`（側 2）。
  - `ChamferFeature`：`faces?: Ref[]`（維持 `edges`）。
- **面展開成邊（引擎）**：`faceEdges(body, faces)`：每個面的所有邊（外圈與孔）；**略過**：接縫邊（同一面出現兩次，如圓柱的縫）、只有一個鄰面的邊（曲面本體的邊界）、兩側的面相切連續的邊（圓角本來就不倒相切邊；SW 也略過）。相切判斷要新增核心方法 `Kernel.smoothEdges(shape, edgeIndices)`：在邊的三個取樣點比較兩側面的法向，夾角 < 1e-3 弧度就算相切。
- **導角量在哪個面**：選面時，邊來自哪個面，**距離 1 就量在那個面上**（使用者點的面，行為可預測）；邊同時屬於兩個選取面時取名稱排序較前者；單選邊線維持現在的規則（名稱排序，「反轉方向」換面）。這是**我的假設**，SW 的細節要使用者確認（第 7 節）。
- **完整圓角的做法**要等 F-0：兩邊側面平行、中央面是等寬長條時，是兩條邊以半徑＝寬度／2 倒圓角，但 OCCT 在兩個圓角剛好「吃掉」整個中央面時常失敗；F-0 會試幾種做法（半徑略小再補面、用旋轉／掃出做刀具、布林）選一個穩的。中央面不是等寬（兩側不平行）時半徑要變化，列為限制。
- **面圓角**：兩組面有共同的邊（相鄰）時，就是對共同的邊倒圓角（凸邊去料、凹邊補料）；**兩組面沒有共同的邊（不相鄰）**需要滾球與偏移曲面求交，OCCT 的 `MakeFillet` 做不到。F-0 評估有沒有便宜的做法；沒有的話，不相鄰時**明確拒絕並說原因**（「兩組面沒有共同的邊；不相鄰的面圓角還沒做」），不假裝成功。
- **命名**：新面的命名走既有的 `nameElements`（來源是被倒的邊，`role: 'fillet'`／`'chamfer'`），改選面、面多一條邊時其他面的名稱不變；對這個面本身的參考之後的特徵照舊。
- **介面**：圓角／導角的面板選取清單分「邊線」與「面」兩個區（面圓角與完整圓角各自的清單：面組 1／面組 2／中央面組），在圖形區點到面就加進目前這一個清單；點已選的取消；遺失的標示（沿用）。圓角面板最上方有「圓角種類」選單。圖形區在這些面板開著時，邊與面都能點（優先序：靠近邊先選邊，否則選面）。
- **說明（SSOT）**：`help.fillet`、`help.chamfer` 的內文原本寫著「只能選邊」，改寫成現況；手冊新增一項「圓角與導角」，`help-links.json` 連到 `fillet`、`chamfer`（`_untied` 裡的 `chamfer` 同時移除）。

## 3. 量化驗收（手算；除註明外誤差 < 1e-3 mm³）

項目 1–3 的頂點處理我假設是斜接（兩個圓柱在 45° 面相交，沒有圓角的第三條邊）；如果 OCCT 實際做的角落不同，以 F-0 的實測為準，並把差異與原因寫進 ADR，不為了湊數字而改手算。

## 5. 風險

1. **完整圓角最危險**：OCCT 的圓角在「剛好吃光整個面」時容易失敗，F-0 前不能保證做得出來；做不出穩的做法時，範圍縮成「等寬長條、兩側平行」或延後，並誠實寫進限制。
2. **面圓角不相鄰**可能做不到（第 2 節）。
3. **選面展開的邊很多**時，OCCT 的圓角比較容易失敗（頂點處三條以上的圓角、半徑大過鄰面）；失敗要說是哪個半徑／哪個面，不用 OCCT 的原話。F-1 要有「半徑太大」的訊息與驗收。
4. **相切延伸**：OCCT 預設沿相切邊傳遞，與 SW 的預設相同；使用者若想關掉，要另外加選項（本次不做）。
5. **Schema 43**：新增欄位的改法與過去相同（舊檔照讀），但這是又一次升版；所有讀 `FilletFeature`／`ChamferFeature` 的地方（遺失參考修復、遞移刪除與相依、工程圖的特徵樹、組合件的衍生零件）都要檢查有沒有只看 `edges`。F-1 要用 grep 逐一列出並測試。
6. **導角的距離 1 量在選的面上是我的假設**，與 SW 可能不同。

## 6. 假設（沒有問過使用者，先這樣做）

- 選面的導角：距離 1 量在選的面上。
- 選面時略過相切連續的邊與接縫邊。
- 面圓角與完整圓角只做「面組之間有共同邊」的情況（相鄰）；其餘明確拒絕。
- 圓角預設「相切延伸」開（OCCT 預設），不提供關閉的選項。

## 7. 要使用者決定或確認的事

1. **導角選面時距離 1 量在哪一面**：我的做法是「你選的那個面」。你在 SW 做同一個零件看看，SW 是不是這樣（例如選方塊頂面導角距離 3 × 1，是頂面縮 3 還是縮 1）？
2. **不相鄰的面圓角**：F-0 若找不到穩的做法，接受「明確拒絕、列入限制」嗎？還是這個必須做到？
3. **完整圓角兩側不平行**（半徑變化）接受先不做嗎？
4. **順序**：F-0 → F-1 → F-2 → F-3；每個里程碑做完你要先看（提交前）還是做完一個就提交推送？
